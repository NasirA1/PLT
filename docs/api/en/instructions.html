    Instruction set

    The virtual machine's instruction set, as the code generator emits it (thunderc --emit asm shows a program's listing). The stack effect reads before → after.

    Read the full guide →

    CodeMnemonicOperand bytesStack effectDescription
    0HALT0->Stop the program.
    1CONST2-> valuePush a constant from the constant pool.
    2TRUE0-> truePush the boolean true.
    3FALSE0-> falsePush the boolean false.
    4POP0value ->Discard the value on top of the stack.
    5LOAD_LOCAL2-> valuePush the value of a local variable.
    6STORE_LOCAL2value ->Pop a value into a local variable.
    7LOAD_GLOBAL2-> valuePush the value of a global variable.
    8STORE_GLOBAL2value ->Pop a value into a global variable.
    9ADD0a b -> a+bAdd two numbers (runtime error on overflow).
    10SUB0a b -> a-bSubtract two numbers (runtime error on overflow).
    11MUL0a b -> a*bMultiply two numbers (runtime error on overflow).
    12DIV0a b -> a/bDivide two numbers (integers round toward zero; error if b is 0).
    13MOD0a b -> a%bRemainder of integer division (runtime error if b is 0).
    14NEG0a -> -aNegate a number.
    15NOT0a -> !aLogical NOT of a boolean.
    16CONCAT0a b -> abJoin two strings.
    17EQ0a b -> a==bCompare two values for equality.
    18NE0a b -> a!=bCompare two values for inequality.
    19LT0a b -> a<bLess than (numbers or strings).
    20LE0a b -> a<=bLess than or equal (numbers or strings).
    21GT0a b -> a>bGreater than (numbers or strings).
    22GE0a b -> a>=bGreater than or equal (numbers or strings).
    23JUMP4->Continue execution at the target address.
    24JUMP_IF_FALSE4cond ->Pop a boolean; jump to the target if it is false.
    25CALL2args -> result?Call a function; its arguments become its first locals.
    26CALL_BUILTIN2args -> result?Call a built-in function.
    27RETURN0value ->Return the value on top of the stack to the caller.
    28RETURN_VOID0->Return to the caller without a value.
    29MAKE_ARRAY2v1..vn -> arrayPop n values and push an array containing them.
    30INDEX_GET0a i -> a[i]Read an array element or a string character.
    31INDEX_SET0a i v ->Write an array element.
    32DUP0v -> v vDuplicate the value on top of the stack.
    33DUP20a b -> a b a bDuplicate the two values on top of the stack (used by a[i] += v).
    34INT_TO_FLOAT0i -> fConvert an integer to a decimal number.
    35NEW_STRUCT2f1..fn -> sPop the field values (in declaration order) and push a new struct.
    36GET_FIELD2s -> s.fReplace a struct by the value of one of its fields.
    37SET_FIELD2s v ->Store a value in a field of a struct.
    38MAKE_TUPLE2v1..vn -> tuplePop n values and push a tuple containing them.
    39TUPLE_GET2t -> t.iReplace a tuple by one of its elements.
    40MAKE_MAP2k1 v1..kn vn -> mapPop n key/value pairs and push a map containing them.
    41FUNC_REF2-> fPush a function value: a reference to a function, which can be stored, passed and called.
    42CALL_VALUE2args f -> result?Pop a function value and call it with the n arguments below it.
    43CALL_NATIVE2args -> result?Call a function in a native library (import native).
    44BIT_AND0a b -> a&bBitwise AND: each result bit is 1 where both operands have a 1.
    45BIT_OR0a b -> a|bBitwise OR: each result bit is 1 where either operand has a 1.
    46BIT_XOR0a b -> a^bBitwise XOR: each result bit is 1 where the operands differ.
    47SHL0a n -> a<<nShift the bits left by n (0..63); bits shifted out are lost.
    48SHR0a n -> a>>nShift the bits right by n (0..63), keeping the sign (arithmetic).
    49BIT_NOT0a -> ~aInvert every bit of an integer (~a equals -a - 1).
    50BYTE_TO_INT0b -> iWiden a byte to an int (a byte used where an int is wanted).
    51INT_TO_BYTE0i -> bKeep the low 8 bits of an int as a byte (to_byte, and a literal written as a byte).
    52ENUM_CONST4-> ePush a member of an enum (operands: the enum, the member's position).
    53ENUM_FROM2v -> ePop an int (a position) or a string (a name) and push that member of the enum; runtime error if there is none.
    54ENUM_VALUES2-> arrayPush an array holding every member of the enum, in order.
    55NEW_BOX0v -> boxMove a value into a new heap box (a variable some function value captures lives in one).
    56BOX_GET0box -> vReplace a box by the value inside it.
    57BOX_SET0v box ->Pop a box, then a value, and store the value in the box.
    58MAKE_CLOSURE4b1..bn -> fPop n boxes and push a function value that carries them (a closure).
    59LOAD_CAPTURE2-> boxPush one of the running closure's boxes (captured variables are read and written through it).
    60CALL_METHOD4obj args -> result?Call the named method of the struct below the arguments (the receiver becomes its first local).
