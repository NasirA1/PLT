    راوړه "testing" پروګرام ته د ازموینو یو کوچنی چوکاټ راوړي، د دوو ټولګو په بڼه: ازموینه ازموینې چلوي او تمه وايي چې څه باید رښتیا وي. هره ازموینه د یوې دندې په توګه ولیکئ، له نوم سره یې ازموینه.وچلوه() ته ورکړئ، د تمه.برابر() او ملګرو سره یې ووایئ چې څه باید رښتیا وي، او د ازموینه.پای_ته_ورسوه() سره پای ته ورسوئ. هغه ازموینې چې سره تړاو لري په خپل یوه ټولګي کې ځي، چې د ازموینو یوه ډله (suite) یې جوړوي. په فایل کې هېڅ بهرنی نشته - دا ساده تندر دی، په lib/thunder/ps/testing.th کې، د لوستلو لپاره لیکل شوی. انګلیسي فایل (lib/thunder/en/testing.th) همدا چوکاټ له انګلیسي نومونو سره دی؛ دواړه پخپله، د اوزارو تر څنګ، موندل کېږي.

    ویې آزمویئ: samples/ps/28_testing.th دوه کوچنۍ دندې په دوو ډلو کې ازمویي (انګلیسي: samples/en/28_testing.th)؛ د IDE د بېلګو په لړ کې د ۲۸ - ازموینه په نوم ده.

    دندې#

    ټولګی ازموینه:

    دنده څه کوي
    ازموینه.وچلوه(نوم: متن، بدنه: دنده())دنده «بدنه» د «نوم» په نوم ازموینه چلوي: ✓ نوم که هره تمه یې پوره شوه، ✗ نوم: پیغام د هرې هغې لپاره چې پوره نه شوه. کله چې «بدنه» د یوه ټولګي وي، ازموینه د هغې ډلې ده.
    ازموینه.ناکامه_کړه(پیغام: متن)اوسنۍ ازموینه د خپل پیغام سره ناکامه کوي.
    ازموینه.پای_ته_ورسوه()د هرې ډلې ډله: N تېرې شوې، M ناکامې چاپوي (کله چې له یوې زیاتې ډلې وي)، بیا N تېرې شوې، M ناکامې، او که کومه ازموینه ناکامه وي پروګرام د وتلو کوډ ۱ سره پای ته رسوي. وروستۍ یې وبولئ.
    ازموینه.د_ټولګي_نوم(بدنه: دنده()): متنهغه ډله چې د ازموینې دنده پکې ده: د هغه ټولګي نوم چې دنده پکې اعلان شوې، "" د هغې دندې لپاره چې په هېڅ ټولګي کې نه وي.

    ټولګی تمه:

    دنده څه کوي
    تمه.دا_وي(شرط: منطقي، پیغام: متن)اوسنۍ ازموینه د «پیغام» سره ناکامه کوي کله چې «شرط» درواغ وي. نورې له همدې سره لیکل شوې دي.
    تمه.رښتیا_وي(شرط: منطقي)ناکامه، مګر دا چې شرط رښتیا وي.
    تمه.درواغ_وي(شرط: منطقي)ناکامه، مګر دا چې شرط درواغ وي.
    تمه.برابر<ت>(ترلاسه: ت، تمه_شوی: ت)ناکامه، مګر دا چې دواړه یو شان چاپ شي - نو لړۍ، ټاپلونه، نقشې او جوړښتونه د خپلو توکو له مخې پرتله کېږي؛ پیغام دواړه ښيي: تمه [۱، ۴، ۹] وه، [۱، ۴، ۸] ترلاسه شو.
    تمه.نابرابر<ت>(ترلاسه: ت، ناغوښتل: ت)ناکامه کله چې دواړه یو شان چاپ شي.
    تمه.نږدې(ترلاسه: اعشاري، تمه_شوی: اعشاري، زغم: اعشاري)د اعشاري شمېرو لپاره، چې لږ کله بشپړ برابرې وي: ناکامه، مګر دا چې «ترلاسه» له «تمه_شوی» څخه په «زغم» کې وي.

    هره ناکامه تمه خپله ✗ کرښه چاپوي، نو هغه ازموینه چې درې ناسمې تمې لري درې واړه راپور کوي؛ ازموینه یو ځل ناکامه شمېرل کېږي.

    ازموینه او تمه د ټولګو نومونه دي، نو په هغه پروګرام کې چې "testing" راوړي د متغیرونو یا دندو نومونه نشي کېدای (تېروتنه S065).

    د ازموینو ډلې#

    ډله د ازموینو یو ټولګی دی. هغه ازموینې چې سره تړاو لري په یوه ټولګي کې کېږدئ، او د ټولګي له نوم سره یې ازموینه.وچلوه ته ورکړئ - ازموینه.وچلوه("پالیندرومونه"، متنونه_ازموینې.پالیندرومونه). چوکاټ له دندې پوښتي چې په کوم ټولګي کې اعلان شوې (د دندې نوم کاروي، چې "متنونه_ازموینې.پالیندرومونه" ورکوي)، او هغه ټولګی د ازموینې ډله ده:

    • نوم یې د ازموینو پورته چاپېږي، چې دوه تشې ننوتې چاپېږي؛ د یوې ډلې ازموینې یوه پسې بله وچلوئ، که نه نو کله چې بېرته راشي نوم یې بیا چاپېږي؛
    • شمېرې یې بېلې ساتل کېږي: کله چې پروګرام له یوې زیاتې ډلې ولري، ازموینه.پای_ته_ورسوه() له ټولټال مخکې د هرې یوې لپاره ډله: N تېرې شوې، M ناکامې چاپوي، په هغه ترتیب چې لومړی چلېدلې؛
    • یوازې هم چلېدای شي، کله چې یې نوم پر امر کرښه ورکړئ (راتلونکې برخه).

    د ازموینې خپل نوم هماغه دی چې ازموینه.وچلوه ته ورکړل شو؛ ډله یې یوازې ډلبندي کوي. په ټولګي کې ازموینې کولای شي د ټولګي ځانګړې مرستندویې (_نوم) او متغیرونه وکاروي، لکه هر غړی.

    څه نشي کولای#

    چوکاټ د تندر شاوخوا سل کرښې دی، او په قصد کوچنی ساتل کېږي.

    • ډلې هو؛ ډله په ډله کې نه. ډله یو ټولګی دی، او ټولګي یو په بل کې نه ځي، نو په ډلو کې ډلې نشته. د پیل یا پای چمتو کولو ګام هم نشته: د هرې ازموینې په پیل کې خپله یوه دنده وبولئ.
    • د تېروتنو نیول نشته. په تندر کې استثناوې نشته: د ازموینې دننه د اجرا تېروتنه (له پایه اخوا شاخص، پر صفر وېش) ټول پروګرام د معمول راپور سره دروي، لکه هر بل ځای - وروسته ازموینې نه چلېږي. نو ازموینه نشي کتلای چې یو څه ناکامېږي؛ پر ځای یې هغه شرط وازمویئ چې ناکامي به راوړي (تمه.رښتیا_وي(اوږدوالی(ارزښتونه) > ۰)).
    • جعلي بدیلونه (mocks) نشته. هېڅ لاره نشته چې د یوې ازموینې لپاره یوه دنده، فایل یا ساکټ بدل کړئ. هغې دندې ته چې ازمویل کېږي هغه څه ورکړئ چې اړتیا ورته لري - د دندې ارزښت، د فایل پر ځای متن - نو ازموینه ورته یو ساده شی ورکولای شي.

    په IDE او VS Code کې#

    • د تندر IDE: فایل وچلوئ. ډلې او د ✓ او ✗ کرښې د وتنې پاڼه کې راځي؛ د حالت پټه د وتلو کوډ ښيي.
    • VS Code: هغه فایل چې "testing" راوړي د ازموینو لړ (Test Explorer، په فعالیت پټه کې د کیمیا بوتل) کې د یوې ونې په بڼه راځي: فایل ← ډله ← ازموینه، د هرې ازموینه.وچلوه(...) لپاره یوه ننوتنه (هغه ازموینه چې په هېڅ ټولګي کې نه وي نېغ د خپل فایل لاندې ځي). سمونګر د هرې ازموینه.وچلوه تر څنګ په ګټر کې د چلولو تڼۍ ښيي. یوه ازموینه، یوه ډله، یو فایل یا ټول وچلوئ؛ ناکامۍ خپل پیغام په کرښه کې او د ازموینو د پایلو لید کې ښيي. د سمونګر د سرلیک پټې Run Tests in This File تڼۍ (او د دواړو سمونګرو د شرایطو مینو کې، د ښي-څخه-کیڼ سمونګر په ګډون) مخکښ فایل چلوي؛ Thunder: Run All Tests د کاري ځای ټول د ازموینو فایلونه چلوي. د Debug پروفایل ټاکل شوې ازموینې د مرستیال (debugger) لاندې، له ټولو ودرېدو ټکو سره، چلوي.
    • امر کرښه: thunderc tests.th && thundervm tests.thc؛ د وتلو کوډ وايي چې ټول تېر شول که نه.

    نومونه په دواړو ژبو#

    انګلیسي پښتو انګلیسي پښتو
    ټولګی testازموینهټولګی expectتمه
    test.runازموینه.وچلوهexpect.thatتمه.دا_وي

    پښتو فایل خپلې کرښې په پښتو چاپوي (۲ تېرې شوې، ۰ ناکامې)، له همغو ✓ او ✗ نښو سره او د ډلې نوم د خپلو ازموینو پورته، نو د VS Code د ازموینو لړ دواړه یو شان لولي.

    له ۰٫۷ مخکې دا ساده دندې وې: ازموینه (اوس ازموینه.وچلوه)، تمه (تمه.دا_وي)، رښتیا_تمه، درواغ_تمه، برابر_تمه، نابرابر_تمه، نږدې_تمه (تمه.رښتیا_وي ... تمه.نږدې)، ناکامه_کړه (ازموینه.ناکامه_کړه) او ازموینې_پای_کړه (ازموینه.پای_ته_ورسوه).

    د tools/apidoc.py له لارې د اوزارو د ژبې له معلوماتو، د SDK له خپلو تبصرو او له لارښودونو جوړ شوی. د MIT جواز.
