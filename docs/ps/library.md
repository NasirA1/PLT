# د تندر د کتابتون لارښود

*[د تندر SDK لارښود](README.md) یوه برخه.*

> دا سند د `docs/library.md` پښتو ژباړه ده. انګلیسي اصل معتبر دی؛ ژباړه د یوه ژبپوه
> کتنې ته اړتیا لري.

دا سند بیانوي:

1. **ماډیولونه** – پروګرام په څو فایلونو وېشل، له `راوړه` سره (۲ برخه).
2. **ننوت** – د کاروونکي لیکلي کرښې لوستل، له `ولوله()` سره (۳ برخه).
3. **د متن، جوړو او لړیو دندې** (۴–۷ برخې)، له **دندو-د-ارزښت-په-توګه** سره، چې
   `پر هر یو`، `چاڼ کړه` او `راټول کړه` ورته اړتیا لري (۷ برخه).
4. **د سیسټم ماډیول** – فایلونه، امرونه، ساعت او چاپېریال (۸ برخه).

د **ګرافیک** ماډیول (کښل، حرکت، تڼۍ او موږک) او تصادفي عددونه (`تصادفي عدد`،
`تصادفي بنسټ`) خپل سند لري: [د ګرافیک لارښود](graphics.md).

بېلګې: نمونې `19_modules` تر `23_os` (په `samples/ps/` کې هم).

---

## ۱. دودونه

* **ځایونه توري شمېري**، له ۰ پیلېږي — لکه `اوږدوالی(م)` او `م[ش]`. «پښتو» ۴ توري لري.
* **واټن پیل لري، پای نه:** `د متن برخه("تندر"، ۰، ۲)` «تن» دی، `واټن(۱، ۴)` `[۱، ۲، ۳]`.
  له حده بهر واټن د اجرا تېروتنه `R012` ده؛ تندر یې پټ نه سموي.
* **نوی ارزښت، که په ځای بدلون؟** هغه دندې چې شیان بدلوي (`ورزیات کړه`، `وروستی واخله`،
  `ننباسه`، `له ځایه لیرې کړه`، `لیرې کړه`) خپله لړۍ/نقشه بدلوي. نورې ټولې نوی ارزښت
  راګرځوي: `ترتیب کړه(ل)` ترتیب شوې کاپي ده.
* **ډولونه د جوړولو پر مهال ازمویل کېږي.** `پاک کړه(۵)` د جوړولو تېروتنه ده (`S010`)،
  نه د اجرا حادثه.
* لاندې لاسلیکونه `T`، `U`، `A`، `K`، `V` د «هر ډول» لپاره کاروي.

## ۲. ماډیولونه

### د فایل راوړل

```thunder
# lib/geometry.th
جوړښت مستطیل
    پلنوالی: عدد
    لوړوالی: عدد

دنده مساحت(م: مستطیل): عدد
    راګرځه م.پلنوالی * م.لوړوالی
```

```thunder
# main.th
راوړه "lib/geometry"

متغیر کوټه = مستطیل(۴، ۳)
کرښه چاپ(مساحت(کوټه))          # ۱۲
```

`راوړه "نوم"` فایل `نوم.th` لولي (د `.th` لیکل اختیاري دي) او **هر هغه څه چې اعلانوي یې په
خپل نوم د کارونې وړ کوي**، لکه چې په همدې فایل کې لیکل شوي وي. تندر `geometry.مساحت` ډوله
مختاړي نه لري، نو د ماډیول نومونه باید د پروګرام له خپلو نومونو سره ټکر ونه کړي (ټکر
همغه د دوو اعلانونو تېروتنه ده: `S002`، `S003`، `S028`).

### فایل چېرته لټول کېږي

1. **د راوړونکي فایل تر څنګ.** `main.th` خپل `lib/geometry.th` په خپله پوښۍ کې مومي؛
   که `lib/geometry.th` ولیکي `راوړه "numbers"`، مطلب یې `lib/numbers.th` دی.
2. **د ماډیول پوښیو کې** چې جوړونکي ته ورکړل شوي: `thunderc -I <پوښۍ>`
   (یا `--module-path`؛ تکرارېدای شي). IDE هغه پوښۍ ورکوي چې پروګرام ترې پرانیستل شوی.

که فایل ونه موندل شي، تېروتنه `S045` هر لټول شوی ځای نوموي.

### ماډیول څه لرلای شي

ماډیول **یوازې اعلانوي**: دندې، جوړښتونه، متغیرونه، ثابتونه او نور راوړنې. امرونه لکه
`کرښه چاپ(...)` نه منل کېږي (`S047`)، نو راوړل هېڅکله څه نه چاپوي. ماډیول `اصلي` نشي
تعریفولای (`S048`). د ماډیول متغیرونه عادي عمومي متغیرونه دي او د راوړونکي له امرونو
**مخکې** چمتو کېږي. `راوړه` یوازې د فایل په سر کچه راتلای شي (`P016`).

### هر فایل یو ځل لوستل کېږي

څو ځله راوړل — مستقیم یا د نورو ماډیولونو له لارې — بې زیانه دي؛ دوه ماډیولونه کولای شي
یو درېیم (یا حتی یو بل) راوړي.

### ژبه

ماډیول باید د راوړونکي پروګرام **په ژبه** وي؛ بې لارښوونې ماډیول د راوړونکي ژبه اخلي.
بله ژبه تېروتنه `S046` ده — په `thunderc --translate` یې وژباړئ.

### په ماډیولونو کې تېروتنې

تېروتنې د ماډیول په خپل فایل، د هغه له کرښو او سرچینې سره راپور کېږي؛ د اجرا تېروتنې هم
ماډیول نوموي: `په مساحت [lib/geometry.th] کې (کرښه ۷)`. IDE کې د ستونزو پاڼه د ماډیول
فایل-نوم ښيي، د بایټ کوډ پاڼه د هرې لارښوونې فایل، او ډیبګر هم.

### دنني ماډیولونه

بې قوسونو نوم دننی ماډیول راوړي: `راوړه سیسټم` (یا `os`) او `راوړه ګرافیک` (یا
`graphics`). نابلد نوم `S050` دی، چې ور یادوي فایلونه په قوسونو کې راوړل کېږي.

## ۳. ننوت او پایله

| دنده | بیان |
| --- | --- |
| `چاپ(ارزښت، ...)` | ارزښتونه پرته له بېلوونکي او نوې کرښې لیکي. |
| `کرښه چاپ(ارزښت، ...)` | لکه چاپ، ورپسې نوې کرښه. |
| `ولوله(): متن` | یوه کرښه لولي، بې د کرښې ماتېدو؛ د ننوت په پای `""`. |
| `ولوله(پوښتنه: متن): متن` | لومړی پوښتنه لیکي، بیا کرښه لولي. |
| `د ننوت پای(): منطقي` | رښتیا کله چې نور د لوستلو څه نشته. |
| `بڼه کړه(کالب، ارزښتونه...): متن` | کالب چې هر `{}` یې په راتلونکي ارزښت بدل شوی؛ `{x}` بشپړ عدد په شپاړسیز لیکي، `{b}` په دوه ییز؛ `{{` او `}}` خپله لینده ده. بڼه لرونکی چاپ: `کرښه چاپ(بڼه کړه(...))`. لږ یا ډېر ارزښتونه `R031` دي؛ `{x}`/`{b}` پر نا-عدد `R032`. |

```thunder
متغیر نوم = ولوله("نوم مو څه دی؟ ")
کرښه چاپ("سلام، "، نوم، "!")

متغیر ټول = ۰
ترڅو نه د ننوت پای()
    متغیر کرښه = پاک کړه(ولوله())
    که عدد دی(کرښه)
        ټول = ټول + عدد کړه(کرښه)
کرښه چاپ("ټول: "، ټول)
```

**ننوت له کومه راځي:** په قومانده کې له معیاري ننوت (کرښې ولیکئ یا فایل ورکړئ:
`thundervm sum.thc < numbers.txt`)؛ په IDE کې د پایلې پاڼې لاندې **ننوت** کرښه (د چلېدو
پر مهال فعاله ده؛ Enter یا «ولېږه» کرښه لېږي، «د ننوت پای» یې پای ته رسوي). پوښتنه سمدستي
ښکاري. ننوت ته انتظار لارښوونې نه لګوي، نو د IDE د ګامونو حد یې نه دروي؛ «درول» یې دروي.

## ۴. د متن دندې

| دنده | پایله | بېلګه |
| --- | --- | --- |
| `د متن برخه(م، پیل، پای)` | له پیل څخه تر پای پورې (پای پکې نه) توري | `د متن برخه("تندر"، ۰، ۲)` ← `"تن"` |
| `ټوټه(م، پیل، پای)` | همغه (په لړیو هم کار کوي) | |
| `پاک کړه(م)` | بې د پیل/پای تشو | `پاک کړه("  سلام ")` ← `"سلام"` |
| `لوی توري کړه(م)` / `کوچنی توري کړه(م)` | a–z ↔ A–Z (پښتو توري لویوالی نلري) | |
| `وېشه(م، بېلوونکی)` | د بېلوونکي ترمنځ ټوټې؛ `""` یو-یو توری | `وېشه("الف،ب"، "،")` ← `["الف"، "ب"]` |
| `یو ځای کړه(ټوټې، بېلوونکی)` | ټوټې یو متن | `یو ځای کړه(["الف"، "ب"]، "، ")` ← `"الف، ب"` |
| `بدل کړه(م، زوړ، نوی)` | هر «زوړ» په «نوی» بدل | |
| `پیلېږي په(م، سریزه)` / `پایېږي په(م، پایله)` | منطقي | |
| `شامل دی(م، برخه)` / `ځای یې(م، برخه)` | منطقي / لومړی ځای یا `-۱` | |
| `تکرار کړه(م، ن)` | متن ن ځله | `تکرار کړه("اب"، ۳)` ← `"اباباب"` |
| `سرچپه کړه(م)` | توري سرچپه | |
| `د توري کوډ(ت)` / `د کوډ توری(ن)` | یونیکوډ کوډ ↔ یو-توریز متن | `د توري کوډ("ا")` ← `۱۵۷۵` |
| `عدد دی(م)` | رښتیا که `عدد کړه(م)` بریالی شي | `عدد دی("۴۲")` ← `رښتیا` |

**د اجرا تېروتنې:** له حده بهر واټن (`R012`)، منفي شمېر `تکرار کړه` ته (`R014`)، له حده
لویه پایله (`R007`)، `د توري کوډ` له یو توري پرته (`R015`)، ناسم کوډ-ټکی (`R016`).

## ۵. ټاپلونه او جوړې

| دنده | پایله | بېلګه |
| --- | --- | --- |
| `لومړی(ت)` / `دوهم(ت)` | د ټاپل لومړی/دوهم توکی (= `ت.0` / `ت.1`) | |
| `ځای بدلول(ج)` | جوړه اړولې: `(B، A)` | `ځای بدلول((۱، "یو"))` ← `("یو"، ۱)` |
| `جوړې کړه(الف، ب)` | د یو-ځای توکو جوړې؛ د لنډې لړۍ اندازه | `جوړې کړه([۱، ۲]، ["الف"])` ← `[(۱، "الف")]` |
| `شمېره ورکړه(ل)` | هر توکی له خپل ځای سره | `شمېره ورکړه(["س"])` ← `[(۰، "س")]` |
| `توکي(م)` | د نقشې توکي د (کیلۍ، ارزښت) جوړو په بڼه | |

```thunder
متغیر خلک = جوړې کړه(["احمد"، "ملالۍ"]، [۱۷۲۲، ۱۸۶۱])
لپاره متغیر ش = ۰، ش < اوږدوالی(خلک)، ش = ش + ۱
    متغیر (نوم، کال) = خلک[ش]
    کرښه چاپ(نوم، " په "، کال، " کې")
```

## ۶. د لړیو او نقشو دندې

### لړۍ په ځای بدلول

| دنده | اثر (له `ل = [۳، ۱، ۲]` سره) |
| --- | --- |
| `ورزیات کړه(ل، ارزښت)` | پای ته یې ورزیاتوي: `[۳، ۱، ۲، ۴]` |
| `وروستی واخله(ل): T` | وروستی لیرې کوي او راګرځوي (تشه لړۍ: `R013`) |
| `ننباسه(ل، ځای، ارزښت)` | په ځای کې ننباسي (۰ تر `اوږدوالی(ل)`) |
| `له ځایه لیرې کړه(ل، ځای): T` | د ځای توکی لیرې کوي او راګرځوي |

له حده بهر ځای `R003` دی. لړۍ ماخذونه دي: بدلون هر نوم ویني.

### نوې لړۍ

| دنده | پایله |
| --- | --- |
| `ټوټه(ل، پیل، پای)` | له پیل تر پای (پای پکې نه) توکي |
| `سره نښلوه(الف، ب)` | د الف توکي، ورپسې د ب |
| `سرچپه کړه(ل)` | سرچپه ترتیب |
| `ترتیب کړه(ل)` | له کوچني لوی ته (شمېرې یا متنونه؛ مساوي خپل ترتیب ساتي) |
| `واټن(پیل، پای)` | عددونه له پیل تر پای (پای پکې نه) |

### لټون او مجموعه

| دنده | پایله |
| --- | --- |
| `شامل دی(ل، ارزښت)` / `ځای یې(ل، ارزښت)` | منطقي / لومړی ځای یا `-۱` (پرتله په `==`) |
| `مجموعه(ل)` | د `عدد[]` یا `اعشاري[]` مجموعه (تشه: ۰؛ اوښتل: `R002`/`R025`) |

### نقشې

| دنده | پایله |
| --- | --- |
| `ترلاسه کړه(م، کیلۍ، اصلي)` | د کیلۍ ارزښت، یا «اصلي» که نه وي — هېڅکله تېروتنه نه ده |
| `توکي(م)` | (کیلۍ، ارزښت) جوړې (۵ برخه) |

له پخوا: `لري`، `لیرې کړه`، `کیلۍ`، `ارزښتونه`.

### شمېرې او ریاضي

دا دندې تل شته او د `اعشاري` ډول ملګرې دي. هره یوه بشپړ عددونه هم مني (پخپله پراخېږي)،
نو `جذر(۲)` او `نیژدې کړه(۲)` سم دي.

| دنده | پایله |
| --- | --- |
| `اعشاري کړه(س)` | د متن (`"۲٫۵"`) یا د بشپړ عدد اعشاري بڼه (`R026` که متن شمېره نه وي) |
| `شمېره ده(س)` | رښتیا که `اعشاري کړه(س)` بریالی وي |
| `عدد کړه(س)` | اعشاري شمېره هم مني (کسر برخه غورځوي)، او د `0x`/`0b` لیکنې هم: `عدد کړه("0x2a")` = `۴۲` |
| `شپاړسیز کړه(ن)`، `دوه ییز کړه(ن)` | بشپړ عدد په شپاړسیز / دوه ییز بڼه؛ `عدد کړه` دواړه بېرته لولي، نو اړونه دواړو لورو ته ځي: `شپاړسیز کړه(۴۲)` = `"0x2a"`، `دوه ییز کړه(۱۰)` = `"0b1010"` |
| `مطلق(س)` | له صفر څخه واټن؛ عدد ننوځي، عدد راوځي |
| `کمینه(الف، ب)` / `اعظمه(الف، ب)` | د دوو شمېرو یا دوو متنونو کوچنی / لوی |
| `نیژدې کړه(س)` / `کښته کړه(س)` / `پورته کړه(س)` | اعشاري شمېره په بشپړ عدد: نیژدې، کښته، پورته |
| `جذر(س)` | جذر (`R027` که س منفي وي) |
| `توان(س، ی)` | س د ی په توان |
| `نمايي(س)` / `لوګارتم(س)` | e^س او طبیعي لوګارتم (`R027` که س ≤ ۰) |
| `جیب(س)` / `تتمیم جیب(س)` / `ظل(س)` | مثلثات؛ زاویه په **رادیانو** |
| `پای()` | ۳٫۱۴۱۵۹۲۶۵۳۵۸۹۷۹۳ |
| `تصادفي()` | له ۰ (شامل) تر ۱ (نه شامل) یوه تصادفي اعشاري شمېره |

ډېره لویه اعشاري پایله `R025` ده او په `۰٫۰` وېش `R001` دی: تندر هېڅکله بې‌پایه یا NaN
نه جوړوي.

## ۷. دندې د ارزښت په توګه: پر هر یو، چاڼ کړه، راټول کړه

د دندې نوم بې قوسونو **ارزښت** دی؛ ډول یې په `دنده` لیکل کېږي:

| ډول | مانا |
| --- | --- |
| `دنده(عدد): منطقي` | یو عدد اخلي، منطقي راګرځوي |
| `دنده()` | بې پارامټره، بې پایلې |
| `(دنده(عدد): عدد)[]` | د دندو لړۍ |

```thunder
دنده دوه_چنده(ن: عدد): عدد
    راګرځه ن * ۲

متغیر ف = دوه_چنده                   # ډول: دنده(عدد): عدد
کرښه چاپ(ف(۴)، " "، ف)               # ۸ <دنده دوه_چنده>
متغیر ګامونه: (دنده(عدد): عدد)[] = [دوه_چنده، ف]
کرښه چاپ(ګامونه[۱](۳))               # ۶
```

* د دندې ارزښتونه په متغیرونو، لړیو، نقشو، ټاپلونو او د جوړښت برخو کې ساتل کېږي.
* بې ارزښته د دندې متغیر «بې دندې» (`<دنده ?>`) لري؛ بلل یې `R020` ده.
* ځایي متغیر د همنومې دندې مخه نیسي؛ د دندې نوم ته ارزښت نه ورکول کېږي (`S012`)؛
  د دندو ارزښتونه په `==` نه پرتله کېږي (`S006`).
* یوازې ستاسو اعلان شوې دندې ارزښتونه دي؛ دننۍ دندې نه (`S025`) — کوچنۍ دنده پرې
  وتاوئ.
* ننوتې دندې نشته، نو closureونه هم نشته.

| دنده | پایله |
| --- | --- |
| `پر هر یو(ل، ف)` | نوې لړۍ: پر هر توکي `ف` — `دنده(T): U` ← `U[]` |
| `چاڼ کړه(ل، ساته)` | هغه توکي چې `ساته: دنده(T): منطقي` یې مني |
| `راټول کړه(ل، پیل، ف)` | له کیڼ نه ښي: `ف(ف(پیل، ل[۰])، ل[۱]) ...`؛ تشه لړۍ: پیل |

ناسم ډول دنده تېروتنه `S051` ده، چې اړین ډول نوموي. `پر هر یو` او `چاڼ کړه` پر هغو
توکو کار کوي چې لړۍ یې د پیل پر مهال لرل، نو دنده کولای شي لړۍ خوندي بدله کړي. د دندې
دننه د اجرا تېروتنه د بلنو سټک کې د `پر هر یو` بلنه هم ښيي، او ډیبګر ورننوځي.

## ۸. د سیسټم ماډیول

```thunder
راوړه سیسټم
```

دندې یې یوازې له راوړلو وروسته شته؛ بې له هغه نومونه یې ازاد دي، او کارول یې لارښود
پیغام راوړي (`S049`: «راوړه سیسټم» ورزیات کړئ).

### دلیلونه، چاپېریال، وتل

| دنده | پایله |
| --- | --- |
| `دلیلونه(): متن[]` | د پروګرام له نوم وروسته کلمې: `thundervm prog.thc یو دوه` ← `["یو"، "دوه"]` |
| `د چاپېریال ارزښت(نوم): متن` | د چاپېریال متغیر، یا `""` |
| `پای ته ورسوه(کوډ)` | پروګرام سمدستي پای ته رسوي؛ کوډ د `thundervm` د وتلو حالت کېږي |
| `عامل سیسټم(): متن` | `"linux"`، `"windows"`، `"macos"` یا `"unknown"` |

### فایلونه او پوښۍ

| دنده | اثر |
| --- | --- |
| `فایل ولوله(لار): متن` | د متني فایل ټوله منځپانګه (د وینډوز `\r\n` په `\n` اوړي) |
| `فایل ولیکه(لار، متن)` / `فایل ته ورزیات کړه(لار، متن)` | جوړوي/ځای‌نیسي / پای ته ورزیاتوي |
| `فایل شته(لار): منطقي` | رښتیا که فایل یا پوښۍ وي |
| `فایل ړنګ کړه(لار)` | ړنګوي (نشتوالی بې زیانه) |
| `د پوښۍ توکي(لار): متن[]` | د پوښۍ توکي، ترتیب شوي |
| `اوسنۍ پوښۍ(): متن` | کاري پوښۍ |

لارې په `/` لیکل کېږي (وینډوز `\` هم مني)؛ نسبي لارې له کاري پوښۍ پیلېږي (IDE کې: چې
پروګرام ترې پرانیستل شوی). د نه لوستلو تېروتنه `R017` ده، د نه لیکلو `R018`.

### امرونه

| دنده | اثر |
| --- | --- |
| `وچلوه(امر): عدد` | امر د سیسټم شیل کې چلوي؛ وتنه یې د پروګرام پایلې کې راځي؛ حالت راګرځوي |
| `د چلولو پایله(امر): (عدد، متن)` | حالت او وتنه راګرځوي، بې چاپه |

امرونه ستاسو له واک سره چلېږي — یوازې باوري امرونه وچلوئ. نه پیلېدونکی امر `R019` دی.

### وخت

| دنده | پایله |
| --- | --- |
| `وخت(): عدد` | ثانیې له ۱۹۷۰-۰۱-۰۱ (UTC) |
| `ساعت(): عدد` | ملي ثانیې د پروګرام له پیله (د وخت اندازه کولو لپاره توپیرونه وکاروئ) |
| `انتظار(مث)` | مث ملي ثانیې درېږي |
| `نېټه او وخت(): متن` | سیمه‌ییزه، `"2026-11-06 14:30:05"` |

## ۹. نوي د تېروتنو کوډونه

د کوډونو بشپړ جدول د انګلیسي سند ۹ برخه کې دی؛ مهم: `S045` ماډیول ونه موندل شو، `S047`

## ۱۱. د پردې شاته
