# ساکټونه: د شبکې له لارې خبرې

*[د تندر SDK لارښود](README.md) یوه برخه.*

د تندر پروګرام کولای شي د بل کمپیوټر له پروګرام سره (یا له وېب سرور سره، یا له ځان سره)
د **ساکټونو** له لارې خبرې وکړي. یو لوری پر یوه پورټ *اوري*، بل له هغه کمپیوټر او پورټ سره
*نښلي*، او بیا متن دواړو لورو ته بهېږي تر هغه چې یو لوری یې وتړي. د چټ پروګرام، د لوبې
سرور او وېب براوزر تر لاندې همدا کار کوي.

```thunder
# ژبه: ps
راوړه "sockets"

سرور سره = ټي_سي_پي.اورېدونکی_جوړ_کړه(""، ۵۰۰۰)            # پر پورټ ۵۰۰۰ غږ کوونکو ته انتظار
    اړیکه سره = ټي_سي_پي.اړیکه_ومنه(سرور)                   # ... یو راغی
        کرښه چاپ(اړیکه.کرښه_واخله())                        # څه یې وویل
        اړیکه.کرښه_ولېږه("بېرته سلام")                       # ځواب
# دلته «سره» لومړی اړیکه تړلې، بیا اورېدونکی
```

```thunder
# ژبه: ps
راوړه "sockets"

اړیکه سره = ټي_سي_پي.ونښلېږه("192.168.1.20"، ۵۰۰۰)   # هغه کمپیوټر چې پورتنی پروګرام چلوي
    که اړیکه == هېڅ
        کرښه چاپ("نښلېدل نشي: "، ساکټ.تېروتنه())
    کنه
        اړیکه.کرښه_ولېږه("سلام")
        کرښه چاپ(اړیکه.کرښه_واخله())                    # "بېرته سلام"
```

ساکټونه له یوه [بهرني ماډیول](native.md) څخه راځي: د ++C کتابتون `thunder_sockets`
(`lib/native/sockets/thunder_sockets.cpp`)، چې له توکپانګې سره جوړېږي او د `thundervm` تر
څنګ کېني. د تندر فایل [`sockets.th`](../../lib/thunder/ps/sockets.th) د هغه پر سر د
**`ساکټ.ساکټ`** شی اعلانوي - د هر ساکټ هره چاره د هغه یوه دنده ده - او څلور ټولګي -
`ټي_سي_پي`، `یو_ډي_پي`، `ساکټ` او `کوربه` - نو پروګرام یوازې `راوړه "sockets"` ته
اړتیا لري: thunderc د SDK فایلونه د ځان تر څنګ په `lib/thunder/<ژبه>` کې مومي. په IDE کې
دا لارښود د **مرسته > د ساکټونو لارښود** لاندې دی؛ بېلګه ۳۸ (`samples/ps/38_sockets.th`)
سرور او پېرېدونکی په یوه پروګرام کې چلوي.

## ۱. بنسټیز مفهومونه

| کلمه | مانا |
| --- | --- |
| **پته** | کوم کمپیوټر: `"127.0.0.1"` تل *همدا* دی، `"192.168.1.20"` یو ګاونډی، `"example.org"` یو نوم چې شبکه یې لټوي |
| **پورټ** | پر هغه کمپیوټر کوم پروګرام: له ۱ تر ۶۵۵۳۵ یو عدد؛ `۰` له سیسټم څخه هر تش پورټ غواړي |
| **TCP** | یوه *اړیکه*: متن بشپړ او په ترتیب رسېږي، دواړو لورو ته، تر هغه چې یو لوری یې وتړي |
| **UDP** | یو یو *پیغام* (ډاټاګرام) هرې پتې ته، بې اړیکې؛ چټک، خو یو کېدای شي ورک شي |
| **ساکټ** | یو `ساکټ.ساکټ`: هغه څه چې پروګرام یې د اړیکې، اورېدونکي یا UDP ساکټ لپاره ساتي، چې هر څه چې کولای یې شي د هغه دندې دي (دننه یې هغه شمېره ده چې ++C یې پرې پېژني) |

څلور ټولګي کار همداسې وېشي:

| ټولګی | څه پکې دي |
| --- | --- |
| `ټي_سي_پي` | اړیکې: `اورېدونکی_جوړ_کړه`، `اړیکه_ومنه`، `ونښلېږه`، او `غوښتنه` (یوه بشپړه تبادله) |
| `یو_ډي_پي` | یو یو پیغام: `پرانیزه`، `ولېږه`، `واخله`، `لېږونکی` |
| `ساکټ` | ډول `ساکټ.ساکټ`، چې **دندې** یې هغه څه دي چې هر ساکټ یې کولای شي - د متن یا بایټونو لېږل او اخیستل، `وتړه()`، د وخت حد - او سربېره پرې `ساکټ.تېروتنه()` او `ساکټ.له_نښې` |
| `کوربه` | نومونه او پتې: `کوربه.پته("example.org")`، `کوربه.نوم()` |

د ساکټ پرانیستل ناکامېدای شي - څوک نه اوري، پورټ نیول شوی، نوم نامعلوم دی. بیا
`ټي_سي_پي.اورېدونکی_جوړ_کړه`، `ټي_سي_پي.اړیکه_ومنه`، `ټي_سي_پي.ونښلېږه` او `یو_ډي_پي.پرانیزه`
د ساکټ پر ځای **`هېڅ`** راګرځوي، او `ساکټ.تېروتنه()` وايي ولې.

د ټولګو نومونه په هغه پروګرام کې ساتل شوي دي چې `"sockets"` راوړي: یو متغیر `ساکټ`،
`ټي_سي_پي`، `یو_ډي_پي` یا `کوربه` نشي نومول کېدای (تېروتنه `S065`). `اړیکه`، `اورېدونکی`،
`پېرېدونکی` ... یې ونوموئ.

## ۲. TCP

| دنده | راګرځوي | څه کوي |
| --- | --- | --- |
| `ټي_سي_پي.اورېدونکی_جوړ_کړه(پته، پورټ): ساکټ.ساکټ` | اورېدونکی، یا `هېڅ` | اړیکو ته انتظار پیلوي. پته `""` د دې کمپیوټر هره پته؛ پورټ `۰` سیسټم ته پرېږدي چې وټاکي (د اورېدونکي `پورټ()` وپوښتئ). |
| `ټي_سي_پي.اړیکه_ومنه(اورېدونکی): ساکټ.ساکټ` | اړیکه، یا `هېڅ` | راتلونکي غږ کوونکي ته انتظار کوي او ورسره اړیکه راګرځوي (که پر اورېدونکي `وخت_حد` ټاکل شوی وي، هغه مهال هم `هېڅ` چې څوک په وخت رانغی). |
| `ټي_سي_پي.ونښلېږه(سرور، پورټ): ساکټ.ساکټ` | اړیکه، یا `هېڅ` | له یوه اورېدونکي پروګرام سره نښلي. `هېڅ` که هلته څوک نه اوري، یا نوم نامعلوم وي. |
| `ټي_سي_پي.غوښتنه(سرور، پورټ، کرښه): متن` | ځواب، یا `""` | ونښلېږه، یوه کرښه ولېږه، یوه کرښه ولوله، پرې کړه - ټوله تبادله په یوه بلنه (په تندر لیکل شوې، په `sockets.th` کې، د «سره» سره). |

هغه څه چې هر ساکټ یې کولای شي، د `ساکټ.ساکټ` د دندو په توګه (`س` هر ساکټ دی):

| دنده | راګرځوي | څه کوي |
| --- | --- | --- |
| `س.ولېږه(متن): عدد` | لېږل شوي بایټونه، یا -۱ | متن لېږي (د UTF-8 بایټونو په بڼه). |
| `س.کرښه_ولېږه(متن): عدد` | لېږل شوي بایټونه، یا -۱ | متن او د کرښې پای لېږي. |
| `س.واخله(تر_ټولو_ډېر_بایټونه): متن` | متن، یا `""` | تر حد پورې متن ته انتظار کوي. |
| `س.کرښه_واخله(): متن` | یوه کرښه، یا `""` | بشپړې کرښې ته انتظار کوي او پرته له پای څخه یې راګرځوي. |
| `س.بایټونه_ولېږه(ډېټا: بایټ[]): عدد` | لېږل شوي بایټونه، یا -۱ | خام بایټونه لکه چې دي لېږي (فایل، د دوه‌ییز پروتوکول بسته). |
| `س.بایټونه_واخله(تر_ټولو_ډېر_بایټونه): بایټ[]` | بایټونه، یا `[]` | تر حد پورې هر څه چې راځي د `بایټ[]` په توګه اخلي؛ د [کتابتون لارښود](library.md)، «بایټونه» وګورئ. |
| `س.پرانیستی_دی(): منطقي` | | تر هغه رښتیا چې اړیکه لا څه راوړلای شي. |
| `س.وتړه()` | | اړیکه، اورېدونکی یا UDP ساکټ تړي؛ بل لوری یې پوهېږي. «سره» یې ستاسې لپاره بلي (۳مه برخه)؛ د یوه ساکټ دوه ځله تړل هېڅ زیان نه لري. |
| `س.وخت_حد(ملي_ثانیې): منطقي` | | `ټي_سي_پي.اړیکه_ومنه`، `واخله` او `یو_ډي_پي.واخله` څومره انتظار کولای شي؛ -۱ (اصلي) مانا تل. د اورېدونکي د وخت حد هغو اړیکو ته هم رسېږي چې دی یې مني. |
| `س.پورټ(): عدد` | | پر دې کمپیوټر پورټ (له `ټي_سي_پي.اورېدونکی_جوړ_کړه(پته، ۰)` وروسته ګټور). |
| `س.مقابل_لوری(): متن` | `"ip:port"` | د اړیکې په بل سر څوک دی. |

او د `ساکټ` ټولګي خپلې دوه دندې:

| دنده | راګرځوي | څه کوي |
| --- | --- | --- |
| `ساکټ.تېروتنه(): متن` | | ولې وروستۍ بلنه چې ناکامه شوه (`هېڅ`، -۱ یا `""`) داسې وشوه: `"Connection refused"`، `"timed out"`، `"closed by the other side"`، ... |
| `ساکټ.له_نښې(نښه): ساکټ.ساکټ` | ساکټ، یا `هېڅ` | د هغې شمېرې ساکټ چې ++C راوګرځوله (د -۱ لپاره `هېڅ`). ټولګي یې کاروي؛ ستاسې خپل بهرنی کتابتون یې هم کارولای شي که ساکټونه پرانیزي. |

**کرښې طبیعي واحد دی.** ډېری ساده پروتوکولونه «هرې خوا ته یوه کرښه» دي: پېرېدونکی یوه
کرښه لېږي، سرور یې د `کرښه_واخله()` سره لولي، او د `کرښه_ولېږه` سره ځواب ورکوي.
`واخله` د هغه متن لپاره ده چې د کرښو بڼه نه لري؛ هر څه چې رسېدلي، تر حد پورې،
راګرځوي، او `""` کله چې بل لوری وتړل شي.

**انتظار.** `ټي_سي_پي.اړیکه_ومنه`، `واخله` او `کرښه_واخله` *انتظار کوي* تر هغه چې
څه وشي - لکه `ولوله()` کاروونکي ته انتظار کوي. هغه پروګرام چې نه باید تل انتظار وکړي، د
وخت حد ږدي:

```thunder
# ژبه: ps
راوړه "sockets"

# یوه کرښه لولي، تر ټولو ډېر دوه ثانیې انتظار کوي.
دنده کرښه_ولوله(اړیکه: ساکټ.ساکټ): متن
    اړیکه.وخت_حد(۲۰۰۰)                             # دوه ثانیې
    متغیر کرښه = اړیکه.کرښه_واخله()
    که کرښه == "" او نه اړیکه.پرانیستی_دی()
        کرښه چاپ("بل لوری ولاړ")
    کنه که کرښه == ""
        کرښه چاپ("هېڅ رانغلل: "، ساکټ.تېروتنه())     # "timed out"
    راګرځه کرښه
```

## ۳. د ساکټونو تړل: «سره»

ساکټ د پروګرام بهر یو څه استازیتوب کوي - هغه اړیکه چې بل لوري پرانیستې ساتلې، هغه پورټ
چې سیسټم پور ورکړی - نو کله چې پروګرام ترې فارغ شي، باید بېرته ورکړل شي. «سره» همدا کوي،
د ساکټ د خپلې `وتړه()` دندې له لارې:
هغه ساکټ چې دا یې پرانیزي د بلاک په پای کې تړل کېږي، بلاک **که هر ډول** پای ته ورسېږي - د
بلاک په پای کې، یا د داسې `راګرځه`، `ودرېږه` یا `دوام` له لارې چې ترې وځي.

```thunder
# ژبه: ps
راوړه "sockets"

اړیکه سره = ټي_سي_پي.ونښلېږه("localhost"، ۷۰۰۰)
    که اړیکه != هېڅ
        اړیکه.کرښه_ولېږه("سلام")
# دلته اړیکه تړل شوې
```

په `sockets.th` کې `ټي_سي_پي.غوښتنه` همداسې لیکل شوې: د بلاک له منځه ژر `راګرځه` هم اړیکه
تړي، او ارزښت یې له تړلو مخکې حسابېږي.

```thunder
# ژبه: ps
راوړه "sockets"

دنده غوښتنه(سرور: متن، پورټ: عدد، کرښه: متن): متن
    اړیکه سره = ټي_سي_پي.ونښلېږه(سرور، پورټ)
        که اړیکه == هېڅ
            راګرځه ""
        اړیکه.کرښه_ولېږه(کرښه)
        راګرځه اړیکه.کرښه_واخله()            # لومړی لوستل، بیا تړل
```

* **هېڅ نه تړل کېږي.** کله چې پرانیستل ناکام شي، نوم `هېڅ` لري او د بلاک پای یې پرېږدي؛
  د بلاک دننه `هېڅ` وازمویئ، لکه پورته.
* **ننوتي بلاکونه لومړی تر ټولو دننني تړي:** په لومړۍ بېلګه کې اړیکه له اورېدونکي مخکې
  تړل کېږي.
* **دوه ځله تړل زیان نه لري.** پروګرام کولای شي د بلاک دننه پخپله هم `وتړه()` وبولي
  (د مثال په توګه، چې بل لوری پای وویني)؛ د بلاک په پای کې تړل بیا نور څه نه کوي.
* **هغه ساکټ چې دمخه یې لرئ** بې نومه ورکول کېږي: `اورېدونکی سره` د بلاک په پای کې
  `اورېدونکی` تړي.
* نوم د بلاک دننه ثابت دی: ورته ارزښت ورکول تېروتنه ده (`S012`).
* نه تړل کېږي: کله چې پروګرام د اجرا له تېروتنې یا `سیسټم.پای ته ورسوه()` سره ودرېږي. عامل
  سیسټم د پای ته رسېدلې پروسې ټول ساکټونه خوشې کوي، نو هېڅ نه پاتې کېږي.

«سره» د هر هغه جوړښت لپاره کار کوي چې خپله **د `وتړه()` دنده** لري - `ساکټ.ساکټ` یو
داسې دی - او د داسې ساده ارزښت لپاره هم، لکه د `عدد` لاستی، چې د یوه `وتړه` لرونکي ټولګي
دنده یې راګرځوي؛ د [ژبې لارښود](language.md) او بېلګه ۳۹ (`samples/ps/39_with.th`) ټوله جمله ښيي.
**په پښتو کې کلیدي کلمه له نوم وروسته راځي** (`اړیکه سره = ...`)، یا کله چې نوم نه وي له ارزښت
وروسته (`ساکټ سره`، چې هلته کرښه پای ته رسوي)، لکه څنګه چې ژبه یې وايي - «ساکټ سره»؛
انګلیسي یې د کرښې په پیل کې لیکي:

```thunder
import "sockets"

with connection = tcp.connect("localhost", 7000)
    if connection != nothing
        connection.send_line("hello")
```

`thunderc --translate` (او د IDE ژباړه) کلیدي کلمه په بله ژبه کې خپل ځای ته وړي.

## ۴. UDP

| دنده | راګرځوي | څه کوي |
| --- | --- | --- |
| `یو_ډي_پي.پرانیزه(پورټ): ساکټ.ساکټ` | ساکټ، یا `هېڅ` | د دې کمپیوټر پر یوه پورټ UDP ساکټ پرانیزي (`۰`: هر تش پورټ). |
| `یو_ډي_پي.ولېږه(ساکټ_، سرور، پورټ، متن): عدد` | لېږل شوي بایټونه، یا -۱ | یو پیغام `سرور:پورټ` ته لېږي. |
| `یو_ډي_پي.واخله(ساکټ_، تر_ټولو_ډېر_بایټونه): متن` | پیغام، یا `""` | یوه پیغام ته انتظار کوي. |
| `یو_ډي_پي.بایټونه_ولېږه(ساکټ_، سرور، پورټ، ډېټا: بایټ[]): عدد` | لېږل شوي بایټونه، یا -۱ | د خامو بایټونو ډاټاګرام. |
| `یو_ډي_پي.بایټونه_واخله(ساکټ_، تر_ټولو_ډېر_بایټونه): بایټ[]` | بایټونه، یا `[]` | ډاټاګرام د `بایټ[]` په توګه. |
| `یو_ډي_پي.لېږونکی(): متن` | `"ip:port"` | چا هغه پیغام لېږلی چې `یو_ډي_پي.واخله` وروستی راوګرځاوه - نو سرور ورته ځواب ورکولای شي. |

UDP ساکټ هم لکه هر بل یو `ساکټ.ساکټ` دی: د `وخت_حد()`، `پورټ()` او `وتړه()` دندې یې پرې
کار کوي، او «سره» یې تړي. (ډاټاګرام خپل مقصد هر ځل نوموي - ساکټ یوازې ټاپه ده - نو
`یو_ډي_پي.ولېږه` او ملګري یې د ټولګي دندې پاتې دي چې ساکټ اخلي.)

```thunder
# ژبه: ps
راوړه "sockets"

اخیستونکی سره = یو_ډي_پي.پرانیزه(۰)
    لېږونکی سره = یو_ډي_پي.پرانیزه(۰)
        یو_ډي_پي.ولېږه(لېږونکی، "127.0.0.1"، اخیستونکی.پورټ()، "یو ډاټاګرام")
        کرښه چاپ(یو_ډي_پي.واخله(اخیستونکی، ۱۰۰))       # یو ډاټاګرام
```

UDP نه اړیکه لري نه تضمین: پیغام کېدای شي ناوخته، دوه ځله یا هېڅ ونه رسېږي. هغه ځای ته
مناسب دی چې نوی ارزښت تر هر ارزښت مهم وي - په لوبه کې د لوبغاړي ځای، هره ثانیه د سینسر لوستنه.

## ۶. دوه ډوله ستونزې

*پر شبکه* د څه خرابېدل عادي دي او د **ارزښت** په بڼه راپور کېږي: د ساکټ پر ځای `هېڅ`، -۱
یا `""`، او `ساکټ.تېروتنه()` وايي ولې. پروګرام پرېکړه کوي څه وکړي - بیا هڅه، کاروونکي ته
ویل، پرېښودل.

**د پروګرام تېروتنه** - له تړلو وروسته د ساکټ کارول، د اورېدونکي پر ځای پر اړیکه
`ټي_سي_پي.اړیکه_ومنه` بلل، پر TCP ساکټ `یو_ډي_پي.ولېږه` - پروګرام د اجرا تېروتنې `R030` او
داسې پیغام سره دروي لکه `socket.send_line: socket 0 is not open` (د ++C پیغام، په انګلیسي)، لکه د
دننۍ دندې ناسمه بلنه.
هغه `هېڅ` چې ناکامه `ټي_سي_پي.ونښلېږه` راګرځولی، داسې کارول لکه ساکټ چې وي، هم پروګرام دروي
(`R033`، «ارزښت هېڅ دی»). دا د سمولو ستونزې دي، نه د سمبالولو حالتونه.

## ۷. چلول او بسته کول

* په IDE کې **چلول** سمدستي کار کوي: `thunder_sockets` له توکپانګې سره جوړېږي او د `thundervm`
  تر څنګ موندل کېږي. له IDE بهر هم `thundervm program.thc` همداسې کار کوي.
* [بسته شوی](packaging.md) پروګرام کتابتون پخپله د ځان تر څنګ کاپي شوی لري، ځکه چې یو عادي
  بهرنی کتابتون دی (په `sockets.th` کې `راوړه بهرنی "thunder_sockets"`): پوښۍ ولېږئ، نه یوازې
  اجرا کېدونکی فایل.
* په خپل پروګرام کې یوازې `راوړه "sockets"` ولیکئ: فایل د `thunderc` تر څنګ په
  `lib/thunder/<ژبه>` کې موندل کېږي (د بلې نسخې لپاره یې د خپل پروګرام تر څنګ کاپي کړئ، یا
  `-I <dir>` وکاروئ).
* کتابتون د پلیټفارم خپل ساکټونه کاروي - په لینکس او macOS کې BSD ساکټونه، په وینډوز کې
  Winsock - او بل هېڅ. سرچینه یې، د ++C شاوخوا ۸۰۰ کرښې، د هغه بهرني ماډیول کاري بېلګه ده
  چې د بلنو ترمنځ حالت (د پرانیستو ساکټونو جدول) ساتي.
* `sockets.th` د [ټولګي دننه د بهرنیو دندو](native.md#د-ټولګي-دننه-بهرنۍ-دندې) کاري بېلګه هم
  ده: `ټولګی ساکټ` اعلانوي `بهرنی دنده _ولېږه(نښه: عدد، متن_یې: متن): عدد`، او ++C دا دنده د
  خپل بشپړ نوم لاندې ثبتوي، `"ساکټ._ولېږه"` (او انګلیسي `"socket._send"`). `_` دا خامې،
  شمېره اخیستونکې دندې خپل ټولګي ته ځانګړې ساتي؛ د `ساکټ.ساکټ` عامې دندې، لکه `ولېږه`،
  نغاړي یې.

**د خوندیتوب یادونه.** هغه پروګرام چې پر `""` (هره پته) اوري له نورو کمپیوټرونو څخه هم رسېدل
کېږي؛ پر `"127.0.0.1"` یوازې له همدې ماشین څخه. د [بهرني اړیکي](native.md) عادي قواعد پلي کېږي:
کتابتون د پروسې په واکونو چلېږي، او `thundervm --no-native` یې (او هر بهرنی کتابتون) بندوي.

## ۸. انګلیسي نومونه

`sockets.th` په انګلیسي هم شته (`lib/thunder/en/sockets.th`)، له همغه `Socket` شي او همغو
ټولګو سره؛ کتابتون هره دنده د دواړو نومونو لاندې ثبتوي. د ساکټ دندې
(`س.کرښه_ولېږه("سلام")`) په دواړو ژبو کې له ټکي وروسته لیکل کېږي:

| انګلیسي | پښتو |
| --- | --- |
| ټولګی `tcp` | `ټي_سي_پي` |
| `tcp.listen` / `tcp.accept` / `tcp.connect` / `tcp.request` | `ټي_سي_پي.اورېدونکی_جوړ_کړه` / `ټي_سي_پي.اړیکه_ومنه` / `ټي_سي_پي.ونښلېږه` / `ټي_سي_پي.غوښتنه` |
| ټولګی `socket`، ډول `socket.Socket` | `ساکټ`، `ساکټ.ساکټ` |
| `.send` / `.send_line` (دندې) | `.ولېږه` / `.کرښه_ولېږه` |
| `.receive` / `.receive_line` | `.واخله` / `.کرښه_واخله` |
| `.send_bytes` / `.receive_bytes` | `.بایټونه_ولېږه` / `.بایټونه_واخله` |
| `.is_open` | `.پرانیستی_دی` |
| `.close` | `.وتړه` |
| `.set_timeout` | `.وخت_حد` |
| `.port` / `.peer` | `.پورټ` / `.مقابل_لوری` |
| `socket.error` / `socket.from_handle` | `ساکټ.تېروتنه` / `ساکټ.له_نښې` |
| ټولګی `udp` | `یو_ډي_پي` |
| `udp.open` / `udp.send` / `udp.receive` / `udp.sender` | `یو_ډي_پي.پرانیزه` / `یو_ډي_پي.ولېږه` / `یو_ډي_پي.واخله` / `یو_ډي_پي.لېږونکی` |
| `udp.send_bytes` / `udp.receive_bytes` | `یو_ډي_پي.بایټونه_ولېږه` / `یو_ډي_پي.بایټونه_واخله` |
| ټولګی `host` | `کوربه` |
| `host.address` / `host.name` | `کوربه.پته` / `کوربه.نوم` |
| `with name = resource` | `نوم سره = سرچینه` (کلیدي کلمه له نوم وروسته) |

**له ۰٫۷ مخکې** دا د مختاړو سره ساده دندې وې - `ونښلېږه`، `ساکټ_کرښه_ولېږه`، `ساکټ_وتړه`،
`د_کوربه_پته` ... - او ساکټ یو لوڅ `عدد` و، د ناکامۍ لپاره -۱. ۰٫۷ هره یوه په خپل ټولګي کې د
لنډ نوم لاندې کېښوده (`ټي_سي_پي.ونښلېږه`، `ساکټ.کرښه_ولېږه(س، متن_یې)`، `کوربه.پته`)، او
`غوښتنه` `ټي_سي_پي.غوښتنه` شوه. اوس د هر ساکټ دندې د `ساکټ.ساکټ` خپلې دندې دي:
`ساکټ.کرښه_ولېږه(س، متن_یې)` اوس `س.کرښه_ولېږه(متن_یې)` لیکل کېږي، `ساکټ.وتړه(س)` اوس
`س.وتړه()`، او همداسې نور.
