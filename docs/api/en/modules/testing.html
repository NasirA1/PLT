    testing

    import "testing"

    a small test framework, written in Thunder itself (docs/testing.md)

    import "testing", write each test as a function, hand it to test() with a name, and end the program with finish_tests():

    import "testing"

    func adds_up() expect_equal(2 + 2, 4)

    test("adds up", adds_up) finish_tests()

    Every test prints one line - "✓ name" when it passed, "✗ name: what went wrong" for each expectation that failed - and finish_tests() prints how many passed and failed, ending the program with exit status 1 when any failed (so a script, or the VS Code extension, can tell). Program arguments choose which tests run: "thundervm tests.thc adds" runs only the tests named on the command line, which is how VS Code's Test Explorer runs a single one.

    Nothing here is native: this is ordinary Thunder, written to be read.
