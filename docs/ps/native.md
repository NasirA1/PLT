# د تندر بهرنی اړیکی (د ++C بلل)

د تندر پروګرام کولای شي هغه دندې وبلي چې په **C یا ++C** کې لیکل شوې، او هغه کوډ هم کولای
شي تندر بیا وبلي — لکه په جاوا کې JNI. د ++C خوا یو عادي شریک کتابتون دی، د تندر خوا وايي
چې څه بللای شي، او ترمنځ یې یو کوچنی C اړیکی دی.

```thunder
راوړه بهرنی "mathx"                        // libmathx.so / mathx.dll راوړي
بهرنی دنده fast_hypot(س: اعشاري، ص: اعشاري): اعشاري

کرښه چاپ(fast_hypot(۳، ۴))                 // ۵٫۰
```

اړیکی قصداً کوچنی دی: **یو سرلیک** (`include/thunder/native.h`)، په کتابتون کې **یوه
ننوتنه**، او د ارزښت لپاره **یوه جوړه**. هېڅ شی نه ځای نیسي او هېڅ شی نه خوشې کېږي.

بشپړه، جوړېدونکې بېلګه په [`lib/native/`](../../lib/native/) کې ده. ټول تفصیل:
[انګلیسي سند](../native.md).

---

## ۱. د تندر خوا

| کرښه | مانا |
| --- | --- |
| `راوړه بهرنی "mathx"` | د پروګرام په پیل کې کتابتون `mathx` راوړي. یوازې په سر کچه. |
| `بهرنی دنده نوم(پارامټرونه): ډول` | هغه دنده چې کتابتون یې لري. بدن نه لري: په کتابتون کې دی. |

بهرنۍ دنده لکه هره بله ده: مخکې له اعلانه بللای شئ، دلیلونه یې **د جوړولو پر مهال** کتل
کېږي، او ناسمه بلنه د جوړولو تېروتنه ده، نه ماتېدنه. یو توپیر: بهرنۍ دنده *ارزښت* نه ده،
نو `پر هر یو` ته یې نشئ ورکولای (تېروتنه `S025`).

### کوم ډولونه له پولې اوړي

| د تندر ډول | په C کې | یادښت |
| --- | --- | --- |
| `عدد` | `int64_t` | |
| `اعشاري` | `double` | بشپړ عدد پخپله پراخېږي، نو `fast_hypot(۳، ۴)` سم دی. |
| `منطقي` | `int` (۰ یا ۱) | |
| `متن` | `const char*` + اوږدوالی | UTF-8، **نه** حتماً په صفر پای ته رسېدلی. |
| `دنده(...)` | `ThunderValue` | **یوازې پارامټر**: هغه بیا-بلنه چې ++C یې بولي. |
| هېڅ | `THUNDER_VOID` | هغه `بهرنی دنده` چې د راګرځېدو ډول نه لري. |

لړۍ، نقشې، ټاپلونه او جوړښتونه **نشي** اوړېدای (تېروتنه `S053`). همدا هغه کرښه ده چې
اړیکی ساده ساتي: شریکه ملکیت نشته، نو هېڅ خوا هغه څه نشي خوشې کولی چې بله یې لا کاروي.

بهرنۍ دنده تر ۱۶ پارامټره لرلای شي (`S055`)، او بې کتابتونه اعلان تېروتنه ده (`S054`).

## ۲. د ++C خوا

```cpp
#include <thunder/native.h>
#include <cmath>

static const ThunderApi* host = nullptr;

static ThunderValue fast_hypot(ThunderEnv*, const ThunderValue* args, int32_t)
{
    return thunder_float(std::hypot(args[0].number, args[1].number));
}

extern "C" THUNDER_EXPORT int thunder_module_init(ThunderRegistry* reg, const ThunderApi* api)
{
    if (api->abi_version != THUNDER_NATIVE_ABI) { return 0; }
    host = api;
    return reg->add(reg, "fast_hypot", fast_hypot);
}
```

* **ارزښتونه:** `ThunderValue` یوه ساده جوړه ده؛ په `thunder_void()`، `thunder_int(n)`،
  `thunder_float(x)`، `thunder_bool(b)`، `thunder_text(pointer, length)` یې جوړوئ.
* **متنونه:** د دلیل متن تر راګرځېدو پورې سم دی. هغه متن چې راګرځوئ، VM یې سمدستي کاپي
  کوي، نو ثابت یا `static` بفر خوندي دی؛ د ځایي لړۍ پتنوس چې دمخه پای ته رسېدلی — نه.
* **تېروتنه:** `host->fail(env, "...")` بیا سمدستي راګرځئ؛ پروګرام په `R030` درېږي.
  `fail` *راګرځي* (نه خوځوي)، ځکه چې د ++C استثنا د C چوکاټ له لارې خوندي نه ده.
* **بیا-بلنه:** `host->call(env, args[1], &argument, 1)` د تندر دنده پر همدې VM چلوي؛ بیا
  `host->failed(env)` وګورئ او که ناکامه وه، راوګرځئ.

## ۳. جوړول او لټون

```sh
c++ -std=c++17 -shared -fPIC -I<thunder>/include -o libmathx.so mathx.cpp
```
```powershell
cl /std:c++17 /LD /I<thunder>\include mathx.cpp /Fe:mathx.dll
```

کتابتون په دې ترتیب لټول کېږي: ۱) د چلېدونکي پروګرام پوښۍ؛ ۲) د `thundervm` پوښۍ (هلته
یوه [بسته](packaging.md) خپل کتابتونونه ساتي)؛ ۳) `--native-path <dir>` او بیا د
`THUNDER_NATIVE_PATH` پوښۍ؛ ۴) هر چېرې چې عامل سیسټم پخپله ګوري.

`thundervm --no-native` هېڅ کتابتون نه راوړي: پروګرام په `R028` درېږي.

**د خوندیتوب یادښت.** بهرنی کوډ د پروسې په بشپړو واکونو چلېږي: VM یې نه ګوري او نه یې
محدودوي. تندر پخپله بشپړ خوندي دی — هېڅ ناجوت چلند نه لري — او `راوړه بهرنی` یوازینۍ
دروازه ده چې ترې وځي. یوازې هغه کتابتونونه راوړئ چې تاسې جوړ کړي یا پرې باور لرئ.

## ۵. د پردې شاته

بهرنی اعلان د پروګرام **بهرني جدول** ته ورځي، او بلنه یوه لارښوونه کېږي: `CALL_NATIVE i`
(د «بایټ کوډ» پاڼه کې یې وګورئ). کتابتونونه **له لومړي امره مخکې** یو ځل راوړل کېږي، نو
ورک کتابتون یا ورکه دنده سمدستي راپور کېږي (`R028`، `R029`). د راګرځېدو ډول هغه دی چې په
اعلان کې لیکل شوی، نو ناسم ډول ارزښت په ټایپ شوي پروګرام کې نشي ننوتلی.
