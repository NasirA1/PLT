# د تندر ژبې لارښود

*[د تندر SDK لارښود](README.md) یوه برخه.*

> دا سند د `docs/language.md` پښتو ژباړه ده. انګلیسي اصل پره‌مختللی (معتبر) متن دی؛ دا ژباړه
> د مسلکي اصطلاحاتو له پلوه د یوه ژبپوه کتنې ته اړتیا لري.

تندر یوه کوچنۍ، په جامد ډول ډول‌ شوې (statically typed) ژبه ده چې د دې لپاره جوړه شوې چې
زده کوونکي وګوري پروګرام‌ژبې له دننه څنګه کار کوي. هر پروګرام له همغه لارې تېرېږي چې په IDE
کې یې لیدلای شئ:

```
سرچینه متن --لغوي تحلیل--> توکي --نحوي تحلیل--> نحوي ونه --معنايي تحلیل--> ډول لرونکې ونه + نښې
        --کوډ جوړونه--> بایټ کوډ (.thc) --مجازي ماشین--> پایله
```

د سرچینې فایلونه `.th` شاوند لري او UTF-8 متن دی. جوړ شوي بایټ کوډ فایلونه `.thc` لري.
پروګرامونه په **انګلیسي** یا **پښتو** لیکل کېدای شي (۱۱ برخه).

---

## ۱. لومړی پروګرام

```thunder
// ژبه: ps
// د سر کچې امرونه له پاسه کښته اجرا کېږي، په هره کرښه یو.
کرښه چاپ("سلام، تندر!")

جوړښت ټکی
    س: عدد
    ص: عدد

دنده مربع(ن: عدد): عدد
    راګرځه ن * ن

لپاره متغیر ش = ۱، ش <= ۳، ش = ش + ۱
    کرښه چاپ(ش، " مربع یې "، مربع(ش)، " ده، په "، ټکی(ش، مربع(ش)))
```

بلاکونه، لکه په پایتن کې، په **ننوتنه** ښودل کېږي: د دندې، «که»، «کنه»، «ترڅو»، «لپاره» یا
جوړښت برخه هغه کرښې دي چې یوه کچه (۴ تشې؛ ټب = ۴) ننوتې وي. قوسونه `{}` او جلا کوونکي
`;` نشته، او منطقي عملګرونه کلمې دي: `او`، `یا`، `نه`. IDE د بلاک پیلوونکې کرښې وروسته
پخپله ننوتنه ورکوي او له «راګرځه»، «ودرېږه»، «دوام» او «تېر» وروسته یې بېرته راوباسي.

## ۲. لغوي جوړښت

| توکی | بېلګې | یادښت |
| --- | --- | --- |
| تبصرې | `// تر کرښې پایه`، `/* بلاک */` | بلاک تبصرې نه ننوتل کېږي (nest). |
| نومونه | `شمېر`، `is_prime`، `_لنډ` | یو توری یا `_`، بیا توري، رقمونه یا `_`. د هرې لیکدود توري منل کېږي. |
| عددي ارزښتونه | `0`، `42`، `۴۲`، `0x2A`، `0b101010` | لسیز رقمونه ASCII، پښتو/فارسي (۰–۹) یا عربي (٠–٩) کېدای شي. `0x` شپاړس‌بنسټیز عدد پیلوي (رقمونه `0-9 a-f A-F`)، `0b` دوه‌بنسټیز (`0` او `1`): همغه ارزښت، داسې لیکل شوی چې بیټونه یې ښکاري (۵ برخه، بیټي عملګر، او د IDE «بیټونه» پاڼه). تر ټولو لوی ارزښت 2⁶³−1 دی. |
| اعشاري ارزښتونه | `۳٫۱۴`، `۰٫۵`، `3.14` | رقم، اعشاریه، رقم: `۱٫` او `٫۵` شمېرې نه دي، او `ټ.۰` لا هم د ټاپل توکی دی. د توان بڼه نشته. |
| متني ارزښتونه | `"متن"`، `«متن»` | باید په همغه کرښه پای ته ورسېږي. ترکیبونه: `\n` `\t` `\r` `\0` `\"` `\\` (او `\«` `\»`). |
| منطقي ارزښتونه | `رښتیا`، `درواغ` | |
| کلیدي کلمې | `متغیر ثابت دنده جوړښت که کنه ترڅو لپاره په ودرېږه دوام راګرځه تېر راوړه بهرنی` | خوندي دي. |
| د ډول نومونه | `عدد اعشاري منطقي متن` | خوندي دي. د جوړښت نومونه هم ډولونه دي. |
| عملګرونه | `+ - * / % == != < <= > >= & \| ^ ~ << >> = += -= *= /= %= .` او کلمې `او یا نه` | کلمې خوندي دي. |
| نښې | `( ) { } [ ] ، :` | پښتو پروګرامونه کامه `،` لیکي (`,` هم منل کېږي). |

هغه سمبولونه چې نورې ژبې یې کاروي خو تندر نه، له لارښوونې سره راپور کېږي: `&&` ← `او`،
`||` ← `یا`، `!س` ← `نه س` (خو `!=` پاتې دی)، او `;` ← `،` (لغوي تېروتنه `L002`).

**د کیبورډ توري:** عربي کیبورډونه ك (U+0643) او گ (U+06AF) ورکوي؛ تندر یې د لټون پر مهال
په پښتو ک (U+06A9) او ګ (U+06AB) اړوي، نو `كرښه چاپ` هم همغه `کرښه چاپ` ده.

تشې، ټبونه او د یونیکوډ د لوري نښې توکي بېلوي خو بل اثر نه لري. **د کرښې ماتېدل مهم دي**:
امر پای ته رسوي (۶ برخه).

## ۳. ډولونه

| ډول | ارزښتونه | اصلي (default) ارزښت |
| --- | --- | --- |
| `عدد` | ۶۴-بټه علامت لرونکي بشپړ عددونه | `۰` |
| `اعشاري` | اعشاري شمېرې: ۶۴-بټه ځنډېدونکې نقطه (IEEE 754) | `۰٫۰` |
| `منطقي` | `رښتیا`، `درواغ` | `درواغ` |
| `متن` | نه بدلېدونکې د یونیکوډ تورو لړۍ | `""` |
| `T[]` | لړۍ، لکه `عدد[]`، `متن[][]` | `[]` (تشه) |
| `(T1، T2، ...)` | ټاپلونه: ټاکلی شمېر ارزښتونه (۸ برخه) | د توکو اصلي ارزښتونه |
| `{K: V}` | نقشې؛ کیلۍ `عدد`، `منطقي` یا `متن` (۸ برخه) | `{}` (تشه) |
| د جوړښت نوم | د هغه جوړښت ارزښتونه (۸ برخه) | جوړښت چې ټولې برخې یې اصلي ارزښت لري |
| `دنده(T1، ...): R` | د دندو ارزښتونه، لکه `دنده(عدد): منطقي` (۷ برخه) | «بې دندې» (بلل یې د اجرا تېروتنه `R020` ده) |

هغه دنده چې د راګرځېدو ډول نلري هېڅ نه راګرځوي؛ پایله یې نشي کارېدای.

**پټ اړونې (implicit conversions) نشته.** `"س = " + ۵` د ډول تېروتنه ده؛ `متن کړه(۵)` ولیکئ،
یا کرښه چاپ ته څو دلیلونه ورکړئ.

لړۍ، نقشې او جوړښتونه **ماخذي ډولونه** دي: ورکول یا دندې ته لېږل یې همغه ارزښت شریکوي.
د خپلواکې کاپي لپاره `کاپي(ارزښت)` وکاروئ. ټاپلونه نه بدلېږي، نو د هغوی لپاره شریکول او
کاپي یو شی دی. لړۍ په `[۱، ۲، ۳]` یا `لړۍ(ن، ارزښت)` جوړېږي، نقشې په `{کیلۍ: ارزښت}`،
ټاپلونه په `(الف، ب)` او جوړښتونه د جوړښت د نوم په بللو. `new` نشته: حافظه پخپله
(د ماخذ شمېرنې سره) اداره کېږي؛ ۸ برخه وايي ولې دورونه (cycles) ناشوني دي.

## ۴. اعلانونه

```thunder
متغیر کال: عدد = ۲۰۲۶       // ډول + ارزښت
متغیر ژبه = "تندر"          // ډول له ارزښته معلومېږي
متغیر اونۍ: عدد             // بې ارزښته: له اصلي ارزښته (۰) پیلېږي
ثابت د_اونۍ_ورځې = ۷        // بیا نشي بدلېدای
```

«متغیر» بې ډوله او بې ارزښته نه منل کېږي (`P008`). «ثابت» تل ارزښت غواړي. د سر کچې
متغیرونه عمومي (global) دي؛ نور ځایي دي او د خپل بلاک تر پایه ژوند کوي. نه کارېدلی ځایي
متغیر خبرداری `W001` راوړي.

## ۵. افادې

عملګرونه له لوړ لومړیتوب نه ټیټ ته. ټول دوه-اړخیز عملګرونه له کیڼ نه ښي ته ګروپ کېږي.

| لومړیتوب | عملګرونه | د عملوندو ډولونه | پایله |
| --- | --- | --- | --- |
| ۱۳ | بلنه `f(...)`، لړ `a[i]` / `m[کیلۍ]`، برخه `s.برخه`، `t.0` | | |
| ۱۲ | `-س`، `~س` بیټي نفي | `عدد`، `اعشاري` (`~` یوازې `عدد`) | همغه ډول |
| ۱۱ | `*` `/` | دوه عددونه یا دوه اعشاري شمېرې | همغه ډول |
| ۱۱ | `%` | `عدد` | `عدد` |
| ۱۰ | `+` `-` | دوه شمېرې (او `متن + متن`) | همغه ډول / `متن` |
| ۹ | `<<` `>>` بیټي ښويېدنې | `عدد` (شمېر یې ۰..۶۳) | `عدد` |
| ۸ | `&` بیټي او (AND) | `عدد` | `عدد` |
| ۷ | `^` بیټي XOR | `عدد` | `عدد` |
| ۶ | `\|` بیټي یا (OR) | `عدد` | `عدد` |
| ۵ | `<` `<=` `>` `>=` | دوه شمېرې یا دوه متنونه | `منطقي` |
| ۴ | `==` `!=` | دوه یو-ډوله ارزښتونه (`عدد`، `اعشاري`، `منطقي`، `متن` یا ټاپل) | `منطقي` |
| ۳ | `نه س` | `منطقي` | `منطقي` |
| ۲ | `او` | `منطقي` | `منطقي` (لنډه لار) |
| ۱ | `یا` | `منطقي` | `منطقي` (لنډه لار) |

* د عدد وېش صفر ته نیژدې کېږي (`-۷ / ۲` = `-۳`)؛ خو `۷ / ۲٫۰` = `۳٫۵`. د `%` نښه د کیڼ
  عملوند نښه ده او یوازې د بشپړو عددونو لپاره تعریف شوی دی.
* **یوازې یوه ناڅرګنده اړونه شته:** هر چېرې چې اعشاري شمېره غوښتل کېږي، بشپړ عدد پراخېږي
  (`۱ + ۰٫۵`، `متغیر ش: اعشاري = ۲`، د دندې دلیلونه، `راګرځه`، او د لړۍ توکي `[۱، ۲٫۵]`).
  بله لار پرانیستې نه ده: اعشاري شمېره پخپله بشپړ عدد نه کېږي (`نیژدې کړه`، `کښته کړه`،
  `پورته کړه` یا `عدد کړه` وکاروئ).
* اعشاري شمېره په دوه بنسټ کې ساتل کېږي، نو `۰٫۱ + ۰٫۲ == ۰٫۳` درواغ دی؛ د یوې کوچنۍ
  زغمنې سره پرتله کړئ: `مطلق(الف - ب) < ۰٫۰۰۰۰۰۱`.
* له حد اوښتل، په صفر وېش (بشپړ یا اعشاري)، ډېره لویه اعشاري پایله (`R025`) او له حده بهر
  لړ شمېرې **د اجرا تېروتنې** دي. تندر ناجوت (undefined) چلند نه لري او هېڅکله بې‌پایه
  (infinity) یا NaN نه جوړوي.
* `s[i]` یو-توریز متن ورکوي. متنونه نه بدلېږي.
* متنونه د یونیکوډ د کوډ-ټکو په ترتیب پرتله کېږي؛ ټاپلونه توکی په توکی. لړۍ، نقشې او
  جوړښتونه په `==` نه پرتله کېږي.
* `الف او ب` ب یوازې هغه وخت ارزوي چې الف رښتیا وي؛ `الف یا ب` یوازې چې الف درواغ وي.
* «نه» د پرتلې نه ټیټ لومړیتوب لري (لکه پایتن): `نه الف == ب` یعنې `نه (الف == ب)`.
* **بیټونه.** بیټي عملګر د `عدد` پر ۶۴ بیټونو کار کوي (two's complement) او د پرتلو نه
  *لوړ* لومړیتوب لري (لکه پایتن)، نو `بیرغونه & نقاب != ۰` یعنې `(بیرغونه & نقاب) != ۰`.
  `~الف` د `-الف - ۱` سره برابر دی. له ۰..۶۳ بهر د ښويېدو شمېر د اجرا تېروتنه ده؛ `<<`
  له سره وتلي بیټونه غورځوي، او `>>` نښه ساتي (`-۱۶ >> ۲` = `-۴`). د IDE د «بیټونه» پاڼه
  (د پردې شاته) هره دا عملیه بیټ په بیټ ښيي.

## ۶. امرونه، د کرښې ماتېدل او ننوتنه

امر د خپلې کرښې په پای پای ته رسېږي؛ جلا کوونکی نشته:

```thunder
متغیر س = ۱
متغیر ص = ۲
س = س + ص
```

که کرښه د قوسونو دننه یا سم له عملګر (`او`، `یا`، `نه` هم) وروسته پای شي، امر بلې کرښې ته
دوام کوي:

```thunder
متغیر سم = پلنوالی > ۰ او
    لوړوالی > ۰
کرښه چاپ("مساحت: "،
        پلنوالی * لوړوالی)
```

هغه عملګر چې کرښه پرې **پیل** شي، تل نوی امر دی. هر امر خپله کرښه لري؛ دوه امرونه په
یوه کرښه نحوي تېروتنه `P010` ده. «راګرځه» د کرښې په پای بې ارزښته راګرځي.

**بلاکونه ننوتل کېږي.** هغه کرښه چې له مخکینۍ ډېره ننوتې وي بلاک پرانیزي؛ بلاک هلته
پای ته رسېږي چې ننوتنه بېرته راکمه شي (لغوي تحلیل دا بدلونونه د `INDENT`/`DEDENT` توکو
په بڼه ورکوي، چې د «توکي» پاڼه کې یې لیدلای شئ). «تېر» هغه امر دی چې هېڅ نه کوي،
د قصداً تش بلاک لپاره. له یوې کچې کمه ننوتنه چې هېڅ بلاک ورسره سمون نه خوري تېروتنه
`L008` ده؛ بې‌ځایه ننوتنه `P013` ده. شرطونه قوسونو ته اړتیا نلري.

```thunder
س = س + ۱                // ارزښت ورکول
س += ۱                   // همدا، خو لنډ؛ همدا ډول -= *= /= %=
ارزښتونه_یې[ش] = ۰
ارزښتونه_یې[ش] += ۱۰     // ارزښتونه_یې[ش] او ش هر یو یوازې یو ځل ارزول کېږي
ټ.س = ۳
کرښه چاپ(س)              // د افادې امر (معمولاً بلنه)

که س > ۰                 // شرط باید منطقي وي؛ برخه یې ننوتې ده
    کرښه چاپ("مثبت")
کنه که س < ۰
    کرښه چاپ("منفي")
کنه
    کرښه چاپ("صفر")

ترڅو س > ۰
    س = س - ۱

لپاره متغیر ش = ۰، ش < ۱۰، ش = ش + ۱    // پیل، شرط، ګام - په کامو بېل
    که ش == ۳
        دوام           // ګام ته ورټوپ کړه (ش = ش + ۱)
    که ش == ۷
        ودرېږه         // تکرار پرېږده
```

ارزښت ورکول امر دی، نه افاده، نو `که س = ۱` نحوي تېروتنه ده.

**«لپاره ... په»** یوه ټولګه ګرځوي: د لړۍ توکي، د متن توري، یا د نقشې **کیلۍ**
(`توکي(نقشه)` د (کیلۍ، ارزښت) جوړې ورکوي). د تکرار متغیر پخپله تکرار اعلانوي او یوازې
د هغه دننه شته؛ `ودرېږه` او `دوام` لکه په هر بل تکرار کې کار کوي. د ټولګې افاده یوازې یو
ځل، له لومړي دور نه مخکې، ارزول کېږي، خو ځای په هر دور کې د ټولګې له **اوسني** اوږدوالي
سره پرتله کېږي؛ نو که د ګرځولو پر مهال لړۍ ته څه ورزیات یا ترې لیرې کړئ، تکرار بدلېږي —
په دې حال کې `کاپي(ل)` وګرځوئ. (د نقشې ګرځول تل خوندي دي: کیلۍ له لومړي دور نه مخکې
اخیستل کېږي.) په قوسونو کې څو نومونه یو ټاپل وېشي:

```thunder
لپاره نمره په نمرې
    ټولټال += نمره

لپاره (ځای، نوم) په شمېره ورکړه(نومونه)
    کرښه چاپ(ځای، ": "، نوم)
```

**لنډ ورکول.** `س += ا` د `س = س + ا` مانا لري؛ همدا ډول `-=` `*=` `/=` `%=`. کیڼ اړخ
متغیر، د لړۍ یا نقشې توکی، یا د جوړښت برخه کېدای شي، او **یوازې یو ځل** ارزول کېږي.
`+=` متنونه هم سره نښلوي.

### بهرنۍ دندې (++C)

`راوړه بهرنی "mathx"` یو ++C کتابتون راوړي، او `بهرنی دنده` وايي چې څه لري:

```thunder
راوړه بهرنی "mathx"
بهرنی دنده fast_hypot(س: اعشاري، ص: اعشاري): اعشاري
کرښه چاپ(fast_hypot(۳، ۴))                      // ۵٫۰
```

بهرنۍ دنده لکه هره بله دنده کتل کېږي او بلل کېږي، خو بدن یې د ماشین کوډ دی. یوازې
`عدد`، `اعشاري`، `منطقي`، `متن` او د بیا-بلنې دندې (`دنده(...)`) له پولې اوړي، او ++C
کولای شي د تندر دندې بیا وبلي. بشپړ بیان: [د بهرني اړیکي لارښود](../native.md)،
او یوه چلېدونکې بېلګه په `lib/native/` کې.

## ۷. دندې

```thunder
دنده لوی_وېشونکی(الف: عدد، ب: عدد): عدد
    ترڅو ب != ۰
        متغیر لنډ = ب
        ب = الف % ب
        الف = لنډ
    راګرځه الف

دنده سلام(نوم: متن)      // بې د راګرځېدو ډوله: هېڅ نه راګرځوي
    کرښه چاپ("سلام، "، نوم)
```

* دندې یوازې د سر کچه کې اعلانېږي او د اعلان له کرښې مخکې هم بلل کېدای شي.
* پارامټرونه لکه ځایي متغیرونه دي. `عدد`، `منطقي` او `متن` کاپي کېږي؛ لړۍ او جوړښتونه شریکېږي.
* د راګرځېدو ډول لرونکې دندې هره لار باید په «راګرځه ارزښت» پای شي.
* تکراري بلنې منل کېږي؛ VM د بلنو ژوروالی محدودوي (اصلي حد ۱۰۰۰۰).
* **اصلي (main):** که پروګرام `دنده اصلي()` (یا `main()`) ولري، د سر کچې له امرونو وروسته بلل کېږي.

### دندې د ارزښت په توګه

د دندې نوم بې قوسونو یو **ارزښت** دی چې ساتل کېدای، لېږل کېدای او بلل کېدای شي:

```thunder
دنده دوه_چنده(ن: عدد): عدد
    راګرځه ن * ۲

متغیر ف: دنده(عدد): عدد = دوه_چنده
کرښه چاپ(ف(۲۱))                          // ۴۲
کرښه چاپ(پر هر یو([۱، ۲، ۳]، دوه_چنده))   // [۲، ۴، ۶]
```

هره هغه افاده چې ارزښت یې دنده وي بلل کېدای شي: `چلوونکي[ش](س)`. ننوتې (nested) دندې نشته،
نو closureونه هم نشته. نور په [د کتابتون لارښود](library.md) ۷ برخه کې.

### ماډیولونه

`راوړه "lib/geometry"` هر هغه څه چې فایل `lib/geometry.th` یې اعلانوي دلته د کارونې وړ کوي.
`راوړه سیسټم` او `راوړه ګرافیک` دنني ماډیولونه راوړي. وګورئ:
[د کتابتون لارښود](library.md) ۲ برخه او [د ګرافیک لارښود](graphics.md).

## ۸. جوړښتونه، ټاپلونه او نقشې

```thunder
جوړښت ټکی
    س: عدد
    ص: عدد

متغیر مبدا = ټکی(۰، ۰)            // برخې په ترتیب
متغیر هدف = ټکی(ص: ۳، س: ۷)       // یا په نوم؛ پاتې برخې اصلي ارزښت اخلي
هدف.س = ۸                          // برخې بدلېدای شي
```

جوړښتونه ماخذونه دي (لکه لړۍ)؛ `کاپي()` خپلواکه (ژوره) کاپي جوړوي. جوړښت نشي کولای ځان
(مستقیم یا د بلې لارې) ولري (`S030`)، نو هر ارزښت محدود پاتې کېږي او د ماخذ شمېرنه هېڅکله
دور نه جوړوي. `کتنه()` او `وښایه()` جوړښت برخه په برخه، له ډولونو سره ښيي.

### ټاپلونه

```thunder
متغیر جوړه = (۱، "یو")             // ډول: (عدد، متن)
کرښه چاپ(جوړه.0، جوړه.1)
متغیر (شمېره، کلمه) = جوړه         // خلاصول
```

ټاپلونه نه بدلېږي، توکی په توکی پرتله کېږي او لږ تر لږه دوه توکي غواړي (`P015`).

### نقشې

```thunder
متغیر عمرونه = {"ناصر": ۴۰، "ساره": ۷}    // ډول: {متن: عدد}
عمرونه["علي"] = ۱۲
کرښه چاپ(عمرونه["ناصر"])            // نشته کیلۍ د اجرا تېروتنه R011 ده
کرښه چاپ(لري(عمرونه، "عمر"))        // درواغ
```

کیلۍ `عدد`، `منطقي` یا `متن` کېدای شي. نقشې د **ورزیاتېدو ترتیب** ساتي؛ `کیلۍ(م)` او
`ارزښتونه(م)` په همغه ترتیب لړۍ راګرځوي. تشه نقشه د ډول ښودنې ته اړتیا لري (`S038`).

## ۹. دننۍ دندې

تل شته: `چاپ`، `کرښه چاپ`، `اوږدوالی`، `متن کړه`، `عدد کړه`، `لړۍ`، `کتنه`، `وښایه`، `کاپي`،
`لري`، `لیرې کړه`، `کیلۍ`، `ارزښتونه` — او د **کتابتون** دندې: ننوت (`ولوله`، `د ننوت پای`)،
متن (`د متن برخه`، `پاک کړه`، `لوی توري کړه`، `وېشه`، `یو ځای کړه`، `بدل کړه` ...)، جوړې
(`لومړی`، `دوهم`، `ځای بدلول`، `جوړې کړه`، `شمېره ورکړه`، `توکي`)، لړۍ (`ورزیات کړه`،
`وروستی واخله`، `ننباسه`، `ټوټه`، `ترتیب کړه`، `واټن`، `مجموعه`، `پر هر یو`، `چاڼ کړه`،
`راټول کړه` ...)، شمېرې او ریاضي (`اعشاري کړه`، `شمېره ده`، `مطلق`، `کمینه`، `اعظمه`،
`نیژدې کړه`، `کښته کړه`، `پورته کړه`، `جذر`، `توان`، `نمايي`، `لوګارتم`، `جیب`،
`تتمیم جیب`، `ظل`، `پای`، `تصادفي`)، او تصادفي عددونه (`تصادفي عدد`، `تصادفي بنسټ`). بشپړ لړ:
[د کتابتون لارښود](library.md).

د **سیسټم** ماډیول (فایلونه، امرونه، وخت) او د **ګرافیک** ماډیول (کښل، حرکت، تڼۍ او موږک)
یوازې له راوړلو وروسته شته؛ له هغه پرته نومونه یې ازاد دي.

## ۱۰. تېروتنې

هر پړاو خپلې تېروتنې راپوروي؛ هر پیغام ثابت کوډ لري:

| پړاو | کوډونه | بېلګې |
| --- | --- | --- |
| لغوي تحلیل | `L001`–`L009` | ناڅاپي توری، نه پای شوی متن، ډېر لوی عدد، ناسمه ننوتنه |
| نحوي تحلیل | `P001`–`P016` | `تمه د ')'`، دوه امرونه په یوه کرښه (`P010`)، ورک ننوتی بلاک (`P012`) |
| معنايي تحلیل | `S001`–`S055` | نااعلان نوم، د ډول ناسمون، ورک ماډیول (`S045`)، بې `راوړه سیسټم` د سیسټم دنده (`S049`)، «لپاره ... په» پر داسې ارزښت چې ټولګه نه وي (`S052`) |
| خبرداري | `W001`–`W003` | نه کارېدلی متغیر، نه رسېدونکی کوډ |
| د اجرا | `R001`–`R030` | په صفر وېش، له حد اوښتل، له حده بهر لړ شمېره، له حده بهر واټن (`R012`)، ډېره لویه اعشاري پایله (`R025`)، د منفي عدد جذر (`R027`) |

جوړول په لومړي ناکام پړاو درېږي. نحوي تحلیل له تېروتنې رغېږي، نو په یو ځل کې څو
تېروتنې راپورولای شي.

## ۱۱. پروګرامونه په پښتو

د ژبې هره کلمه پښتو بڼه لري او پښتو پروګرام پایلې هم په پښتو چاپوي. ژبه د لومړۍ کرښې
لارښوونه ټاکي: `// ژبه: ps` (یا `thunderc --lang ps`).

| انګلیسي | پښتو | انګلیسي | پښتو |
| --- | --- | --- | --- |
| `var` | `متغیر` | `int` | `عدد` |
| `in` (په «لپاره ... په» کې) | `په` | `float` | `اعشاري` |
| `native` (++C) | `بهرنی` | | |
| `const` | `ثابت` | `bool` | `منطقي` |
| `func` | `دنده` | `string` | `متن` |
| `struct` | `جوړښت` | `true` / `false` | `رښتیا` / `درواغ` |
| `if` / `else` | `که` / `کنه` | `print` / `println` | `چاپ` / `کرښه چاپ` |
| `while` | `ترڅو` | `len` | `اوږدوالی` |
| `for` | `لپاره` | `str` / `to_int` | `متن کړه` / `عدد کړه` |
| `break` | `ودرېږه` | `array` | `لړۍ` |
| `sqrt` / `pow` | `جذر` / `توان` | `to_float` | `اعشاري کړه` |
| `min` / `max` | `کمینه` / `اعظمه` | `abs` / `round` | `مطلق` / `نیژدې کړه` |
| `continue` | `دوام` | `inspect` / `dump` | `کتنه` / `وښایه` |
| `return` | `راګرځه` | `copy` | `کاپي` |
| `pass` | `تېر` | `has` / `remove` | `لري` / `لیرې کړه` |
| `import` | `راوړه` | `keys` / `values` | `کیلۍ` / `ارزښتونه` |
| `and` / `or` / `not` | `او` / `یا` / `نه` | `main` (دنده) | `اصلي` |

* **څو-کلمه‌يي نومونه** (`کرښه چاپ`، `متن کړه`، ...) د عادي پښتو په څېر په تشه لیکل کېږي؛
  لغوي تحلیل یې یو توکی کوي.
* **رقمونه:** `۰۱۲۳۴۵۶۷۸۹` (ASCII او عربي `٠١٢` هم منل کېږي). اعشاري شمېرې د عربي
  اعشاریې `٫` سره لیکل کېږي (`۳٫۱۴`)؛ `.` هم منل کېږي او پایلې په `٫` چاپېږي.
* **نښې او قوسونه:** پښتو پروګرامونه په کامه `،` بېلوي (په `لپاره` کې هم) او `"..."` قوسونه
  کاروي. ASCII کامه، `٪`، `×`/`÷` او `«...»` هم منل کېږي؛ ژباړن غوره بڼې (`،`، `%`، `"`) لیکي.
* **نومونه:** د سر دنده `اصلي` (یا `main`) نومېدای شي؛ `کښېکښل شوې تڼۍ()` تڼۍ په پښتو نوموي
  («کیڼ»، «ښي»، ...). یو-توریز نومونه د ریاضي د عربي-لیکدود دود تعقیبوي: `ن` د n لپاره،
  `س`/`ص` د x/y، `الف`/`ب` د a/b.
* **پایله:** پښتو پروګرام عددونه په پښتو رقمونو، منطقي ارزښتونه `رښتیا`/`درواغ`، او د لړیو
  دننه `«»` قوسونه او `، ` بېلوونکي چاپوي. **منفي عددونه** په هر لیکدود کې علامت-مخکې لیکل
  کېږي: `-۳` (IDE یې همداسې ښيي — د ښي-نه-کیڼ لوستلو استثنا).
* **پیغامونه:** د جوړونکي او اجرا ټولې تېروتنې په پښتو دي.
* **د لوستلو لوری:** پښتو پروګرام توکی په توکی له ښي نه کیڼ ته لوستل کېږي؛ په لاتیني
  تورو نومونه خپل لوری ساتي. (README، «Right-to-left programs».)

```thunder
// ژبه: ps
جوړښت ټکی
    س: عدد
    ص: عدد

دنده جمع(الف: عدد، ب: عدد): عدد
    راګرځه الف + ب

متغیر ټ = ټکی(ص: ۵، س: ۱۰)
که ټ.س > ۰ او نه ټ.ص == ۰
    کرښه چاپ(جمع(۲۰، ۲۲)، " "، ټ)      // ۴۲ ټکی(س: ۱۰، ص: ۵)
```

**د پروګرامونو ژباړل.** `thunderc --translate ps program.th` پروګرام له ټولو کلیدي کلمو،
دننیو دندو، رقمونو او کامو سره په پښتو چاپوي؛ `--translate en` یې بېرته اړوي، او د IDE
«ژباړه» تڼۍ همدا کار کوي. تبصرې او ستاسو خپل نومونه نه بدلېږي؛ هغه نوم چې په موخنه ژبه
کې خوندي وي `_` ورپسې اخلي.

## ۱۲. ګرامر (EBNF)

ګرامر د انګلیسي سند ۱۲ برخه کې دی ([docs/language.md](../language.md#12-grammar-ebnf))؛
د کلیدي کلمو پښتو بڼې پورته جدول ورکوي. لنډیز: امرونه د کرښې په پای، بلاکونه د INDENT/DEDENT
ترمنځ، افادې د Pratt الګوریتم په لومړیتوبونو (۵ برخه)، او د `لپاره` سرلیک درې برخې په کامو بېلې دي.

**نحوي تحلیل څنګه کار کوي.** امرونه په تکراري-کښته (recursive descent) تحلیل کېږي: د ګرامر
هره قاعده په `src/core/parser.cpp` کې یوه دنده ده. افادې د **Pratt** د لومړیتوب-ځواک الګوریتم
سره تحلیلېږي: هر عملګر «تړلو ځواک» لري او تحلیل تر هغه کیڼ عملوند غځوي چې راتلونکی عملګر
ټینګ تړي. له قوسونو بهر د کرښې ماتېدل دا غځېدل دروي — له همدې امله امرونه بې جلا کوونکو
پای ته رسېږي.

## ۱۳. د پراختیا لپاره ډیزاین

* **نورې طبیعي ژبې.** لغوي تحلیل هېڅکله د کلیدي کلمې له متن سره نه پرتله کوي: کلمې، نښې،
  رقمونه او قوسونه له **ژبنۍ بستې** (`src/core/language_pack.cpp`؛ پښتو په
  `src/core/language_pashto.cpp`) لټول کېږي. بسته دا هم ټاکي چې ارزښتونه څنګه چاپ شي او
  د هر پیغام متن څه وي. په پیغامونو کې ستنې توري شمېري، نه بایټونه، نو د عربي-لیکدود
  متن ځایونه سم پاتې کېږي.
* **نوي ډولونه او عملګرونه.** ډولونه `Type` بیانوي (`include/thunder/types.hpp`)، عملګرونه
  د تړلو-ځواک جدول، او لارښوونې په `include/thunder/bytecode.hpp` کې یو جدول.
