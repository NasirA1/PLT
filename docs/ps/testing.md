# د ازموینې لارښود

`راوړه "testing"` پروګرام ته د ازموینو یو کوچنی چوکاټ راوړي، د دوو ټولګو په بڼه: **`ازموینه`**
ازموینې چلوي او **`تمه`** وايي چې څه باید رښتیا وي. هره ازموینه د یوې دندې په توګه ولیکئ، له
نوم سره یې `ازموینه.وچلوه()` ته ورکړئ، د `تمه.برابر()` او ملګرو سره یې ووایئ چې څه باید
رښتیا وي، او د `ازموینه.پای_ته_ورسوه()` سره پای ته ورسوئ. هغه ازموینې چې سره تړاو لري په خپل
یوه ټولګي کې ځي، چې د ازموینو یوه **ډله** (suite) یې جوړوي. په فایل کې هېڅ بهرنی نشته - دا
ساده تندر دی، په [`lib/thunder/ps/testing.th`](../../lib/thunder/ps/testing.th) کې، د لوستلو
لپاره لیکل شوی. انګلیسي فایل ([`lib/thunder/en/testing.th`](../../lib/thunder/en/testing.th))
همدا چوکاټ له انګلیسي نومونو سره دی؛ دواړه پخپله، د اوزارو تر څنګ، موندل کېږي.

**ویې آزمویئ:** [`samples/ps/28_testing.th`](../../samples/ps/28_testing.th) دوه کوچنۍ دندې
په دوو ډلو کې ازمویي (انګلیسي: [`samples/en/28_testing.th`](../../samples/en/28_testing.th))؛
د IDE د بېلګو په لړ کې د *۲۸ - ازموینه* په نوم ده.

## د ازموینو فایل

```thunder
# ژبه: ps
راوړه "testing"

# هغه کوډ چې ازمویل کېږي.
دنده تر_ټولو_لوی(ارزښتونه: عدد[]): عدد
    متغیر غوره = ارزښتونه[۰]
    تکرار ارزښت په ارزښتونه
        که ارزښت > غوره
            غوره = ارزښت
    راګرځه غوره

دنده پالیندروم_دی(کلمه: متن): منطقي
    متغیر اړول_شوې = ""
    تکرار متغیر ش = اوږدوالی(کلمه) - ۱، ش >= ۰، ش = ش - ۱
        اړول_شوې = اړول_شوې + کلمه[ش]
    راګرځه اړول_شوې == کلمه

# ازموینې. هره یوه ساده دنده ده، بې پارامترونو؛ هر ټولګی یوه ډله ده.
ټولګی شمېرې
    دنده د_لړۍ_تر_ټولو_لوی()
        تمه.برابر(تر_ټولو_لوی([۳، ۹، ۲])، ۹)
        تمه.برابر(تر_ټولو_لوی([-۵])، -۵)

    دنده اعشاري_په_زغم_پرتله_کېږي()
        تمه.نږدې(۱.۰ / ۳.۰، ۰.۳۳۳۳، ۰.۰۰۱)
        تمه.دا_وي(اوږدوالی("الف") == ۳، "ستاسې خپل پیغام")

ټولګی متنونه_ازموینې
    دنده پالیندرومونه()
        تمه.رښتیا_وي(پالیندروم_دی("level"))
        تمه.درواغ_وي(پالیندروم_دی("تندر"))

    دنده لړۍ_د_توکو_له_مخې_پرتله_کېږي()
        متغیر مربعونه: عدد[] = []
        تکرار ن په [۱، ۲، ۳]
            ورزیات کړه(مربعونه، ن * ن)
        تمه.برابر(مربعونه، [۱، ۴، ۹])
        تمه.نابرابر(مربعونه، [۱، ۲، ۳])

ازموینه.وچلوه("د لړۍ تر ټولو لوی"، شمېرې.د_لړۍ_تر_ټولو_لوی)
ازموینه.وچلوه("اعشاري په زغم پرتله کېږي"، شمېرې.اعشاري_په_زغم_پرتله_کېږي)
ازموینه.وچلوه("پالیندرومونه"، متنونه_ازموینې.پالیندرومونه)
ازموینه.وچلوه("لړۍ د توکو له مخې پرتله کېږي"، متنونه_ازموینې.لړۍ_د_توکو_له_مخې_پرتله_کېږي)
ازموینه.پای_ته_ورسوه()
```

چلول یې د هرې ډلې نوم، د هغې لاندې هرې ازموینې ته یوه کرښه، او یو لنډیز چاپوي - لومړی د
هرې ډلې شمېرې، بیا ټولټال:

```
شمېرې
  ✓ د لړۍ تر ټولو لوی
  ✓ اعشاري په زغم پرتله کېږي
متنونه_ازموینې
  ✓ پالیندرومونه
  ✓ لړۍ د توکو له مخې پرتله کېږي
شمېرې: ۲ تېرې شوې، ۰ ناکامې
متنونه_ازموینې: ۲ تېرې شوې، ۰ ناکامې
۴ تېرې شوې، ۰ ناکامې
```

هغه ازموینه چې تمه یې پوره نه شي پر ځای یې چاپوي چې څه ناسم شول، او لنډیز پروګرام د **وتلو
کوډ ۱** سره پای ته رسوي، نو یو سکریپټ - یا یو سمونګر - پوهېدلی شي. که په `تر_ټولو_لوی` کې
تېروتنه وي (د `>` پر ځای `<`):

```
شمېرې
  ✗ د لړۍ تر ټولو لوی: تمه ۹ وه، ۲ ترلاسه شو
  ✓ اعشاري په زغم پرتله کېږي
متنونه_ازموینې
  ✓ پالیندرومونه
  ✓ لړۍ د توکو له مخې پرتله کېږي
شمېرې: ۱ تېرې شوې، ۱ ناکامې
متنونه_ازموینې: ۲ تېرې شوې، ۰ ناکامې
۳ تېرې شوې، ۱ ناکامې
```

ازموینه هره هغه دنده ده چې پارامترونه نه لري؛ `ازموینه.وچلوه()` هماغه شېبه یې، د ورکړل شوي
نوم لاندې، چلوي، نو ازموینې په هغه ترتیب چلېږي چې لیکل شوې دي. د ازموینې دنده اړ نه ده چې په
ټولګي کې وي: `ازموینه.وچلوه("جمع سمه ده"، جمع_سمه_ده)` د سر کچې `دنده جمع_سمه_ده()` سره
`✓ جمع سمه ده` چاپوي، پرته له ډلې او پرته له ننوتلو.

## دندې

ټولګی `ازموینه`:

| دنده | څه کوي |
| --- | --- |
| `ازموینه.وچلوه(نوم: متن، بدنه: دنده())` | دنده «بدنه» د «نوم» په نوم ازموینه چلوي: `✓ نوم` که هره تمه یې پوره شوه، `✗ نوم: پیغام` د هرې هغې لپاره چې پوره نه شوه. کله چې «بدنه» د یوه ټولګي وي، ازموینه د هغې ډلې ده. |
| `ازموینه.ناکامه_کړه(پیغام: متن)` | اوسنۍ ازموینه د خپل پیغام سره ناکامه کوي. |
| `ازموینه.پای_ته_ورسوه()` | د هرې ډلې `ډله: N تېرې شوې، M ناکامې` چاپوي (کله چې له یوې زیاتې ډلې وي)، بیا `N تېرې شوې، M ناکامې`، او که کومه ازموینه ناکامه وي پروګرام د وتلو کوډ ۱ سره پای ته رسوي. وروستۍ یې وبولئ. |
| `ازموینه.د_ټولګي_نوم(بدنه: دنده()): متن` | هغه ډله چې د ازموینې دنده پکې ده: د هغه ټولګي نوم چې دنده پکې اعلان شوې، `""` د هغې دندې لپاره چې په هېڅ ټولګي کې نه وي. |

ټولګی `تمه`:

| دنده | څه کوي |
| --- | --- |
| `تمه.دا_وي(شرط: منطقي، پیغام: متن)` | اوسنۍ ازموینه د «پیغام» سره ناکامه کوي کله چې «شرط» درواغ وي. نورې له همدې سره لیکل شوې دي. |
| `تمه.رښتیا_وي(شرط: منطقي)` | ناکامه، مګر دا چې شرط رښتیا وي. |
| `تمه.درواغ_وي(شرط: منطقي)` | ناکامه، مګر دا چې شرط درواغ وي. |
| `تمه.برابر<ت>(ترلاسه: ت، تمه_شوی: ت)` | ناکامه، مګر دا چې دواړه یو شان چاپ شي - نو لړۍ، ټاپلونه، نقشې او جوړښتونه د خپلو توکو له مخې پرتله کېږي؛ پیغام دواړه ښيي: `تمه [۱، ۴، ۹] وه، [۱، ۴، ۸] ترلاسه شو`. |
| `تمه.نابرابر<ت>(ترلاسه: ت، ناغوښتل: ت)` | ناکامه کله چې دواړه یو شان چاپ شي. |
| `تمه.نږدې(ترلاسه: اعشاري، تمه_شوی: اعشاري، زغم: اعشاري)` | د اعشاري شمېرو لپاره، چې لږ کله بشپړ برابرې وي: ناکامه، مګر دا چې «ترلاسه» له «تمه_شوی» څخه په «زغم» کې وي. |

هره ناکامه تمه خپله `✗` کرښه چاپوي، نو هغه ازموینه چې درې ناسمې تمې لري درې واړه راپور
کوي؛ ازموینه یو ځل ناکامه شمېرل کېږي.

`ازموینه` او `تمه` د ټولګو نومونه دي، نو په هغه پروګرام کې چې `"testing"` راوړي د متغیرونو یا
دندو نومونه نشي کېدای (تېروتنه `S065`).

## د ازموینو ډلې

ډله د **ازموینو یو ټولګی** دی. هغه ازموینې چې سره تړاو لري په یوه ټولګي کې کېږدئ، او د ټولګي
له نوم سره یې `ازموینه.وچلوه` ته ورکړئ - `ازموینه.وچلوه("پالیندرومونه"،
متنونه_ازموینې.پالیندرومونه)`. چوکاټ له دندې پوښتي چې په کوم ټولګي کې اعلان شوې (`د دندې نوم`
کاروي، چې `"متنونه_ازموینې.پالیندرومونه"` ورکوي)، او هغه ټولګی د ازموینې ډله ده:

* **نوم یې د ازموینو پورته چاپېږي**، چې دوه تشې ننوتې چاپېږي؛ د یوې ډلې ازموینې یوه پسې بله
  وچلوئ، که نه نو کله چې بېرته راشي نوم یې بیا چاپېږي؛
* **شمېرې یې بېلې ساتل کېږي**: کله چې پروګرام له یوې زیاتې ډلې ولري، `ازموینه.پای_ته_ورسوه()`
  له ټولټال مخکې د هرې یوې لپاره `ډله: N تېرې شوې، M ناکامې` چاپوي، په هغه ترتیب چې لومړی
  چلېدلې؛
* **یوازې هم چلېدای شي**، کله چې یې نوم پر امر کرښه ورکړئ (راتلونکې برخه).

د ازموینې خپل نوم هماغه دی چې `ازموینه.وچلوه` ته ورکړل شو؛ ډله یې یوازې ډلبندي کوي. په
ټولګي کې ازموینې کولای شي د ټولګي ځانګړې مرستندویې (`_نوم`) او متغیرونه وکاروي، لکه هر غړی.

```thunder
# ژبه: ps
راوړه "testing"

ټولګی حساب
    دنده جمع_سمه_ده()
        تمه.برابر(۲ + ۲، ۴)

    دنده وېش()
        که ۷ / ۲ != ۳
            ازموینه.ناکامه_کړه("بشپړ عددونه باید صفر ته نږدې شي")

ازموینه.وچلوه("جمع سمه ده"، حساب.جمع_سمه_ده)     # "حساب" د "  ✓ جمع سمه ده" پورته چاپوي
ازموینه.وچلوه("وېش"، حساب.وېش)
ازموینه.پای_ته_ورسوه()
```

## د ځینو ازموینو چلول

د پروګرام دلیلونه ازموینې ټاکي، او نورې نه پیلېږي. بې دلیلونو هره ازموینه چلېږي. دلیل کېدای
شي:

| دلیل | څه چلوي |
| --- | --- |
| د ازموینې نوم: `"د لړۍ تر ټولو لوی"` | د هغه نوم هره ازموینه، په هره ډله کې چې وي |
| د ډلې نوم: `متنونه_ازموینې` | د هغې ډلې هره ازموینه |
| `ډله/ازموینه`: `"شمېرې/د لړۍ تر ټولو لوی"` | د هغې یوې ډلې همدا یوه ازموینه |

څو دلیلونه، څو انتخابونه:

```
$ thundervm 28_testing.thc متنونه_ازموینې
متنونه_ازموینې
  ✓ پالیندرومونه
  ✓ لړۍ د توکو له مخې پرتله کېږي
۲ تېرې شوې، ۰ ناکامې
$ thundervm 28_testing.thc "شمېرې/د لړۍ تر ټولو لوی" پالیندرومونه
شمېرې
  ✓ د لړۍ تر ټولو لوی
متنونه_ازموینې
  ✓ پالیندرومونه
شمېرې: ۱ تېرې شوې، ۰ ناکامې
متنونه_ازموینې: ۱ تېرې شوې، ۰ ناکامې
۲ تېرې شوې، ۰ ناکامې
```

VS Code د خپل د ازموینو لړ (Test Explorer) له لارې یوه ازموینه یا یوه ډله همداسې چلوي (لاندې)،
او یو سکریپټ هغه یوه بیا چلوي چې ناکامه شوه.

## څه نشي کولای

چوکاټ د تندر شاوخوا سل کرښې دی، او په قصد کوچنی ساتل کېږي.

* **ډلې هو؛ ډله په ډله کې نه.** ډله یو ټولګی دی، او ټولګي یو په بل کې نه ځي، نو په ډلو کې
  ډلې نشته. د پیل یا پای چمتو کولو ګام هم نشته: د هرې ازموینې په پیل کې خپله یوه دنده وبولئ.
* **د تېروتنو نیول نشته.** په تندر کې استثناوې نشته: د ازموینې دننه د اجرا تېروتنه (له پایه
  اخوا شاخص، پر صفر وېش) ټول پروګرام د معمول راپور سره دروي، لکه هر بل ځای - وروسته ازموینې
  نه چلېږي. نو ازموینه نشي کتلای چې یو څه *ناکامېږي*؛ پر ځای یې هغه شرط وازمویئ چې ناکامي به
  راوړي (`تمه.رښتیا_وي(اوږدوالی(ارزښتونه) > ۰)`).
* **جعلي بدیلونه (mocks) نشته.** هېڅ لاره نشته چې د یوې ازموینې لپاره یوه دنده، فایل یا ساکټ
  بدل کړئ. هغې دندې ته چې ازمویل کېږي هغه څه ورکړئ چې اړتیا ورته لري - د دندې ارزښت، د فایل
  پر ځای متن - نو ازموینه ورته یو ساده شی ورکولای شي.

## په IDE او VS Code کې

* **د تندر IDE:** فایل وچلوئ. ډلې او د ✓ او ✗ کرښې د وتنې پاڼه کې راځي؛ د حالت پټه د وتلو
  کوډ ښيي.
* **VS Code:** هغه فایل چې `"testing"` راوړي د **ازموینو لړ** (Test Explorer، په فعالیت پټه
  کې د کیمیا بوتل) کې د یوې ونې په بڼه راځي: **فایل ← ډله ← ازموینه**، د هرې `ازموینه.وچلوه(...)`
  لپاره یوه ننوتنه (هغه ازموینه چې په هېڅ ټولګي کې نه وي نېغ د خپل فایل لاندې ځي). سمونګر د
  هرې `ازموینه.وچلوه` تر څنګ په ګټر کې د چلولو تڼۍ ښيي. یوه ازموینه، یوه ډله، یو فایل یا ټول
  وچلوئ؛ ناکامۍ خپل پیغام په کرښه کې او د ازموینو د پایلو لید کې ښيي. د سمونګر د سرلیک پټې
  **Run Tests in This File** تڼۍ (او د دواړو سمونګرو د شرایطو مینو کې، د ښي-څخه-کیڼ سمونګر په
  ګډون) مخکښ فایل چلوي؛ **Thunder: Run All Tests** د کاري ځای ټول د ازموینو فایلونه چلوي. د
  *Debug* پروفایل ټاکل شوې ازموینې د مرستیال (debugger) لاندې، له ټولو ودرېدو ټکو سره، چلوي.
* **امر کرښه:** `thunderc tests.th && thundervm tests.thc`؛ د وتلو کوډ وايي چې ټول تېر شول که نه.
