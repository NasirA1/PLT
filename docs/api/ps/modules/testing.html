    testing

    راوړه "testing"

    د ازموینو یو کوچنی چوکاټ، پخپله په تندر کې لیکل شوی (docs/ps/testing.md)

    راوړه "testing" ولیکئ، هره ازموینه د یوې دندې په توګه ولیکئ، له نوم سره یې ازموینه() ته ورکړئ، او پروګرام د ازموینې_پای_کړه() سره پای ته ورسوئ:

    راوړه "testing"

    دنده جمع_سمه_ده() برابر_تمه(۲ + ۲، ۴)

    ازموینه("جمع سمه ده"، جمع_سمه_ده) ازموینې_پای_کړه()

    هره ازموینه یوه کرښه چاپوي - "✓ نوم" کله چې تېره شي، "✗ نوم: څه ناسم شول" د هرې هغه تمې لپاره چې پوره نه شوه - او ازموینې_پای_کړه() شمېري چې څو تېرې شوې او څو ناکامې، او که کومه ناکامه وي پروګرام د وتلو کوډ ۱ سره پای ته رسوي (نو یو سکریپټ، یا د VS Code غځونه، پوهېدلی شي). د پروګرام دلیلونه ټاکي چې کومې ازموینې وچلېږي: "thundervm tests.thc جمع" یوازې هغه چلوي چې نوم یې پر امر کرښه راغلی - د VS Code د ازموینو لړ یوه ازموینه همداسې چلوي.

    دلته هېڅ بهرنی نشته: دا ساده تندر دی، د لوستلو لپاره لیکل شوی.
