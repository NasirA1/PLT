    راوړه "sockets"

    د شبکې له لارې خبرې: TCP او UDP ساکټونه (docs/ps/sockets.md)

    راوړه "sockets" ولیکئ او څلور ټولګي ستاسې دي (thunderc دا فایل د ځان تر څنګ په lib/thunder کې مومي، یا یوه پوښۍ د --module-path سره ورکړئ):

    ټي_سي_پي اړیکې: اورېدل، منل، نښلول، او غوښتنه (یوه بشپړه تبادله) یو_ډي_پي یو یو پیغام (ډاټاګرام): پرانیستل، لېږل، اخیستل، لېږونکی ساکټ هغه څه چې هر ساکټ یې کولای شي: د متن یا بایټونو لېږل او اخیستل، تړل، د وخت حد ... کوربه نومونه او پتې: کوربه.پته("example.org")، کوربه.نوم()

    کار په ++C کې کېږي (lib/native/sockets/thunder_sockets.cpp)، چې له توکپانګې سره د بهرني کتابتون thunder_sockets په بڼه جوړېږي، د thunderc او thundervm تر څنګ کېني او د بسته شوي پروګرام تر څنګ پخپله کاپي کېږي.

    ساکټ یو ساکټ.ساکټ دی. پرانیستل یې ناکامېدای شي - څوک نه اوري، پورټ نیول شوی وي - او بیا ځواب هېڅ دی، او ساکټ.تېروتنه() وايي ولې. ساکټ سرچینه ده، نو «سره» یې ستاسې لپاره د بلاک په پای کې تړي، که بلاک هر ډول پای ته ورسېږي:

    اړیکه = ټي_سي_پي.ونښلېږه("localhost"، ۷۰۰۰) سره که اړیکه != هېڅ ساکټ.کرښه_ولېږه(اړیکه، "سلام")

    داسې ساکټ ورکول چې دمخه تړل شوی وي د پروګرام تېروتنه ده او پروګرام دروي، لکه د دننۍ دندې ناسمه بلنه.
