# د الګوریتمونو لارښود

`راوړه "algorithms"` د ترتیب او لټون کلاسیک الګوریتمونه پروګرام ته راوړي، د دریو ټولګو په
بڼه: **`ترتیب`**، **`لټون`** او **`متنونه`**. په فایل کې هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/algorithms.th`](../../lib/thunder/ps/algorithms.th) کې، د لوستلو لپاره لیکل
شوی: پرانیزئ یې او وګورئ چې هغه الګوریتمونه چې هره ژبه یې لري رښتیا څنګه کار کوي. (د
ورځنۍ کارونې لپاره تندر دننۍ دنده `ترتیب کړه()` لري؛ دلته لیکل شوي دي چې داسې دنده
دننه څه کوي.) انګلیسي فایل ([`lib/thunder/en/algorithms.th`](../../lib/thunder/en/algorithms.th))
همدا دندې له انګلیسي نومونو سره دي.

| ټولګی | څه پکې دي |
| --- | --- |
| `ترتیب` | `حبابي`، `غوراوی`، `ننویستل`، `چټک` او `ګډولو` ترتیب؛ `شوې_ده`، `ګډوډه_کړه` |
| `لټون` | `پرله_پسې` او `نیمایي` لټون؛ `د_کمینې_ځای` |
| `متنونه` | `ومومه`، `ټول_ومومه`، `سرچپه_ورته_ده`، `تر_ټولو_اوږد_ګډ_مختاړی`، `د_بدلون_واټن` |

هره دنده له خپل ټولګي سره لیکل کېږي: `ترتیب.چټک(ارزښتونه)`، `لټون.نیمایي(ارزښتونه، ۷)`،
`متنونه.ومومه("سلام نړۍ"، "نړۍ")`. **د ټولګو نومونه ساتل شوي دي** په هغه پروګرام کې چې
`"algorithms"` راوړي: یو متغیر `ترتیب`، `لټون` یا `متنونه` نشي نومول کېدای (تېروتنه `S065`) -
پر ځای یې `وییونه`، `پیغام`، `کرښه` ونوموئ.

د ترتیب او لټون دندې **عمومي (generic)** دي: پر هره `ت[]` کار کوي چې توکي یې د `<` سره
پرتله کېږي - عددونه یا متنونه (د [ژبې لارښود](language.md)، ۸ برخه). ترتیب **پر خپل ځای**،
په پورته کېدونکي ترتیب دی. لټونونه د ارزښت ځای (شاخص) راګرځوي، یا `-۱` کله چې نه وي.

**ویې آزمویئ:** [`samples/advanced/ps/02_algorithms.th`](../../samples/advanced/ps/02_algorithms.th)
هر الګوریتم چلوي (انګلیسي:
[`samples/advanced/en/02_algorithms.th`](../../samples/advanced/en/02_algorithms.th)). دا بېلګې
په قصد د IDE په لړ کې نشته - له همدې ځایه یې پرانیزئ.

## ترتیب

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `ترتیب.حبابي<ت>(ارزښتونه)` | بیا بیا جارو، ناسم ترتیب شوي ګاونډیان بدلېږي؛ جارو بې بدلونه مانا ترتیب شوې. | O(n²) |
| `ترتیب.غوراوی<ت>(ارزښتونه)` | د پاتې برخې کمینه ومومه، مخ ته یې بدله کړه، بیا نور. هر ارزښت تر یوه ځله زیات نه خوځي. | O(n²) |
| `ترتیب.ننویستل<ت>(ارزښتونه)` | هر بل ارزښت له لویو ارزښتونو کیڼ لور ته وښویوه - لکه د پتو پاڼې چې اڼل کېږي. | O(n²)، نږدې ترتیب شوې O(n) |
| `ترتیب.چټک<ت>(ارزښتونه)` | محور وټاکه، پر کوچنیو او لویو یې ووېشه، دواړې خواوې ترتیب کړه - ووېشه او وګټه. | په منځني ډول O(n log n) |
| `ترتیب.ګډولو<ت>(ارزښتونه)` | هره نیمایي ترتیب کړه، بیا دواړه سره ګډې کړه. ډاډمن، د مرستندویه ځای په بیه. | همېش O(n log n) |

دوه مرستندویې ورسره اوسېږي:

| دنده | څه کوي |
| --- | --- |
| `ترتیب.شوې_ده<ت>(ارزښتونه): منطقي` | رښتیا که لړۍ په پورته کېدونکي ترتیب وي (مساوي ګاونډیان روا دي). |
| `ترتیب.ګډوډه_کړه<ت>(ارزښتونه)` | ارزښتونه په تصادفي ترتیب اڼي (Fisher-Yates). مخکې `تصادفي.بنسټ(ن)` یې تکرارېدونکی کوي. |

```thunder
# ژبه: ps
راوړه "algorithms"

متغیر عددونه = [۵، ۲، ۹، ۱، ۵، ۶]
ترتیب.چټک(عددونه)
کرښه چاپ(عددونه)                   # [۱، ۲، ۵، ۵، ۶، ۹]
کرښه چاپ(ترتیب.شوې_ده(عددونه))     # رښتیا
```

## لټون

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `لټون.پرله_پسې<ت>(ارزښتونه، غوښتل_شوی): عدد` | هر ارزښت وګوره ترڅو همغه وي. پر هره لړۍ کار کوي. | O(n) |
| `لټون.نیمایي<ت>(ارزښتونه، غوښتل_شوی): عدد` | لړۍ باید **ترتیب شوې** وي: له منځني سره پرتله کړه، یوازې هغه نیمایي وساته چې ارزښت لا پکې کېدای شي. | O(log n) |
| `لټون.د_کمینې_ځای<ت>(ارزښتونه): عدد` | د تر ټولو کوچني ارزښت ځای (`-۱` د تشې لړۍ لپاره). | O(n) |

## متن

د متن الګوریتمونه توری په توري کار کوي (توری یو کوډ-پوینټ دی، نو پښتو متن سم اندازه کېږي).

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `متنونه.ومومه(متن_، نمونه): عدد` | نمونه د متن په اوږدو وښویوه، توری په توري پرتله کړه - هغه چې دننۍ `ځای یې()` د متنونو لپاره کوي، دلته لیکل شوي. نه و: `-۱`. | O(n·m) |
| `متنونه.ټول_ومومه(متن_، نمونه): عدد[]` | هر هغه ځای چې نمونه پکې پیلېږي، پراته پیدا کېدل هم پکې. | O(n·m) |
| `متنونه.سرچپه_ورته_ده(متن_): منطقي` | دواړه سرونه پرتله کړه او دننه راشه. | O(n) |
| `متنونه.تر_ټولو_اوږد_ګډ_مختاړی(وییونه): متن` | لومړی ویی د نورو هر یوه پر وړاندې لنډ کړه. | O(ټول اوږدوالی) |
| `متنونه.د_بدلون_واټن(الف، ب): عدد` | د Levenshtein واټن: تر ټولو لږ یو-توریز ننویستل، لیرې کول او بدلول چې الف ب ته اړوي - متحرک پروګرامول، کتار په کتار. | O(n·m) |

```thunder
# ژبه: ps
راوړه "algorithms"

کرښه چاپ(متنونه.ومومه("سلام نړۍ"، "نړۍ"))                    # ۵
کرښه چاپ(متنونه.د_بدلون_واټن("کور"، "کار"))                  # ۱
کرښه چاپ(متنونه.تر_ټولو_اوږد_ګډ_مختاړی(["کور"، "کورنۍ"]))    # «کور»
```

د دې فایل ټولګی `متنونه` د ژبې دننی ټولګی `متن` نه دی (`متن.پاک کړه`، `متن.وېشه` ...): هغه د
ژبې خپل دي، تل شته؛ دا الګوریتمونه دي، لیکل شوي.
