    راوړه "testing" پروګرام ته د ازموینو یو کوچنی چوکاټ راوړي: هره ازموینه د یوې دندې په توګه ولیکئ، له نوم سره یې ازموینه() ته ورکړئ، د برابر_تمه() او ملګرو سره یې ووایئ چې څه باید رښتیا وي، او د ازموینې_پای_کړه() سره پای ته ورسوئ. په ماډیول کې هېڅ بهرنی نشته - دا ساده تندر دی، په [lib/thunder/ps/testing.th](../../lib/thunder/ps/testing.th) کې، د لوستلو لپاره لیکل شوی. انګلیسي ماډیول ([lib/thunder/en/testing.th](../../lib/thunder/en/testing.th)) همدا چوکاټ له انګلیسي نومونو سره دی؛ دواړه پخپله، د اوزارو تر څنګ، موندل کېږي.

    ویې آزمویئ: [samples/ps/28_testing.th](../../samples/ps/28_testing.th) دوه کوچنۍ دندې ازمویي (انګلیسي: [samples/en/28_testing.th](../../samples/en/28_testing.th))؛ د IDE د بېلګو په لړ کې د ۳۷ - ازموینه په نوم ده.

    چلول یې هرې ازموینې ته یوه کرښه او یو لنډیز چاپوي:

    ✓ د لړۍ تر ټولو لوی

    هغه ازموینه چې تمه یې پوره نه شي پر ځای یې چاپوي چې څه ناسم شول، او لنډیز پروګرام د وتلو کوډ ۱ سره پای ته رسوي، نو یو سکریپټ - یا یو سمونګر - پوهېدلی شي:

    ✗ د لړۍ تر ټولو لوی: تمه ۹ وه، ۳ ترلاسه شو
۰ تېرې شوې، ۱ ناکامې

    ازموینه هره هغه دنده ده چې پارامترونه نه لري؛ ازموینه() هماغه شېبه یې، د ورکړل شوي نوم لاندې، چلوي، نو ازموینې په هغه ترتیب چلېږي چې لیکل شوې دي. په تندر کې استثناوې نشته: د ازموینې دننه د اجرا تېروتنه (له پایه اخوا شاخص، پر صفر وېش) ټول پروګرام د معمول راپور سره دروي، لکه هر بل ځای - وروسته ازموینې نه چلېږي.

    دندې#

    دنده څه کوي
    ازموینه(نوم: متن، بدنه: دنده())دنده «بدنه» د «نوم» په نوم ازموینه چلوي: ✓ نوم که هره تمه یې پوره شوه، ✗ نوم: پیغام د هرې هغې لپاره چې پوره نه شوه.
    تمه(شرط: منطقي، پیغام: متن)اوسنۍ ازموینه د «پیغام» سره ناکامه کوي کله چې «شرط» درواغ وي. نورې له همدې سره لیکل شوې دي.
    رښتیا_تمه(شرط: منطقي)ناکامه، مګر دا چې شرط رښتیا وي.
    درواغ_تمه(شرط: منطقي)ناکامه، مګر دا چې شرط درواغ وي.
    برابر_تمه<ت>(ترلاسه: ت، تمه_شوی: ت)ناکامه، مګر دا چې دواړه یو شان چاپ شي - نو لړۍ، ټاپلونه، نقشې او جوړښتونه د خپلو توکو له مخې پرتله کېږي؛ پیغام دواړه ښيي: تمه [۱، ۴، ۹] وه، [۱، ۴، ۸] ترلاسه شو.
    نابرابر_تمه<ت>(ترلاسه: ت، ناغوښتل: ت)ناکامه کله چې دواړه یو شان چاپ شي.
    نږدې_تمه(ترلاسه: اعشاري، تمه_شوی: اعشاري، زغم: اعشاري)د اعشاري شمېرو لپاره، چې لږ کله بشپړ برابرې وي: ناکامه، مګر دا چې «ترلاسه» له «تمه_شوی» څخه په «زغم» کې وي.
    ناکامه_کړه(پیغام: متن)اوسنۍ ازموینه د خپل پیغام سره ناکامه کوي.
    ازموینې_پای_کړه()N تېرې شوې، M ناکامې چاپوي او کله چې M > ۰ وي پروګرام د وتلو کوډ ۱ سره پای ته رسوي. وروستۍ یې وبولئ.

    هره ناکامه تمه خپله ✗ کرښه چاپوي، نو هغه ازموینه چې درې ناسمې تمې لري درې واړه راپور کوي؛ ازموینه یو ځل ناکامه شمېرل کېږي.

    د ځینو ازموینو چلول#

    د پروګرام دلیلونه ازموینې ټاکي: thundervm tests.thc "د لړۍ تر ټولو لوی" یوازې هغه ازموینې چلوي چې نوم یې پر امر کرښه راغلی (څو نومونه، څو ازموینې)، او نورې نه پیلېږي. بې دلیلونو هره ازموینه چلېږي. VS Code د خپل د ازموینو لړ (Test Explorer) له لارې یوه ازموینه همداسې چلوي (لاندې)، او یو سکریپټ هغه یوه بیا چلوي چې ناکامه شوه.

    په IDE او VS Code کې#

    • د تندر IDE: فایل وچلوئ. د ✓ او ✗ کرښې د وتنې پاڼه کې راځي؛ د حالت پټه د وتلو کوډ ښيي.
    • VS Code: هغه فایل چې "testing" راوړي د ازموینو لړ (Test Explorer، په فعالیت پټه کې د کیمیا بوتل) کې راځي، د هرې ازموینه(...) لپاره یوه ننوتنه، او سمونګر د هرې یوې تر څنګ په ګټر کې د چلولو تڼۍ ښيي. یوه ازموینه، یو فایل یا ټول وچلوئ؛ ناکامۍ خپل پیغام په کرښه کې او د ازموینو د پایلو لید کې ښيي. د سمونګر د سرلیک پټې Run Tests in This File تڼۍ (او د دواړو سمونګرو د شرایطو مینو کې، د ښي-څخه-کیڼ سمونګر په ګډون) مخکښ فایل چلوي؛ Thunder: Run All Tests د کاري ځای ټول د ازموینو فایلونه چلوي. د Debug پروفایل ټاکل شوې ازموینې د مرستیال (debugger) لاندې، له ټولو ودرېدو ټکو سره، چلوي.
    • امر کرښه: thunderc tests.th && thundervm tests.thc؛ د وتلو کوډ وايي چې ټول تېر شول که نه.
