# د تندر د بایټ کوډ او مجازي ماشین لارښود

*[د تندر SDK لارښود](README.md) یوه برخه.*

> دا سند د `docs/bytecode.md` پښتو ژباړه ده. انګلیسي اصل معتبر دی (د لارښوونو بشپړ جدول
> او د فایل بڼه هلته ده)؛ ژباړه د یوه ژبپوه کتنې ته اړتیا لري.

`thunderc` هر پروګرام **بایټ کوډ** ته اړوي: د یوه ساده سټک-ماشین لارښوونې، چې `thundervm`
یې اجرا کوي. IDE کې د «بایټ کوډ»، «بائنري» او VM پاڼې همدا ښيي.

## ۱. د ماشین انځور

مجازي ماشین **سټک-ماشین** دی: لارښوونې ارزښتونه پر یوه سټک ږدي او ترې اخلي.

```
کرښه چاپ(۲ + ۳ * ۴)

بایټ کوډ: CONST 0            ; ۲ کېږده            سټک: [۲]
          CONST 1            ; ۳ کېږده            سټک: [۲، ۳]
          CONST 2            ; ۴ کېږده            سټک: [۲، ۳، ۴]
          MUL                ; ۳ * ۴              سټک: [۲، ۱۲]
          ADD                ; ۲ + ۱۲             سټک: [۱۴]
          CALL_BUILTIN 1 1   ; کرښه چاپ(۱۴)       سټک: []
```

### ارزښتونه

د اجرا ارزښتونه: عدد، منطقي، متن، لړۍ، جوړښت، ټاپل، نقشه او د دندې ارزښت. لړۍ، جوړښتونه
او نقشې ماخذونه دي (د ماخذ شمېرنه یې پاکوي؛ د ډولونو سیسټم دورونه ناشوني کوي). ټاپلونه
نه بدلېږي او `EQ` یې توکی په توکی پرتله کوي.

### دندې، چوکاټونه او ځایي ځایونه

هره دنده خپل کوډ لري. بلنه یو **چوکاټ (frame)** ږدي: دلیلونه د بلل شوې دندې لومړي ځایي
ځایونه (slots) کېږي، ورپسې نور ځایي متغیرونه، او له هغو پورته یې لنډمهالي عملوندونه.
«راګرځه» چوکاټ لرې کوي او پایله بلونکي ته ږدي. د سر کچې کوډ په `<main>` (`<اصلي>`) کې دی،
چې لومړی چلېږي او که `اصلي()` تعریف وي، په پای کې یې بولي.

## ۲. د لارښوونو ټولګه

هره لارښوونه ۱-بایټ کوډ + کوچني-اختر (little-endian) عملوندونه ده. بشپړ جدول (۴۱ لارښوونې)
د انګلیسي سند ۲ برخه کې دی؛ ډلې یې:

| ډله | لارښوونې |
| --- | --- |
| ثابت/منطقي | `CONST`، `TRUE`، `FALSE`، `POP`، `DUP`، `DUP2` (د `ل[ش] += ا` لپاره) |
| متغیرونه | `LOAD_LOCAL`، `STORE_LOCAL`، `LOAD_GLOBAL`، `STORE_GLOBAL` |
| حساب | `ADD`، `SUB`، `MUL`، `DIV`، `MOD`، `NEG` (اوښتل او په صفر وېش = د اجرا تېروتنې). دا لارښوونې پر بشپړو عددونو او اعشاري شمېرو یو شان کار کوي: د سټک د ارزښتونو ډول ګوري. |
| اړونه | `INT_TO_FLOAT` (بشپړ عدد اعشاري کوي؛ هلته چې ډول کتونکي پراخه کړې ده) |
| متن/پرتله | `CONCAT`، `EQ`، `NE`، `LT`، `LE`، `GT`، `GE`، `NOT` |
| ورټوپونه | `JUMP`، `JUMP_IF_FALSE` |
| بلنې | `CALL`، `CALL_BUILTIN`، `RETURN`، `RETURN_VOID` |
| لړۍ/نقشې | `MAKE_ARRAY`، `INDEX_GET`، `INDEX_SET`، `MAKE_TUPLE`، `TUPLE_GET`، `MAKE_MAP` |
| جوړښتونه | `NEW_STRUCT`، `GET_FIELD`، `SET_FIELD` |
| د دندو ارزښتونه | `FUNC_REF` (د دندې ارزښت ږدي؛ 65535 = «بې دندې»)، `CALL_VALUE` |
| بیټي عملګر | `BIT_AND`، `BIT_OR`، `BIT_XOR`، `SHL`، `SHR` (شمېر ۰..۶۳)، `BIT_NOT` |

`CALL_BUILTIN` دننۍ دنده د شمېرې له مخې بولي (جدول: `src/core/builtins.cpp`). د ګرافیک
ماډیول نوې لارښوونې نه غواړي: دندې یې د VM ټاټ بدلوي، او `چوکاټ()` یې ګرافیک کوربه ته
وړاندې کوي ([د ګرافیک لارښود](graphics.md) ۸ برخه). `پر هر یو`/`چاڼ کړه`/`راټول کړه` خپله
دنده د VM له دننه، لکه `CALL_VALUE`، بولي.

## ۳. امرونه بایټ کوډ ته

`که ش` (برخه A)، `کنه` (برخه B):

```
        <ش>
        JUMP_IF_FALSE else
        <A>
        JUMP end            ; که A تل راګرځي، نه لیکل کېږي
else:   <B>
end:
```

`ترڅو ش` له ننوتې برخې سره:

```
start:  <ش>
        JUMP_IF_FALSE end
        <برخه>              ; ودرېږه -> JUMP end، دوام -> JUMP start
        JUMP start
end:
```

`لپاره پیل، ش، ګام` له ننوتې برخې سره:

```
        <پیل>
start:  <ش>
        JUMP_IF_FALSE end
        <برخه>              ; دوام -> JUMP next
next:   <ګام>
        JUMP start
end:
```

`ټکی(۱، ۲)` د برخو ارزښتونه ږدي او `NEW_STRUCT` یې جوړوي؛ `ټکی(ص: ۲، س: ۱)` له اصلي
ارزښتونو پیلوي او هره نومول شوې برخه په `SET_FIELD` ږدي، نو دلیلونه له کیڼه ښي ارزول کېږي.

`الف او ب` ورټوپونه کاروي چې ب یوازې د الف له رښتیا وروسته وارزول شي (لنډه لار):

```
        <الف>
        JUMP_IF_FALSE false
        <ب>
        JUMP end
false:  FALSE
end:
```

## ۴. د `.thc` فایل بڼه

سرلیک: جادويي `"THND"`، بڼه-نسخه (۵؛ نسخه ۵ اعشاري ثابتونه زیات کړل)، د سرچینې نوم، د ژبې کوډ (`en`/`ps`) او د سرچینو
فایلونو لړ (پروګرام + راوړل شوي ماډیولونه). ورپسې: ثابتونه، جوړښتونه، عمومي متغیرونه،
د دندو جدول او د هرې دندې کوډ له **د کرښو جدول** سره، چې هره لارښوونه بېرته سرچینې ته
(فایل، کرښه، ستن) نقشه کوي — د اجرا تېروتنې او ډیبګر همدا کاروي. د ژبې کوډ ټاکي چې VM
ارزښتونه او پیغامونه څنګه ښيي: له پښتو جوړ شوی پروګرام `۴۲`، `رښتیا` او پښتو تېروتنې
چاپوي. تفصیلي جدول: انګلیسي سند ۴ برخه. IDE کې «بائنري» پاڼه هره برخه په خپل رنګ ښيي؛
په قومانده کې `thunderc --emit hex`.

## ۵. خوندیتوب: تایید کوونکی

`thundervm` هېڅکله پر `.thc` فایل باور نه کوي. له چلولو مخکې **تاییدوي**: جادويي شمېره او
اوږدوالي، هر کوډ پېژندل شوی او هر عملوند په حد کې (ثابتونه، ځایونه، دندې، جوړښتونه،
دننۍ دندې...)، هر ورټوپ د لارښوونې پر پیل، او هره دنده په `HALT`/`RETURN`/`RETURN_VOID`/
`JUMP` پای ته رسېږي. د چلولو پر مهال د عملوندونو ډولونه، د سټک ژوروالی، د بلنو ژوروالی
او (اختیاري) د ګامونو حد هم ګوري. ناسم فایل د `R010` پیغام راوړي، نه حادثه. ازموینې د
جوړ شوي فایل هر بایټ اړوي او په هر اوږدوالي یې پرېکوي.

## ۶. د قوماندې وسایل

```
thunderc program.th                 # جوړول → program.thc
thunderc --lang ps program.th       # پروګرام پښتو دی (یا "// ژبه: ps")
thunderc --translate ps program.th  # پروګرام پښتو ته وژباړه
thunderc --emit all program.th      # توکي، نحوي ونه، نښې، بایټ کوډ، hex هم چاپ کړه
thunderc --json program.th          # هر څه JSON (IDE همدا کاروي)
thunderc -I libs program.th         # راوړل شوي فایلونه په libs/ کې هم ولټوه
thundervm program.thc               # چلول (ولوله() معیاري ننوت لولي)
thundervm program.thc یو دوه        # دلیلونه پروګرام ته (دلیلونه() په سیسټم ماډیول)
thundervm --trace program.thc       # هره لارښوونه او سټک ښيه
thundervm --stats program.thc       # شمېرنې: ګامونه، بلنې، ژوروالی
thundervm --svg out.svg --max-frames 50 anim.thc   # ګرافیک: تر ۵۰ چوکاټه، انځور وساته
```

د وتلو حالت: ۰ بریا (یا د `پای ته ورسوه(کوډ)` کوډ)، ۱ د اجرا تېروتنه، ۲ ناسم کارول یا
ناسم فایل.
