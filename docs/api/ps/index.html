    عمومي کتنه

    عمومي کتنه

    تندر یوه کوچنۍ، ثابت-ډوله ژبه ده چې د پروګرامولۍ ژبو د کار زده کړې لپاره جوړه شوې، له کمپایلر، د بایټ کوډ مجازي ماشین، IDE او د VS Code له غځونې سره. پروګرامونه په انګلیسي یا پښتو لیکل کېدای شي؛ دا لارښود په دواړو ژبو شته او هره پاڼه خپلې بلې ژبې ته تړنه لري.

    ژبه

    کلیدي کلمې، ډولونه، لفظي ارزښتونه او کلمه‌يي عملګر، د هرې منل شوې لیکبڼې او په بله ژبه د نوم سره.

    دننۍ دندې

    ننوت او وتنه، متن، لړۍ، نقشې، ریاضي، لوړ-رتبه دندې، او د سیسټم او ګرافیک ماډیولونه.

    د SDK ماډیولونه

    ډېټا جوړښتونه، الګوریتمونه، ساکټونه او ازموینه: جوړښتونه او دندې د پارامترونو، د راګرځېدو ډولونو او تشریح سره.

    لارښودونه

    د لوستلو په ترتیب لارښودونه: ژبه، کتابتون، ګرافیک، ساکټونه، بهرنی اړیکی، بستول، بایټ کوډ او ډیبګر.

    د لارښوونو ټولګه

    د مجازي ماشین هره لارښوونه د عملوندونو او د سټک اغېز سره.
