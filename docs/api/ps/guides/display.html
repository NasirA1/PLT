    ښودونکي: د ګرافیک پروګرام لپاره کړکۍ

    په دې پاڼه کې

    • ۱. د ښودونکي کارول
    • ۲. خپل ښودونکی لیکل

    د تندر SDK لارښود یوه برخه.

    هغه پروګرام چې ګرافیک راوړي (راوړه ګرافیک)، د ګرافیک.دایره(...) او ملګرو سره ټاټ ته کاږي؛ بل څوک باید هغه ټاټ پر پردې وښيي. په IDE کې دا کار پخپله IDE کوي. له هغې بهر — په ټرمینل کې، یا په بسته شوې کړنلاره کې — دا کار یو د ښودونکي پلگ-ان کوي:

    thunderc 36_snake.th -o snake.thc
thundervm --display sdl snake.thc          # خپله کړکۍ

    پلگ-ان یو شریک کتابتون دی چې کړکۍ پرانیزي، د هر چوکاټ شکلونه کاږي، او د تڼیو او موږک پېښې بېرته لېږي. ټول اړیکی یو ساده C سرلیک دی: include/thunder/display.h. بشپړ بیان: انګلیسي سند. دوې بشپړې بېلګې په lib/display/ کې دي: یوه پر SDL2 جوړه، او یوه کوچنۍ چې چوکاټونه په متن لیکي.

    ۱. د ښودونکي کارول#

    امر څه کوي
    thundervm --display sdl program.thclibthunder_display_sdl.so راوړي (په وینډوز کې thunder_display_sdl.dll)
    thundervm --display win32 program.thcیوازې وینډوز: thunder_display_win32.dll راوړي، چې هېڅ نصب ته اړتیا نه لري
    ./app --thunder-display sdlهمدا، د بستې لپاره
    ./appبسته شوی ګرافیکي پروګرام د ځان تر څنګ لومړی موندل شوی پلگ-ان پخپله کاروي (په وینډوز کې win32 بیا sdl، بل ځای sdl)، یا د پیغام سره درېږي
    thunderc p.th --package app --display sdlپروګرام بستوي او پلگ-ان یې ورسره ږدي

    کتابتون په دې ترتیب لټول کېږي: د پروګرام تر څنګ، د thundervm تر څنګ، بیا د --native-path او THUNDER_NATIVE_PATH پوښۍ، او بالاخره هر چېرې چې عامل سیسټم ګوري — لکه د بهرني ماډیول لپاره.

    د کړکۍ بندول پروګرام پای ته رسوي. پلگ-ان THUNDER_EVENT_QUIT راپوروي، او پروګرام هماغسې درېږي لکه کله چې د چوکاټونو حد پوره شي: په نورمال ډول، او وروستی انځور یې خوندي پاتې کېږي.

    پلگ-ان څه لپاره
    lib/display/sdlریښتینې کړکۍ، پر SDL2 جوړه. تڼۍ، موږک، هر شکل.
    lib/display/win32پر وینډوز ریښتینې کړکۍ، پر GDI کښل شوې: هېڅ نصب ته اړتیا نشته، او متن په ریښتیني لیک راځي (پښتو هم). پر وینډوز تل جوړېږي.
    lib/display/textبې کړکۍ: هر چوکاټ په عادي تېروتنې جریان کې لیکل کېږي. لومړی همدا ولولئ.

    متني ښودونکی کولای شي د کاروونکي ځای هم ونیسي، نو لوبه بې پردې هم آزمویل کېږي:

    THUNDER_DISPLAY_TEXT_KEYS=left,space THUNDER_DISPLAY_TEXT_FRAMES=20 \
    thundervm --display text snake.thc

    ۲. خپل ښودونکی لیکل#

    پلگ-ان یو سرلیک راوړي، د تندر له هېڅ شي سره نښلول نه غواړي، او یوه دنده صادروي:

    #include <thunder/display.h>

THUNDER_DISPLAY_EXPORT int thunder_display_init(ThunderDisplay* display)
{
    display->abi_version = THUNDER_DISPLAY_ABI;
    display->state = my_state_new();   /* ستاسې خپل معلومات؛ تندر ورته نه ګوري */
    display->open = my_open;
    display->present = my_present;
    display->poll = my_poll;
    display->close = my_close;
    return 1;
}
    بلنه کله باید څه وکړي
    openله لومړي چوکاټ مخکې، کله چې د ټاټ اندازه معلومه شيکړکۍ پرانیزي؛ که نشي، ۰ راوګرځوي او *error وټاکي
    presentد هر ګرافیک.چوکاټ() یا ګرافیک.ښکاره کړه() لپاره یو ځلد چوکاټ شکلونه وکاږي
    pollله هر چوکاټ وروسته، تر هغه چې ۰ راوګرځويیوه یوه پېښه ورکړي
    closeیو ځل، په پای کې — حتی که open هېڅکله ونه بلل شيهغه څه خوشې کړي چې thunder_display_init نیولي وو

    چوکاټ یوازې نوي شکلونه وړي: keep وايي چې ښودونکي له پخوا څو شکله کښلي دي. ارزښتونه اعشاري دي او کېدای شي له ټاټه بهر وي — پرې یې کړئ. رنګونه تل "#rrggbb" دي.

    د تڼیو نومونه د تندر انګلیسي نومونه دي ("left"، "space" ...)؛ VM یې د پروګرام ژبې ته اړوي، نو پښتو پروګرام "کیڼ" ویني پرته له دې چې پلگ-ان له پښتو څخه څه پوه شي.

    cc -std=c11 -shared -fPIC -I<thunder>/include -o libthunder_display_mine.so mine.c

    نوم ټاکي چې کومه ټاکنه ده: libthunder_display_mine.so یعنې --display mine. ځکه چې پوله ساده C ده، پلگ-ان په C، ++C، Rust یا هره بله ژبه لیکل کېدای شي.

    د خوندیتوب یادښت: د ښودونکي پلگ-ان بهرنی کوډ دی او د پروسې په بشپړو واکونو چلېږي. VM یې نه ګوري. یوازې هغه پلگ-انونه راوړئ چې تاسې جوړ کړي یا پرې باور لرئ.

    د tools/apidoc.py له لارې د اوزارو د ژبې له معلوماتو، د SDK له خپلو تبصرو او له لارښودونو جوړ شوی. د MIT جواز.
