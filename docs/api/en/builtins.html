    Built-in functions

    On this page

    • Core (always available)
    • The os module (import "os")
    • The graphics module (import "graphics")

    Every function the compiler knows without an import, and the functions of the built-in modules. The signature and the description are the compiler's own (thunderc --language-info), so they cannot drift from what the toolchain does; the library guide explains each group with examples.
