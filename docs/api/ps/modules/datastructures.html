    راوړه "datastructures"

    کلاسیک ډېټا جوړښتونه، پخپله په تندر کې لیکل شوي (docs/ps/datastructures.md)

    راوړه "datastructures" ولیکئ او ټول لاندې جوړښتونه ستاسې دي (thunderc دا فایل د ځان تر څنګ په lib/thunder کې مومي، یا یوه پوښۍ د --module-path سره ورکړئ). د ساکټونو یا ګرافیک په خلاف دلته هېڅ بهرنی نشته: دا ساده تندر دی، د لوستلو لپاره لیکل شوی - دا فایل پرانیزئ او وګورئ چې ډېرۍ، لیکه، ځنځیر، د لټون دوه‌اړخیزه ونه او د لومړیتوب لیکه رښتیا څنګه کار کوي.

    هر جوړښت عمومي (generic) دی: ډېرۍ<ت> د هر ډول توکو لپاره کار کوي، او ت له کارونې معلومېږي - د متنونو ډېرۍ یا ډېرۍ(توکي: [«الف»]) ده، یا «متغیر د: ډېرۍ<متن> = نوې_ډېرۍ()». ونه او د لومړیتوب لیکه خپل توکي د < سره پرتله کوي، نو توکي یې عددونه یا متنونه دي.

    له تش جوړښته اخیستل د پروګرام تېروتنه ده او پروګرام دروي، لکه د دننۍ دندې ناسمه بلنه. لومړی ډېرۍ_تشه_ده / لیکه_تشه_ده / لومړیتوب_لیکه_تشه_ده وپوښتئ.
