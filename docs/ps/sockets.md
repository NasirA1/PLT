# ساکټونه: د شبکې له لارې خبرې

*[د تندر SDK لارښود](README.md) یوه برخه.*

د تندر پروګرام کولای شي د بل کمپیوټر له پروګرام سره (یا له وېب سرور سره، یا له ځان سره)
د **ساکټونو** له لارې خبرې وکړي. یو لوری پر یوه پورټ *اوري*، بل له هغه کمپیوټر او پورټ سره
*نښلي*، او بیا متن دواړو لورو ته بهېږي تر هغه چې یو لوری یې وتړي. د چټ پروګرام، د لوبې
سرور او وېب براوزر تر لاندې همدا کار کوي.

```thunder
# ژبه: ps
راوړه "sockets"

متغیر سرور = اورېدونکی_جوړ_کړه(""، ۵۰۰۰)        # پر پورټ ۵۰۰۰ غږ کوونکو ته انتظار
متغیر اړیکه = اړیکه_ومنه(سرور)                   # ... یو راغی
کرښه چاپ(ساکټ_کرښه_واخله(اړیکه))                 # څه یې وویل
ساکټ_کرښه_ولېږه(اړیکه، "بېرته سلام")              # ځواب
```

```thunder
# ژبه: ps
راوړه "sockets"

متغیر ساکټ = ونښلېږه("192.168.1.20"، ۵۰۰۰)       # هغه کمپیوټر چې پورتنی پروګرام چلوي
ساکټ_کرښه_ولېږه(ساکټ، "سلام")
کرښه چاپ(ساکټ_کرښه_واخله(ساکټ))                  # "بېرته سلام"
ساکټ_وتړه(ساکټ)
```

ساکټونه له یوه [بهرني ماډیول](native.md) څخه راځي: د ++C کتابتون `thunder_sockets`
(`lib/native/sockets/thunder_sockets.cpp`)، چې له توکپانګې سره جوړېږي او د `thundervm` تر
څنګ کېني. د تندر ماډیول [`sockets.th`](../../lib/thunder/ps/sockets.th) د هغه دندې اعلانوي،
نو پروګرام یوازې `راوړه "sockets"` ته اړتیا لري. په IDE کې دا لارښود د **مرسته > د ساکټونو
لارښود** لاندې دی؛ بېلګه ۳۵ سرور او پېرېدونکی په یوه پروګرام کې چلوي.

---

## ۱. بنسټیز مفهومونه

| کلمه | مانا |
| --- | --- |
| **پته** | کوم کمپیوټر: `"127.0.0.1"` تل *همدا* دی، `"192.168.1.20"` یو ګاونډی، `"example.org"` یو نوم چې شبکه یې لټوي |
| **پورټ** | پر هغه کمپیوټر کوم پروګرام: له ۱ تر ۶۵۵۳۵ یو عدد؛ `۰` له سیسټم څخه هر تش پورټ غواړي |
| **TCP** | یوه *اړیکه*: متن بشپړ او په ترتیب رسېږي، دواړو لورو ته، تر هغه چې یو لوری یې وتړي |
| **UDP** | یو یو *پیغام* (ډاټاګرام) هرې پتې ته، بې اړیکې؛ چټک، خو یو کېدای شي ورک شي |
| **ساکټ** | هغه نښه (یو `عدد`) چې پروګرام یې د اړیکې، اورېدونکي یا UDP ساکټ لپاره لري |

---

## ۲. TCP

| دنده | راګرځوي | څه کوي |
| --- | --- | --- |
| `اورېدونکی_جوړ_کړه(کوربه، پورټ): عدد` | اورېدونکی، یا -۱ | اړیکو ته انتظار پیلوي. کوربه `""` د دې کمپیوټر هره پته؛ پورټ `۰` سیسټم ته پرېږدي (`ساکټ_پورټ` وپوښتئ). |
| `اړیکه_ومنه(اورېدونکی): عدد` | اړیکه، یا -۱ | راتلونکي غږ کوونکي ته انتظار کوي او ورسره اړیکه راګرځوي. |
| `ونښلېږه(کوربه، پورټ): عدد` | اړیکه، یا -۱ | له یوه اورېدونکي پروګرام سره نښلي. -۱ که هلته څوک نه اوري، یا نوم نامعلوم وي. |
| `ساکټ_ولېږه(ساکټ، متن): عدد` | لېږل شوي بایټونه، یا -۱ | متن لېږي (د UTF-8 بایټونو په بڼه). |
| `ساکټ_کرښه_ولېږه(ساکټ، متن): عدد` | لېږل شوي بایټونه، یا -۱ | متن او د کرښې پای لېږي. |
| `ساکټ_واخله(ساکټ، تر_ټولو_ډېر_بایټونه): متن` | متن، یا `""` | تر حد پورې متن ته انتظار کوي. |
| `ساکټ_کرښه_واخله(ساکټ): متن` | یوه کرښه، یا `""` | بشپړې کرښې ته انتظار کوي او پرته له پای څخه یې راګرځوي. |
| `ساکټ_پرانیستی_دی(ساکټ): منطقي` | | تر هغه رښتیا چې اړیکه لا څه راوړلای شي. |
| `ساکټ_وتړه(ساکټ)` | | اړیکه، اورېدونکی یا UDP ساکټ تړي؛ بل لوری یې پوهېږي. |
| `ساکټ_وخت_حد(ساکټ، ملي_ثانیې): منطقي` | | `اړیکه_ومنه`، `ساکټ_واخله` او `یو_ډي_پي_واخله` څومره انتظار کولای شي؛ -۱ (اصلي) مانا تل. |
| `ساکټ_پورټ(ساکټ): عدد` | | پر دې کمپیوټر پورټ (له `اورېدونکی_جوړ_کړه(کوربه، ۰)` وروسته ګټور). |
| `ساکټ_مقابل_لوری(ساکټ): متن` | `"ip:port"` | د اړیکې په بل سر څوک دی. |
| `ساکټ_تېروتنه(): متن` | | ولې وروستۍ بلنه چې -۱ یا `""` یې راوګرځول داسې وشول. |
| `غوښتنه(کوربه، پورټ، کرښه): متن` | ځواب، یا `""` | ونښلېږه، یوه کرښه ولېږه، یوه کرښه ولوله، پرې کړه - ټوله تبادله په یوه بلنه (دا په تندر لیکل شوې، په `sockets.th` کې). |

**انتظار.** `اړیکه_ومنه`، `ساکټ_واخله` او `ساکټ_کرښه_واخله` *انتظار کوي* تر هغه چې څه وشي - لکه
`ولوله()` کاروونکي ته انتظار کوي. هغه پروګرام چې نه باید تل انتظار وکړي، د وخت حد ږدي:

```thunder
# ژبه: ps
ساکټ_وخت_حد(اړیکه، ۲۰۰۰)                       # دوه ثانیې
متغیر کرښه = ساکټ_کرښه_واخله(اړیکه)
که کرښه == "" او نه ساکټ_پرانیستی_دی(اړیکه)
    کرښه چاپ("بل لوری ولاړ")
کنه که کرښه == ""
    کرښه چاپ("هېڅ رانغلل: "، ساکټ_تېروتنه())     # "timed out"
```

## ۳. UDP

| دنده | راګرځوي | څه کوي |
| --- | --- | --- |
| `یو_ډي_پي_پرانیزه(پورټ): عدد` | ساکټ، یا -۱ | د دې کمپیوټر پر یوه پورټ UDP ساکټ پرانیزي (`۰`: هر تش). |
| `یو_ډي_پي_ولېږه(ساکټ، کوربه، پورټ، متن): عدد` | لېږل شوي بایټونه، یا -۱ | یو پیغام کوربه:پورټ ته لېږي. |
| `یو_ډي_پي_واخله(ساکټ، تر_ټولو_ډېر_بایټونه): متن` | پیغام، یا `""` | یوه پیغام ته انتظار کوي. |
| `یو_ډي_پي_لېږونکی(): متن` | `"ip:port"` | چا هغه پیغام لېږلی چې `یو_ډي_پي_واخله` وروستی راوګرځاوه. |

UDP نه اړیکه لري نه تضمین: پیغام کېدای شي ناوخته، دوه ځله یا هېڅ ونه رسېږي. هغه ځای ته
مناسب دی چې نوی ارزښت تر هر ارزښت مهم وي - په لوبه کې د لوبغاړي ځای، هره ثانیه د سینسر لوستنه.

## ۴. نومونه او پتې

| دنده | څه کوي |
| --- | --- |
| `د_کوربه_پته(نوم): متن` | د یوه نوم IP پته، `""` که شبکه یې نه پېژني. |
| `د_کوربه_نوم(): متن` | د همدې کمپیوټر خپل نوم. |

## ۵. دوه ډوله ستونزې

*پر شبکه* د څه خرابېدل عادي دي او د **ارزښت** په بڼه راپور کېږي: -۱ یا `""`، او
`ساکټ_تېروتنه()` وايي ولې. پروګرام پرېکړه کوي څه وکړي - بیا هڅه، کاروونکي ته ویل، پرېښودل.

**د پروګرام تېروتنه** - داسې نښه کارول چې پرانیستې نه ده، پر اړیکه `اړیکه_ومنه` بلل، پر TCP ساکټ
`یو_ډي_پي_ولېږه` - پروګرام د اجرا تېروتنې `R030` سره دروي، لکه د دننۍ دندې ناسمه بلنه. دا
د سمولو ستونزې دي، نه د سمبالولو حالتونه.

---

## ۶. چلول او بسته کول

* په IDE کې **چلول** سمدستي کار کوي: `thunder_sockets` له توکپانګې سره جوړېږي او د `thundervm`
  تر څنګ موندل کېږي.
* [بسته شوی](packaging.md) پروګرام کتابتون پخپله د ځان تر څنګ کاپي شوی لري، ځکه چې یو عادي
  بهرنی کتابتون دی: پوښۍ ولېږئ، نه یوازې فایل.
* په خپل پروګرام کې یوازې `راوړه "sockets"` ولیکئ: ماډیول د `thunderc` تر څنګ په
  `lib/thunder/<ژبه>` کې موندل کېږي (بله نسخه د `-I <dir>` سره ورکولای شئ).

**د خوندیتوب یادونه.** هغه پروګرام چې پر `""` (هره پته) اوري له نورو کمپیوټرونو څخه هم رسېدل
کېږي؛ پر `"127.0.0.1"` یوازې له همدې ماشین څخه. د [بهرني اړیکي](native.md) عادي قواعد پلي کېږي، او
`thundervm --no-native` یې (او هر بهرنی کتابتون) بندوي.
