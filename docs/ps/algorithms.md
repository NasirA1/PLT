# د الګوریتمونو لارښود

`راوړه "algorithms"` د ترتیب او لټون کلاسیک الګوریتمونه پروګرام ته راوړي. په ماډیول کې
هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/algorithms.th`](../../lib/thunder/ps/algorithms.th) کې، د لوستلو لپاره لیکل
شوی: پرانیزئ یې او وګورئ چې هغه الګوریتمونه چې هره ژبه یې لري رښتیا څنګه کار کوي. (د
ورځنۍ کارونې لپاره تندر دننۍ دنده `ترتیب کړه()` لري؛ دلته لیکل شوي دي چې داسې دنده
دننه څه کوي.)

هر ترتیب پر `عدد[]` کار کوي او **پر خپل ځای** یې په پورته کېدونکي ترتیب اڼي. لټونونه
د ارزښت ځای (شاخص) راګرځوي، یا `-۱` کله چې نه وي.

## ترتیب

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `حبابي_ترتیب(ارزښتونه)` | بیا بیا جارو، ناسم ترتیب شوي ګاونډیان بدلېږي؛ جارو بې بدلونه مانا ترتیب شوې. | O(n²) |
| `غوراوی_ترتیب(ارزښتونه)` | د پاتې برخې کمینه ومومه، مخ ته یې بدله کړه، بیا نور. هر ارزښت تر یوه ځله زیات نه خوځي. | O(n²) |
| `ننویستل_ترتیب(ارزښتونه)` | هر بل ارزښت له لویو ارزښتونو کیڼ لور ته وښویوه - لکه د پتو پاڼې چې اڼل کېږي. | O(n²)، نږدې ترتیب شوې O(n) |
| `چټک_ترتیب(ارزښتونه)` | محور وټاکه، پر کوچنیو او لویو یې ووېشه، دواړې خواوې ترتیب کړه - ووېشه او وګټه. | په منځني ډول O(n log n) |
| `ګډولو_ترتیب(ارزښتونه)` | هره نیمایي ترتیب کړه، بیا دواړه سره ګډې کړه. ډاډمن، د مرستندویه ځای په بیه. | همېش O(n log n) |

```thunder
# ژبه: ps
راوړه "algorithms"

متغیر عددونه = [۵، ۲، ۹، ۱، ۵، ۶]
چټک_ترتیب(عددونه)
کرښه چاپ(عددونه)             # [۱، ۲، ۵، ۵، ۶، ۹]
کرښه چاپ(ترتیب_شوې_ده(عددونه))  # رښتیا
```

## لټون

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `پرله_پسې_لټون(ارزښتونه، غوښتل_شوی): عدد` | هر ارزښت وګوره ترڅو همغه وي. پر هره لړۍ کار کوي. | O(n) |
| `نیمایي_لټون(ارزښتونه، غوښتل_شوی): عدد` | لړۍ باید **ترتیب شوې** وي: له منځني سره پرتله کړه، یوازې اړینه نیمایي وساته. | O(log n) |

## مرستندویې

| دنده | څه کوي |
| --- | --- |
| `ترتیب_شوې_ده(ارزښتونه): منطقي` | رښتیا که لړۍ په پورته کېدونکي ترتیب وي (مساوي ګاونډیان روا دي). |
| `د_کمینې_ځای(ارزښتونه): عدد` | د تر ټولو کوچني ارزښت ځای (`-۱` د تشې لړۍ لپاره). |
| `ګډوډه_کړه(ارزښتونه)` | ارزښتونه په تصادفي ترتیب اڼي (Fisher-Yates). `تصادفي بنسټ()` یې تکرارېدونکی کوي. |

د لومړیتوب لیکې، له همدې الماري.
