    راوړه "testing"

    د ازموینو یو کوچنی چوکاټ، پخپله په تندر کې لیکل شوی (docs/ps/testing.md)

    راوړه "testing" ولیکئ او دوه ټولګي ستاسې دي: ازموینه ازموینې چلوي، تمه وايي چې څه باید رښتیا وي. هره ازموینه د یوې بې پارامترونو دندې په توګه ولیکئ، له نوم سره یې ازموینه.وچلوه ته ورکړئ، او پروګرام د ازموینه.پای_ته_ورسوه() سره پای ته ورسوئ:

    راوړه "testing"

    دنده جمع_سمه_ده() تمه.برابر(۲ + ۲، ۴)

    ازموینه.وچلوه("جمع سمه ده"، جمع_سمه_ده) ازموینه.پای_ته_ورسوه()

    د ازموینو ډلې ټولګي دي. هغه ازموینې چې سره تړاو لري په خپل یوه ټولګي کې کېږدئ، او د ټولګي نوم د ډلې نوم کېږي: ازموینې یې د هغه لاندې چاپېږي، د هغه لاندې شمېرل کېږي، او کله چې د ډلې نوم پر امر کرښه ورکړئ، یو ځای چلېدای شي.

    ټولګی حساب دنده جمع_سمه_ده() تمه.برابر(۲ + ۲، ۴)

    ازموینه.وچلوه("جمع سمه ده"، حساب.جمع_سمه_ده) # "حساب" د " ✓ جمع سمه ده" پورته چاپوي

    هره ازموینه یوه کرښه چاپوي - "✓ نوم" کله چې تېره شي، "✗ نوم: څه ناسم شول" د هرې هغې تمې لپاره چې پوره نه شوه - او ازموینه.پای_ته_ورسوه() شمېري چې څو تېرې شوې او څو ناکامې، او که کومه ناکامه وي پروګرام د وتلو کوډ ۱ سره پای ته رسوي (نو یو سکریپټ، یا د VS Code غځونه، پوهېدلی شي). د پروګرام دلیلونه ټاکي چې کومې ازموینې وچلېږي: "thundervm tests.thc جمع" یوازې هغه ازموینې (یا ډلې) چلوي چې نوم یې پر امر کرښه راغلی - "ډله/ازموینه" د یوې ډلې یوه ازموینه نوموي - د VS Code د ازموینو لړ یوه ازموینه یا یوه ډله همداسې چلوي.

    دلته هېڅ بهرنی نشته: دا ساده تندر دی، د لوستلو لپاره لیکل شوی.
