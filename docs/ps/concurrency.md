# د همکارۍ لارښود

یو د تندر پروګرام کولای شي څو کاره په یوه وخت کې وکړي. **کار** د پروګرام هغه برخه ده چې د
نورو تر څنګ ځي: یو سرور چې د اړیکې انتظار باسي پداسې حال کې چې پرده بیا بیا کښل کېږي، یو
مهالګر چې چلېږي پداسې حال کې چې پروګرام یوه کرښه لولي، پنځه فیلسوفان چې پر یوه مېز خوري.

په تندر کې همکاري دوه پوړه لري، او دواړه د لوستلو لپاره دي:

* **بنسټ** (کرنل)، ټولګی `کارونه`، چې مجازي ماشین پخپله ورکوي ځکه چې باید ورکړي یې: د
  کارونو پیلول او د پای انتظار یې، ویده کېدل، لار ورکول، او هغه دوه بنسټیز شیان چې باید
  نه‌وېشل‌کېدونکي وي - **قلف** او **حالت**. ټولګی تل شته، لکه `ریاضي`؛ راوړلو ته اړتیا نشته؛
* **کتابتون**، `راوړه "concurrency"`، چې بنسټ په شیانو کې پوښي او نور هرڅه ترې جوړوي -
  `کار`، `قلف`، `حالت`، `سیمافور`، `خنډ`، `کانال<ت>`، `ډله`، `دروازه`، `لوست_لیک_قلف` او
  `مهالګر` - په ساده تندر کې، په
  [`lib/thunder/ps/concurrency.th`](../../lib/thunder/ps/concurrency.th) کې. پرانیزئ یې: خنډ
  پنځلس کرښې دی، او همغه پنځلس کرښې دي چې یو درسي کتاب یې لیکي.

```thunder
راوړه "concurrency"

متغیر ټولټال = ۰
متغیر ساتونکې = قلف()

دنده ورزیاته()
    تکرار ن په واټن(۱، ۱۰۱)
        ساتونکې.قلف_کړه() سره
            ټولټال += ن

متغیر یو = کار(ورزیاته)
متغیر دوه = کار(ورزیاته)
یو.راته_ودرېږه()
دوه.راته_ودرېږه()
کرښه چاپ(ټولټال)          # ۱۰۱۰۰، په هر ځل کې
```

**وې ازمویئ:** بېلګه [۴۱ همکاري](../../samples/ps/41_concurrency.th) زده‌کوونکی له کارونو،
ورک شوي بدلون، قلف، کانالونو او بیده کېدو سره بلدوي؛ دا د IDE په بېلګو لیست کې ده. بیا هره
پرمختللې بېلګه یوه برخه نوره هم ژوره کوي - دا په لیست کې نه دي، نو له همدې ځایه یې پرانیزئ:
[کارونه](../../samples/advanced/ps/03_tasks.th)، [قلف](../../samples/advanced/ps/04_mutex.th)،
[کانالونه](../../samples/advanced/ps/05_channels.th)،
[انتظار](../../samples/advanced/ps/06_waiting.th)،
[فیلسوفان](../../samples/advanced/ps/07_philosophers.th) او
[مهالګرونه](../../samples/advanced/ps/08_timers.th).

## ۱. کارونه څنګه ځي

کارونه **شنه مزي** دي: مجازي ماشین پخپله یې چلوي، ټول پر هغه یوه مزي چې پروګرام یې لا کاروي.
کار له خپلې عملیاتي ډېرۍ، خپلو د بلنو چوکاټونو او هغې لارښوونې پرته بل څه نه دی چې پرې ودرېد،
نو پیلول یې ارزان دي او د دوو ترمنځ بدلون درې حرکتونه دي.

* **پروګرام د یوه کار په توګه پیلېږي، چې نوم یې `اصلي` دی.** `کار(چار)` بل پیلوي؛ نوی کار
  سمدلاسه چمتو دی خو ترڅو روان کار خپله وارۍ پرې نږدي نه ځي.
* **پروګرام هغه وخت پای ته رسېږي چې ټول کارونه پای ته ورسېږي** - نه کله چې `اصلي` پای ته
  ورسېږي. یو لا روان کار پروګرام ژوندی ساتي؛ `راته_ودرېږه()` ورته وکړئ، یا یې لغوه کړئ.
* **یوه وارۍ ۱۰۰ لارښوونې ده** (`thundervm --slice n`)، وروسته یې روان کار یو خوا کېږي او
  بل چمتو کار ځي. کار هغه وخت هم خپله وارۍ پرېږدي چې انتظار وباسي (`راته_ودرېږه`،
  `بیده شه`، قلف، حالت، کانال، `ولوله()`) یا `کارونه.لار ورکړه()` وبلي.
  `--slice 0` یوازې هلته بدلوي چې کار انتظار وباسي یا لار ورکړي: بشپړه همکارې وارۍ.
* **انتظار عادلانه دی**: هغه کارونه چې د قلف، حالت یا کانال انتظار باسي، په هغه ترتیب
  راویښېږي چې انتظار یې پیل کړی دی.
* **هیڅ شی رښتیا په یوه شېبه کې نه ځي**، نو پروګرام د کارونو له امله چټک نه دی - خو دوه
  داسې برخې چې هره یوه *انتظار* باسي، لکه دوه ساده کرښې لیکل کېږي، او همکاري همدې لپاره ده.
  (د څو پروسېسر هستو کارول بېله پوښتنه ده، او وروسته.)

### وارۍ په هر ځل کې یو شان ده

ځکه چې مجازي ماشین هر بدلون پخپله پرېکړه کوي، یو همکار پروګرام په هر ځل کې همغه شی چاپوي.
دا نادره او په قصد ده: یوه ننګونه (race) ټولګي ته ښودل کېږي، په ډیبګر کې ګام په ګام تېرېږي،
سمېږي، او د تمې شوې وتنې په وړاندې ازمویل کېږي.

`thundervm --schedule-seed n` د هرې وارۍ اوږدوالی بدلوي - خو بیا هم په تکرارېدونکې توګه، نو
پروګرام د څو بنسټونو (seeds) لاندې چلېدای شي چې هغه ننګونې راوباسي چې ثابته وارۍ یې پټوي.

### ننګونې رښتیني دي

بدلون *د دوو لارښوونو ترمنځ* کېږي، او `ټولټال += ۱` درې لارښوونې دي: لوستل، ورزیاتول، ساتل.
دوه کاره چې دا بې قلفه کوي بدلونونه ورکوي، دقیقاً لکه رښتیني مزي - بېلګه ۴۱ او پرمختللې ۰۴ وګورئ. قاعده
معمولي ده: **هر هغه څه چې دوه کاره یې لیکي، یا یو یې لیکي او بل یې لولي، د قلف دننه دي.**

هغه څه چې کارونه یې شریکوي عام متغیرونه دي، او هر هغه متغیر چې د دوی تړلې دندې یې نیسي.

## ۲. کتابتون: `راوړه "concurrency"`

### کار

| غړی | څه کوي |
| --- | --- |
| `کار(چار: دنده())` | چار د خپل کار په توګه پیلوي. |
| `ک.راته_ودرېږه()` | د پای انتظار یې باسي؛ نور کارونه په دې منځ کې ځي. |
| `ک.پای_ته_رسېدلی(): منطقي` | رښتیا، کله چې پای ته ورسېږي. |
| `ک.نوم(): متن` | `«کار#۲»`، `«کار#۳»`، ... (`«اصلي»` لومړی کار دی). |
| `ک.نښه(): عدد` | هغه شمېره چې بنسټ پرې پېژني یې. |

چار هیڅ دلیل نه اخلي، نو هغه کار چې خپل څه غواړي، له یوې تړلې دندې یې اخلي. یاد ولرئ چې یو
نیول شوی متغیر یو متغیر دی، شریک: د دې لپاره چې هر کار خپل ولري، په خپله دنده کې یې جوړ کړئ.

### قلف او ساتونکی - یوازې یو کار دننه

| غړی | څه کوي |
| --- | --- |
| `قلف()` | نوی، خلاص قلف. |
| `ق.قلف_کړه(): ساتونکی` | نیسي یې (که بل یې لري انتظار باسي)؛ ساتونکی راګرځوي. |
| `ق.هڅه_وکړه(): منطقي` | یوازې که خلاص وي نیسي یې؛ هېڅکله انتظار نه باسي. |
| `ق.خلاص_کړه()` | په لاس یې بېرته ورکوي (یوازې هغه چې لري یې). |
| `ق.نښه(): عدد` | هغه شمېره چې بنسټ پرې پېژني یې. |
| `ساتونکی.وتړه()` | قلف بېرته ورکوي (هغه څه چې `سره` یې بلي). |

`ق.قلف_کړه() سره` د لیکلو سمه لار ده: قلف د بلاک په پای کې بېرته ورکول کېږي، په هر ډول چې
بلاک پای ته ورسېږي، نو د حساسې برخې دننه `راګرځه` یا `ودرېږه` نور قلف نیولی نه پرېږدي.

د هغه قلف نیول چې کار یې لا لري تېروتنه ده (`R041`) - یوازې د خپل ځان انتظار به وي. د هغه
قلف بېرته ورکول چې کار یې نه لري هم تېروتنه ده (`R040`).

### حالت - د قلف دننه انتظار

حالت هغه څه دی چې کار یې *د قلف په نیولو کې* انتظار باسي: «لیکه تشه نه ده»، «ټول چمتو دي».
`انتظار_وباسه()` د انتظار پر مهال قلف بېرته ورکوي او تر تلو مخکې یې بیا نیسي، نو حالت لاندې
نه بدلېږي. **تل په یوه تکرار کې انتظار وباسئ** - کېدای شي بل کار مخکې راویښ شوی وي.

| غړی | څه کوي |
| --- | --- |
| `حالت(ق: قلف)` | هغه حالت چې دې قلف پورې تړلی دی. |
| `ح.انتظار_وباسه()` | قلف خلاصوي، د خبر انتظار باسي، قلف بېرته نیسي. |
| `ح.خبر()` | هغه کار راویښوي چې تر ټولو ډېر یې انتظار ایستلی. |
| `ح.ټولو_ته_خبر()` | هر انتظار باسونکی کار راویښوي. |

### سیمافور، خنډ، ډله، دروازه، لوست_لیک_قلف

| جوړښت | غړي |
| --- | --- |
| `سیمافور(اجازې)` | `اجازه_واخله()`، `بېرته_ورکړه()`، `د_اجازې_هڅه(): منطقي`، `شته_شمېر(): عدد` |
| `خنډ(ګډونوال)` | `انتظار_وباسه()`، `ګډونوال(): عدد` |
| `ډله()` | `ورزیات_کړه(ن)`، `بشپړه_شوه()`، `انتظار_وباسه()`، `شمېر(): عدد` |
| `دروازه(شمېر)` | `یو_کم_کړه()`، `انتظار_وباسه()`، `شمېر(): عدد`، `پرانیستې_ده(): منطقي` |
| `لوست_لیک_قلف()` | `د_لوست_قلف()`، `د_لوست_خلاصول()`، `د_لیک_قلف()`، `د_لیک_خلاصول()`، `لوستونکي(): عدد` |

**سیمافور** شمېرل شوې اجازه ده: په یوه وخت کې تر ډېره *n* کاره دننه. **خنډ** د کتنې ځای دی چې
بیا هم کارېدای شي - هیڅوک نه تېرېږي ترڅو ټول ورسېږي. **ډله** د یوې ډلې کارونو انتظار باسي
پرته له نومولو یې. **دروازه** یو ځل پرانیستل کېږي، کله چې شمېر یې صفر شي، او پرانیستې پاتې
کېږي. **لوست_لیک_قلف** پرېږدي چې هر شمېر لوستونکي یوځای یې ولري، خو لیکونکی یې یوازې لري.

### کانال - اړیکه

| غړی | څه کوي |
| --- | --- |
| `کانال(ظرفیت)` | کانال چې د دومره ارزښتونو ځای لري (`۰`: لاس په لاس). |
| `ک.ولېږه(ارزښت)` | لېږي یې، او ترڅو ډک وي انتظار باسي. |
| `ک.واخله(): ت` | بل ارزښت اخلي، او ترڅو تش وي انتظار باسي. |
| `ک.بل_شته(): منطقي` | انتظار باسي ترڅو *د دې کار لپاره* ارزښت وي، یا کانال تړلی او تش شي. |
| `ک.وتړه()` | نور څه نه لېږل کېږي؛ انتظار باسونکي راویښېږي. |
| `ک.تړلی_دی()`، `ک.شمېر()`، `ک.ظرفیت()` | څه کوي. |

`بل_شته()` هغه ارزښت چې یې ولید د پوښتونکي کار لپاره ساتي، نو دوه کاروونکي په داسې تکرار کې
د وروستي پر سر نه جنګېږي. د `۰` ظرفیت **لاس په لاس** دی: لېږونکی انتظار باسي ترڅو اخیستونکی
ارزښت له لاسه واخلي. له تړلي او تش کانال څخه اخیستل، یا په تړلي کې لېږل، پروګرام دروي (`R043`).

### مهالګر - وروسته، او بیا بیا

| غړی | څه کوي |
| --- | --- |
| `مهالګر.وروسته(ملي_ثانیې، چار): مهالګر` | چار یو ځل چلوي، د دومره ملي ثانیو وروسته. |
| `مهالګر.هر_ځل(ملي_ثانیې، چار): مهالګر` | بیا بیا یې چلوي، ترڅو لغوه شي. |
| `م.لغوه_کړه()` | نور (بیا) نه چلېږي. |
| `م.لغوه_شوی()`، `م.راته_ودرېږه()` | څه کوي؛ د کار یې د پای انتظار. |

مهالګر *یو کار دی* چې بیده کېږي، نو د پروګرام پاتې برخه د انتظار پر مهال خپل کار کوي - او کله
چې ټول کارونه یوازې د وخت انتظار باسي، مجازي ماشین رښتیا بیده کېږي: پروګرام تر راتلونکي
مهالګره پورې هیڅ پروسېسر نه کاروي. هغه تکراري مهالګر چې هېڅکله لغوه نه شي، پروګرام تل ژوندی ساتي.

## ۳. بنسټ: ټولګی `کارونه`

پورتنی کتابتون په همدې لیکل شوی دی. دا له ساده بشپړو عددونو سره کار کوي - کار، قلف او حالت
هر یو شمېره لري، لکه څنګه چې ساکټ نښه لري - نو ډول‌ګر یو له بل نشي بېلولای: شیان همدې لپاره
دي. مستقیم یې وکاروئ چې وګورئ لاندې یې څه دي.

| دنده | څه کوي |
| --- | --- |
| `کارونه.پیل کړه(چار: دنده()): عدد` | کار پیلوي؛ شمېره یې ورکوي. |
| `کارونه.راته ودرېږه(کار: عدد)` | د هغه کار د پای انتظار باسي. |
| `کارونه.پای ته رسېدلی(کار: عدد): منطقي` | رښتیا، کله چې پای ته ورسېږي. |
| `کارونه.بیده شه(ملي_ثانیې: عدد)` | دا کار انتظار باسي؛ نور ځي. |
| `کارونه.لار ورکړه()` | نورو ته همدا اوس وار ورکوي. |
| `کارونه.اوسنی(): عدد` | د روان کار شمېره. |
| `کارونه.نوم(کار: عدد): متن` | `«اصلي»`، `«کار#۲»`، ... |
| `کارونه.شمېر(): عدد` | څومره کارونه پای ته نه دي رسېدلي. |
| `کارونه.نوی قلف(): عدد` | نوی قلف. |
| `کارونه.قلف کړه(قلف: عدد)` / `کارونه.خلاص کړه(قلف: عدد)` | نیسي یې (په انتظار) / بېرته یې ورکوي. |
| `کارونه.هڅه وکړه(قلف: عدد): منطقي` | یوازې که خلاص وي نیسي یې. |
| `کارونه.نوی حالت(): عدد` | نوی حالت. |
| `کارونه.انتظار وباسه(حالت: عدد، قلف: عدد)` | خلاصوي، انتظار باسي، قلف بېرته نیسي. |
| `کارونه.خبر(حالت)` / `کارونه.ټولو ته خبر(حالت)` | یو / ټول راویښوي. |

## ۴. د بهرنۍ نړۍ انتظار

| عملیه | د وارۍ ویشونکي لاندې |
| --- | --- |
| `سیسټم.انتظار(ملي)`، `کارونه.بیده شه(ملي)` | یوازې دا کار انتظار باسي. کله چې ټول کارونه د وخت انتظار باسي، ماشین پخپله تر لومړۍ نېټې پورې بیده کېږي - هیڅ بوخت انتظار نشته. |
| `ګرافیک.چوکاټ()` | کار د راتلونکي چوکاټ انتظار باسي؛ نور کارونه په دې منځ کې ځي. |
| `ولوله()` | کار انتظار باسي. کرښه هغه وخت لوستل کېږي چې بل څه نشي چلېدای، نو پروګرام په یوه کار کې پوښتنه کولای شي او په بل کې خپل کار. |
| `د ننوت پای()` | سمدلاسه ځواب وايي؛ وارۍ نه پرېږدي. |
| ساکټونه، `سیسټم.وچلوه`، `فایل.*` | **ټول کارونه دروي** ترڅو چلېږي. که مهم وي، ساکټ ته د ۰ وخت حد ورکړئ او پوښتنه یې کړئ. |
| بهرنۍ C++ دندې | ټول کارونه دروي، لکه هره بله C++ بلنه. |

## ۵. څه چې (لا) نشي کېدای

* **کار د بلنې دننه انتظار نشي ایستلای.** د `پر هر یو`، `چاڼ کړه` او `راټول کړه` بلنې، او
  هغه بلنې چې بهرنۍ دنده یې کوي، د C++ ډېرۍ پر سر ځي، چې یو خوا کېدای نشي. انتظار پکې پاکه
  تېروتنه ده (`R038`). ویده کېدل پکې روا دي، خو ټول پروګرام ورسره درېږي.
* **ډیبګر لا کارونه نه لیستوي.** په هغه کار کې درېږي چې روان و او د همغه کار ډېرۍ او متغیرونه
  ښيي، او ګام هغه کار پورې اړه لري چې پکې غوښتل شوی دی ([د ډیبګ لارښود](debugging.md)) - خو
  VS Code لا یو مزی ښيي، نو د درېدنې پر مهال بل کار له هغه ځایه نشي کتل کېدای.
* **څو پروسېسر هستې** نه کارېږي: هر کار پر یوه مزي دی.

## ۶. کله چې هیڅ شی مخته نشي تلای: بند کرښه

که هر پاتې کار د هغه څه انتظار وباسي چې یوازې بل انتظار باسونکی کار یې کولای شي، نو بیا به
هېڅکله څه ونه شي. مجازي ماشین سمدلاسه پوهېږي او پروګرام په `R037` دروي، او وايي چې هر کار د
څه انتظار باسي:

```
تېروتنه R037: بند کرښه: ټول کارونه انتظار باسي او هیڅ یو یې مخته تلای نشي (اصلي د هغه
قلف انتظار باسي چې کار#۲ یې لري؛ کار#۲ د اصلي د پای انتظار باسي)
```

همدا د دې ټولې لارې اصل دی: بند کرښه یو پیغام دی چې د کرښې شمېره لري، نه هغه پروګرام چې
ځوړند پاتې شي.

## ۷. تېروتنې

| کوډ | کله |
| --- | --- |
| `R037` | بند کرښه: ټول کارونه انتظار باسي او هیڅ یو مخته تلای نشي. |
| `R038` | کار د بلنې (`پر هر یو`، `چاڼ کړه`، `راټول کړه`، بهرنۍ بلنه) دننه انتظار وایست. |
| `R039` | هغه شمېره چې د دې پروګرام کار، قلف یا حالت نه ده. |
| `R040` | `خلاص کړه` / `انتظار وباسه` پر هغه قلف چې دا کار یې نه لري. |
| `R041` | د هغه قلف نیول چې دا کار یې لا لري. |
| `R042` | کار د خپل ځان د پای انتظار وایست. |
| `R043` | `ناکام شه("...")`: پروګرام ځان ودراوه (کانال پرې وايي چې څه ناسم شول). |

د هر کار د اجرا تېروتنه ټول پروګرام دروي، او راپور هغه کار نوموي چې پکې پېښه شوه.

## ۸. `ناکام شه` - پروګرام په قصد درول

`ناکام شه(پیغام)` پروګرام د ستاسې خپل پیغام سره دروي، لکه څنګه چې یوه ناسمه دننۍ بلنه یې
دروي: د سرچینې کرښې او د بلنو ډېرۍ سره. یو کتابتون پرې وايي چې پروګرام څه ناسم وکړل - کانال
همداسې کوي - او پروګرام یې د خپلې کتنې لپاره کارولای شي.
