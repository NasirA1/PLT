# د ډېټا جوړښتونو لارښود

`راوړه "datastructures"` کلاسیک ډېټا جوړښتونه پروګرام ته راوړي: **ډېرۍ** (stack)،
**لیکه** (queue)، **دوسرې لیکه** (deque)، **ځنځیر** (یو اړخیز او دوه اړخیز)، **د لټون
دوه‌اړخیزه ونه**، **د لومړیتوب لیکه** (heap)، دوه ډوله **ټولګه** (set)، **ګراف** له خپلو
لټونونو سره، او **مختاړې ونه** (trie). په فایل کې هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/datastructures.th`](../../lib/thunder/ps/datastructures.th) کې، د لوستلو لپاره
لیکل شوی: پرانیزئ یې او وګورئ چې هر جوړښت رښتیا څنګه کار کوي. انګلیسي فایل
([`lib/thunder/en/datastructures.th`](../../lib/thunder/en/datastructures.th)) همدا جوړښتونه له
انګلیسي نومونو سره دي؛ دواړه پخپله، د اوزارو تر څنګ، موندل کېږي.

هر جوړښت خپل یو **ټولګی** دی، چې خپل جوړښت او دندې پکې دي: ډېرۍ `ډېرۍ.ډېرۍ<ت>` ده، د
`ډېرۍ.نوې()` سره جوړېږي او د `ډېرۍ.ورزیات_کړه`، `ډېرۍ.واخله` ... سره کارول کېږي؛ لیکه
`لیکه.لیکه<ت>` ده له `لیکه.ورزیات_کړه`، `لیکه.واخله` ... سره؛ او همداسې لاندې.

| ټولګی | جوړښت(ونه) | | ټولګی | جوړښت(ونه) |
| --- | --- | --- | --- | --- |
| `ډېرۍ` | `ډېرۍ.ډېرۍ<ت>` | | `ټولګه` | `ټولګه.ټولګه<ت>` |
| `لیکه` | `لیکه.لیکه<ت>` | | `ترتیب_شوې_ټولګه` | `ترتیب_شوې_ټولګه.ترتیب_شوې_ټولګه<ت>` |
| `ځنځیر` | `ځنځیر.ځنځیر<ت>`، `ځنځیر.د_ځنځیر_غوټۍ<ت>` | | `دوسرې_لیکه` | `دوسرې_لیکه.دوسرې_لیکه<ت>` |
| `ونه` | `ونه.ونه<ت>`، `ونه.د_ونې_غوټۍ<ت>` | | `دوه_اړخیز_ځنځیر` | `دوه_اړخیز_ځنځیر.دوه_اړخیز_ځنځیر<ت>`، `دوه_اړخیز_ځنځیر.د_دوه_اړخیز_ځنځیر_غوټۍ<ت>` |
| `لومړیتوب_لیکه` | `لومړیتوب_لیکه.لومړیتوب_لیکه<ت>` | | `ګراف` | `ګراف.ګراف<ت>` |
| `مختاړې_ونه` | `مختاړې_ونه.مختاړې_ونه`، `مختاړې_ونه.د_مختاړې_ونې_غوټۍ` | | | |

**د ټولګو نومونه ساتل شوي دي.** په هغه پروګرام کې چې `"datastructures"` راوړي، `ډېرۍ`،
`لیکه`، `ځنځیر`، `ونه`، `لومړیتوب_لیکه`، `ټولګه`، `ترتیب_شوې_ټولګه`، `دوسرې_لیکه`،
`دوه_اړخیز_ځنځیر`، `ګراف` او `مختاړې_ونه` ټولګي نوموي، نو هېڅ متغیر، پارامټر یا دنده دا نوم
نشي لرلای (تېروتنه `S065`، «'ونه' د یوه ټولګي نوم دی؛ دې متغیر ته بل نوم ورکړئ»). متغیر د هغه
څه په نوم ونوموئ چې ساتي یې: `کاسې`، `وییونه`، `لیدل_شوي`، `لارې`.

هر جوړښت **عمومي (generic)** دی: `ډېرۍ.ډېرۍ<ت>` د هر ډول توکي `ت` ساتي، چې له کارونې
معلومېږي - `ډېرۍ.ډېرۍ(توکي: ["الف"])` یوه `ډېرۍ.ډېرۍ<متن>` ده، او
`متغیر د: ډېرۍ.ډېرۍ<عدد> = ډېرۍ.نوې()` وايي چې تشه به څه وساتي (د [ژبې لارښود](language.md)،
۸ برخه). ونه او د لومړیتوب لیکه خپل توکي د `<` سره پرتله کوي، نو توکي یې عددونه یا متنونه
دي. له تش جوړښته اخیستل پروګرام د اجرا له تېروتنې سره دروي، لکه د دننۍ دندې ناسمه بلنه؛
لومړی `ډېرۍ.تشه_ده` / `لیکه.تشه_ده` / `لومړیتوب_لیکه.تشه_ده` وپوښتئ.

**ویې آزمویئ:** [`samples/advanced/ps/01_datastructures.th`](../../samples/advanced/ps/01_datastructures.th)
هر جوړښت په کار اچوي (انګلیسي:
[`samples/advanced/en/01_datastructures.th`](../../samples/advanced/en/01_datastructures.th)).
دا بېلګې په قصد د IDE په لړ کې نشته - له همدې ځایه یې پرانیزئ.

## ډېرۍ - وروستی دننه، لومړی بهر

د کاسو ډېرۍ: هغه چې وروستی سر ته کېښودل شي، لومړی بېرته راځي. هره عملیه O(1) ده.

| دنده | څه کوي |
| --- | --- |
| `ډېرۍ.نوې<ت>(): ډېرۍ.ډېرۍ<ت>` | یوه نوې، تشه ډېرۍ. |
| `ډېرۍ.ورزیات_کړه<ت>(ډېرۍ_، ارزښت)` | یو ارزښت سر ته ږدي. |
| `ډېرۍ.واخله<ت>(ډېرۍ_): ت` | د سر ارزښت اخلي او راګرځوي یې. |
| `ډېرۍ.وګوره<ت>(ډېرۍ_): ت` | د سر ارزښت، بې له اخیستلو. |
| `ډېرۍ.کچه<ت>(ډېرۍ_): عدد` | څومره ارزښتونه لري. |
| `ډېرۍ.تشه_ده<ت>(ډېرۍ_): منطقي` | رښتیا کله چې هېڅ پرې نه وي. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر کاسې: ډېرۍ.ډېرۍ<عدد> = ډېرۍ.نوې()
ډېرۍ.ورزیات_کړه(کاسې، ۱)
ډېرۍ.ورزیات_کړه(کاسې، ۲)
کرښه چاپ(ډېرۍ.واخله(کاسې))   # ۲ - وروستی دننه، لومړی بهر
کرښه چاپ(ډېرۍ.وګوره(کاسې))   # ۱ - لا هلته دی
```

`ډېرۍ.ورزیات_کړه` د ټولګي خپله ده؛ د ژبې ساده `ورزیات کړه` (د لړیو لپاره) هر ځای خپله مانا
ساتي - د ټولګي دننه هم، چېرې چې `ډېرۍ.ورزیات_کړه` بشپړه لیکل کېږي.

## لیکه - لومړی دننه، لومړی بهر

د دوکان مخې ته لیکه: `لیکه.ورزیات_کړه` پای ته درېږي، `لیکه.واخله` سر خدمتوي. د سر شاخص
ښویېږي، پر ځای د دې چې هر توکی وخوځوي، نو دواړه په منځني ډول O(1) دي.

| دنده | څه کوي |
| --- | --- |
| `لیکه.نوې<ت>(): لیکه.لیکه<ت>` | یوه نوې، تشه لیکه. |
| `لیکه.ورزیات_کړه<ت>(لیکه_، ارزښت)` | د لیکې پای ته درېږي. |
| `لیکه.واخله<ت>(لیکه_): ت` | سر خدمتوي (لیرې کوي یې او راګرځوي یې). |
| `لیکه.وګوره<ت>(لیکه_): ت` | سر، بې له خدمتولو. |
| `لیکه.کچه<ت>(لیکه_): عدد` | څومره ارزښتونه انتظار کوي. |
| `لیکه.تشه_ده<ت>(لیکه_): منطقي` | رښتیا کله چې هیڅوک انتظار نه کوي. |

## ځنځیر - د غوټیو کړۍ په کړۍ

هره غوټۍ (`ځنځیر.د_ځنځیر_غوټۍ<ت>`) خپل ارزښت او راتلونکې غوټۍ ساتي؛ `هېڅ` ځنځیر پای ته
رسوي. دا د درسي کتابونو انځور دی، له یوه تکراري جوړښته جوړ. سر ته ورزیاتول O(1) دي؛ پای ته
ورزیاتول او لټون ځنځیر ګرځي، O(n).

| دنده | څه کوي |
| --- | --- |
| `ځنځیر.نوی<ت>(): ځنځیر.ځنځیر<ت>` | یو نوی، تش ځنځیر. |
| `ځنځیر.سر_ته_ورزیات_کړه<ت>(ځنځیر_، ارزښت)` | سر ته ورزیاتوي، O(1). |
| `ځنځیر.پای_ته_ورزیات_کړه<ت>(ځنځیر_، ارزښت)` | پای ته ورزیاتوي. |
| `ځنځیر.له_سره_واخله<ت>(ځنځیر_): ت` | د سر ارزښت لیرې کوي او راګرځوي یې. |
| `ځنځیر.لیرې_کړه<ت>(ځنځیر_، ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي؛ رښتیا که ومونده. |
| `ځنځیر.لري<ت>(ځنځیر_، ارزښت): منطقي` | رښتیا که کومه غوټۍ دا ارزښت لري. |
| `ځنځیر.کچه<ت>(ځنځیر_): عدد` | څومره ارزښتونه لري. |
| `ځنځیر.لړۍ_کړه<ت>(ځنځیر_): ت[]` | ارزښتونه د ځنځیر په ترتیب، د ساده لړۍ په بڼه. |

## د لټون دوه‌اړخیزه ونه - ترتیب شوي لټونونه

د هرې غوټۍ کیڼه څانګه کوچني ارزښتونه لري، ښۍ یې لوی، نو یو ارزښت په O(لوړوالی) ګامونو
کې موندل کېږي - O(log n) کله چې ونه برابره وي. تکراري ارزښتونه له پامه غورځول کېږي.

| دنده | څه کوي |
| --- | --- |
| `ونه.نوې<ت>(): ونه.ونه<ت>` | یوه نوې، تشه ونه. |
| `ونه.ورزیات_کړه<ت>(ونه_، ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورزیاتوي. |
| `ونه.لري<ت>(ونه_، ارزښت): منطقي` | رښتیا که ارزښت په ونه کې وي. |
| `ونه.لیرې_کړه<ت>(ونه_، ارزښت): منطقي` | ارزښت لیرې کوي؛ رښتیا که هلته و. |
| `ونه.کچه<ت>(ونه_): عدد` | څومره ارزښتونه لري. |
| `ونه.لوړوالی<ت>(ونه_): عدد` | له ریښې تر ټولو اوږده لار له څومره غوټیو تېرېږي (تشه: ۰). |
| `ونه.کمینه<ت>(ونه_): ت` / `ونه.اعظمه<ت>(ونه_): ت` | د ترتیب دواړه څنډې. |
| `ونه.په_ترتیب<ت>(ونه_): ت[]` | هر ارزښت په پورته کېدونکي ترتیب (منځنی تګ). |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر وییونه: ونه.ونه<متن> = ونه.نوې()     # نه «متغیر ونه»: ونه د ټولګي نوم دی
تکرار ویی په ["ناک"، "مڼه"، "انځر"]
    ونه.ورزیات_کړه(وییونه، ویی)
کرښه چاپ(ونه.په_ترتیب(وییونه))     # [«انځر»، «مڼه»، «ناک»] - ونه ترتیب ساتي
کرښه چاپ(ونه.لري(وییونه، "انځر"))  # رښتیا، په O(log n) ګامونو کې موندل شوی
```

## د لومړیتوب لیکه - کمینه لومړی

`لومړیتوب_لیکه.واخله` همېش تر ټولو کوچنی ارزښت لومړی راکوي، ارزښتونه چې په هر ترتیب راغلي
وي - د لومړیتوب لیکه. دا یوه دوه‌اړخیزه ونه ده چې په یوه لړۍ کې ځای شوې: د `ش` شاخص بچي په
`۲*ش + ۱` او `۲*ش + ۲` کې ناست دي، او هر مور و پلار له خپلو بچیو `<=` دی. ورزیاتول او اخیستل
O(log n) دي؛ کتل O(1).

| دنده | څه کوي |
| --- | --- |
| `لومړیتوب_لیکه.نوې<ت>(): لومړیتوب_لیکه.لومړیتوب_لیکه<ت>` | یوه نوې، تشه لیکه. |
| `لومړیتوب_لیکه.ورزیات_کړه<ت>(لیکه_، ارزښت)` | یو ارزښت ورزیاتوي. |
| `لومړیتوب_لیکه.واخله<ت>(لیکه_): ت` | تر ټولو کوچنی ارزښت لیرې کوي او راګرځوي یې. |
| `لومړیتوب_لیکه.وګوره<ت>(لیکه_): ت` | تر ټولو کوچنی، بې له لیرې کولو. |
| `لومړیتوب_لیکه.کچه<ت>(لیکه_): عدد` | څومره ارزښتونه لري. |
| `لومړیتوب_لیکه.تشه_ده<ت>(لیکه_): منطقي` | رښتیا کله چې هېڅ نه لري. |

## ټولګه - ځانګړي توکي

راټولونه چې هر ارزښت پکې یو ځل راځي. د تندر پر خپله نقشه جوړه ده - ارزښت کیلۍ ده - نو
ورزیاتول، لیرې کول او شتون کتل ټول O(1) دي، او توکي د نقشې کیلۍ دي: `عدد`، `منطقي` یا
`متن`. `ټولګه.ارزښتونه` یې د لومړي ورزیاتېدو په ترتیب راګرځوي.

| دنده | څه کوي |
| --- | --- |
| `ټولګه.نوې<ت>(): ټولګه.ټولګه<ت>` | یوه نوې، تشه ټولګه. |
| `ټولګه.ورزیات_کړه<ت>(ټولګه_، ارزښت)` | یو ارزښت ورننباسي؛ هغه چې وي، یو پاتې کېږي. |
| `ټولګه.لیرې_کړه<ت>(ټولګه_، ارزښت): منطقي` | یو ارزښت باسي؛ رښتیا که هلته و. |
| `ټولګه.لري<ت>(ټولګه_، ارزښت): منطقي` | رښتیا که ارزښت پکې وي. |
| `ټولګه.کچه<ت>(ټولګه_): عدد` / `ټولګه.تشه_ده<ت>(ټولګه_): منطقي` | څومره ارزښتونه لري. |
| `ټولګه.ارزښتونه<ت>(ټولګه_): ت[]` | ارزښتونه، د لومړي ورزیاتېدو په ترتیب. |
| `ټولګه.یوځای<ت>(الف، ب): ټولګه.ټولګه<ت>` | هر ارزښت چې په یوه یا بله کې وي. |
| `ټولګه.ګډ<ت>(الف، ب): ټولګه.ټولګه<ت>` | هر ارزښت چې په دواړو کې وي. |
| `ټولګه.توپیر<ت>(الف، ب): ټولګه.ټولګه<ت>` | د الف هر هغه ارزښت چې په ب کې نشته. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر لیدل_شوي: ټولګه.ټولګه<متن> = ټولګه.نوې()
ټولګه.ورزیات_کړه(لیدل_شوي، "سور")
ټولګه.ورزیات_کړه(لیدل_شوي، "شین")
ټولګه.ورزیات_کړه(لیدل_شوي، "سور")          # له وړاندې شته: لا هم یو «سور»
کرښه چاپ(ټولګه.ارزښتونه(لیدل_شوي))          # [«سور»، «شین»]
کرښه چاپ(ټولګه.لري(لیدل_شوي، "زرغون"))     # درواغ
```

## ترتیب شوې ټولګه - ځانګړي او اڼل شوي

ټولګه چې خپل ارزښتونه په پورته کېدونکي ترتیب ساتي: لاندې یې د لټون دوه‌اړخیزه ونه ده،
نو ورزیاتول، لیرې کول او شتون کتل O(log n) دي او `ترتیب_شوې_ټولګه.ارزښتونه` ترتیب شوي
راوځي. توکي د `<` سره پرتله کېږي، نو عددونه یا متنونه دي.

| دنده | څه کوي |
| --- | --- |
| `ترتیب_شوې_ټولګه.نوې<ت>(): ترتیب_شوې_ټولګه.ترتیب_شوې_ټولګه<ت>` | یوه نوې، تشه ترتیب شوې ټولګه. |
| `ترتیب_شوې_ټولګه.ورزیات_کړه<ت>(ټولګه_، ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورننباسي. |
| `ترتیب_شوې_ټولګه.لیرې_کړه<ت>(ټولګه_، ارزښت): منطقي` | یو ارزښت باسي؛ رښتیا که هلته و. |
| `ترتیب_شوې_ټولګه.لري<ت>(ټولګه_، ارزښت): منطقي` | رښتیا که ارزښت پکې وي. |
| `ترتیب_شوې_ټولګه.کچه<ت>(ټولګه_): عدد` / `ترتیب_شوې_ټولګه.تشه_ده<ت>(ټولګه_): منطقي` | څومره ارزښتونه لري. |
| `ترتیب_شوې_ټولګه.ارزښتونه<ت>(ټولګه_): ت[]` | ارزښتونه، په پورته کېدونکي ترتیب. |
| `ترتیب_شوې_ټولګه.کمینه<ت>(ټولګه_): ت` / `ترتیب_شوې_ټولګه.اعظمه<ت>(ټولګه_): ت` | د ترتیب دواړه څنډې. |

## دوسرې لیکه - دواړه سرونه پرانیستي

لیکه چې دواړه سرونه یې خدمت کوي: ارزښتونه له مخې او له شا دواړو ننوځي او وځي (هغه جوړښت
چې د ښوېدونکو کړکیو او د کار د غلا تر شا دی). دوه ډېرۍ شا په شا هره عملیه په منځني ډول
O(1) ساتي.

| دنده | څه کوي |
| --- | --- |
| `دوسرې_لیکه.نوې<ت>(): دوسرې_لیکه.دوسرې_لیکه<ت>` | یوه نوې، تشه دوسرې لیکه. |
| `دوسرې_لیکه.سر_ته_ورزیات_کړه<ت>(لیکه_، ارزښت)` / `دوسرې_لیکه.پای_ته_ورزیات_کړه<ت>(لیکه_، ارزښت)` | هر سر ته ارزښت ږدي. |
| `دوسرې_لیکه.له_سره_واخله<ت>(لیکه_): ت` / `دوسرې_لیکه.له_پایه_واخله<ت>(لیکه_): ت` | له هر سره ارزښت اخلي. |
| `دوسرې_لیکه.سر_وګوره<ت>(لیکه_): ت` / `دوسرې_لیکه.پای_وګوره<ت>(لیکه_): ت` | ګوري، بې له اخیستلو. |
| `دوسرې_لیکه.کچه<ت>(لیکه_): عدد` / `دوسرې_لیکه.تشه_ده<ت>(لیکه_): منطقي` | څومره ارزښتونه لري. |
| `دوسرې_لیکه.لړۍ_کړه<ت>(لیکه_): ت[]` | ارزښتونه له مخې تر شا. |

## دوه اړخیز ځنځیر - دواړه لوري ګرځي

لکه ځنځیر، خو هره غوټۍ (`دوه_اړخیز_ځنځیر.د_دوه_اړخیز_ځنځیر_غوټۍ<ت>`) مخکېنۍ هم پېژني او
ځنځیر دواړه سرونه ساتي: په دواړو سرونو کې ورزیاتول او لیرې کول O(1) دي، او شاتګ هم کېدای شي.

| دنده | څه کوي |
| --- | --- |
| `دوه_اړخیز_ځنځیر.نوی<ت>(): دوه_اړخیز_ځنځیر.دوه_اړخیز_ځنځیر<ت>` | یو نوی، تش ځنځیر. |
| `دوه_اړخیز_ځنځیر.سر_ته_ورزیات_کړه<ت>(ځنځیر_، ارزښت)` / `دوه_اړخیز_ځنځیر.پای_ته_ورزیات_کړه<ت>(ځنځیر_، ارزښت)` | هر سر ته، O(1). |
| `دوه_اړخیز_ځنځیر.له_سره_واخله<ت>(ځنځیر_): ت` / `دوه_اړخیز_ځنځیر.له_پایه_واخله<ت>(ځنځیر_): ت` | له هر سره، O(1). |
| `دوه_اړخیز_ځنځیر.لیرې_کړه<ت>(ځنځیر_، ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي. |
| `دوه_اړخیز_ځنځیر.لري<ت>(ځنځیر_، ارزښت): منطقي` | رښتیا که کومه غوټۍ دا ارزښت لري. |
| `دوه_اړخیز_ځنځیر.کچه<ت>(ځنځیر_): عدد` | څومره ارزښتونه لري. |
| `دوه_اړخیز_ځنځیر.لړۍ_کړه<ت>(ځنځیر_): ت[]` / `دوه_اړخیز_ځنځیر.سرچپه_لړۍ_کړه<ت>(ځنځیر_): ت[]` | دواړه د تګ لوري. |

## ګراف - څوکې، غاړې او لټونونه

د ګاونډیتوب نقشه: هره څوکه هغو څوکو ته نقشه کېږي چې غاړه ورته ځي. غاړې یو لوري دي؛
`ګراف.ونښلوه` د ناجهته ګراف لپاره دواړه لوري ورزیاتوي. څوکې د نقشې کیلۍ دي (عدد، منطقي
یا متن). لټونونه د همدې فایل `لیکه.لیکه` او `ټولګه.ټولګه` کاروي.

| دنده | څه کوي |
| --- | --- |
| `ګراف.نوی<ت>(): ګراف.ګراف<ت>` | یو نوی، تش ګراف. |
| `ګراف.څوکه_ورزیاته_کړه<ت>(ګراف_، څوکه)` | څوکه بې غاړو ورزیاتوي. |
| `ګراف.غاړه_ورزیاته_کړه<ت>(ګراف_، له_، ته_)` | یولورې غاړه (څوکې په اړتیا ورزیاتېږي). |
| `ګراف.ونښلوه<ت>(ګراف_، الف_، ب_)` | ناجهته غاړه: یوه هرې خوا ته. |
| `ګراف.څوکې<ت>(ګراف_): ت[]` / `ګراف.ګاونډیان<ت>(ګراف_، څوکه): ت[]` | څه شته. |
| `ګراف.پلن_لټون<ت>(ګراف_، پیل): ت[]` | پلن لټون (BFS): هره رسېدونکې څوکه، لومړی نږدې کړۍ. |
| `ګراف.ژور_لټون<ت>(ګراف_، پیل): ت[]` | ژور لټون (DFS): هره لار تر پایه، بیا بله. |
| `ګراف.لنډه_لار<ت>(ګراف_، له_، ته_): ت[]` | تر ټولو لږې غاړې، `[له، ...، ته]`؛ تشه کله چې نه رسېږي. |
| `ګراف.لار_لري<ت>(ګراف_، له_، ته_): منطقي` | رښتیا که د غاړو کوم ځنځیر هلته ځي. |

```thunder
# ژبه: ps

متغیر لارې: ګراف.ګراف<متن> = ګراف.نوی()

```

## مختاړې ونه - د مختاړو ونه (trie)

هر ویی خپله لار له هر هغه ویي سره شریکوي چې همداسې پیلېږي، نو لټون او د مختاړي پوښتنې
د ویي د اوږدوالي بیه لري، که هر څومره وییونه پکې وي - هغه جوړښت چې د بشپړونې (autocomplete)
تر شا دی. (مختاړې ونه متنونه ساتي، نو عمومي نه ده.)

| دنده | څه کوي |
| --- | --- |
| `مختاړې_ونه.نوې(): مختاړې_ونه.مختاړې_ونه` | یوه نوې، تشه ونه. |
| `مختاړې_ونه.ورزیات_کړه(ونه_، ویی)` | ویی ورزیاتوي (دوه ځله یې یو ساتي). |

| `مختاړې_ونه.مختاړی_لري(ونه_، مختاړی): منطقي` | رښتیا که کوم ویی پرې پیلېږي. |
| `مختاړې_ونه.کچه(ونه_): عدد` | څومره بېلابېل وییونه لري. |
| `مختاړې_ونه.وییونه(ونه_): متن[]` | هر ویی، د الفبا په ترتیب. |
