# د الګوریتمونو لارښود

`راوړه "algorithms"` د ترتیب او لټون کلاسیک الګوریتمونه پروګرام ته راوړي. په ماډیول کې
هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/algorithms.th`](../../lib/thunder/ps/algorithms.th) کې، د لوستلو لپاره لیکل
شوی: پرانیزئ یې او وګورئ چې هغه الګوریتمونه چې هره ژبه یې لري رښتیا څنګه کار کوي. (د
ورځنۍ کارونې لپاره تندر دننۍ دنده `ترتیب کړه()` لري؛ دلته لیکل شوي دي چې داسې دنده
دننه څه کوي.)

هره دنده **عمومي (generic)** ده: پر هره `ت[]` کار کوي چې توکي یې د `<` سره پرتله کېږي -
عددونه یا متنونه (د [ژبې لارښود](language.md)، ۸ برخه). ترتیب **پر خپل ځای**، په پورته
کېدونکي ترتیب دی. لټونونه د ارزښت ځای (شاخص) راګرځوي، یا `-۱` کله چې نه وي.

**ویې آزمویئ:** [`samples/advanced/ps/02_algorithms.th`](../../samples/advanced/ps/02_algorithms.th)
هر الګوریتم چلوي. دا بېلګې په قصد د IDE په لړ کې نشته - له همدې ځایه یې پرانیزئ.

## ترتیب

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `حبابي_ترتیب<ت>(ارزښتونه)` | بیا بیا جارو، ناسم ترتیب شوي ګاونډیان بدلېږي؛ جارو بې بدلونه مانا ترتیب شوې. | O(n²) |
| `غوراوی_ترتیب<ت>(ارزښتونه)` | د پاتې برخې کمینه ومومه، مخ ته یې بدله کړه، بیا نور. هر ارزښت تر یوه ځله زیات نه خوځي. | O(n²) |
| `ننویستل_ترتیب<ت>(ارزښتونه)` | هر بل ارزښت له لویو ارزښتونو کیڼ لور ته وښویوه - لکه د پتو پاڼې چې اڼل کېږي. | O(n²)، نږدې ترتیب شوې O(n) |
| `چټک_ترتیب<ت>(ارزښتونه)` | محور وټاکه، پر کوچنیو او لویو یې ووېشه، دواړې خواوې ترتیب کړه - ووېشه او وګټه. | په منځني ډول O(n log n) |
| `ګډولو_ترتیب<ت>(ارزښتونه)` | هره نیمایي ترتیب کړه، بیا دواړه سره ګډې کړه. ډاډمن، د مرستندویه ځای په بیه. | همېش O(n log n) |

```thunder
# ژبه: ps
راوړه "algorithms"

متغیر عددونه = [۵، ۲، ۹، ۱، ۵، ۶]
چټک_ترتیب(عددونه)
کرښه چاپ(عددونه)             # [۱، ۲، ۵، ۵، ۶، ۹]
کرښه چاپ(ترتیب_شوې_ده(عددونه))  # رښتیا
```

## لټون

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `پرله_پسې_لټون<ت>(ارزښتونه، غوښتل_شوی): عدد` | هر ارزښت وګوره ترڅو همغه وي. پر هره لړۍ کار کوي. | O(n) |
| `نیمایي_لټون<ت>(ارزښتونه، غوښتل_شوی): عدد` | لړۍ باید **ترتیب شوې** وي: له منځني سره پرتله کړه، یوازې اړینه نیمایي وساته. | O(log n) |

## مرستندویې

| دنده | څه کوي |
| --- | --- |
| `ترتیب_شوې_ده<ت>(ارزښتونه): منطقي` | رښتیا که لړۍ په پورته کېدونکي ترتیب وي (مساوي ګاونډیان روا دي). |
| `د_کمینې_ځای<ت>(ارزښتونه): عدد` | د تر ټولو کوچني ارزښت ځای (`-۱` د تشې لړۍ لپاره). |
| `ګډوډه_کړه<ت>(ارزښتونه)` | ارزښتونه په تصادفي ترتیب اڼي (Fisher-Yates). `تصادفي بنسټ()` یې تکرارېدونکی کوي. |

## متن

د متن الګوریتمونه توری په توري کار کوي (توری یو کوډ-پوینټ دی، نو پښتو متن سم اندازه کېږي).

| دنده | مفکوره | بیه |
| --- | --- | --- |
| `د_متن_لټون(متن، نمونه): عدد` | نمونه د متن په اوږدو وښویوه، توری په توري پرتله کړه - هغه چې دننۍ `ځای یې()` د متنونو لپاره کوي، دلته لیکل شوي. نه و: `-۱`. | O(n·m) |
| `د_متن_ټول_ځایونه(متن، نمونه): عدد[]` | هر هغه ځای چې نمونه پکې پیلېږي، پراته پیدا کېدل هم پکې. | O(n·m) |
| `سرچپه_ورته_ده(متن): منطقي` | دواړه سرونه پرتله کړه او دننه راشه. | O(n) |
| `تر_ټولو_اوږد_ګډ_مختاړی(وییونه): متن` | لومړی ویی د نورو هر یوه پر وړاندې لنډ کړه. | O(ټول اوږدوالی) |
| `د_بدلون_واټن(الف، ب): عدد` | د Levenshtein واټن: تر ټولو لږ یو-توریز ننویستل، لیرې کول او بدلول چې الف ب ته اړوي - متحرک پروګرامول، کتار په کتار. | O(n·m) |

```thunder
# ژبه: ps
راوړه "algorithms"

کرښه چاپ(د_متن_لټون("سلام نړۍ"، "نړۍ"))        # ۵
کرښه چاپ(د_بدلون_واټن("کور"، "کار"))            # ۱
کرښه چاپ(تر_ټولو_اوږد_ګډ_مختاړی(["کور"، "کورنۍ"]))  # «کور»
```
