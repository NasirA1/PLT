    راوړه "testing"

    د ازموینو چوکاټ، پخپله په تندر کې لیکل شوی (docs/ps/testing.md)

    ازموینې په خپلو فایلونو کې اوسي. هره ازموینه په @ازموینه نښه کړئ - یوه دنده، یا ټول یو جوړښت یا ټولګی (یوه ډله) - او فایل وچلوئ؛ ژباړونکی ازموینې پیدا کوي، دا فایل راوړي او ازموینې یوه په بل پسې چلوي، بیا لنډیز چاپوي:

    راوړه "lib/ډېرۍ" # هغه کوډ چې ازمویل کېږي

    @ازموینه دنده جمع_سمه_ده() # د «جمع سمه ده» په نوم ښکاري تمه.برابر(۲ + ۲، ۴)

    @ازموینه("نوې ډېرۍ") جوړښت نوې_ډېرۍ # ډله: هره عامه دنده چې پارامټر نه لري یوه _ډېرۍ: ډېرۍ<عدد> # ازموینه ده، هر ځل پر یوې نوې نوې_ډېرۍ چلېږي

    نوې_ډېرۍ() # جوړوونکی هره ازموینه چمتو کوي ... _ډېرۍ = ډېرۍ()

    دنده تشه_ده() تمه.رښتیا_وي(_ډېرۍ.تشه_ده())

    دنده وتړه() # ... او وتړه()، که وي، پاکوي یې تېر

    یو ټولګی هم ډله کېدای شي (پر ټولګي @ازموینه: عامې دندې یې چې پارامټر نه لري ازموینې دي)، او پر یوې دندې @ازموینه یوازې هماغه نښه کوي، د خوښې له تشریح سره: @ازموینه("یو توکی ورزیاتوي").

    د ازموینې فایل یوازې ازموینې لري - نه خپل امرونه او نه اصلي() - او د پروګرام فایل دا ټولګی نشي کارولای: د ازموینې کوډ له اصلي کوډ څخه بېل پاتې کېږي.

    هره ازموینه یوه کرښه چاپوي - "✓ نوم" کله چې تېره شي، "✗ نوم: څه ناسم شول" د هرې هغې تمې لپاره چې پوره نه شوه - د خپلې ډلې د نوم لاندې، او لنډیز پروګرام د وتلو کوډ ۱ سره پای ته رسوي کله چې کومه ازموینه ناکامه وي (نو یو سکریپټ، یا د VS Code غځونه، پوهېدلی شي). د پروګرام دلیلونه ټاکي چې کومې ازموینې وچلېږي: "thundervm tests.thc جمع" یوازې هغه ازموینې (یا ډلې) چلوي چې نوم یې پر امر کرښه راغلی - "ډله/ازموینه" د یوې ډلې یوه ازموینه نوموي - د VS Code د ازموینو لړ یوه ازموینه یا یوه ډله همداسې چلوي.

    پېښه ګران. «@پېښه ګر جوړښت پېښه_ګر_ساعت: ساعت» د هغو برسېرونو ځای نیوونکی جوړوي چې جوړښت یې نوموي: د هغوی هره دنده خپلې بلنې ثبتوي، بیا د جوړښت د خپلې همنومې دندې ځواب ورکوي، یا، که نه وي، هېڅ نه کوي او اصلي ارزښت راګرځوي (۰، ""، درواغ، هېڅ، []). جوړښت د پېښه ګران ګډون دندې لري چې وپوښتي څه پېښ شول:

    برسېر ساعت دنده ساعت_یې(): عدد

    @پېښه ګر جوړښت پېښه_ګر_ساعت: ساعت وخت: عدد # هغه چې ازموینه غواړي ساعت یې ووايي دنده ساعت_یې(): عدد راګرځه وخت

    @ازموینه دنده سهار_پخیر_وايي() متغیر ګړۍ = پېښه_ګر_ساعت(وخت: ۹) تمه.برابر(ستاینه(ګړۍ)، "سهار پخیر") ګړۍ.تمه_د_بللو("ساعت_یې"، ۱)

    دلته هېڅ بهرنی نشته: دا ساده تندر دی، د لوستلو لپاره لیکل شوی.
