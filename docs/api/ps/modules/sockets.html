    راوړه "sockets"

    د شبکې له لارې خبرې: TCP او UDP ساکټونه (docs/ps/sockets.md)

    راوړه "sockets" ولیکئ او ټولې لاندې دندې ستاسې دي (thunderc دا فایل د ځان تر څنګ په lib/thunder کې مومي، یا یوه پوښۍ د --module-path سره ورکړئ). دوی په ++C کې لیکل شوې (lib/native/sockets/thunder_sockets.cpp) او له توکپانګې سره د بهرني کتابتون thunder_sockets په بڼه جوړېږي، چې د thunderc او thundervm تر څنګ کېني او د بسته شوي پروګرام تر څنګ پخپله کاپي کېږي.

    ساکټ یو عددي نښه ده، لکه د ټکټ شمېره. د -۱ پایله مانا «کار یې ونه کړ» او ساکټ_تېروتنه() وايي ولې؛ داسې نښه ورکول چې پرانیستې نه ده د پروګرام تېروتنه ده او پروګرام دروي، لکه د دننۍ دندې ناسمه بلنه.
