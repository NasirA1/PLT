# د ډېټا جوړښتونو لارښود

`راوړه "datastructures"` کلاسیک ډېټا جوړښتونه پروګرام ته راوړي: **ډېرۍ** (stack)،
**لیکه** (queue)، **دوسرې لیکه** (deque)، **ځنځیر** (یو اړخیز او دوه اړخیز)، **د لټون
دوه‌اړخیزه ونه**، **د لومړیتوب لیکه** (heap)، دوه ډوله **ټولګه** (set)، **ګراف** له خپلو
لټونونو سره، او **مختاړې ونه** (trie). په ماډیول کې هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/datastructures.th`](../../lib/thunder/ps/datastructures.th) کې، د لوستلو لپاره
لیکل شوی: پرانیزئ یې او وګورئ چې هر جوړښت رښتیا څنګه کار کوي.

هر جوړښت **عمومي (generic)** دی: `ډېرۍ<ت>` د هر ډول توکي `ت` ساتي، چې له کارونې معلومېږي -
`ډېرۍ(توکي: [«الف»])` یوه `ډېرۍ<متن>` ده، او `متغیر د: ډېرۍ<عدد> = نوې_ډېرۍ()` وايي چې
تشه به څه وساتي (د [ژبې لارښود](language.md)، ۸ برخه). ونه او د لومړیتوب لیکه خپل توکي د
`<` سره پرتله کوي، نو توکي یې عددونه یا متنونه دي. له تش جوړښته اخیستل پروګرام د اجرا له
تېروتنې سره دروي؛ لومړی `ډېرۍ_تشه_ده` / `لیکه_تشه_ده` / `لومړیتوب_لیکه_تشه_ده` وپوښتئ.

**ویې آزمویئ:** [`samples/advanced/ps/01_datastructures.th`](../../samples/advanced/ps/01_datastructures.th)
هر جوړښت په کار اچوي. دا بېلګې په قصد د IDE په لړ کې نشته - له همدې ځایه یې پرانیزئ.

## ډېرۍ - وروستی دننه، لومړی بهر

د کاسو ډېرۍ: هغه چې وروستی سر ته کېښودل شي، لومړی بېرته راځي. هره عملیه O(1) ده.

| دنده | څه کوي |
| --- | --- |
| `نوې_ډېرۍ<ت>(): ډېرۍ<ت>` | یوه نوې، تشه ډېرۍ. |
| `ډېرۍ_ته_ورزیات_کړه<ت>(ډېرۍ، ارزښت)` | یو ارزښت سر ته ږدي. |
| `له_ډېرۍ_واخله<ت>(ډېرۍ): ت` | د سر ارزښت اخلي او راګرځوي یې. |
| `ډېرۍ_وګوره<ت>(ډېرۍ): ت` | د سر ارزښت، بې له اخیستلو. |
| `د_ډېرۍ_کچه<ت>(ډېرۍ): عدد` | څومره ارزښتونه لري. |
| `ډېرۍ_تشه_ده<ت>(ډېرۍ): منطقي` | رښتیا کله چې هېڅ پرې نه وي. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر کاسې: ډېرۍ<عدد> = نوې_ډېرۍ()
ډېرۍ_ته_ورزیات_کړه(کاسې، ۱)
ډېرۍ_ته_ورزیات_کړه(کاسې، ۲)
کرښه چاپ(له_ډېرۍ_واخله(کاسې))   # ۲ - وروستی دننه، لومړی بهر
کرښه چاپ(ډېرۍ_وګوره(کاسې))      # ۱ - لا هلته دی
```

## لیکه - لومړی دننه، لومړی بهر

د دوکان مخې ته لیکه: `لیکې_ته_ورزیات_کړه` پای ته درېږي، `له_لیکې_واخله` سر خدمتوي.
د سر شاخص ښویېږي، نو دواړه په منځني ډول O(1) دي.

| دنده | څه کوي |
| --- | --- |
| `نوې_لیکه<ت>(): لیکه<ت>` | یوه نوې، تشه لیکه. |
| `لیکې_ته_ورزیات_کړه<ت>(لیکه، ارزښت)` | د لیکې پای ته درېږي. |
| `له_لیکې_واخله<ت>(لیکه): ت` | سر خدمتوي (لیرې کوي یې او راګرځوي یې). |
| `لیکه_وګوره<ت>(لیکه): ت` | سر، بې له خدمتولو. |
| `د_لیکې_کچه<ت>(لیکه): عدد` | څومره ارزښتونه انتظار کوي. |
| `لیکه_تشه_ده<ت>(لیکه): منطقي` | رښتیا کله چې هیڅوک انتظار نه کوي. |

## ځنځیر - د غوټیو کړۍ په کړۍ

هره غوټۍ (`د_ځنځیر_غوټۍ<ت>`) خپل ارزښت او راتلونکې غوټۍ ساتي؛ `هېڅ` ځنځیر پای ته رسوي.
دا د درسي کتابونو انځور دی، له یوه تکراري جوړښته جوړ. سر ته ورزیاتول O(1) دي؛ پای ته
ورزیاتول او لټون ځنځیر ګرځي، O(n).

| دنده | څه کوي |
| --- | --- |
| `نوی_ځنځیر<ت>(): ځنځیر<ت>` | یو نوی، تش ځنځیر. |
| `ځنځیر_سر_ته_ورزیات_کړه<ت>(ځنځیر، ارزښت)` | سر ته ورزیاتوي، O(1). |
| `ځنځیر_پای_ته_ورزیات_کړه<ت>(ځنځیر، ارزښت)` | پای ته ورزیاتوي. |
| `ځنځیر_له_سره_واخله<ت>(ځنځیر): ت` | د سر ارزښت لیرې کوي او راګرځوي یې. |
| `له_ځنځیره_لیرې_کړه<ت>(ځنځیر، ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي؛ رښتیا که ومونده. |
| `ځنځیر_لري<ت>(ځنځیر، ارزښت): منطقي` | رښتیا که کومه غوټۍ دا ارزښت لري. |
| `د_ځنځیر_کچه<ت>(ځنځیر): عدد` | څومره ارزښتونه لري. |
| `ځنځیر_لړۍ_کړه<ت>(ځنځیر): ت[]` | ارزښتونه د ځنځیر په ترتیب، د ساده لړۍ په بڼه. |

## د لټون دوه‌اړخیزه ونه - ترتیب شوي لټونونه

د هرې غوټۍ کیڼه څانګه کوچني ارزښتونه لري، ښۍ یې لوی، نو یو ارزښت په O(لوړوالی) ګامونو
کې موندل کېږي - O(log n) کله چې ونه برابره وي. تکراري ارزښتونه له پامه غورځول کېږي.

| دنده | څه کوي |
| --- | --- |
| `نوې_ونه<ت>(): ونه<ت>` | یوه نوې، تشه ونه. |
| `ونې_ته_ورزیات_کړه<ت>(ونه، ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورزیاتوي. |
| `ونه_لري<ت>(ونه، ارزښت): منطقي` | رښتیا که ارزښت په ونه کې وي. |
| `له_ونې_لیرې_کړه<ت>(ونه، ارزښت): منطقي` | ارزښت لیرې کوي؛ رښتیا که هلته و. |
| `د_ونې_کچه<ت>(ونه): عدد` | څومره ارزښتونه لري. |
| `د_ونې_لوړوالی<ت>(ونه): عدد` | له ریښې تر ټولو اوږده لار له څومره غوټیو تېرېږي (تشه: ۰). |
| `د_ونې_کمینه<ت>(ونه): ت` / `د_ونې_اعظمه<ت>(ونه): ت` | د ترتیب دواړه څنډې. |
| `ونه_په_ترتیب<ت>(ونه): ت[]` | هر ارزښت په پورته کېدونکي ترتیب (منځنی تګ). |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر ونه_: ونه<عدد> = نوې_ونه()
تکرار ن په [۵، ۳، ۸، ۱، ۴]
    ونې_ته_ورزیات_کړه(ونه_، ن)
کرښه چاپ(ونه_په_ترتیب(ونه_))   # [۱، ۳، ۴، ۵، ۸] - ونه ترتیب ساتي
کرښه چاپ(ونه_لري(ونه_، ۴))     # رښتیا، په O(log n) ګامونو کې موندل شوی
```

## د لومړیتوب لیکه - کمینه لومړی

`له_لومړیتوب_لیکې_واخله` همېش تر ټولو کوچنی ارزښت لومړی راکوي، ارزښتونه چې په هر ترتیب
راغلي وي. لیکه یوه دوه‌اړخیزه ونه ده چې په یوه لړۍ کې ځای شوې: د `ش` شاخص بچي په
`۲*ش + ۱` او `۲*ش + ۲` کې ناست دي. ورزیاتول او اخیستل O(log n) دي؛ کتل O(1).

| دنده | څه کوي |
| --- | --- |
| `نوې_لومړیتوب_لیکه<ت>(): لومړیتوب_لیکه<ت>` | یوه نوې، تشه لیکه. |
| `لومړیتوب_لیکې_ته_ورزیات_کړه<ت>(لیکه، ارزښت)` | یو ارزښت ورزیاتوي. |
| `له_لومړیتوب_لیکې_واخله<ت>(لیکه): ت` | تر ټولو کوچنی ارزښت لیرې کوي او راګرځوي یې. |
| `لومړیتوب_لیکه_وګوره<ت>(لیکه): ت` | تر ټولو کوچنی، بې له لیرې کولو. |
| `د_لومړیتوب_لیکې_کچه<ت>(لیکه): عدد` | څومره ارزښتونه لري. |
| `لومړیتوب_لیکه_تشه_ده<ت>(لیکه): منطقي` | رښتیا کله چې هېڅ نه لري. |

## ټولګه - ځانګړي توکي

راټولونه چې هر ارزښت پکې یو ځل راځي. د تندر پر خپله نقشه جوړه ده - ارزښت کیلۍ ده - نو
ورزیاتول، لیرې کول او شتون کتل ټول O(1) دي، او توکي د نقشې کیلۍ دي: `عدد`، `منطقي` یا
`متن`. `د_ټولګې_ارزښتونه` د لومړي ورزیاتېدو په ترتیب راځي.

| دنده | څه کوي |
| --- | --- |
| `نوې_ټولګه<ت>(): ټولګه<ت>` | یوه نوې، تشه ټولګه. |
| `ټولګې_ته_ورزیات_کړه<ت>(ټولګه، ارزښت)` | یو ارزښت ورننباسي؛ هغه چې وي، یو پاتې کېږي. |
| `له_ټولګې_لیرې_کړه<ت>(ټولګه، ارزښت): منطقي` | یو ارزښت باسي؛ رښتیا که هلته و. |
| `ټولګه_لري<ت>(ټولګه، ارزښت): منطقي` | رښتیا که ارزښت پکې وي. |
| `د_ټولګې_کچه<ت>(ټولګه): عدد` / `ټولګه_تشه_ده<ت>(ټولګه): منطقي` | څومره ارزښتونه لري. |
| `د_ټولګې_ارزښتونه<ت>(ټولګه): ت[]` | ارزښتونه، د لومړي ورزیاتېدو په ترتیب. |
| `د_ټولګو_یوځای<ت>(الف، ب): ټولګه<ت>` | هر ارزښت چې په یوه یا بله کې وي. |
| `د_ټولګو_ګډ<ت>(الف، ب): ټولګه<ت>` | هر ارزښت چې په دواړو کې وي. |
| `د_ټولګو_توپیر<ت>(الف، ب): ټولګه<ت>` | د الف هر هغه ارزښت چې په ب کې نشته. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر لیدل_شوي: ټولګه<متن> = نوې_ټولګه()
ټولګې_ته_ورزیات_کړه(لیدل_شوي، «سور»)
ټولګې_ته_ورزیات_کړه(لیدل_شوي، «شین»)
ټولګې_ته_ورزیات_کړه(لیدل_شوي، «سور»)   # له وړاندې شته: لا هم یو «سور»
کرښه چاپ(د_ټولګې_ارزښتونه(لیدل_شوي))    # [«سور»، «شین»]
```

## ترتیب شوې ټولګه - ځانګړي او اڼل شوي

ټولګه چې خپل ارزښتونه په پورته کېدونکي ترتیب ساتي: لاندې یې د لټون دوه‌اړخیزه ونه ده،
نو ورزیاتول، لیرې کول او شتون کتل O(log n) دي او `د_ترتیب_شوې_ټولګې_ارزښتونه` ترتیب
شوي راوځي. توکي د `<` سره پرتله کېږي، نو عددونه یا متنونه دي.

| دنده | څه کوي |
| --- | --- |
| `نوې_ترتیب_شوې_ټولګه<ت>(): ترتیب_شوې_ټولګه<ت>` | یوه نوې، تشه ترتیب شوې ټولګه. |
| `ترتیب_شوې_ټولګې_ته_ورزیات_کړه<ت>(ټولګه، ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورننباسي. |
| `له_ترتیب_شوې_ټولګې_لیرې_کړه<ت>(ټولګه، ارزښت): منطقي` | یو ارزښت باسي؛ رښتیا که هلته و. |
| `ترتیب_شوې_ټولګه_لري<ت>(ټولګه، ارزښت): منطقي` | رښتیا که ارزښت پکې وي. |
| `د_ترتیب_شوې_ټولګې_کچه<ت>(ټولګه): عدد` / `ترتیب_شوې_ټولګه_تشه_ده<ت>(ټولګه): منطقي` | څومره ارزښتونه لري. |
| `د_ترتیب_شوې_ټولګې_ارزښتونه<ت>(ټولګه): ت[]` | ارزښتونه، په پورته کېدونکي ترتیب. |
| `د_ترتیب_شوې_ټولګې_کمینه<ت>(ټولګه): ت` / `د_ترتیب_شوې_ټولګې_اعظمه<ت>(ټولګه): ت` | د ترتیب دواړه څنډې. |

## دوسرې لیکه - دواړه سرونه پرانیستي

لیکه چې دواړه سرونه یې خدمت کوي: ارزښتونه له مخې او له شا دواړو ننوځي او وځي. دوه ډېرۍ
شا په شا هره عملیه په منځني ډول O(1) ساتي.

| دنده | څه کوي |
| --- | --- |
| `نوې_دوسرې_لیکه<ت>(): دوسرې_لیکه<ت>` | یوه نوې، تشه دوسرې لیکه. |
| `دوسرې_لیکې_سر_ته_ورزیات_کړه` / `دوسرې_لیکې_پای_ته_ورزیات_کړه` | هر سر ته ارزښت ږدي. |
| `دوسرې_لیکې_له_سره_واخله` / `دوسرې_لیکې_له_پایه_واخله` | له هر سره ارزښت اخلي. |
| `دوسرې_لیکې_سر_وګوره` / `دوسرې_لیکې_پای_وګوره` | ګوري، بې له اخیستلو. |
| `د_دوسرې_لیکې_کچه` / `دوسرې_لیکه_تشه_ده` | څومره ارزښتونه لري. |
| `دوسرې_لیکه_لړۍ_کړه` | ارزښتونه له مخې تر شا. |

## دوه اړخیز ځنځیر - دواړه لوري ګرځي

لکه ځنځیر، خو هره غوټۍ مخکېنۍ هم پېژني او ځنځیر دواړه سرونه ساتي: په دواړو سرونو کې
ورزیاتول او لیرې کول O(1) دي، او شاتګ هم کېدای شي.

| دنده | څه کوي |
| --- | --- |
| `نوی_دوه_اړخیز_ځنځیر<ت>(): دوه_اړخیز_ځنځیر<ت>` | یو نوی، تش ځنځیر. |
| `دوه_اړخیز_ځنځیر_سر_ته_ورزیات_کړه` / `دوه_اړخیز_ځنځیر_پای_ته_ورزیات_کړه` | هر سر ته، O(1). |
| `دوه_اړخیز_ځنځیر_له_سره_واخله` / `دوه_اړخیز_ځنځیر_له_پایه_واخله` | له هر سره، O(1). |
| `له_دوه_اړخیز_ځنځیره_لیرې_کړه(ځنځیر، ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي. |

| `دوه_اړخیز_ځنځیر_لړۍ_کړه` / `دوه_اړخیز_ځنځیر_سرچپه_لړۍ_کړه` | دواړه د تګ لوري. |

## ګراف - څوکې، غاړې او لټونونه

د ګاونډیتوب نقشه: هره څوکه هغو څوکو ته نقشه کېږي چې غاړه ورته ځي. غاړې یو لوري دي؛
`ګراف_ونښلوه` د ناجهته ګراف لپاره دواړه لوري ورزیاتوي. څوکې د نقشې کیلۍ دي (عدد، منطقي
یا متن). لټونونه د همدې ماډیول لیکه او ټولګه کاروي.

| دنده | څه کوي |
| --- | --- |
