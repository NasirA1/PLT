    راوړه "datastructures" کلاسیک ډېټا جوړښتونه پروګرام ته راوړي: ډېرۍ (stack)، لیکه (queue)، دوسرې لیکه (deque)، ځنځیر (یو اړخیز او دوه اړخیز)، د لټون دوه‌اړخیزه ونه، د لومړیتوب لیکه (heap)، دوه ډوله ټولګه (set)، ګراف له خپلو لټونونو سره، او مختاړې ونه (trie). په فایل کې هېڅ بهرنی نشته - دا ساده تندر دی، په lib/thunder/ps/datastructures.th کې، د لوستلو لپاره لیکل شوی: پرانیزئ یې او وګورئ چې هر جوړښت رښتیا څنګه کار کوي. انګلیسي فایل (lib/thunder/en/datastructures.th) همدا جوړښتونه له انګلیسي نومونو سره دي؛ دواړه پخپله، د اوزارو تر څنګ، موندل کېږي.

    هر جوړښت خپل یو ټولګی دی، چې خپل جوړښت او دندې پکې دي: ډېرۍ ډېرۍ.ډېرۍ<ت> ده، د ډېرۍ.نوې() سره جوړېږي او د ډېرۍ.ورزیات_کړه، ډېرۍ.واخله ... سره کارول کېږي؛ لیکه لیکه.لیکه<ت> ده له لیکه.ورزیات_کړه، لیکه.واخله ... سره؛ او همداسې لاندې.

    د ټولګو نومونه ساتل شوي دي. په هغه پروګرام کې چې "datastructures" راوړي، ډېرۍ، لیکه، ځنځیر، ونه، لومړیتوب_لیکه، ټولګه، ترتیب_شوې_ټولګه، دوسرې_لیکه، دوه_اړخیز_ځنځیر، ګراف او مختاړې_ونه ټولګي نوموي، نو هېڅ متغیر، پارامټر یا دنده دا نوم نشي لرلای (تېروتنه S065، «'ونه' د یوه ټولګي نوم دی؛ دې متغیر ته بل نوم ورکړئ»). متغیر د هغه څه په نوم ونوموئ چې ساتي یې: کاسې، وییونه، لیدل_شوي، لارې.

    هر جوړښت عمومي (generic) دی: ډېرۍ.ډېرۍ<ت> د هر ډول توکي ت ساتي، چې له کارونې معلومېږي - ډېرۍ.ډېرۍ(توکي: ["الف"]) یوه ډېرۍ.ډېرۍ<متن> ده، او متغیر د: ډېرۍ.ډېرۍ<عدد> = ډېرۍ.نوې() وايي چې تشه به څه وساتي (د ژبې لارښود، ۸ برخه). ونه او د لومړیتوب لیکه خپل توکي د < سره پرتله کوي، نو توکي یې عددونه یا متنونه دي. له تش جوړښته اخیستل پروګرام د اجرا له تېروتنې سره دروي، لکه د دننۍ دندې ناسمه بلنه؛ لومړی ډېرۍ.تشه_ده / لیکه.تشه_ده / لومړیتوب_لیکه.تشه_ده وپوښتئ.

    ویې آزمویئ: samples/advanced/ps/01_datastructures.th هر جوړښت په کار اچوي (انګلیسي: samples/advanced/en/01_datastructures.th). دا بېلګې په قصد د IDE په لړ کې نشته - له همدې ځایه یې پرانیزئ.
