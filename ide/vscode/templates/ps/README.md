# {{name}}

د تندر یوه پروژه.

```
main.th              پروګرام: هغه پیل ټکی چې په thunder.json کې نومول شوی
lib/greeting.th      د کتابتون فایل، چې د ښه_راغلاست ټولګی اعلانوي
tests/               ازموینې (هر فایل په ازموینه.پای_ته_ورسوه() پای ته رسېږي)
thunder.json         پروژه: پیل ټکی، ژبه او وتنه یې
.vscode/             د جوړولو دنده، د ډیبګ تنظیم او د سمونګر تنظیمات
```

## په VS Code کې

| تڼۍ | څه کوي |
| --- | --- |
| **F5** | پروژه په ډیبګر چلوي — د درېدو ټکي، مخ ته *او شا ته* ګامونه، متغیرونه، د بلنو ډېرۍ |
| **Ctrl+F5** | چلوي یې |
| **F7** | ژباړي یې (ستونزې د Problems په پینل کې ښکاري) |
| **Ctrl+Shift+P** ← *Thunder* | د تندر ټول امرونه: ټاټ، د کمپایلر پړاوونه (توکي، د نحوې ونه، سمبولونه، بایټ کوډ)، د انګلیسي او پښتو ترمنځ ژباړه، د پروګرام بسته کول |

د **Testing** کتنه په `tests/` کې ازموینې لیستوي؛ «Thunder: Run All Tests» ټولې چلوي.

## له کمانډ لاینه

```sh
thunderc main.th -o main.thc     # ژباړل
thundervm main.thc               # چلول
thunderc --package myapp main.th # یو خپلواک اجرا کېدونکی فایل
```

## د تندر زده کړه

د څنګ په پټه کې د **Thunder** کتنه د ژبې، کتابتون، ډېټا جوړښتونو، الګوریتمونو او د ازموینې
د ټولګي لارښودونه پرانیزي، او هره بېلګه یې په یوه کلیک کې ده.
