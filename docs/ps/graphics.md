# د تندر د ګرافیک لارښود

*[د تندر SDK لارښود](README.md) یوه برخه.*

> دا سند د `docs/graphics.md` پښتو ژباړه ده. انګلیسي اصل معتبر دی؛ ژباړه د یوه ژبپوه
> کتنې ته اړتیا لري.

دننی ماډیول **`ګرافیک`** پروګرام ته انځور کښل، حرکت (انیمېشن) او د کیبورډ او موږک غبرګون
ورکوي — د سمولېشنونو او ساده لوبو لپاره بس دی. انځور په IDE کې د **ټاټ** پاڼه کې ښکاري؛
په قومانده کې SVG انځور ته ساتل کېدای شي.

```thunder
// ژبه: ps
راوړه ګرافیک

ټاټ(۴۰۰، ۳۰۰)
ټاټ پاک کړه(رنګ(۰، ۰، ۱۲۸))
دایره(۲۰۰، ۱۵۰، ۴۰، "نارنجي")
لیکنه(۱۰، ۱۰، "سلام، ګرافیک!"، "سپین")
```

نمونې `24_drawing` تر `28_snake` (انګلیسي او پښتو دواړه) له ولاړ انځوره تر لوبې پورې ځي:

| نمونه | ښيي |
| --- | --- |
| `24_drawing` | ټاټ، ځایونه، رنګونه، هر ډول شکل، لیکنه |
| `25_bouncing_ball` | د حرکت تکرار: پاکول، کښل، `چوکاټ()`، خوځول |
| `26_fireworks` | د ذرو سمولېشن: جوړښتونه، جاذبه، ثابت-ټکی عددونه، د موږک کلیک |
| `27_life` | د کانوې د ژوند لوبه: ۲-بعدي جال، تڼۍ، موږک |
| `28_snake` | لوبه: د غشو تڼۍ، ټکر، نمره، بیا پیل |
| `31_waves` | جیب، تتمیم جیب او ظل، کښل شوي او حرکت ورکړل شوي؛ رادیان او `پای()` |
| `32_orbits` | دایروي حرکت: سیارې په جیب/تتمیم جیب مدارونو، او له دوو دایرو سپیروګراف |
| `33_pendulum` | جذر، نمايي او جیب: د ځنګنده فورمول د حرکت له دقیق قانون سره پرتله |

له IDE بهر، ګرافیکي پروګرام کولای شي **خپله کړکۍ** ولري: `thundervm --display sdl program.thc`
یې د یوه ښودونکي پلگ-ان له لارې کاږي. پلگ-انونه شریک کتابتونونه دي چې یو کوچنی C اړیکی لري،
نو د هرې بلې ګرافیکي کتابتون لپاره بل لیکل کېدای شي — [د ښودونکي لارښود](display.md) او
`lib/display/` وګورئ.

## ۱. ټاټ

* **ځایونه** د پکسلونو بشپړ عددونه دي. `(۰، ۰)` **پورته کیڼ** کونج دی؛ س ښي خوا ته
  لویېږي او **ص ښکته لویېږي** (لکه پر هره پرده؛ د ریاضي برعکس).
* `ټاټ(پلنوالی، لوړوالی)` اندازه ټاکي (۱ تر ۲۰۰۰ پکسله) او ټاټ سپینوي. بې هغه ۴۰۰ × ۳۰۰ ده.
* **شکلونه په ترتیب کښل کېږي**: وروستي مخکیني پټوي. له ټاټه بهر برخې نه ښکاري.
* **ټاټ هر څه ساتي** چې له وروستي `ټاټ پاک کړه()` راهیسې کښل شوي، لکه رنګ پر کاغذ.
  حرکت نو هر چوکاټ په `ټاټ پاک کړه(...)` پیلوي. د دوو پاکولو ترمنځ تر ۱۰۰٬۰۰۰ شکلونه
  منل کېږي (`R024`) — هغه پروګرامونه نیسي چې پاکول هېر کړي.

### رنګونه

رنګ یو متن دی:

* یو **نوم**: انګلیسي (`black`، `red`، `sky`، ...) یا پښتو: `تور`، `سپین`، `سور`، `زرغون`،
  `آبي`، `ژېړ`، `نارنجي`، `ګلابي`، `خړ`، `نسواري`، `بنفش`، `اسماني`، `طلايي`؛
* یو **کوډ** `"#rrggbb"` یا `"#rgb"`: `"#ff8800"`؛
* د **`رنګ(سور، زرغون، آبي)`** پایله، هر یو ۰ تر ۲۵۵: `رنګ(۲۵۵، ۱۳۶، ۰)` = `"#ff8800"` —
  د محاسبه شویو رنګونو لپاره.

بل هر څه د اجرا تېروتنه `R021` ده.

## ۲. کښل

| دنده | کاږي |
| --- | --- |
هر ارزښت او اندازه **اعشاري** (`اعشاري`) دي، نو شکل هلته کېني چې حساب یې ټاکي —
`دایره(مس + تتمیم جیب(ز) * و، مص + جیب(ز) * و، ۲٫۵، "سپین")` بشپړولو ته اړتیا نه لري.
بشپړ عددونه پخپله پراخېږي، نو `دایره(۵۰، ۵۰، ۱۰، "سور")` لا هم سم دی، او بشپړ ارزښت
بېرته د بشپړ عدد په بڼه لیکل کېږي.

| `ټاټ پاک کړه(رنګ_یې)` | ټول ټاټ ډکوي، پخواني شکلونه لرې کوي |
| `ټکی(س، ص، رنګ_یې)` | یو پکسل |
| `لیکه(س۱، ص۱، س۲، ص۲، رنګ_یې)` | لیکه |
| `مستطیل(س، ص، پلنوالی، لوړوالی، رنګ_یې)` | ډک مستطیل؛ (س، ص) پورته کیڼ کونج |
| `د مستطیل څنډه(...)` | د مستطیل څنډه |
| `دایره(س، ص، وړانګه، رنګ_یې)` | ډکه دایره؛ (س، ص) مرکز |
| `د دایرې څنډه(...)` | د دایرې څنډه |
| `لیکنه(س، ص، پیغام، رنګ_یې)` | متن؛ (س، ص) پورته کیڼ کونج، د هرې لیکدود لپاره |

| ترتیب | اثر پر راتلونکو شکلونو |
| --- | --- |
| `د لیکې پلنوالی(پلنوالی)` | د لیکو/څنډو پلنوالی (۰٫۱ تر ۱۰۰، اصلي ۱) |
| `د لیکنې اندازه(اندازه)` | د متن لوړوالی (۱ تر ۴۰۰، اصلي ۱۶) |

منفي پلنوالی/لوړوالی مستطیل کیڼ/پورته خوا ته کاږي. له حده بهر ترتیبونه `R022` دي.

## ۳. حرکت (انیمېشن)

حرکت یو تکرار دی چې په یو وخت کې یو انځور — یو **چوکاټ** — کاږي:

```thunder
راوړه ګرافیک

متغیر س = ۰
ترڅو رښتیا
    ټاټ پاک کړه("تور")                  // ۱. له تش ټاټه پیل
    دایره(س، ۱۵۰، ۲۰، "نارنجي")         // ۲. هر څه چېرته چې اوس دي وکاږه
    چوکاټ()                              // ۳. چوکاټ وښيه او انتظار وکړه
    س = (س + ۴) % ۴۰۰                    // ۴. لږ وخوځوه
```

| دنده | اثر |
| --- | --- |
| `چوکاټ()` | انځور ښيي، بیا **انتظار کوي** تر راتلونکي چوکاټه — حرکت پر هر کمپیوټر یو شان چټک دی |
| `د چوکاټ چټکتیا(شمېر)` | په ثانیه کې څو چوکاټه (۱ تر ۱۲۰، اصلي ۳۰) |
| `ښکاره کړه()` | انځور **همدا اوس** ښيي، بې انتظاره |

* نه ښودل شوی انځور د پروګرام په پای (تر تېروتنې وروسته هم) ښودل کېږي.
* ورو چوکاټ حرکت ورو کوي؛ نه هڅه کوي چې ورسېږي.
* نه ختمېدونکی تکرار په IDE کې «درول» دروي. د لارښوونو حد د **دوو چوکاټونو ترمنځ**
  لګېږي، نو حرکت تر هر وخته چلېدای شي.
* د نرم حرکت لپاره ځایونه اعشاري وساتئ: `س = س + ۰٫۳۵` په هر چوکاټ کې د پکسل دریمه
  برخه ځي. (`26_fireworks` له اعشاري شمېرو مخکې لیکل شوی و او ځایونه د پکسل په لسمو
  برخو ساتي — هغه لار لا هم ګټوره ده کله چې پروګرام باید سم پاتې شي.)

## ۴. کیبورډ او موږک

| دنده | پایله |
| --- | --- |
| `کښېکښل شوې تڼۍ(): متن` | **راتلونکې نه-اخیستل شوې کښېکښنه**، یا `""` |
| `تڼۍ کښېکښل شوې ده(تڼۍ): منطقي` | رښتیا ترڅو تڼۍ نیول شوې وي |
| `د موږک افقي ځای(): عدد` / `د موږک عمودي ځای(): عدد` | د موږک ځای، د ټاټ په پکسلونو |
| `موږک کښېکښل شوی(): منطقي` | رښتیا ترڅو تڼۍ پر ټاټ نیول شوې وي |

**د تڼیو نومونه** په پښتو پروګرامونو کې: «کیڼ»، «ښي»، «پورته»، «ښکته»، «تشه»، «ننوتل»،
«وتل»، «شاته»، «ټب» — او لیکل شوی توری یا رقم (`"a"`، `"۷"`؛ پښتو کیبورډ پښتو توري ورکوي).
`تڼۍ کښېکښل شوې ده` دواړه (پښتو او انګلیسي) نومونه مني.

* `کښېکښل شوې تڼۍ()` **کتار** دی: هره کښېکښنه ساتل کېږي (تر ۶۴) ترڅو پروګرام یې واخلي،
  نو دوه چټکې کښېکښنې نه ورکېږي. لوبه معمولاً په هر چوکاټ کې یوه اخلي (`28_snake`).
* `تڼۍ کښېکښل شوې ده` دوامداره خوځېدو ته ښه ده: `که تڼۍ کښېکښل شوې ده("کیڼ")` ...
* یو-ځلي کلیک له مخکیني چوکاټ سره پرتله کړئ (`26_fireworks`).
* په IDE کې **پر ټاټ کلیک وکړئ** چې کیبورډ واخلي؛ لومړی چوکاټ یې پخپله ورکوي.
* په قومانده کې (بې IDE) تڼۍ او موږک نشته: `""` او `درواغ` راځي.

## ۵. تصادفي عددونه

تل شته، بې `راوړه ګرافیک` هم:

| دنده | پایله |
| --- | --- |
| `تصادفي عدد(کم، ډېر): عدد` | تصادفي بشپړ عدد له کم تر ډېر، **دواړه پکې** (`کم > ډېر`: `R023`) |
| `تصادفي بنسټ(بنسټ: عدد)` | لړۍ بیا پیلوي: له یو بنسټ وروسته همغه عددونه راځي |

بې بنسټه هر چل بل دی. `thundervm --seed ن` (او طلايي ازموینې) له ټاکلي بنسټه پیلوي؛ تندر
خپل جوړوونکی (SplitMix64) کاروي، نو یو بنسټ پر هر سیسټم همغه عددونه ورکوي.

## ۶. په IDE کې

* د **ټاټ** پاڼه د «د پردې شاته» تر څنګ یوه ټوټه (tab) ده او د لومړي چوکاټ سره مخې ته
  راځي. لکه نورې پاڼې خوځول، بېلول (د لوبو لپاره ګټور) او تړل کېدای شي.
* انځور د پاڼې له اندازې سره برابرېږي (تناسب ساتل کېږي)؛ د موږک ځایونه بېرته د ټاټ
  پکسلونو ته اړول کېږي.
* د انځور پورته کرښه د چوکاټ شمېره او اندازه ښيي.
* `کرښه چاپ` لا هم د پایلې پاڼې ته ځي. د جوړولو یادښت وايي څو چوکاټونه ښودل شوي.
* وروستی انځور تر بل جوړولو/چلولو پاتې کېږي.

## ۷. په قومانده کې

```
thundervm picture.thc                        # چلوي؛ بې پردې هېڅ نه ښيي
thundervm --svg picture.svg picture.thc      # وروستی انځور SVG ته ساتي
thundervm --max-frames 100 --svg f.svg anim.thc   # نه ختمېدونکی حرکت تر ۱۰۰ چوکاټه
thundervm --seed 7 game.thc                  # په هر چل همغه تصادفي عددونه
thundervm --canvas game.thc                  # د ښودلو پروتوکول، لکه IDE چې کاروي
```

بې `--canvas` `چوکاټ()` انتظار نه کوي (څوک یې نه ګوري)، نو بې-پردې چل ژر پای ته رسېږي.
SVG فایلونه هر براوزر پرانیزي.

## ۸. د پردې شاته

ټاټ د شکلونو لړۍ ده (`include/thunder/graphics.hpp`)؛ `چوکاټ()`/`ښکاره کړه()` یې یوه
**ګرافیک کوربه** ته وړاندې کوي. `thundervm --canvas` هر چوکاټ د معیاري پایلې پر یوه کرښه
د ریکارډ-بېلوونکي (ASCII 30) + JSON په بڼه لیکي، او تڼۍ/موږک د معیاري ننوت پر کرښو بېرته
راځي — د پروتوکول تفصیل د انګلیسي سند ۸ برخه کې دی. انځور د پکسلونو پر ځای د شکلونو په
بڼه لېږل کېږي: د `28_snake` عادي چوکاټ له ۳۰۰ بایټو کم دی.

## ۱۰. نومونه

انګلیسي ↔ پښتو نومونه د انګلیسي سند ۱۰ برخه کې جدول شوي؛ ټول د پښتو ژبنۍ بستې کې دي
(`src/core/language_pashto.cpp`) او د ژبپوه کتنې ته اړتیا لري. مهم: `canvas` = `ټاټ`،
`clear` = `ټاټ پاک کړه`، `frame` = `چوکاټ`، `key_pressed` = `کښېکښل شوې تڼۍ`،
`mouse_x`/`mouse_y` = `د موږک افقي/عمودي ځای`، `random_int` = `تصادفي عدد`،
`seed_random` = `تصادفي بنسټ`.
