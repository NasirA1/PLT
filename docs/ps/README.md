# د تندر SDK لارښود

د تندر د پروګرامولۍ هر څه، د لوستلو په ترتیب. په IDE کې دا لارښودونه د **مرسته** لاندې دي،
په یوه کتونکي کې چې نيوليک او د کلیدي کلمو لټون لري. انګلیسي اصل په [`docs/`](../README.md)
کې دی او هر ځای چې ژباړه نیمګړې وي، اصل باوري دی.

## د ژبې زده کړه

| لارښود | څه رانغاړي |
| --- | --- |
| [د ژبې لارښود](language.md) | ټوله ژبه: لغوي قواعد (د `0x`/`0b` لیکنو سره)، ډولونه، عملګر (حسابي، پرتله، منطقي او بیټي)، امرونه، دندې، جوړښتونه، ټاپلونه، نقشې، ماډیولونه او ګرامر. |
| [د کتابتون لارښود](library.md) | هر دنننی شی: ننوت/وتنه او `بڼه کړه`، متني دندې، اړونې (`عدد کړه`، `شپاړسیز کړه`، `دوه ییز کړه`، ...)، لړۍ، نقشې، ریاضي او د `سیسټم` ماډیول. |
