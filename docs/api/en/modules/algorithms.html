    import "algorithms"

    the classic sorting and searching algorithms, written in Thunder itself (docs/algorithms.md)

    import "algorithms" and every function below is yours. Nothing here is native: this is ordinary Thunder, written to be read - open this file to see how the algorithms every language ships really work. (For everyday sorting Thunder already has the built-in sort(); these spell out what such a built-in does.)

    Every function is generic: it works on any T[] whose elements compare with < - numbers or strings. Sorting is in place, in ascending order. The searches return the index of the value, or -1 when it is not there.

    sorting

    bubble_sort#

    Bubble sort, O(n²): sweep the array again and again, swapping neighbours that are in the wrong order. After each sweep the largest value has "bubbled" to its final place at the end; a sweep that swaps nothing means the array is sorted.
