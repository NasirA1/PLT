    راوړه "datastructures"

    کلاسیک ډېټا جوړښتونه، پخپله په تندر کې لیکل شوي (docs/ps/datastructures.md)

    راوړه "datastructures" ولیکئ او ټول لاندې جوړښتونه ستاسې دي (thunderc دا فایل د ځان تر څنګ په lib/thunder کې مومي، یا یوه پوښۍ د --module-path سره ورکړئ). د ساکټونو یا ګرافیک په خلاف دلته هېڅ بهرنی نشته: دا ساده تندر دی، د لوستلو لپاره لیکل شوی - دا فایل پرانیزئ او وګورئ چې ډېرۍ، لیکه، ځنځیر، د لټون دوه‌اړخیزه ونه او د لومړیتوب لیکه رښتیا څنګه کار کوي.

    هر جوړښت یو جوړښت دی چې جوړوونکې دنده او خپلې دندې لري: په خپل نوم یې جوړ کړئ («متغیر د: ډېرۍ<عدد> = ډېرۍ()») او د دندو له لارې یې وکاروئ («د.ورزیات_کړه(۱)»، «د.واخله()»). ډېری یې عمومي (generic) دي: ډېرۍ<ت> د هر ډول توکو لپاره کار کوي، او ت هلته نومول کېږي چې متغیر اعلانېږي. ونه او د لومړیتوب لیکه خپل توکي د < سره پرتله کوي، نو توکي یې عددونه یا متنونه دي. غړی چې نوم یې په '_' پیلېږي شخصي دی: یوازې د جوړښت خپلې دندې یې لمسولای شي - پروګرامونه دندې کاروي، هېڅکله دننۍ برخې نه.

    له تش جوړښته اخیستل د پروګرام تېروتنه ده او پروګرام دروي، لکه د دننۍ دندې ناسمه بلنه. لومړی تشه_ده وپوښتئ.
