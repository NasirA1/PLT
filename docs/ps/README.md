# د تندر SDK لارښود

د تندر د پروګرامولۍ هر څه، د لوستلو په ترتیب. په IDE کې دا لارښودونه د **مرسته** لاندې دي،
د لاندې HTML API لارښود د پاڼو په توګه، په یوه براوزر کړکۍ کې. انګلیسي اصل په [`docs/`](../README.md)
کې دی او هر ځای چې ژباړه نیمګړې وي، اصل باوري دی.

## د API لارښود (HTML)

همدا توکي د یوې کتونکې او لټون‌وړ HTML5 پاڼې په بڼه - کلیدي کلمې او ډولونه، هره دننۍ دنده د
خپلې بڼې سره، د SDK ماډیولونو جوړښتونه او دندې د پارامترونو او تشریح سره، د لارښوونو ټولګه او
دا لارښودونه - په [`docs/api/index.html`](../api/index.html) کې دي، په انګلیسي او پښتو، او هره
پاڼه بلې ژبې ته تړنه لري. `tools/apidoc.py` یې د کمپایلر د ژبې له معلوماتو، د SDK له خپلو تبصرو
او له دې لارښودونو جوړوي (له هر بدلون وروسته یې وچلوئ؛ ازموینې ګوري چې تازه دی).
