# ښودونکي: د ګرافیک پروګرام لپاره کړکۍ

هغه پروګرام چې `ګرافیک` راوړي، ټاټ ته کاږي؛ بل څوک باید هغه ټاټ پر پردې وښيي. په IDE کې دا
کار پخپله IDE کوي. له هغې بهر — په ټرمینل کې، یا په [بسته شوې کړنلاره](packaging.md) کې —
دا کار یو **د ښودونکي پلگ-ان** کوي:

```sh
thunderc 28_snake.th -o snake.thc
thundervm --display sdl snake.thc          # خپله کړکۍ
```

پلگ-ان یو شریک کتابتون دی چې کړکۍ پرانیزي، د هر چوکاټ شکلونه کاږي، او د تڼیو او موږک پېښې
بېرته لېږي. ټول اړیکی یو ساده C سرلیک دی:
[`include/thunder/display.h`](../../include/thunder/display.h). بشپړ بیان:
[انګلیسي سند](../display.md). دوې بشپړې بېلګې په [`samples/display/`](../../samples/display/)
کې دي: یوه پر **SDL2** جوړه، او یوه کوچنۍ چې چوکاټونه په متن لیکي.

---

## ۱. د ښودونکي کارول

| امر | څه کوي |
| --- | --- |
| `thundervm --display sdl program.thc` | `libthunder_display_sdl.so` راوړي (په وینډوز کې `thunder_display_sdl.dll`) |
| `thundervm --display win32 program.thc` | یوازې وینډوز: `thunder_display_win32.dll` راوړي، چې هېڅ نصب ته اړتیا نه لري |
| `./app --thunder-display sdl` | همدا، د [بستې](packaging.md) لپاره |
| `./app` | بسته شوی ګرافیکي پروګرام د ځان تر څنګ لومړی موندل شوی پلگ-ان پخپله کاروي (په وینډوز کې `win32` بیا `sdl`، بل ځای `sdl`)، یا د پیغام سره درېږي |
| `thunderc p.th --package app --display sdl` | پروګرام بستوي **او** پلگ-ان یې ورسره ږدي |

کتابتون په دې ترتیب لټول کېږي: د پروګرام تر څنګ، د `thundervm` تر څنګ، بیا د `--native-path`
او `THUNDER_NATIVE_PATH` پوښۍ، او بالاخره هر چېرې چې عامل سیسټم ګوري — لکه د
[بهرني ماډیول](native.md) لپاره.

**د کړکۍ بندول پروګرام پای ته رسوي.** پلگ-ان `THUNDER_EVENT_QUIT` راپوروي، او پروګرام هماغسې
درېږي لکه کله چې د چوکاټونو حد پوره شي: په نورمال ډول، او وروستی انځور یې خوندي پاتې کېږي.

| پلگ-ان | څه لپاره |
| --- | --- |
| `samples/display/sdl` | ریښتینې کړکۍ، پر SDL2 جوړه. تڼۍ، موږک، هر شکل. |
| `samples/display/win32` | پر وینډوز ریښتینې کړکۍ، پر GDI کښل شوې: هېڅ نصب ته اړتیا نشته، او متن په ریښتیني لیک راځي (پښتو هم). پر وینډوز تل جوړېږي. |
| `samples/display/text` | بې کړکۍ: هر چوکاټ په عادي تېروتنې جریان کې لیکل کېږي. لومړی همدا ولولئ. |

متني ښودونکی کولای شي د کاروونکي ځای هم ونیسي، نو لوبه بې پردې هم آزمویل کېږي:

```sh
THUNDER_DISPLAY_TEXT_KEYS=left,space THUNDER_DISPLAY_TEXT_FRAMES=20 \
    thundervm --display text snake.thc
```

## ۲. خپل ښودونکی لیکل

پلگ-ان یو سرلیک راوړي، د تندر له هېڅ شي سره نښلول نه غواړي، او یوه دنده صادروي:

```c
#include <thunder/display.h>

THUNDER_DISPLAY_EXPORT int thunder_display_init(ThunderDisplay* display)
{
    display->abi_version = THUNDER_DISPLAY_ABI;
    display->state = my_state_new();   /* ستاسې خپل معلومات؛ تندر ورته نه ګوري */
    display->open = my_open;
    display->present = my_present;
    display->poll = my_poll;
    display->close = my_close;
    return 1;
}
```

| بلنه | کله | باید څه وکړي |
| --- | --- | --- |
| `open` | له لومړي چوکاټ مخکې، کله چې د ټاټ اندازه معلومه شي | کړکۍ پرانیزي؛ که نشي، ۰ راوګرځوي او `*error` وټاکي |
| `present` | د هر `چوکاټ()` یا `ښکاره کړه()` لپاره یو ځل | د چوکاټ شکلونه وکاږي |
| `poll` | له هر چوکاټ وروسته، تر هغه چې ۰ راوګرځوي | یوه یوه پېښه ورکړي |
| `close` | یو ځل، په پای کې — **حتی که `open` هېڅکله ونه بلل شي** | هغه څه خوشې کړي چې `thunder_display_init` نیولي وو |

چوکاټ یوازې **نوي** شکلونه وړي: `keep` وايي چې ښودونکي له پخوا څو شکله کښلي دي. ارزښتونه
اعشاري دي او کېدای شي له ټاټه بهر وي — پرې یې کړئ. رنګونه تل `"#rrggbb"` دي.

د تڼیو نومونه د تندر انګلیسي نومونه دي (`"left"`، `"space"` ...)؛ VM یې د پروګرام ژبې ته
اړوي، نو پښتو پروګرام `"کیڼ"` ویني پرته له دې چې پلگ-ان له پښتو څخه څه پوه شي.

```sh
cc -std=c11 -shared -fPIC -I<thunder>/include -o libthunder_display_mine.so mine.c
```

نوم ټاکي چې کومه ټاکنه ده: `libthunder_display_mine.so` یعنې `--display mine`. ځکه چې پوله
ساده C ده، پلگ-ان په C، ++C، Rust یا هره بله ژبه لیکل کېدای شي.

**د خوندیتوب یادښت:** د ښودونکي پلگ-ان بهرنی کوډ دی او د پروسې په بشپړو واکونو چلېږي. VM یې
نه ګوري. یوازې هغه پلگ-انونه راوړئ چې تاسې جوړ کړي یا پرې باور لرئ.
