# د ډېټا جوړښتونو لارښود

`راوړه "datastructures"` کلاسیک ډېټا جوړښتونه پروګرام ته راوړي: **ډېرۍ** (stack)،
**لیکه** (queue)، **ځنځیر** (linked list)، **د لټون دوه‌اړخیزه ونه** (binary search tree) او
**د لومړیتوب لیکه** (heap). په ماډیول کې هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/datastructures.th`](../../lib/thunder/ps/datastructures.th) کې، د لوستلو لپاره
لیکل شوی: پرانیزئ یې او وګورئ چې هر جوړښت رښتیا څنګه کار کوي.

توکي `عدد` دي. تندر عمومي (generic) ډولونه نه لري، نو د متنونو (یا ستاسې د خپل جوړښت)
جوړښت داسې جوړېږي چې اړین جوړښت خپل پروګرام ته کاپي کړئ او د توکي ډول یې بدل کړئ -
الګوریتمونه په خپل حال پاتې کېږي.

له تش جوړښته اخیستل پروګرام د اجرا له تېروتنې سره دروي، لکه د دننۍ دندې ناسمه بلنه؛
لومړی `ډېرۍ_تشه_ده` / `لیکه_تشه_ده` / `لومړیتوب_لیکه_تشه_ده` وپوښتئ.

## ډېرۍ - وروستی دننه، لومړی بهر

د کاسو ډېرۍ: هغه چې وروستی سر ته کېښودل شي، لومړی بېرته راځي. هره عملیه O(1) ده.

| دنده | څه کوي |
| --- | --- |
| `نوې_ډېرۍ(): ډېرۍ` | یوه نوې، تشه ډېرۍ. |
| `ډېرۍ_ته_ورزیات_کړه(ډېرۍ، ارزښت)` | یو ارزښت سر ته ږدي. |
| `له_ډېرۍ_واخله(ډېرۍ): عدد` | د سر ارزښت اخلي او راګرځوي یې. |
| `ډېرۍ_وګوره(ډېرۍ): عدد` | د سر ارزښت، بې له اخیستلو. |
| `د_ډېرۍ_کچه(ډېرۍ): عدد` | څومره ارزښتونه لري. |
| `ډېرۍ_تشه_ده(ډېرۍ): منطقي` | رښتیا کله چې هېڅ پرې نه وي. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر کاسې = نوې_ډېرۍ()
ډېرۍ_ته_ورزیات_کړه(کاسې، ۱)
ډېرۍ_ته_ورزیات_کړه(کاسې، ۲)
کرښه چاپ(له_ډېرۍ_واخله(کاسې))   # ۲ - وروستی دننه، لومړی بهر
کرښه چاپ(ډېرۍ_وګوره(کاسې))      # ۱ - لا هلته دی
```

## لیکه - لومړی دننه، لومړی بهر

د دوکان مخې ته لیکه: `لیکې_ته_ورزیات_کړه` پای ته درېږي، `له_لیکې_واخله` سر خدمتوي.
د سر شاخص ښویېږي، نو دواړه په منځني ډول O(1) دي.

| دنده | څه کوي |
| --- | --- |
| `نوې_لیکه(): لیکه` | یوه نوې، تشه لیکه. |
| `لیکې_ته_ورزیات_کړه(لیکه، ارزښت)` | د لیکې پای ته درېږي. |
| `له_لیکې_واخله(لیکه): عدد` | سر خدمتوي (لیرې کوي یې او راګرځوي یې). |
| `لیکه_وګوره(لیکه): عدد` | سر، بې له خدمتولو. |
| `د_لیکې_کچه(لیکه): عدد` | څومره ارزښتونه انتظار کوي. |
| `لیکه_تشه_ده(لیکه): منطقي` | رښتیا کله چې هیڅوک انتظار نه کوي. |

## ځنځیر - د غوټیو کړۍ په کړۍ

هره غوټۍ خپل ارزښت او راتلونکې غوټۍ پېژني. د تندر جوړښتونه ځانونه نشي رانغښتلای، نو
غوټۍ په موازي لړیو کې دي او «اشاره» یو شاخص دی (`-۱` مانا «هېڅ») - همداسې ځنځیرونه د
هغو ژبو دننه جوړېږي چې اشارې (pointers) نه لري. سر ته ورزیاتول O(1) دي؛ پای ته
ورزیاتول او لټون ځنځیر ګرځي، O(n).

| دنده | څه کوي |
| --- | --- |
| `نوی_ځنځیر(): ځنځیر` | یو نوی، تش ځنځیر. |
| `ځنځیر_سر_ته_ورزیات_کړه(ځنځیر، ارزښت)` | سر ته ورزیاتوي، O(1). |
| `ځنځیر_پای_ته_ورزیات_کړه(ځنځیر، ارزښت)` | پای ته ورزیاتوي. |
| `ځنځیر_له_سره_واخله(ځنځیر): عدد` | د سر ارزښت لیرې کوي او راګرځوي یې. |
| `له_ځنځیره_لیرې_کړه(ځنځیر، ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي؛ رښتیا که ومونده. |
| `ځنځیر_لري(ځنځیر، ارزښت): منطقي` | رښتیا که کومه غوټۍ دا ارزښت لري. |
| `د_ځنځیر_کچه(ځنځیر): عدد` | څومره ارزښتونه لري. |
| `ځنځیر_لړۍ_کړه(ځنځیر): عدد[]` | ارزښتونه د ځنځیر په ترتیب، د ساده لړۍ په بڼه. |

## د لټون دوه‌اړخیزه ونه - ترتیب شوي لټونونه

د هرې غوټۍ کیڼه څانګه کوچني ارزښتونه لري، ښۍ یې لوی، نو یو ارزښت په O(لوړوالی) ګامونو
کې موندل کېږي - O(log n) کله چې ونه برابره وي. تکراري ارزښتونه له پامه غورځول کېږي.

| دنده | څه کوي |
| --- | --- |
| `نوې_ونه(): ونه` | یوه نوې، تشه ونه. |
| `ونې_ته_ورزیات_کړه(ونه، ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورزیاتوي. |
| `ونه_لري(ونه، ارزښت): منطقي` | رښتیا که ارزښت په ونه کې وي. |
| `له_ونې_لیرې_کړه(ونه، ارزښت): منطقي` | ارزښت لیرې کوي؛ رښتیا که هلته و. |
| `د_ونې_کچه(ونه): عدد` | څومره ارزښتونه لري. |
| `د_ونې_لوړوالی(ونه): عدد` | له ریښې تر ټولو اوږده لار له څومره غوټیو تېرېږي (تشه: ۰). |
| `د_ونې_کمینه(ونه): عدد` / `د_ونې_اعظمه(ونه): عدد` | د ترتیب دواړه څنډې. |
| `ونه_په_ترتیب(ونه): عدد[]` | هر ارزښت په پورته کېدونکي ترتیب (منځنی تګ). |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر ونه_ = نوې_ونه()
لپاره ن په [۵، ۳، ۸، ۱، ۴]
    ونې_ته_ورزیات_کړه(ونه_، ن)
کرښه چاپ(ونه_په_ترتیب(ونه_))   # [۱، ۳، ۴، ۵، ۸] - ونه ترتیب ساتي
کرښه چاپ(ونه_لري(ونه_، ۴))     # رښتیا، په O(log n) ګامونو کې موندل شوی
```

## د لومړیتوب لیکه - کمینه لومړی

`له_لومړیتوب_لیکې_واخله` همېش تر ټولو کوچنی ارزښت لومړی راکوي، ارزښتونه چې په هر ترتیب
راغلي وي. لیکه یوه دوه‌اړخیزه ونه ده چې په یوه لړۍ کې ځای شوې: د `ش` شاخص بچي په
`۲*ش + ۱` او `۲*ش + ۲` کې ناست دي. ورزیاتول او اخیستل O(log n) دي؛ کتل O(1).

| دنده | څه کوي |
| --- | --- |
| `نوې_لومړیتوب_لیکه(): لومړیتوب_لیکه` | یوه نوې، تشه لیکه. |
| `لومړیتوب_لیکې_ته_ورزیات_کړه(لیکه، ارزښت)` | یو ارزښت ورزیاتوي. |
| `له_لومړیتوب_لیکې_واخله(لیکه): عدد` | تر ټولو کوچنی ارزښت لیرې کوي او راګرځوي یې. |
| `لومړیتوب_لیکه_وګوره(لیکه): عدد` | تر ټولو کوچنی، بې له لیرې کولو. |
| `د_لومړیتوب_لیکې_کچه(لیکه): عدد` | څومره ارزښتونه لري. |
| `لومړیتوب_لیکه_تشه_ده(لیکه): منطقي` | رښتیا کله چې هېڅ نه لري. |
