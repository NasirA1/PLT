# د ډېټا جوړښتونو لارښود

`راوړه "datastructures"` کلاسیک ډېټا جوړښتونه پروګرام ته راوړي: **ډېرۍ** (stack)،
**لیکه** (queue)، **دوسرې لیکه** (deque)، **ځنځیر** (یو اړخیز او دوه اړخیز)، **د لټون
دوه‌اړخیزه ونه**، **د لومړیتوب لیکه** (heap)، دوه ډوله **ټولګه** (set)، **ګراف** له خپلو
لټونونو سره، او **مختاړې ونه** (trie). په فایل کې هېڅ بهرنی نشته - دا ساده تندر دی، په
[`lib/thunder/ps/datastructures.th`](../../lib/thunder/ps/datastructures.th) کې، د لوستلو لپاره
لیکل شوی: پرانیزئ یې او وګورئ چې هر جوړښت رښتیا څنګه کار کوي. انګلیسي فایل
([`lib/thunder/en/datastructures.th`](../../lib/thunder/en/datastructures.th)) همدا جوړښتونه له
انګلیسي نومونو سره دي؛ دواړه پخپله، د اوزارو تر څنګ، موندل کېږي.

هر جوړښت یو **جوړښت دی چې جوړوونکې دنده او دندې لري**: ډېرۍ `ډېرۍ<ت>` ده، د `ډېرۍ()`
سره جوړېږي او د `د.ورزیات_کړه(۱)`، `د.واخله()` ... سره کارول کېږي؛ لیکه `لیکه<ت>` ده له
`ل.ورزیات_کړه`، `ل.واخله` ... سره؛ او همداسې لاندې.

| جوړښت | غوټۍ یې | | جوړښت | غوټۍ یې |
| --- | --- | --- | --- | --- |
| `ډېرۍ<ت>` | | | `ټولګه<ت>` | |
| `لیکه<ت>` | | | `ترتیب_شوې_ټولګه<ت>` | |
| `ځنځیر<ت>` | `د_ځنځیر_غوټۍ<ت>` | | `دوسرې_لیکه<ت>` | |
| `ونه<ت>` | `د_ونې_غوټۍ<ت>` | | `دوه_اړخیز_ځنځیر<ت>` | `د_دوه_اړخیز_ځنځیر_غوټۍ<ت>` |
| `لومړیتوب_لیکه<ت>` | | | `ګراف<ت>` | |
| `مختاړې_ونه` | `د_مختاړې_ونې_غوټۍ` | | | |

**دننۍ چارې یې شخصي دي.** هغه غړی چې نوم یې په `_` پیلېږي یوازې د جوړښت خپلې
دندې کارولای شي (`_توکي`، `_سر`، `_شمېر`، ... - له بهره تېروتنه `S076`): پروګرامونه دندې
کاروي، هېڅکله دننۍ برخې نه. او څرنګه چې دا جوړښتونه دي، نه ټولګي، متغیر اوس ازاد `ډېرۍ`
یا `ونه` نومېدای شي؛ بیا هم یې د هغه څه په نوم ونوموئ چې ساتي یې: `کاسې`، `وییونه`،
`لیدل_شوي`، `لارې`.

هر جوړښت **عمومي (generic)** دی: `ډېرۍ<ت>` د هر ډول توکي `ت` ساتي، او د توکو ډول په
اعلان کې نومول کېږي - `متغیر د: ډېرۍ<عدد> = ډېرۍ()` وايي چې تشه ډېرۍ به څه وساتي
(د [ژبې لارښود](language.md)، ۸ برخه). ونه او د لومړیتوب لیکه خپل توکي د `<` سره پرتله
کوي، نو توکي یې عددونه یا متنونه دي. له تش جوړښته اخیستل پروګرام د اجرا له تېروتنې سره
دروي، لکه د دننۍ دندې ناسمه بلنه؛ لومړی `تشه_ده()` وپوښتئ.

**ویې آزمویئ:** [`samples/advanced/ps/01_datastructures.th`](../../samples/advanced/ps/01_datastructures.th)
هر جوړښت په کار اچوي (انګلیسي:
[`samples/advanced/en/01_datastructures.th`](../../samples/advanced/en/01_datastructures.th)).
دا بېلګې په قصد د IDE په لړ کې نشته - له همدې ځایه یې پرانیزئ.

## ډېرۍ - وروستی دننه، لومړی بهر

د کاسو ډېرۍ: هغه چې وروستی سر ته کېښودل شي، لومړی بېرته راځي. هره عملیه O(1) ده.

| دنده | څه کوي |
| --- | --- |
| `ډېرۍ()` | یوه نوې، تشه ډېرۍ: `متغیر د: ډېرۍ<عدد> = ډېرۍ()`. |
| `د.ورزیات_کړه(ارزښت)` | یو ارزښت سر ته ږدي. |
| `د.واخله(): ت` | د سر ارزښت اخلي او راګرځوي یې. |
| `د.وګوره(): ت` | د سر ارزښت، بې له اخیستلو. |
| `د.کچه(): عدد` | څومره ارزښتونه لري. |
| `د.تشه_ده(): منطقي` | رښتیا کله چې هېڅ پرې نه وي. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر کاسې: ډېرۍ<عدد> = ډېرۍ()
کاسې.ورزیات_کړه(۱)
کاسې.ورزیات_کړه(۲)
کرښه چاپ(کاسې.واخله())   # ۲ - وروستی دننه، لومړی بهر
کرښه چاپ(کاسې.وګوره())   # ۱ - لا هلته دی
```

`کاسې.ورزیات_کړه` د ډېرۍ خپله دنده ده؛ د ژبې ساده `ورزیات کړه` (د لړیو لپاره) هر ځای
خپله مانا ساتي - د دندو دننه هم، چېرې چې `ورزیات کړه(_توکي، ارزښت)` دننۍ ده.

## لیکه - لومړی دننه، لومړی بهر

د دوکان مخې ته لیکه: `ورزیات_کړه` پای ته درېږي، `واخله` سر خدمتوي. د سر شاخص
ښویېږي، پر ځای د دې چې هر توکی وخوځوي، نو دواړه په منځني ډول O(1) دي.

| دنده | څه کوي |
| --- | --- |
| `لیکه()` | یوه نوې، تشه لیکه: `متغیر ل: لیکه<متن> = لیکه()`. |
| `ل.ورزیات_کړه(ارزښت)` | د لیکې پای ته درېږي. |
| `ل.واخله(): ت` | سر خدمتوي (لیرې کوي یې او راګرځوي یې). |
| `ل.وګوره(): ت` | سر، بې له خدمتولو. |
| `ل.کچه(): عدد` | څومره ارزښتونه انتظار کوي. |
| `ل.تشه_ده(): منطقي` | رښتیا کله چې هیڅوک انتظار نه کوي. |

## ځنځیر - د غوټیو کړۍ په کړۍ

هره غوټۍ (`د_ځنځیر_غوټۍ<ت>`) خپل ارزښت او راتلونکې غوټۍ ساتي؛ `هېڅ` ځنځیر پای ته
رسوي. دا د درسي کتابونو انځور دی، له یوه تکراري جوړښته جوړ؛ غوټۍ ساده ډېټا ده، او
`ځنځیر<ت>` هغه شی دی چې ځنځیر لري او چلوي یې. سر ته ورزیاتول O(1) دي؛ پای ته
ورزیاتول او لټون ځنځیر ګرځي، O(n).

| دنده | څه کوي |
| --- | --- |
| `ځنځیر()` | یو نوی، تش ځنځیر: `متغیر ځ: ځنځیر<عدد> = ځنځیر()`. |
| `ځ.سر_ته_ورزیات_کړه(ارزښت)` | سر ته ورزیاتوي، O(1). |
| `ځ.پای_ته_ورزیات_کړه(ارزښت)` | پای ته ورزیاتوي. |
| `ځ.له_سره_واخله(): ت` | د سر ارزښت لیرې کوي او راګرځوي یې. |
| `ځ.لیرې_کړه(ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي؛ رښتیا که ومونده. |
| `ځ.لري(ارزښت): منطقي` | رښتیا که کومه غوټۍ دا ارزښت لري. |
| `ځ.کچه(): عدد` | څومره ارزښتونه لري. |
| `ځ.لړۍ_کړه(): ت[]` | ارزښتونه د ځنځیر په ترتیب، د ساده لړۍ په بڼه. |

## د لټون دوه‌اړخیزه ونه - ترتیب شوي لټونونه

د هرې غوټۍ کیڼه څانګه کوچني ارزښتونه لري، ښۍ یې لوی، نو یو ارزښت په O(لوړوالی) ګامونو
کې موندل کېږي - O(log n) کله چې ونه برابره وي. تکراري ارزښتونه له پامه غورځول کېږي.

| دنده | څه کوي |
| --- | --- |
| `ونه()` | یوه نوې، تشه ونه: `متغیر و: ونه<عدد> = ونه()`. |
| `و.ورزیات_کړه(ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورزیاتوي. |
| `و.لري(ارزښت): منطقي` | رښتیا که ارزښت په ونه کې وي. |
| `و.لیرې_کړه(ارزښت): منطقي` | ارزښت لیرې کوي؛ رښتیا که هلته و. |
| `و.کچه(): عدد` | څومره ارزښتونه لري. |
| `و.لوړوالی(): عدد` | له ریښې تر ټولو اوږده لار له څومره غوټیو تېرېږي (تشه: ۰). |
| `و.کمینه(): ت` / `و.اعظمه(): ت` | د ترتیب دواړه څنډې. |
| `و.په_ترتیب(): ت[]` | هر ارزښت په پورته کېدونکي ترتیب (منځنی تګ). |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر وییونه: ونه<متن> = ونه()
تکرار ویی په ["ناک"، "مڼه"، "انځر"]
    وییونه.ورزیات_کړه(ویی)
کرښه چاپ(وییونه.په_ترتیب())     # [«انځر»، «مڼه»، «ناک»] - ونه ترتیب ساتي
کرښه چاپ(وییونه.لري("انځر"))    # رښتیا، په O(log n) ګامونو کې موندل شوی
```

## د لومړیتوب لیکه - کمینه لومړی

`واخله` همېش تر ټولو کوچنی ارزښت لومړی راکوي، ارزښتونه چې په هر ترتیب راغلي
وي - د لومړیتوب لیکه. دا یوه دوه‌اړخیزه ونه ده چې په یوه لړۍ کې ځای شوې: د `ش` شاخص بچي په
`۲*ش + ۱` او `۲*ش + ۲` کې ناست دي، او هر مور و پلار له خپلو بچیو `<=` دی. ورزیاتول او اخیستل
O(log n) دي؛ کتل O(1).

| دنده | څه کوي |
| --- | --- |
| `لومړیتوب_لیکه()` | یوه نوې، تشه لیکه: `متغیر م: لومړیتوب_لیکه<عدد> = لومړیتوب_لیکه()`. |
| `م.ورزیات_کړه(ارزښت)` | یو ارزښت ورزیاتوي. |
| `م.واخله(): ت` | تر ټولو کوچنی ارزښت لیرې کوي او راګرځوي یې. |
| `م.وګوره(): ت` | تر ټولو کوچنی، بې له لیرې کولو. |
| `م.کچه(): عدد` | څومره ارزښتونه لري. |
| `م.تشه_ده(): منطقي` | رښتیا کله چې هېڅ نه لري. |

## ټولګه - ځانګړي توکي

راټولونه چې هر ارزښت پکې یو ځل راځي. د تندر پر خپله نقشه جوړه ده - ارزښت کیلۍ ده - نو
ورزیاتول، لیرې کول او شتون کتل ټول O(1) دي، او توکي د نقشې کیلۍ دي: `عدد`، `منطقي` یا
`متن`. `ارزښتونه()` یې د لومړي ورزیاتېدو په ترتیب راګرځوي.

| دنده | څه کوي |
| --- | --- |
| `ټولګه()` | یوه نوې، تشه ټولګه: `متغیر ټ: ټولګه<متن> = ټولګه()`. |
| `ټ.ورزیات_کړه(ارزښت)` | یو ارزښت ورننباسي؛ هغه چې وي، یو پاتې کېږي. |
| `ټ.لیرې_کړه(ارزښت): منطقي` | یو ارزښت باسي؛ رښتیا که هلته و. |
| `ټ.لري(ارزښت): منطقي` | رښتیا که ارزښت پکې وي. |
| `ټ.کچه(): عدد` / `ټ.تشه_ده(): منطقي` | څومره ارزښتونه لري. |
| `ټ.ارزښتونه(): ت[]` | ارزښتونه، د لومړي ورزیاتېدو په ترتیب. |
| `الف.یوځای(ب): ټولګه<ت>` | هر ارزښت چې په یوه یا بله کې وي. |
| `الف.ګډ(ب): ټولګه<ت>` | هر ارزښت چې په دواړو کې وي. |
| `الف.توپیر(ب): ټولګه<ت>` | د الف هر هغه ارزښت چې په ب کې نشته. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر لیدل_شوي: ټولګه<متن> = ټولګه()
لیدل_شوي.ورزیات_کړه("سور")
لیدل_شوي.ورزیات_کړه("شین")
لیدل_شوي.ورزیات_کړه("سور")          # له وړاندې شته: لا هم یو «سور»
کرښه چاپ(لیدل_شوي.ارزښتونه())        # [«سور»، «شین»]
کرښه چاپ(لیدل_شوي.لري("زرغون"))     # درواغ
```

## ترتیب شوې ټولګه - ځانګړي او اڼل شوي

ټولګه چې خپل ارزښتونه په پورته کېدونکي ترتیب ساتي: لاندې یې د لټون دوه‌اړخیزه ونه ده،
نو ورزیاتول، لیرې کول او شتون کتل O(log n) دي او `ارزښتونه()` ترتیب شوي راوځي. توکي د
`<` سره پرتله کېږي، نو عددونه یا متنونه دي.

| دنده | څه کوي |
| --- | --- |
| `ترتیب_شوې_ټولګه()` | یوه نوې، تشه ترتیب شوې ټولګه: `متغیر ټ: ترتیب_شوې_ټولګه<عدد> = ترتیب_شوې_ټولګه()`. |
| `ټ.ورزیات_کړه(ارزښت)` | ارزښت پر خپل ترتیب شوي ځای ورننباسي. |
| `ټ.لیرې_کړه(ارزښت): منطقي` | یو ارزښت باسي؛ رښتیا که هلته و. |
| `ټ.لري(ارزښت): منطقي` | رښتیا که ارزښت پکې وي. |
| `ټ.کچه(): عدد` / `ټ.تشه_ده(): منطقي` | څومره ارزښتونه لري. |
| `ټ.ارزښتونه(): ت[]` | ارزښتونه، په پورته کېدونکي ترتیب. |
| `ټ.کمینه(): ت` / `ټ.اعظمه(): ت` | د ترتیب دواړه څنډې. |

## دوسرې لیکه - دواړه سرونه پرانیستي

لیکه چې دواړه سرونه یې خدمت کوي: ارزښتونه له مخې او له شا دواړو ننوځي او وځي (هغه جوړښت
چې د ښوېدونکو کړکیو او د کار د غلا تر شا دی). دوه ډېرۍ شا په شا هره عملیه په منځني ډول
O(1) ساتي.

| دنده | څه کوي |
| --- | --- |
| `دوسرې_لیکه()` | یوه نوې، تشه دوسرې لیکه: `متغیر د: دوسرې_لیکه<عدد> = دوسرې_لیکه()`. |
| `د.سر_ته_ورزیات_کړه(ارزښت)` / `د.پای_ته_ورزیات_کړه(ارزښت)` | هر سر ته ارزښت ږدي. |
| `د.له_سره_واخله(): ت` / `د.له_پایه_واخله(): ت` | له هر سره ارزښت اخلي. |
| `د.سر_وګوره(): ت` / `د.پای_وګوره(): ت` | ګوري، بې له اخیستلو. |
| `د.کچه(): عدد` / `د.تشه_ده(): منطقي` | څومره ارزښتونه لري. |
| `د.لړۍ_کړه(): ت[]` | ارزښتونه له مخې تر شا. |

## دوه اړخیز ځنځیر - دواړه لوري ګرځي

لکه ځنځیر، خو هره غوټۍ (`د_دوه_اړخیز_ځنځیر_غوټۍ<ت>`) مخکېنۍ هم پېژني او
ځنځیر دواړه سرونه ساتي: په دواړو سرونو کې ورزیاتول او لیرې کول O(1) دي، او شاتګ هم کېدای شي.

| دنده | څه کوي |
| --- | --- |
| `دوه_اړخیز_ځنځیر()` | یو نوی، تش ځنځیر: `متغیر ځ: دوه_اړخیز_ځنځیر<عدد> = دوه_اړخیز_ځنځیر()`. |
| `ځ.سر_ته_ورزیات_کړه(ارزښت)` / `ځ.پای_ته_ورزیات_کړه(ارزښت)` | هر سر ته، O(1). |
| `ځ.له_سره_واخله(): ت` / `ځ.له_پایه_واخله(): ت` | له هر سره، O(1). |
| `ځ.لیرې_کړه(ارزښت): منطقي` | لومړۍ غوټۍ له دې ارزښت سره لیرې کوي. |
| `ځ.لري(ارزښت): منطقي` | رښتیا که کومه غوټۍ دا ارزښت لري. |
| `ځ.کچه(): عدد` | څومره ارزښتونه لري. |
| `ځ.لړۍ_کړه(): ت[]` / `ځ.سرچپه_لړۍ_کړه(): ت[]` | دواړه د تګ لوري. |

## ګراف - څوکې، غاړې او لټونونه

د ګاونډیتوب نقشه: هره څوکه هغو څوکو ته نقشه کېږي چې غاړه ورته ځي. غاړې یو لوري دي؛
`ونښلوه` د ناجهته ګراف لپاره دواړه لوري ورزیاتوي. څوکې د نقشې کیلۍ دي (عدد، منطقي
یا متن). لټونونه د همدې فایل خپله `لیکه` او `ټولګه` کاروي.

| دنده | څه کوي |
| --- | --- |
| `ګراف()` | یو نوی، تش ګراف: `متغیر ګ: ګراف<متن> = ګراف()`. |
| `ګ.څوکه_ورزیاته_کړه(څوکه)` | څوکه بې غاړو ورزیاتوي. |
| `ګ.غاړه_ورزیاته_کړه(له_، ته_)` | یولورې غاړه (څوکې په اړتیا ورزیاتېږي). |
| `ګ.ونښلوه(الف، ب)` | ناجهته غاړه: یوه هرې خوا ته. |
| `ګ.څوکې(): ت[]` / `ګ.ګاونډیان(څوکه): ت[]` | څه شته. |
| `ګ.پلن_لټون(پیل): ت[]` | پلن لټون (BFS): هره رسېدونکې څوکه، لومړی نږدې کړۍ. |
| `ګ.ژور_لټون(پیل): ت[]` | ژور لټون (DFS): هره لار تر پایه، بیا بله. |
| `ګ.لنډه_لار(له_، ته_): ت[]` | تر ټولو لږې غاړې، `[له، ...، ته]`؛ تشه کله چې نه رسېږي. |
| `ګ.لار_لري(له_، ته_): منطقي` | رښتیا که د غاړو کوم ځنځیر هلته ځي. |

```thunder
# ژبه: ps
راوړه "datastructures"

متغیر لارې: ګراف<متن> = ګراف()
لارې.ونښلوه("کابل"، "غزني")
لارې.ونښلوه("غزني"، "کندهار")
کرښه چاپ(لارې.لنډه_لار("کابل"، "کندهار"))
# [«کابل»، «غزني»، «کندهار»]
```

## مختاړې ونه - د مختاړو ونه (trie)

هر ویی خپله لار له هر هغه ویي سره شریکوي چې همداسې پیلېږي، نو لټون او د مختاړي پوښتنې
د ویي د اوږدوالي بیه لري، که هر څومره وییونه پکې وي - هغه جوړښت چې د بشپړونې (autocomplete)
تر شا دی. (مختاړې ونه متنونه ساتي، نو عمومي نه ده.)

| دنده | څه کوي |
| --- | --- |
| `مختاړې_ونه()` | یوه نوې، تشه ونه: `متغیر و: مختاړې_ونه = مختاړې_ونه()`. |
| `و.ورزیات_کړه(ویی)` | ویی ورزیاتوي (دوه ځله یې یو ساتي). |
| `و.لري(ویی): منطقي` | رښتیا که همدا ویی ورزیات شوی و. |
| `و.مختاړی_لري(مختاړی): منطقي` | رښتیا که کوم ویی پرې پیلېږي. |
| `و.کچه(): عدد` | څومره بېلابېل وییونه لري. |
| `و.وییونه(): متن[]` | هر ویی، د الفبا په ترتیب. |

## پخواني نومونه

کتابتون دوه پخوانۍ بڼې لرلې. له ۰٫۷ مخکې هرې دندې خپل جوړښت په خپل نوم کې ګرځاوه
(`نوې_ډېرۍ()`، `ډېرۍ_ته_ورزیات_کړه`، ...)؛ ۰٫۷ هر جوړښت په خپل ټولګي کې کېښود
(`ډېرۍ.نوې()`، `ډېرۍ.ورزیات_کړه(د، ۱)`). اوس چې جوړښتونه خپله جوړوونکې دنده او خپلې
دندې لري، ټولګي او `نوې` یې ولاړل - جوړوونکې دنده جوړوي، دندې کار کوي:

| پخوا (ټولګی) | اوس (شی) |
| --- | --- |
| `ډېرۍ.نوې()`، `ډېرۍ.ورزیات_کړه(د، ا)`، `ډېرۍ.واخله(د)`، ... | `ډېرۍ()`، `د.ورزیات_کړه(ا)`، `د.واخله()`، ... |
| `لیکه.نوې()`، `لیکه.ورزیات_کړه(ل، ا)`، `لیکه.واخله(ل)`، ... | `لیکه()`، `ل.ورزیات_کړه(ا)`، `ل.واخله()`، ... |
| `ځنځیر.نوی()`، `ځنځیر.سر_ته_ورزیات_کړه(ځ، ا)`، ...، `ځنځیر.د_ځنځیر_غوټۍ<ت>` | `ځنځیر()`، `ځ.سر_ته_ورزیات_کړه(ا)`، ...، `د_ځنځیر_غوټۍ<ت>` |
| `ونه.نوې()`، `ونه.ورزیات_کړه(و، ا)`، ...، `ونه.د_ونې_غوټۍ<ت>` | `ونه()`، `و.ورزیات_کړه(ا)`، ...، `د_ونې_غوټۍ<ت>` |
| `لومړیتوب_لیکه.نوې()`، `لومړیتوب_لیکه.ورزیات_کړه(م، ا)`، ... | `لومړیتوب_لیکه()`، `م.ورزیات_کړه(ا)`، ... |
| `ټولګه.نوې()`، `ټولګه.ورزیات_کړه(ټ، ا)`، `ټولګه.یوځای(الف، ب)`، ... | `ټولګه()`، `ټ.ورزیات_کړه(ا)`، `الف.یوځای(ب)`، ... |
| `ترتیب_شوې_ټولګه.نوې()`، `ترتیب_شوې_ټولګه.ورزیات_کړه(ټ، ا)`، ... | `ترتیب_شوې_ټولګه()`، `ټ.ورزیات_کړه(ا)`، ... |
| `دوسرې_لیکه.نوې()`، `دوسرې_لیکه.سر_ته_ورزیات_کړه(د، ا)`، ... | `دوسرې_لیکه()`، `د.سر_ته_ورزیات_کړه(ا)`، ... |
| `دوه_اړخیز_ځنځیر.نوی()`، `دوه_اړخیز_ځنځیر.سر_ته_ورزیات_کړه(ځ، ا)`، ...، `دوه_اړخیز_ځنځیر.د_دوه_اړخیز_ځنځیر_غوټۍ<ت>` | `دوه_اړخیز_ځنځیر()`، `ځ.سر_ته_ورزیات_کړه(ا)`، ...، `د_دوه_اړخیز_ځنځیر_غوټۍ<ت>` |
| `ګراف.نوی()`، `ګراف.ونښلوه(ګ، الف، ب)`، `ګراف.پلن_لټون(ګ، پیل)`، ... | `ګراف()`، `ګ.ونښلوه(الف، ب)`، `ګ.پلن_لټون(پیل)`، ... |
| `مختاړې_ونه.نوې()`، `مختاړې_ونه.ورزیات_کړه(و، ویی)`، ...، `مختاړې_ونه.د_مختاړې_ونې_غوټۍ` | `مختاړې_ونه()`، `و.ورزیات_کړه(ویی)`، ...، `د_مختاړې_ونې_غوټۍ` |
