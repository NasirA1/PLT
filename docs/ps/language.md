# د تندر ژبې لارښود

*[د تندر SDK لارښود](README.md) یوه برخه.*

> دا سند د `docs/language.md` پښتو ژباړه ده. انګلیسي اصل پره‌مختللی (معتبر) متن دی؛ دا ژباړه
> د مسلکي اصطلاحاتو له پلوه د یوه ژبپوه کتنې ته اړتیا لري.

تندر یوه کوچنۍ، په جامد ډول ډول‌ شوې (statically typed) ژبه ده چې د دې لپاره جوړه شوې چې
زده کوونکي وګوري پروګرام‌ژبې له دننه څنګه کار کوي. هر پروګرام له همغه لارې تېرېږي چې په IDE
کې یې لیدلای شئ:

```
سرچینه متن --لغوي تحلیل--> توکي --نحوي تحلیل--> نحوي ونه --معنايي تحلیل--> ډول لرونکې ونه + نښې
        --کوډ جوړونه--> بایټ کوډ (.thc) --مجازي ماشین--> پایله
```

د سرچینې فایلونه `.th` شاوند لري او UTF-8 متن دی. جوړ شوي بایټ کوډ فایلونه `.thc` لري.
پروګرامونه په **انګلیسي** یا **پښتو** لیکل کېدای شي (۱۴ برخه).

---

## ۱. لومړی پروګرام

```thunder
# ژبه: ps
# د سر کچې امرونه له پاسه کښته اجرا کېږي، په هره کرښه یو.
کرښه چاپ("سلام، تندر!")

جوړښت ټکی
    س: عدد
    ص: عدد

دنده مربع(ن: عدد): عدد
    راګرځه ن * ن

تکرار متغیر ش = ۱، ش <= ۳، ش = ش + ۱
    کرښه چاپ(ش، " مربع یې "، مربع(ش)، " ده، په "، ټکی(ش، مربع(ش)))
```

بلاکونه، لکه په پایتن کې، په **ننوتنه** ښودل کېږي: د دندې، «که»، «کنه»، «ترڅو»، «تکرار»،
جوړښت، «ټولګی» یا «سره» برخه هغه کرښې دي چې یوه کچه (۴ تشې؛ ټب = ۴) ننوتې
وي. قوسونه `{}` او جلا کوونکي `;` نشته، او منطقي عملګرونه کلمې دي: `او`، `یا`، `نه`. IDE د بلاک پیلوونکې کرښې وروسته
پخپله ننوتنه ورکوي او له «راګرځه»، «ودرېږه»، «دوام» او «تېر» وروسته یې بېرته راوباسي.

## ۲. لغوي جوړښت

| توکی | بېلګې | یادښت |
| --- | --- | --- |
| تبصرې | `# تر کرښې پایه`، `''' بلاک '''` | بلاک تبصرې نه ننوتل کېږي (nest). |
| نومونه | `شمېر`، `is_prime`، `_لنډ` | یو توری یا `_`، بیا توري، رقمونه یا `_`. د هرې لیکدود توري منل کېږي. |
| عددي ارزښتونه | `0`، `42`، `۴۲`، `0x2A`، `0b101010` | لسیز رقمونه ASCII، پښتو/فارسي (۰–۹) یا عربي (٠–٩) کېدای شي. `0x` شپاړس‌بنسټیز عدد پیلوي (رقمونه `0-9 a-f A-F`)، `0b` دوه‌بنسټیز (`0` او `1`): همغه ارزښت، داسې لیکل شوی چې بیټونه یې ښکاري (۵ برخه، بیټي عملګر، او د IDE «بیټونه» پاڼه). تر ټولو لوی ارزښت 2⁶³−1 دی. |
| اعشاري ارزښتونه | `۳٫۱۴`، `۰٫۵`، `3.14` | رقم، اعشاریه، رقم: `۱٫` او `٫۵` شمېرې نه دي، او `ټ.۰` لا هم د ټاپل توکی دی. د توان بڼه نشته. |
| متني ارزښتونه | `"متن"`، `«متن»` | باید په همغه کرښه پای ته ورسېږي. ترکیبونه: `\ن` (نوې کرښه)، `\ت` (ټب)، `\ر`، `\۰`، `\"`، `\\` (او `\«` `\»`). انګلیسي توري هم کار کوي - `\n` `\t` `\r` `\0` - او `thunderc --translate` یې اړوي. |
| منطقي ارزښتونه | `رښتیا`، `درواغ` | |
| هېڅ | `هېڅ` | د جوړښت تش ماخذ (۸ برخه). |
| کلیدي کلمې | `متغیر ثابت دنده جوړښت برسېر ګڼنه ټولګی که کنه ترڅو تکرار په سره ودرېږه دوام راګرځه تېر راوړه بهرنی هېڅ` | خوندي دي. |
| د ډول نومونه | `عدد اعشاري منطقي متن بایټ` | خوندي دي. د جوړښت او ګڼنې نومونه هم ډولونه دي. (`متن` د متن د دنني ټولګي نوم هم دی: `متن.پاک کړه(م)`، ۱۰ برخه.) |
| عملګرونه | `+ - * / % == != < <= > >= & \| ^ ~ << >> = += -= *= /= %= .` او کلمې `او یا نه` | کلمې خوندي دي. |
| نښې | `( ) { } [ ] ، :` | پښتو پروګرامونه کامه `،` لیکي (`,` هم منل کېږي). |

هغه سمبولونه چې نورې ژبې یې کاروي خو تندر نه، له لارښوونې سره راپور کېږي: `&&` ← `او`،
`||` ← `یا`، `!س` ← `نه س` (خو `!=` پاتې دی)، او `;` ← `،` (لغوي تېروتنه `L002`).

**د کیبورډ توري:** عربي او فارسي کیبورډونه ك (U+0643)، گ (U+06AF) او ي (U+064A) ورکوي؛ تندر یې
په پښتو ک (U+06A9)، ګ (U+06AB) او ی (U+06CC) اړوي - **د کلیدي کلمو، دننیو دندو او د پروګرام د
خپلو نومونو لپاره یو شان**. نو `كرښه چاپ` همغه `کرښه چاپ` ده، `ټولگى` او `ټولګى` همغه `ټولګی`،
`ګرافیک.رنگونه.سور` همغه `ګرافیک.رنګونه.سور` دی، او یو متغیر چې `رنگ` لیکل شوی وي له `رنګ` سره
یو نوم دی.

تشې، ټبونه او د یونیکوډ د لوري نښې توکي بېلوي خو بل اثر نه لري. **د کرښې ماتېدل مهم دي**:
امر پای ته رسوي (۶ برخه).

## ۳. ډولونه

| ډول | ارزښتونه | اصلي (default) ارزښت |
| --- | --- | --- |
| `عدد` | ۶۴-بټه علامت لرونکي بشپړ عددونه | `۰` |
| `اعشاري` | اعشاري شمېرې: ۶۴-بټه ځنډېدونکې نقطه (IEEE 754) | `۰٫۰` |
| `منطقي` | `رښتیا`، `درواغ` | `درواغ` |
| `متن` | نه بدلېدونکې د یونیکوډ تورو لړۍ | `""` |
| `بایټ` | یو بایټ: له ۰ تر ۲۵۵ بشپړ عدد. `بایټ[]` خامه ډېټا ده - د فایل، غږ یا د شبکې د بستې منځپانګه (۱۰ برخه او د کتابتون لارښود، «بایټونه») | `۰` |
| د ګڼنې نوم | د ګڼنې په اعلان کې له لیکل شویو غړو یو، لکه `لوری.شمال` یا `ګرافیک.رنګونه.سور` (۸ برخه) | لومړی غړی |
| `T[]` | لړۍ، لکه `عدد[]`، `متن[][]` | `[]` (تشه) |
| `(T1، T2، ...)` | ټاپلونه: ټاکلی شمېر ارزښتونه (۸ برخه) | د توکو اصلي ارزښتونه |
| `{K: V}` | نقشې؛ کیلۍ `عدد`، `منطقي` یا `متن` (۸ برخه) | `{}` (تشه) |
| د جوړښت نوم | د هغه جوړښت ارزښتونه (۸ برخه)؛ د ټولګي جوړښت د ټولګي له نوم سره لیکل کېږي، `هندسه.ټکی` (۹ برخه) | جوړښت چې ټولې برخې یې اصلي ارزښت لري (جوړوونکې دنده نه چلېږي) |
| د برسېر نوم | هر هغه د جوړښت ارزښت چې جوړښت یې دا برسېر عملي کوي (۸ برخه)، یا `هېڅ` | `هېڅ` |
| `دنده(T1، ...): R` | د دندو ارزښتونه، لکه `دنده(عدد): منطقي` (۷ برخه) | «بې دندې» (بلل یې د اجرا تېروتنه `R020` ده) |

هغه دنده چې د راګرځېدو ډول نلري هېڅ نه راګرځوي؛ پایله یې نشي کارېدای.

**دوه پټې اړونې (implicit conversions)** شته، دواړه پراخونې چې هېڅ نه ورکوي: `عدد` هر هغه ځای
`اعشاري` کېږي چې اعشاري غوښتل کېږي (`۱ + ۰٫۵`، `ن / ۲٫۰`، `متغیر س: اعشاري = ۲`)، او `بایټ`
په همغو ځایونو کې `عدد` (یا بیا `اعشاري`) کېږي، نو `ب + ۱`، `ب & 0x0F` او `ب == ۲۰۰` د بایټ پر
ارزښت د عدد په توګه کار کوي. هېڅ شی پخپله نه کمېږي: `عدد` پخپله `بایټ` نه کېږي (`بایټ کړه(ن)`
وکاروئ، چې ټیټ ۸ بیټونه ساتي) - پرته له دې چې **له ۰ تر ۲۵۵ یو بشپړ لفظي عدد چې د بایټ په ځای
لیکل شوی وي همغه بایټ دی** (`متغیر ب: بایټ = ۲۰۰`، `ډېټا[ش] = ۰`) - او `"س = " + ۵` د ډول
تېروتنه ده؛ `متن کړه(۵)` ولیکئ، یا کرښه چاپ ته څو دلیلونه ورکړئ.

لړۍ، نقشې او جوړښتونه **ماخذي ډولونه** دي: ورکول یا دندې ته لېږل یې همغه ارزښت شریکوي.
د خپلواکې کاپي لپاره `کاپي(ارزښت)` وکاروئ. ټاپلونه نه بدلېږي، نو د هغوی لپاره شریکول او
کاپي یو شی دی. لړۍ په `[۱، ۲، ۳]` یا `لړۍ(ن، ارزښت)` جوړېږي، نقشې په `{کیلۍ: ارزښت}`،
ټاپلونه په `(الف، ب)` او جوړښتونه د جوړښت د نوم په بللو. `new` نشته: حافظه پخپله
(د ماخذ شمېرنې سره) اداره کېږي؛ ۸ برخه وايي ولې دورونه (cycles) ناشوني دي.

## ۴. اعلانونه

```thunder
متغیر کال: عدد = ۲۰۲۶       # ډول + ارزښت
متغیر ژبه = "تندر"          # ډول له ارزښته معلومېږي
متغیر اونۍ: عدد             # بې ارزښته: له اصلي ارزښته (۰) پیلېږي
ثابت د_اونۍ_ورځې = ۷        # بیا نشي بدلېدای
```

«متغیر» بې ډوله او بې ارزښته نه منل کېږي (`P008`). «ثابت» تل ارزښت غواړي. د سر کچې
متغیرونه عمومي (global) دي؛ نور ځایي دي او د خپل بلاک تر پایه ژوند کوي. نه کارېدلی ځایي
متغیر خبرداری `W001` راوړي.

## ۵. افادې

عملګرونه له لوړ لومړیتوب نه ټیټ ته. ټول دوه-اړخیز عملګرونه له کیڼ نه ښي ته ګروپ کېږي.

| لومړیتوب | عملګرونه | د عملوندو ډولونه | پایله |
| --- | --- | --- | --- |
| ۱۳ | بلنه `f(...)`، لړ `a[i]` / `m[کیلۍ]`، برخه `s.برخه`، `t.0` | | |
| ۱۲ | `-س`، `~س` بیټي نفي | `عدد`، `اعشاري` (`~` یوازې `عدد`) | همغه ډول |
| ۱۱ | `*` `/` | دوه عددونه یا دوه اعشاري شمېرې | همغه ډول |
| ۱۱ | `%` | `عدد` | `عدد` |
| ۱۰ | `+` `-` | دوه شمېرې (او `متن + متن`) | همغه ډول / `متن` |
| ۹ | `<<` `>>` بیټي ښويېدنې | `عدد` (شمېر یې ۰..۶۳) | `عدد` |
| ۸ | `&` بیټي او (AND) | `عدد` | `عدد` |
| ۷ | `^` بیټي XOR | `عدد` | `عدد` |
| ۶ | `\|` بیټي یا (OR) | `عدد` | `عدد` |
| ۵ | `<` `<=` `>` `>=` | دوه شمېرې یا دوه متنونه | `منطقي` |
| ۴ | `==` `!=` | دوه یو-ډوله ارزښتونه (`عدد`، `اعشاري`، `منطقي`، `متن` یا ټاپل) | `منطقي` |
| ۳ | `نه س` | `منطقي` | `منطقي` |
| ۲ | `او` | `منطقي` | `منطقي` (لنډه لار) |
| ۱ | `یا` | `منطقي` | `منطقي` (لنډه لار) |

* د عدد وېش صفر ته نیژدې کېږي (`-۷ / ۲` = `-۳`)؛ خو `۷ / ۲٫۰` = `۳٫۵`. د `%` نښه د کیڼ
  عملوند نښه ده او یوازې د بشپړو عددونو لپاره تعریف شوی دی.
* **یوازې یوه ناڅرګنده اړونه شته:** هر چېرې چې اعشاري شمېره غوښتل کېږي، بشپړ عدد پراخېږي
  (`۱ + ۰٫۵`، `متغیر ش: اعشاري = ۲`، د دندې دلیلونه، `راګرځه`، او د لړۍ توکي `[۱، ۲٫۵]`).
  بله لار پرانیستې نه ده: اعشاري شمېره پخپله بشپړ عدد نه کېږي (`ریاضي.نیژدې کړه`،
  `ریاضي.کښته کړه`، `ریاضي.پورته کړه` یا `عدد کړه` وکاروئ).
* اعشاري شمېره په دوه بنسټ کې ساتل کېږي، نو `۰٫۱ + ۰٫۲ == ۰٫۳` درواغ دی؛ د یوې کوچنۍ
  زغمنې سره پرتله کړئ: `ریاضي.مطلق(الف - ب) < ۰٫۰۰۰۰۰۱`.
* له حد اوښتل، په صفر وېش (بشپړ یا اعشاري)، ډېره لویه اعشاري پایله (`R025`) او له حده بهر
  لړ شمېرې **د اجرا تېروتنې** دي. تندر ناجوت (undefined) چلند نه لري او هېڅکله بې‌پایه
  (infinity) یا NaN نه جوړوي.
* `s[i]` یو-توریز متن ورکوي. متنونه نه بدلېږي.
* متنونه د یونیکوډ د کوډ-ټکو په ترتیب پرتله کېږي؛ ټاپلونه توکی په توکی. لړۍ، نقشې او
  جوړښتونه په `==` نه پرتله کېږي.
* `الف او ب` ب یوازې هغه وخت ارزوي چې الف رښتیا وي؛ `الف یا ب` یوازې چې الف درواغ وي.
* «نه» د پرتلې نه ټیټ لومړیتوب لري (لکه پایتن): `نه الف == ب` یعنې `نه (الف == ب)`.
* **بیټونه.** بیټي عملګر د `عدد` پر ۶۴ بیټونو کار کوي (two's complement) او د پرتلو نه
  *لوړ* لومړیتوب لري (لکه پایتن)، نو `بیرغونه & نقاب != ۰` یعنې `(بیرغونه & نقاب) != ۰`.
  `~الف` د `-الف - ۱` سره برابر دی. له ۰..۶۳ بهر د ښويېدو شمېر د اجرا تېروتنه ده؛ `<<`
  له سره وتلي بیټونه غورځوي، او `>>` نښه ساتي (`-۱۶ >> ۲` = `-۴`). د IDE د «بیټونه» پاڼه
  (د پردې شاته) هره دا عملیه بیټ په بیټ ښيي.

## ۶. امرونه، د کرښې ماتېدل او ننوتنه

امر د خپلې کرښې په پای پای ته رسېږي؛ جلا کوونکی نشته:

```thunder
متغیر س = ۱
متغیر ص = ۲
س = س + ص
```

که کرښه د قوسونو دننه یا سم له عملګر (`او`، `یا`، `نه` هم) وروسته پای شي، امر بلې کرښې ته
دوام کوي:

```thunder
متغیر سم = پلنوالی > ۰ او
    لوړوالی > ۰
کرښه چاپ("مساحت: "،
        پلنوالی * لوړوالی)
```

هغه عملګر چې کرښه پرې **پیل** شي، تل نوی امر دی. هر امر خپله کرښه لري؛ دوه امرونه په
یوه کرښه نحوي تېروتنه `P010` ده. «راګرځه» د کرښې په پای بې ارزښته راګرځي.

**بلاکونه ننوتل کېږي.** هغه کرښه چې له مخکینۍ ډېره ننوتې وي بلاک پرانیزي؛ بلاک هلته
پای ته رسېږي چې ننوتنه بېرته راکمه شي (لغوي تحلیل دا بدلونونه د `INDENT`/`DEDENT` توکو
په بڼه ورکوي، چې د «توکي» پاڼه کې یې لیدلای شئ). «تېر» هغه امر دی چې هېڅ نه کوي،
د قصداً تش بلاک لپاره. له یوې کچې کمه ننوتنه چې هېڅ بلاک ورسره سمون نه خوري تېروتنه
`L008` ده؛ بې‌ځایه ننوتنه `P013` ده. شرطونه قوسونو ته اړتیا نلري.

```thunder
س = س + ۱                # ارزښت ورکول
س += ۱                   # همدا، خو لنډ؛ همدا ډول -= *= /= %=
ارزښتونه_یې[ش] = ۰
ارزښتونه_یې[ش] += ۱۰     # ارزښتونه_یې[ش] او ش هر یو یوازې یو ځل ارزول کېږي
ټ.س = ۳
کرښه چاپ(س)              # د افادې امر (معمولاً بلنه)

که س > ۰                 # شرط باید منطقي وي؛ برخه یې ننوتې ده
    کرښه چاپ("مثبت")
کنه که س < ۰
    کرښه چاپ("منفي")
کنه
    کرښه چاپ("صفر")

ترڅو س > ۰
    س = س - ۱

تکرار متغیر ش = ۰، ش < ۱۰، ش = ش + ۱    # پیل، شرط، ګام - په کامو بېل
    که ش == ۳
        دوام           # ګام ته ورټوپ کړه (ش = ش + ۱)
    که ش == ۷
        ودرېږه         # تکرار پرېږده
```

ارزښت ورکول امر دی، نه افاده، نو `که س = ۱` نحوي تېروتنه ده.

**«سره»** د هغو سرچینو امر دی - پرانیستی فایل، د شبکې اړیکه - چې پروګرام یې له کار وروسته باید
وتړي: بلاک یې سرچینه تړي، که هر ډول پای ته ورسېږي. په ۱۱ برخه کې بیان شوی، له هغو ټولګو وروسته
چې پرې تکیه کوي.

**«تکرار ... په»** یوه ټولګه ګرځوي: د لړۍ توکي، د متن توري، یا د نقشې **کیلۍ**
(`توکي(نقشه)` د (کیلۍ، ارزښت) جوړې ورکوي). د تکرار متغیر پخپله تکرار اعلانوي او یوازې
د هغه دننه شته؛ `ودرېږه` او `دوام` لکه په هر بل تکرار کې کار کوي. د ټولګې افاده یوازې یو
ځل، له لومړي دور نه مخکې، ارزول کېږي، خو ځای په هر دور کې د ټولګې له **اوسني** اوږدوالي
سره پرتله کېږي؛ نو که د ګرځولو پر مهال لړۍ ته څه ورزیات یا ترې لیرې کړئ، تکرار بدلېږي —
په دې حال کې `کاپي(ل)` وګرځوئ. (د نقشې ګرځول تل خوندي دي: کیلۍ له لومړي دور نه مخکې
اخیستل کېږي.) په قوسونو کې څو نومونه یو ټاپل وېشي:

```thunder
تکرار نمره په نمرې
    ټولټال += نمره

تکرار (ځای، نوم) په شمېره ورکړه(نومونه)
    کرښه چاپ(ځای، ": "، نوم)
```

**لنډ ورکول.** `س += ا` د `س = س + ا` مانا لري؛ همدا ډول `-=` `*=` `/=` `%=`. کیڼ اړخ
متغیر، د لړۍ یا نقشې توکی، یا د جوړښت برخه کېدای شي، او **یوازې یو ځل** ارزول کېږي.
`+=` متنونه هم سره نښلوي.

### بهرنۍ دندې (++C)

`راوړه بهرنی "mathx"` یو ++C کتابتون راوړي، او `بهرنی دنده` وايي چې څه لري:

```thunder
راوړه بهرنی "mathx"
بهرنی دنده fast_hypot(س: اعشاري، ص: اعشاري): اعشاري
کرښه چاپ(fast_hypot(۳، ۴))                      # ۵٫۰
```

بهرنۍ دنده لکه هره بله دنده کتل کېږي او بلل کېږي، خو بدن یې د ماشین کوډ دی. یوازې
`عدد`، `اعشاري`، `منطقي`، `متن` او د بیا-بلنې دندې (`دنده(...)`) له پولې اوړي، او ++C
کولای شي د تندر دندې بیا وبلي. بشپړ بیان: [د بهرني اړیکي لارښود](../native.md)،
او یوه چلېدونکې بېلګه په `lib/native/` کې.

## ۷. دندې

```thunder
دنده لوی_وېشونکی(الف: عدد، ب: عدد): عدد
    ترڅو ب != ۰
        متغیر لنډ = ب
        ب = الف % ب
        الف = لنډ
    راګرځه الف

دنده سلام(نوم: متن)      # بې د راګرځېدو ډوله: هېڅ نه راګرځوي
    کرښه چاپ("سلام، "، نوم)
```

* دندې د فایل په سر کچه کې، یا د یوه ټولګي د غړو په توګه (۹ برخه) اعلانېږي، او د اعلان له کرښې
  مخکې هم بلل کېدای شي.
* پارامټرونه لکه ځایي متغیرونه دي. `عدد`، `منطقي` او `متن` کاپي کېږي؛ لړۍ او جوړښتونه شریکېږي.
* د راګرځېدو ډول لرونکې دندې هره لار باید په «راګرځه ارزښت» پای شي.
* تکراري بلنې منل کېږي؛ VM د بلنو ژوروالی محدودوي (اصلي حد ۱۰۰۰۰).
* **اصلي (main):** که پروګرام `دنده اصلي()` (یا `main()`) ولري، د سر کچې له امرونو وروسته بلل کېږي.

### دندې د ارزښت په توګه

د دندې نوم بې قوسونو یو **ارزښت** دی چې ساتل کېدای، لېږل کېدای او بلل کېدای شي:

```thunder
دنده دوه_چنده(ن: عدد): عدد
    راګرځه ن * ۲

متغیر ف: دنده(عدد): عدد = دوه_چنده
کرښه چاپ(ف(۲۱))                          # ۴۲
کرښه چاپ(پر هر یو([۱، ۲، ۳]، دوه_چنده))   # [۲، ۴، ۶]
```

هره هغه افاده چې ارزښت یې دنده وي بلل کېدای شي: `چلوونکي[ش](س)`. نور، او د `پر هر یو`،
`چاڼ کړه` او `راټول کړه` جزییات، په [د کتابتون لارښود](library.md) ۷ برخه کې.

### په خپل ځای لیکل شوې دندې (closures)

د دندې ارزښت **هلته هم لیکل کېدای شي چې ورته اړتیا وي**، له `دنده` سره او بې نومه. تنه یې
یا په همغه کرښه یو امر دی — کله چې د راګرځېدو ډول ولري، یوه افاده، چې ارزښت یې دنده
راګرځوي — یا، له قوسونو بهر، یو ننوتی بلاک:

```thunder
# ژبه: ps
متغیر غږ_کړه = دنده(کرښه: متن) کرښه چاپ(کرښه + "!")
غږ_کړه("ځه")                                      # ځه!

کرښه چاپ(پر هر یو([۱، ۲، ۳]، دنده(ن: عدد): عدد ن * ن))   # [۱، ۴، ۹] - یوه افاده، راګرځول کېږي

متغیر ګام = دنده(ن: عدد): عدد                     # ننوتې تنه (له قوسونو بهر)
    که ن % ۲ == ۰
        راګرځه ن / ۲
    راګرځه ۳ * ن + ۱
کرښه چاپ(ګام(۷))                                  # ۲۲
```

داسې دنده کولای شي **شاوخوا متغیرونه** وکاروي — *closure* ده. نیول شوی متغیر یوه ګډ
صندوق ته ځي: closure او هغه دنده چې جوړه کړې یې ده دواړه همغه متغیر لولي او لیکي، له
هغې وروسته هم چې دا دنده راوګرځي:

```thunder
# ژبه: ps
دنده شمېرونکی_جوړ_کړه(): دنده(): عدد
    متغیر شمېر = ۰
    متغیر زیات_کړه = دنده(): عدد
        شمېر += ۱
        راګرځه شمېر
    راګرځه زیات_کړه

متغیر الف = شمېرونکی_جوړ_کړه()
متغیر ب = شمېرونکی_جوړ_کړه()
کرښه چاپ(الف()، " "، الف()، " "، ب())    # ۱ ۲ ۱ - هر شمېرونکي خپل شمېر نیولی
```

د پارامټرونو ډولونه تل لیکل کېږي؛ د راګرځېدو ډول هغه وخت چې وي، لکه په اعلان کې. عمومي
(global) متغیرونه نه نیول کېږي (تنه یې ساده کاروي)، او نیول شوی `ثابت` ثابت پاتې کېږي. د
تکرار متغیر **یو متغیر دی**: هر هغه closure چې په تکرار کې جوړ شي شریکوي یې او وروستی
ارزښت یې ویني، لکه په پایتن کې — د هر دور د ارزښت لپاره یې په تنه کې کاپي کړئ
(`متغیر زما = ش`). په `--trace` یا ډیبګر کې closure د `دنده@کرښه` په نوم ښکاري.
Closureونه د پېښو د چلوونکو (event handlers) او بیا-بلنو حالت وړي — په ۸ برخه کې
`په_کښېکښلو` وګورئ.

هغه دندې چې سره تړاو لري په یوه **ټولګي** (ماډیول) کې یو ځای کېدای شي او د هغه له نوم سره
بلل کېږي، `هندسه.مساحت(م)`؛ د ژبې خپلې دندې هم همداسې منظمې شوې دي (`ریاضي.جذر(س)`،
`متن.پاک کړه(م)`). ټولګي ۹ برخه ده، دننۍ ټولګي ۱۰ برخه.

## ۸. جوړښتونه، ټاپلونه او نقشې

```thunder
جوړښت ټکی
    س: عدد
    ص: عدد

متغیر مبدا = ټکی(۰، ۰)            # برخې په ترتیب
متغیر هدف = ټکی(ص: ۳، س: ۷)       # یا په نوم؛ پاتې برخې اصلي ارزښت اخلي
هدف.س = ۸                          # برخې بدلېدای شي
```

جوړښتونه د سر کچه کې یا په یوه ټولګي کې (۹ برخه: `هندسه.ټکی`) اعلانېږي. جوړښتونه ماخذونه
دي (لکه لړۍ)؛ `کاپي()` خپلواکه (ژوره) کاپي جوړوي. `کتنه()` او `وښایه()` جوړښت برخه په برخه، له
ډولونو سره ښيي.

**تکراري جوړښتونه او `هېڅ`.** جوړښت کولای شي ځان ولري - د ځنځیر یا د ونې د غوټۍ بڼه.
`هېڅ` د جوړښت تش ماخذ دی: ځنځیر پای ته رسوي، د تکراري برخې اصلي ارزښت دی، او د `==` /
`!=` سره پرتله کېږي. د `هېڅ` د برخې لوستل یا لیکل پروګرام د اجرا له تېروتنې `R033` سره
دروي. `هېڅ` خپل ډول نه لري: د شاوخوا ځای د جوړښت ډول اخلي (اعلان، برخه، پارامټر، یا د
پرتلې بل لوری).

```thunder
جوړښت غوټۍ
    ارزښت: عدد
    بله: غوټۍ                                # جوړښت کولای شي ځان ولري

متغیر پای = غوټۍ(ارزښت: ۲، بله: هېڅ)         # هېڅ ځنځیر پای ته رسوي
متغیر سر = غوټۍ(ارزښت: ۱، بله: پای)
ترڅو سر != هېڅ
    کرښه چاپ(سر.ارزښت)
    سر = سر.بله
```

### دندې او جوړوونکې دنده

جوړښت له ډېټا سره **چلند** هم وړلای شي. د جوړښت په تنه کې، له برخو وروسته، **جوړوونکې
دنده** راځي — هغه غړی چې د جوړښت په نوم لیکل کېږي — او **دندې** یې:

```thunder
# ژبه: ps
جوړښت تڼۍ
    سرلیک_: متن                     # شخصي برخه (لاندې وګورئ)
    په_کښېکښلو(): دنده()            # غړی چې د دندې ارزښت ساتي (closure)

    تڼۍ(سرلیک: متن)                 # جوړوونکې دنده: تڼۍ("سمه ده") یې چلوي
        سرلیک_ = سرلیک

    دنده سرلیک_راکړه(): متن         # دنده: ت.سرلیک_راکړه()
        راګرځه سرلیک_

    دنده وکاږه()
        کرښه چاپ("["، سرلیک_، "]")

متغیر ت = تڼۍ("سمه ده")             # جوړ کړه...
ت.وکاږه()                            # ...او دندې یې په '.' وبله
ت.په_کښېکښلو = دنده() کرښه چاپ("!")  # غړي ته د دندې ارزښت ورکړه
ت.په_کښېکښلو()                       # او همداسې یې وبله
```

**د لیکلو `self` نشته**: د دندې دننه د غړي لغړ نوم د هغه ارزښت غړی دی چې دنده پرې بلل
شوې — پورته `سرلیک_` د اخیستونکي برخه لولي، او یوه دنده بله همداسې بولي (د دندې دننه
`وکاږه()` یعنې «دا ارزښت وکاږه»). د همغه نوم پارامټر یا ځایي متغیر غړی پټوي، او **دننۍ
دندې خپله مانا ساتي**، لکه هر ځای: د هغه جوړښت د دندې دننه چې خپله `ورزیات کړه` لري،
`ورزیات کړه(توکي_، ا)` لا هم دننۍ ده (د جوړښت خپله پر یوه ارزښت بلل کېږي:
`بل.ورزیات کړه(ا)`).

له جوړوونکې دندې سره `تڼۍ("سمه ده")` جوړښت لومړی د هرې برخې له **اصلي ارزښت** سره جوړوي
او بیا یې د جوړوونکې دندې تنه پرې چلوي؛ د برخو-لړ بڼې (`ټکی(۱، ۲)`، `ټکی(ص: ۲، س: ۱)`)
هغو جوړښتونو ته دي چې جوړوونکې دنده **نه لري**. جوړوونکې دنده نه د راګرځېدو ډول اخلي او
نه د ډول پارامټرونه (`S079`)، او د هر غړي نوم یو ځل کارول کېږي (`S080`).

هغه غړی چې `په_کښېکښلو(): دنده()` لیکل شوی وي یوه عادي **د دندې-ډول برخه** ده — قوسونه
یې د بللو وړ ښيي. د دندې ارزښت (معمولاً closure) ورکول کېږي او لکه دنده بلل کېږي؛ لاندې
برسېر هم پوره کولای شي.

### شخصي غړي: '_' د نوم په پای

هغه غړی چې نوم یې **په `_` پای ته رسېږي** شخصي دی: یوازې د جوړښت خپلې دندې یې لوستلای،
لیکلای یا بللای شي (`S076`). `سرلیک_` او مرستندویې دندې لکه `تګ_(غوټۍ)` د جوړښت دننۍ چارې
د هغه خپلې ساتي؛ نور هر څه عام دي. (د ټولګي په کچه، لکه مخکې، د نوم په پیل `_` د ټولګي
شخصي غړي ښيي — دوه دودونه یو له بله نه ګډېږي.)

### برسېرونه (interfaces)

**برسېر** هغه څه نوموي چې یو ارزښت یې کولای شي، نه دا چې څه شی دی:

```thunder
# ژبه: ps
برسېر وسیله
    دنده وکاږه()
    دنده پلنوالی(): عدد

برسېر کښېکښل_وړ
    په_کښېکښلو(): دنده()            # بلل کېدونکی غړی، چې د همدې ډول برخه یې پوره کوي
```

جوړښت هغه برسېرونه چې عملي کوي یې له `:` وروسته لیکي؛ کمپایلر ګوري چې هر ژمنه شوی غړی
له سمې بڼې سره شته (`S074`، `S075`):

```thunder
جوړښت تڼۍ: وسیله، کښېکښل_وړ
    ...                             # باید وکاږه()، پلنوالی() او په_کښېکښلو ولري

جوړښت لیکنه: وسیله
    متن_یې: متن
    دنده وکاږه()
        کرښه چاپ(متن_یې)
    دنده پلنوالی(): عدد
        راګرځه اوږدوالی(متن_یې)
```

د برسېر-ډول متغیر (یا برخه، پارامټر، د لړۍ توکی...) **هر هغه جوړښت** مني چې عملي کوي یې،
او له هغه لارې د غړي بلل د پروګرام په چلېدو کې د جوړښت خپله دنده مومي — *متحرک ورټوپ
(dynamic dispatch)*:

```thunder
# ژبه: ps
متغیر پرده: وسیله[] = [تڼۍ("سمه ده")، لیکنه("سلام")]
تکرار توکی په پرده
    توکی.وکاږه()                    # هر ارزښت په خپله وکاږه ځوابوي
```

د برسېر ارزښت لکه جوړښت ماخذ دی: کېدای شي `هېڅ` وي (پرتله یې په `==` کار کوي؛ د `هېڅ`
د غړي بلل د اجرا تېروتنه `R036` ده)، او جوړښت ورکول نه څه کاپي کوي نه اړوي. برسېرونه
**نومي (nominal)** دي: جوړښت یوازې هغه عملي کوي چې له `:` وروسته یې اعلانوي، نو د ورک
غړي تېروتنه جوړښت ته ګوته نیسي، نه لرې یوې بلنې ته. د برسېر ارزښت خپلې برخې نه لري —
غړي یې په بللو کارول کېږي (`S078`)؛ د جوړښت برخو ته د رسېدو لپاره د جوړښت-ډول متغیر
وساتئ.

### ګډونونه (mixins): جوړښتونه په جوړښتونو کې

هغه **جوړښت** چې له `:` وروسته لیکل شوی وي *ګډون* دی: برخې او دندې یې هغه جوړښت ته
کاپي کېږي چې لیکي یې، لکه هلته چې لیکل شوې وي. دا په کاپي کولو ترکیب دی — نه د پلرني
ټولي (base class) جوړ شته، نه `super`، او **یوه کچه ژور ځي**: ګډون کولای شي برسېرونه
عملي کړي خو خپل ګډون نشي لرلای (`S072`)، او عمومي (generic) جوړښت ګډون نشي کېدای
(`S073`).

```thunder
# ژبه: ps
جوړښت نومیالی                        # ګډون: یوه وړتیا چې شریکول یې ارزي
    نوم: متن
    دنده وپېژنه(): متن
        راګرځه "زه " + نوم + " یم"

جوړښت روبوټ: نومیالی                 # روبوټ اوس نوم او وپېژنه() لري
    ځواک: عدد
    روبوټ(ورکړل_شوی_ځواک: عدد)
        نوم = "روبوټ"               # د ګډون برخه، لکه خپله
        ځواک = ورکړل_شوی_ځواک

کرښه چاپ(روبوټ(۹).وپېژنه())          # زه روبوټ یم
```

د جوړښت خپله دنده د ګډون پر همنومې دنده **بریالۍ ده** (overriding)، تکراري برخه راپور
کېږي (`S029`)، او هغه برسېرونه چې ګډون یې عملي کوي ورسره راځي.

**عمومي (generic) جوړښتونه او دندې.** جوړښت یا دنده کولای شي د نوم وروسته په `<زاویه قوسونو>`
کې د ډول پارامټرونه واخلي. دا یوه کالبه (template) ده: هره کارونه له مشخصو ډولونو سره یوه
بېلګه جوړوي، او ډولونه **پخپله معلومېږي** - له ارزښتونو، یا له هغه ډوله چې پایله یې
ورکول کېږي - هېڅکله په بلنه کې نه لیکل کېږي:

```thunder
جوړښت ډېرۍ<ت>
    توکي: ت[]

دنده ډېرۍ_ته_ورزیات_کړه<ت>(ډېرۍ_: ډېرۍ<ت>، ارزښت: ت)
    ورزیات کړه(ډېرۍ_.توکي، ارزښت)

متغیر کلمې = ډېرۍ(توکي: [«الف»])       # ډېرۍ<متن>، له ارزښته معلومه شوه
متغیر عددونه: ډېرۍ<عدد> = ډېرۍ(توکي: [])  # له اعلانه معلومه شوه
```

لیکل شوي د بېلګې ډولونه (`ډېرۍ<عدد>`، `ډېرۍ<ډېرۍ<متن>>`) هر هغه ځای راتلای شي چې ډول
راځي. کله چې د ډول پارامټر نه معلومېږي، کمپایلر یې وايي (`S058`)؛ اعلان ته ډول ورکړئ. د
SDK ډېټا جوړښتونه او الګوریتمونه ([datastructures](datastructures.md)،
[algorithms](algorithms.md)) همداسې لیکل شوي دي.

### ټاپلونه

```thunder
متغیر جوړه = (۱، "یو")             # ډول: (عدد، متن)
کرښه چاپ(جوړه.0، جوړه.1)
متغیر (شمېره، کلمه) = جوړه         # خلاصول
```

ټاپلونه نه بدلېږي، توکی په توکی پرتله کېږي او لږ تر لږه دوه توکي غواړي (`P015`).

### نقشې

```thunder
متغیر عمرونه = {"ناصر": ۴۰، "ساره": ۷}    # ډول: {متن: عدد}
عمرونه["علي"] = ۱۲
کرښه چاپ(عمرونه["ناصر"])            # نشته کیلۍ د اجرا تېروتنه R011 ده
کرښه چاپ(لري(عمرونه، "عمر"))        # درواغ
```

کیلۍ `عدد`، `منطقي`، `متن`، `بایټ` یا د ګڼنې غړی کېدای شي. نقشې د **ورزیاتېدو ترتیب** ساتي؛ `کیلۍ(م)` او
`ارزښتونه(م)` په همغه ترتیب لړۍ راګرځوي. تشه نقشه د ډول ښودنې ته اړتیا لري (`S038`).

### ګڼنې

**ګڼنه** هغه ډول دی چې د نومول شویو ارزښتونو ټاکلې ټولګه لري - خپل *غړي*. لکه جوړښت اعلانېږي،
په هره کرښه کې یو غړی (یا څو په یوه کرښه کې، په کامو بېل)، او یوازې د فایل په پورتنۍ کچه یا په
یوه ټولګي کې (چېرې چې غړي یې `شکلونه.شکل.دایره` لیکل کېږي):

```thunder
ګڼنه لوری
    شمال
    ختیځ
    سهیل
    لوېدیځ

متغیر مخه = لوری.شمال                 # غړی ډول.غړی لیکل کېږي
کرښه چاپ(مخه)                          # شمال - غړي په نوم چاپېږي
کرښه چاپ(عدد کړه(لوری.سهیل))          # ۲ - هر غړی یو ځای لري: ۰، ۱، ۲، ...
کرښه چاپ(لوری(۱)، لوری("لوېدیځ"))      # ختیځ لوېدیځ - په یوه ځای / د یوه نوم غړی
کرښه چاپ(لوری.شمېر، لوری.ارزښتونه)      # ۴ [لوری.شمال، لوری.ختیځ، لوری.سهیل، لوری.لوېدیځ]
تکرار ل په لوری.ارزښتونه
    چاپ(ل، " ")
```

* **غړي د ځای له مخې پرتله کېږي**: `==`، `!=`، `<`، `<=`، `>` او `>=` د یوې ګڼنې د غړو ترمنځ کار
  کوي، `ترتیب کړه` د غړو لړۍ د ځای له مخې ترتیبوي، او غړی د نقشې کیلۍ کېدای شي.
* **`عدد کړه(غ)`** د غړي ځای ورکوي او **`متن کړه(غ)`** یې نوم؛ `لوری(ن)` او `لوری("نوم")` د
  پروګرام په چلېدو کې بېرته ځي (د چلولو تېروتنې `R034` د ناسم ځای او `R035` د ناپېژندلي نوم لپاره).
  په لړیو، نقشو او ډیبګر کې غړی `لوری.شمال` ښودل کېږي، نو له متن سره نه ګډوډېږي.
* **`لوری.ارزښتونه`** د ټولو غړو نوې لړۍ په ترتیب ده، او **`لوری.شمېر`** د هغوی شمېر (انګلیسي
  `values` او `count` هم منل کېږي). د ګڼنې د ډول متغیر چې پیل ارزښت نه لري لومړی غړی لري.
* ګڼنې **ارزښتونه دي، نه حوالې**: کاپي یا شریکولو ته څه نشته. غړی برخې نه لري؛ پر غړو حساب د ډول
  تېروتنه ده. ځای وکاروئ: `لوری((عدد کړه(ل) + ۱) % لوری.شمېر)` راتلونکی غړی دی، چې په پای کې
  بېرته پیل ته راګرځي.
* اوزار دوه خپلې ګڼنې لري، چې د خپلو دننیو ټولګو غړي دي (۱۰ برخه): **`ګرافیک.رنګونه`**
  (`راوړه ګرافیک`: `ګرافیک.رنګونه.سور`، او همداسې `زرغون`، `شین`، `سپین`، `تور`، `ژېړ`، `نارنجي`،
  `ګلابي`، `خړ`، `نسواري`، `بنفش`، `اسماني`، `طلايي`) - هره د کښلو دنده هغه ځای `ګرافیک.رنګونه`
  مني چې د رنګ متن مني - او **`سیسټم.پلیټفارم`** (`راوړه سیسټم`: `سیسټم.پلیټفارم.لینکس`،
  `وینډوز`، `مېک`، `ناپېژندلی`)، چې `سیسټم.عامل سیسټم()` یې راګرځوي.
* تېروتنې د کمپایل پر مهال نیول کېږي: هغه غړی چې نشته (`S062`)، له عدد یا متن پرته له بل څه څخه
  غړی جوړول (`S063`)، تکراري غړی (`S061`)، تشه ګڼنه (`S060`)، په دنده کې اعلان شوې ګڼنه (`S059`)
  او هغه نوم چې جوړښت یا دنده یې لري (`S028`).

## ۹. ټولګي (ماډیولونه)

**ټولګی** (ماډیول) د هغو اعلانونو یوه نوم لرونکې ډله ده چې سره تړاو لري: دندې، جوړښتونه،
ګڼنې، متغیرونه، ثابتونه او بهرنۍ دندې. د فایل په سر کچه کې اعلانېږي، او غړي یې هغه ننوتی بلاک
دی چې د `ټولګی` کلیدي کلمې او د ټولګي له نوم وروسته راځي:

```thunder
# ژبه: ps
ټولګی هندسه
    جوړښت ټکی
        س: عدد
        ص: عدد

    ثابت د_مبدا_س = ۰
    متغیر جوړ_شوي = ۰                         # هغه متغیر چې د ټولګي دی

    دنده ټکی_جوړ_کړه(س: عدد، ص: عدد): ټکی       # د ټولګي دننه لنډ نومونه کار کوي
        جوړ_شوي += ۱
        راګرځه ټکی(س، ص)

    دنده واټن(الف: ټکی، ب: ټکی): اعشاري
        راګرځه ریاضي.جذر(اعشاري کړه(_مربع(الف.س - ب.س) + _مربع(الف.ص - ب.ص)))

    دنده _مربع(ش: عدد): عدد                  # پټ: یوازې هندسه یې کارولای شي
        راګرځه ش * ش

متغیر ټ: هندسه.ټکی = هندسه.ټکی_جوړ_کړه(۳، ۴)   # بهر، د ټولګي نوم مخکې راځي
متغیر مبدا = هندسه.ټکی_جوړ_کړه(هندسه.د_مبدا_س، ۰)
کرښه چاپ(هندسه.واټن(ټ، مبدا))                # ۵٫۰
کرښه چاپ(هندسه.جوړ_شوي، " "، ټ)             # ۲ هندسه.ټکی(س: ۳، ص: ۴)
هندسه.جوړ_شوي = ۰                            # د ټولګي متغیر له بهره هم بدلېدای شي
```

* **له ټولګي بهر** هر غړی د ټولګي له نوم او ټکي سره لیکل کېږي - *بشپړ نوم*:
  `هندسه.ټکی_جوړ_کړه(۱، ۲)` د دندې لپاره، `هندسه.جوړ_شوي` د متغیر لپاره (د `=` کیڼ اړخ ته هم)،
  `هندسه.د_مبدا_س` د ثابت لپاره، `هندسه.ټکی` د جوړښت لپاره، په بلنو او ډولونو کې یو شان
  (`متغیر ټ: هندسه.ټکی`، `هندسه.ټکی[]`، `دنده(عدد، عدد): هندسه.ټکی`)، او `هندسه.شکل.دایره` د
  هغې ګڼنې د غړي لپاره چې ټولګی یې اعلانوي.
* **د ټولګي دننه** لنډ نومونه هم کار کوي (`ټکی(س، ص)`، `جوړ_شوي += ۱`)، مګر دا چې د همغه نوم
  ځایي متغیر یا پارامټر غړی پټ کړي. بشپړ نوم تل کار کوي، دننه هم او بهر هم.
* **پټ غړي.** هغه غړی چې نوم یې په `_` پیلېږي د خپل ټولګي پټ غړی دی: یوازې د همغه ټولګي غړي
  یې کارولای شي، او `هندسه._مربع(۲)` بل هر ځای `S066` دی.
* **ټولګی یوازې اعلانوي.** د ټولګي دننه امر `S047` دی - هر ځل به چلېده چې فایل راوړل شي.
  ټولګي یو په بل کې نه ننوځي: په بل ټولګي یا دنده کې ټولګی نحوي تېروتنه `P017` ده. د ټولګي
  متغیرونه له بشپړ نوم سره عمومي متغیرونه دي: د پروګرام له چلېدو مخکې خپل اصلي ارزښت لري، او
  پیل ارزښت هغه مهال اخلي چې پروګرام د ټولګي اعلان ته ورسېږي؛ نو د سر کچې کوډ یې له اعلان
  وروسته کاروي (دندې یې، لکه هر عمومي متغیر، هر وخت).
* **د ټولګو نومونه خوندي دي.** هېڅ متغیر، پارامټر، دنده، جوړښت یا ګڼنه د هغه ټولګي نوم نشي
  اخیستلای چې ښکاري (`متغیر هندسه = ۱` د `S065` دی). دننۍ ټولګي هم پکې دي (`متغیر ریاضي = ۰`)،
  او `سیسټم`، `فایل` او `ګرافیک` کله چې راوړل شي. هر ټولګی یو ځل، په یوه ځای کې اعلانېږي
  (`S064`): دوه فایلونه دواړه `هندسه` ته څه نشي ورزیاتولای، او د دنني ټولګي نوم (`ریاضي`، `متن`،
  ...) د خپل ټولګي لپاره نشي کارېدای.
* **غړي له نورو نومونو سره ټکر نه کوي.** غړی تل خپل ټولګی مخکې لري، نو `هندسه.مساحت`،
  `شکلونه.مساحت` او د سر کچې `مساحت` درې بېلې دندې دي، او یو ټولګی کولای شي د `اوږدوالی` یا
  `ورزیات کړه` په نوم غړی ولري (`ډېرۍ.ورزیات کړه`) پرته له دې چې دننۍ دنده ګډوډه کړي.
* **دننۍ دنده د ټولګي دننه خپله مانا ساتي.** په `ټولګی ډېرۍ` کې ساده `ورزیات کړه(...)` لا هم د
  لړیو دننۍ `ورزیات کړه` ده؛ د ټولګي خپله `ورزیات کړه` هلته `ډېرۍ.ورزیات کړه(...)` لیکل کېږي:

```thunder
# ژبه: ps
ټولګی ډېرۍ
    جوړښت ډېرۍ
        عددونه: عدد[]

    دنده ورزیات کړه(ډ: ډېرۍ، ارزښت: عدد)
        ورزیات کړه(ډ.عددونه، ارزښت)             # د لړیو دننۍ «ورزیات کړه»

    دنده دوه_ځله_ورزیات_کړه(ډ: ډېرۍ، ارزښت: عدد)
        ډېرۍ.ورزیات کړه(ډ، ارزښت)               # د همدې ټولګي خپله «ورزیات کړه»
        ډېرۍ.ورزیات کړه(ډ، ارزښت)

متغیر زما_ډېرۍ = ډېرۍ.ډېرۍ([])
ډېرۍ.دوه_ځله_ورزیات_کړه(زما_ډېرۍ، ۷)
کرښه چاپ(زما_ډېرۍ)                           # ډېرۍ.ډېرۍ(عددونه: [۷، ۷])
```

* **`د دندې نوم(د)`** هغه نوم ورکوي چې د دندې ارزښت پرې اعلان شوی، له ټولګي سره:
  `د دندې نوم(هندسه.ټکی_جوړ_کړه)` «هندسه.ټکی_جوړ_کړه» دی.

**ټولګي او فایلونه.** *فایل* هغه څه دی چې لوستل کېږي؛ *ټولګی* د هغه دننه یو نوم‌ځای (namespace)
دی. `راوړه "lib/geometry"` فایل `lib/geometry.th` لولي (لومړی د راوړونکي فایل تر څنګ، بیا په هغو
پوښیو کې چې په `-I` ورکړل شوې، بیا د SDK په `lib/thunder` کې) او هر څه چې اعلانوي یې دلته د
کارونې وړ کوي - ټولګي یې، او هغه اعلانونه چې له ټولګي بهر یې کوي. راوړل شوی فایل **کتابتون
فایل** دی: یوازې اعلانوي، نو راوړل یې هېڅ نه چاپوي، او هر فایل یوازې یو ځل لوستل کېږي، که څو
ځله هم راوړل شي. کتابتون فایل معمولاً یو ټولګی لري (د بېلګو `lib/geometry.th` `ټولګی هندسه`
اعلانوي)، خو ښايي څو ولري - `راوړه "sockets"` څلور ټولګي راوړي: `ټي_سي_پي`، `یو_ډي_پي`، `ساکټ`
او `کوربه` - او یو پروګرام کولای شي د خپلو امرونو تر څنګ خپل ټولګي هم اعلان کړي. د فایلونو د
موندلو، لوستلو او ژباړلو جزییات په [د کتابتون لارښود](library.md) («ماډیولونه») کې دي.

```thunder
# ژبه: ps
راوړه "lib/geometry"      # یو فایل: lib/geometry.th، چې ټولګی هندسه اعلانوي

متغیر کوټه = هندسه.مستطیل(۴، ۳)
کرښه چاپ(هندسه.مساحت(کوټه))
```

**د ازموینو ډلې.** په ازموینیز پروګرام کې هر ټولګی د ازموینو یوه **ډله** (suite) ده:
`ازموینه.وچلوه("جمع سمه ده"، حساب.جمع_سمه_ده)` ازموینه د `حساب` ډلې لاندې ثبتوي، د ډلې نوم د
هغې د ازموینو پورته چاپوي، د هرې ډلې شمېرې بېلې ساتي، او ډله په خپل نوم یوازې هم چلېدای شي.
[د ازموینې لارښود](testing.md) یې بیانوي.

**د پردې شاته.** شنونکی (analyser) د هر څه له کتلو مخکې هر غړی په خپل بشپړ نوم بدلوي (د
`هندسه` دننه `ټکی_جوړ_کړه` په `هندسه.ټکی_جوړ_کړه` اوړي)، نو د نښانونو پاڼه، بایټ کوډ، ډیبګر،
د بلنو لړ او د تېروتنو پیغامونه ټول بشپړ نومونه ښيي. ټولګي د اجرا پر مهال هېڅ لګښت نه لري: د
`هندسه.ټکی_جوړ_کړه` بلنه یوه عادي بلنه ده.

## ۱۰. دننۍ دندې او ټولګي

د ژبې خپلې دندې هم په ټولګو کې منظمې شوې دي. **اصلي ټولګی** - چاپ، اړونې، لړۍ، نقشې، ټاپلونه
او لوړې کچې دندې - مختاړي ته اړتیا نلري: `کرښه چاپ`، `اوږدوالی`، `ورزیات کړه`، `پر هر یو`. هره
بله دننۍ دنده له خپل ټولګي سره لیکل کېږي، لکه د خپل ټولګي غړی: `ریاضي.جذر(۲٫۰)`،
`متن.پاک کړه(م)`، `تصادفي.عدد(۱، ۶)`.

اصلي ټولګی: `چاپ`، `کرښه چاپ`، `اوږدوالی`، `متن کړه`، `عدد کړه`، `اعشاري کړه`، `لړۍ`، `کتنه`،
`وښایه`، `کاپي`، `لري`، `لیرې کړه`، `کیلۍ`، `ارزښتونه`، `د دندې نوم` — او ننوت (`ولوله`،
`د ننوت پای`)، جوړې (`لومړی`، `دوهم`، `ځای بدلول`، `جوړې کړه`، `شمېره ورکړه`، `توکي`)، لړۍ
(`ورزیات کړه`، `وروستی واخله`، `ننباسه`، `له ځایه لیرې کړه`، `ټوټه`، `سره نښلوه`، `ترتیب کړه`،
`واټن`، `مجموعه`، `شامل دی`، `ځای یې`، `سرچپه کړه` ...)، لوړې کچې دندې (`پر هر یو`، `چاڼ کړه`،
`راټول کړه`) او د شمېرو اړونې `شپاړسیز کړه`، `دوه ییز کړه` او `بایټ کړه`.

**دننۍ ټولګي:**

| ټولګی | انګلیسي | اړتیا | څه پکې دي |
| --- | --- | --- | --- |
| `ریاضي` | `math` | - | شمېرې او ریاضي: `ریاضي.مطلق`، `ریاضي.کمینه`، `ریاضي.اعظمه`، `ریاضي.نیژدې کړه`، `ریاضي.کښته کړه`، `ریاضي.پورته کړه`، `ریاضي.جذر`، `ریاضي.توان`، `ریاضي.نمايي`، `ریاضي.لوګارتم`، `ریاضي.جیب`، `ریاضي.تتمیم جیب`، `ریاضي.ظل`، `ریاضي.پای()`؛ زاویې په رادیان دي. |
| `متن` | `string` | - | متن: `متن.برخه`، `متن.پاک کړه`، `متن.لوی توري کړه`، `متن.وېشه`، `متن.یو ځای کړه`، `متن.بدل کړه`، `متن.بڼه کړه`، ... (ټولګی د ډول په نوم دی). |
| `تصادفي` | `random` | - | تصادفي شمېرې: `تصادفي.عدد(الف، ب)`، `تصادفي.اعشاري()` (له ۰ تر ۱، ۱ پکې نه دی)، `تصادفي.بنسټ(ن)`. |
| `بایټونه` | `bytes` | - | خامه ډېټا: `بایټونه.له متنه`، `بایټونه.متن کړه`، `بایټونه.عدد کړه`، `بایټونه.له عدده`. |
| `سیسټم` | `os` | `راوړه سیسټم` | عامل سیسټم: د پروګرام دلیلونه، چاپېریال، امرونه، پوښۍ، وخت، `سیسټم.عامل سیسټم()` او ګڼنه `سیسټم.پلیټفارم`، `سیسټم.پای ته ورسوه(کوډ)`. |
| `فایل` | `file` | `راوړه فایل` | فایلونه: `فایل.ولوله`، `فایل.ولیکه`، `فایل.ورزیات کړه`، `فایل.شته`، `فایل.ړنګ کړه`، او `فایل.بایټونه ولوله`، `فایل.بایټونه ولیکه`، `فایل.بایټونه ورزیات کړه`. |
| `ګرافیک` | `graphics` | `راوړه ګرافیک` | کښل، حرکت، تڼۍ او موږک، او ګڼنه `ګرافیک.رنګونه` ([د ګرافیک لارښود](graphics.md)). |

هر غړی، له پارامټرونو او انګلیسي نوم سره، په [د کتابتون لارښود](library.md) کې دی؛ HTML
[API لارښود](../api/index.html) یې ټولګی په ټولګی لړ کوي.

```thunder
# ژبه: ps
راوړه فایل

متغیر کلمې = متن.وېشه(متن.پاک کړه("  یو دوه درې  ")، " ")
کرښه چاپ(اوږدوالی(کلمې)، " کلمې؛ لومړۍ: "، کلمې[۰])
کرښه چاپ(ریاضي.جذر(۲٫۰)، " "، ریاضي.اعظمه(۳، ۷)، " "، ریاضي.نیژدې کړه(۲٫۵))
متغیر ټاس = تصادفي.عدد(۱، ۶)                 # ۱، ۲، ۳، ۴، ۵ یا ۶
که فایل.شته("notes.txt")
    کرښه چاپ(فایل.ولوله("notes.txt"))
```

* `ریاضي`، `متن`، `تصادفي` او `بایټونه` تل شته. `سیسټم`، `فایل` او `ګرافیک` له پروګرام بهر رسېږي،
  نو پروګرام باید ووايي چې کاروي یې: `راوړه سیسټم` - د ټولګي نوم، پرته له قوسونو. بې راوړلو غړی
  `S049` دی، او پیغام یې هغه راوړه ښيي چې باید ورزیاته شي؛ تر هغه چې پروګرام یې نه وي راوړي،
  نومونه یې د پروګرام د خپلې کارونې لپاره ازاد دي.
* هغه دننۍ دنده چې بې ټولګي ولیکل شي له سمون سره راپور کېږي: `جذر(۲٫۰)` د `S067` دی، «'جذر' د
  'ریاضي' ټولګي برخه ده: ریاضي.جذر ولیکئ». هغه غړی چې نشته (`ریاضي.مکعب`) `S070` دی.
* د اصلي ټولګي نومونه د خپلو دندو یا جوړښتونو لپاره نشي کارېدای (`S004`)؛ د نورو ټولګو نومونه
  کېدای شي، ځکه تل له ټولګي سره لیکل کېږي: د سر کچې `جذر` دنده له `ریاضي.جذر` سره ټکر نه کوي.
* د اجرا تېروتنې د دنني دندې بشپړ نوم یادوي: `ریاضي.جذر(-۱٫۰)` پروګرام له «'ریاضي.جذر' د -۱٫۰
  لپاره تعریف شوی نه دی» (`R027`) سره دروي.
* انګلیسي ټولګي نومونه (`math`، `os`، ...) په پښتو پروګرامونو کې هم منل کېږي، له پښتو غړو نومونو
  سره (`math.جذر`).

## ۱۱. سرچینې: `سره`

ځینې ارزښتونه له پروګرام بهر د یو څه استازي دي چې پروګرام یې له کار وروسته باید بېرته ورکړي:
پرانیستی فایل، د شبکې اړیکه. د یوه تړل هېرول اسانه تېروتنه ده - په ځانګړي توګه کله چې دنده
وختي راوګرځي یا تکرار ودرېږي. **`سره`** سرچینه هغه مهال تړي چې بلاک یې پای ته ورسېږي، که هر ډول
پای ته ورسېږي:

```thunder
# ژبه: ps
راوړه فایل

جوړښت یادښت
    مسیر_: متن
    کرښې_: متن[]

    یادښت(مسیر: متن)
        مسیر_ = مسیر
        کرښې_ = []

    دنده ولیکه(کرښه: متن)
        ورزیات کړه(کرښې_، کرښه)

    دنده وتړه()                                # «سره» دا د بلاک په پای کې بلي
        فایل.ولیکه(مسیر_، متن.یو ځای کړه(کرښې_، "\ن") + "\ن")

یادښتونه سره = یادښت("notes.txt")
    یادښتونه.ولیکه("لومړۍ")
    یادښتونه.ولیکه("دوهمه")
# دلته یادښتونه تړل شوي، او فایل لیکل شوی دی
کرښه چاپ(فایل.ولوله("notes.txt"))
```

| بڼه | مانا |
| --- | --- |
| `نوم سره = سرچینه` | د بلاک لپاره `نوم` اعلانوي، چې سرچینه ساتي. |
| `نوم سره: ډول = سرچینه` | همدا، له لیکل شوي ډول سره (د بېلګې په توګه کله چې ارزښت `هېڅ` وي). |
| `سرچینه سره` | هغه ارزښت چې مخکې شته - معمولاً یو متغیر چې ساتي یې - د بلاک په پای کې تړي. |

* **کله تړل کېږي.** د بلاک په پای کې، یا کله چې `راګرځه`، `ودرېږه` یا `دوام` ترې ووځي - که له هر
  څومره ژورې دننه وي. یو په بل کې `سره` بلاکونه تر ټولو دننني لومړی تړي. د `راګرځه` ارزښت د
  سرچینو له تړلو *مخکې* محاسبه کېږي، نو `راګرځه اړیکه.کرښه_واخله()` لا هم له پرانیستې
  اړیکې لولي. دا RAII دی (*Resource Acquisition Is Initialisation*): د سرچینې ژوند د بلاک ژوند دی.
* **سرچینه څه شی کېدای شي، او څه یې تړي.** دوه قاعدې:
  * **جوړښت** یو شی (object) دی: د خپلې **`وتړه()` دندې** په واسطه تړل کېږي (۸ برخه)، نو
    هر خپل جوړښت هغه شېبه سرچینه کېږي چې یوه ولري. انګلیسي نوم `close` په هره ژبه کې منل
    کېږي. هغه جوړښت چې د `وتړه()` دنده نه لري سرچینه نه ده (`S081`: «'یادښت' نه تړل کېږي:
    جوړښت ته د 'وتړه()' دنده ورکړئ»).
  * **بل هر ارزښت** - د `عدد` لاستی (نښه)، یو متن - د هغه ټولګي د `وتړه` په واسطه تړل کېږي چې
    دندې یې جوړ کړی: `ن سره = لاستی.پرانیزه()` د `لاستی.وتړه(ن)` سره تړل کېږي. نو د سرچینې
    افاده باید د یوه ټولګي د دندې بلنه وي؛ `۵ سره` یا `ریاضي.مطلق(۵) سره` د `S068` دی
    («د 'عدد' ډول ارزښت په 'سره' نه تړل کېږي: سرچینه یا داسې جوړښت دی چې د وتړه() دنده
    لري، یا د یوه ټولګي د دندې پایله، لکه لاستی.پرانیزه()»).
* **`هېڅ`.** هغه جوړښت سرچینه چې `هېڅ` وي نه تړل کېږي، نو هغه دنده چې ښايي ناکامه شي `هېڅ`
  راګرځولای شي او بلاک یې ګوري: `که اړیکه != هېڅ`.
* **ثابت.** هغه نوم چې `سره` یې اعلانوي د بلاک دننه ثابت دی: ورته ارزښت ورکول `S012` دی.
* **څه نه رانغاړي.** کله چې پروګرام د اجرا له تېروتنې یا `سیسټم.پای ته ورسوه` سره ودرېږي، بلاکونه
  پای ته نه رسېږي او هېڅ نه تړل کېږي؛ بیا عامل سیسټم پخپله د پروګرام فایلونه او ساکټونه ازادوي.
* د SDK ساکټونه سرچینې دي: `ټي_سي_پي.ونښلېږه`، `ټي_سي_پي.اورېدونکی_جوړ_کړه`،
  `ټي_سي_پي.اړیکه_ومنه` او `یو_ډي_پي.پرانیزه` یو `ساکټ.ساکټ` راګرځوي، یا `هېڅ` کله چې ناکامه شي
  ([د ساکټونو لارښود](sockets.md)).

دوهمه قاعده په تر ټولو کوچنۍ بڼه - یو ټولګی چې `پرانیزه` یې یو ساده `عدد` لاستی ورکوي او
`وتړه` یې بېرته اخلي:

```thunder
# ژبه: ps
ټولګی لاستی
    دنده پرانیزه(): عدد
        راګرځه ۷                          # هر څه چې سیسټم ورکړي

    دنده وتړه(ن: عدد)
        کرښه چاپ("وتړل شو "، ن)

ن سره = لاستی.پرانیزه()                   # لاستی.وتړه(ن) یې تړي
    کرښه چاپ("کارول کېږي "، ن)
```

**د کلیدي کلمې ځای.** انګلیسي وايي "with the socket" او `with` د کرښې په **پیل** کې لیکي. پښتو
وايي «ساکټ سره» - لومړی ساکټ، بیا «سره» - او **`سره` له هغه څه وروسته لیکي چې ورسره راځي**: له
نوم وروسته (`اړیکه سره = ...`، بیا `=` او افاده)، یا، کله چې نوم نه وي، له ارزښت وروسته، چې هلته
کرښه پای ته رسوي (`ساکټ سره`)؛ هېڅکله «سره ساکټ» د کرښې په پیل کې نه:

```thunder
# ژبه: ps
راوړه "sockets"

اړیکه سره = ټي_سي_پي.ونښلېږه("localhost"، ۷۰۰۰)
    که اړیکه != هېڅ
        اړیکه.کرښه_ولېږه("سلام")
```

```thunder
import "sockets"

with connection = tcp.connect("localhost", 7000)
    if connection != nothing
        connection.send_line("hello")
```

په پښتو کې درې بڼې `نوم سره = سرچینه`، `نوم سره: ډول = سرچینه` او `سرچینه سره` دي. د کلیدي
کلمې لیکل د بلې ژبې په ځای نحوي تېروتنه `P018` ده («په دې ژبه کې 'سره' له نوم وروسته لیکل
کېږي»؛ په انګلیسي کې «د کرښې په پیل کې»)؛ نحوي تحلیل بیا هم کرښه پوهېږي او مخکې ځي، نو نورې
نحوي تېروتنې هم راپور کېږي. ژباړن (`thunderc --translate`، د IDE «ژباړه») کلیدي کلمه په بله ژبه
کې خپل ځای ته وړي. بېلګه `39_with.th` هر حالت ښيي.

## ۱۲. ګرامر (EBNF)

ګرامر د انګلیسي سند ۱۲ برخه کې دی ([docs/language.md](../language.md#12-grammar-ebnf))؛
د کلیدي کلمو پښتو بڼې پورته جدول ورکوي. لنډیز: امرونه د کرښې په پای، بلاکونه د INDENT/DEDENT
ترمنځ، افادې د Pratt الګوریتم په لومړیتوبونو (۵ برخه)، او د `تکرار` سرلیک درې برخې په کامو بېلې دي.

د ټولګو، جوړښتونو، برسېرونو او «سره» قاعدې، د پښتو کلیدي کلمو سره:

```ebnf
module_decl    = "ټولګی" IDENTIFIER INDENT { member } DEDENT ;   (* یوازې د فایل په سر کچه *)
member         = function | native_func | struct | interface | enum | var_decl end ;
qualified_name = IDENTIFIER { "." IDENTIFIER } ;   (* هندسه.ټکی، ریاضي.جذر، ګرافیک.رنګونه.سور *)
type           = ... | qualified_name [ "<" type { "," type } ">" ] | ... ;
struct         = "جوړښت" IDENTIFIER [ "<" IDENTIFIER { "," IDENTIFIER } ">" ]
                 [ ":" qualified_name { "," qualified_name } ]     (* برسېرونه او ګډونونه *)
                 INDENT { struct_member } DEDENT ;
struct_member  = IDENTIFIER ":" type [ "," ]                       (* برخه *)
               | IDENTIFIER "(" ")" ":" function_type [ "," ]      (* بلل کېدونکې برخه (closure) *)
               | "دنده" IDENTIFIER "(" [ parameter { "," parameter } ] ")" [ ":" type ] block  (* دنده *)
               | IDENTIFIER "(" [ parameter { "," parameter } ] ")" block ;  (* جوړوونکې دنده: د جوړښت په نوم *)
interface      = "برسېر" IDENTIFIER INDENT { interface_member } DEDENT ;
interface_member = "دنده" IDENTIFIER "(" [ parameter { "," parameter } ] ")" [ ":" type ] end
               | IDENTIFIER "(" ")" ":" function_type [ "," ] ;    (* بلل کېدونکی غړی *)
lambda         = "دنده" "(" [ parameter { "," parameter } ] ")" [ ":" type ]
                 ( simple_stmt | expression (* د راګرځېدو ډول سره *) | block (* له قوسونو بهر *) ) ;
with_stmt      = IDENTIFIER "سره" [ ":" type ] "=" expression block   (* پښتو: سره له نوم وروسته *)
               | expression "سره" block            (* پښتو: بې نومه، سره کرښه پای ته رسوي *)
               | "سره" with_head block ;            (* انګلیسي ترتیب: P018، خو بیا هم پوهېږي *)
with_head      = [ IDENTIFIER [ ":" type ] "=" ] expression ;
```

په افادو کې بشپړ نوم (`هندسه.ټکی_جوړ_کړه(۱، ۲)`، `ریاضي.جذر(س)`) یو نوم دی چې `"." IDENTIFIER`
ورپسې راځي؛ معنايي تحلیل پرېکړه کوي چې ټکی ټولګي ته، د جوړښت برخې ته یا د ګڼنې غړي ته رسېږي.
په ډول کې ټکي د ډول د نوم برخه دي (`هندسه.ټکی[]`).

**نحوي تحلیل څنګه کار کوي.** امرونه په تکراري-کښته (recursive descent) تحلیل کېږي: د ګرامر
هره قاعده په `src/core/parser.cpp` کې یوه دنده ده. افادې د **Pratt** د لومړیتوب-ځواک الګوریتم
سره تحلیلېږي: هر عملګر «تړلو ځواک» لري او تحلیل تر هغه کیڼ عملوند غځوي چې راتلونکی عملګر
ټینګ تړي. له قوسونو بهر د کرښې ماتېدل دا غځېدل دروي — له همدې امله امرونه بې جلا کوونکو
پای ته رسېږي.

## ۱۳. تېروتنې

هر پړاو خپلې تېروتنې راپوروي؛ هر پیغام ثابت کوډ لري:

| پړاو | کوډونه | بېلګې |
| --- | --- | --- |
| لغوي تحلیل | `L001`–`L009` | ناڅاپي توری، نه پای شوی متن، ډېر لوی عدد، ناسمه ننوتنه |
| نحوي تحلیل | `P001`–`P020` | `تمه د ')'`، دوه امرونه په یوه کرښه (`P010`)، ورک ننوتی بلاک (`P012`)، په بلاک کې `راوړه` (`P016`)، هغه `ټولګی` چې د سر کچه کې نه وي (`P017`)، `سره` / `with` د بلې ژبې په ځای لیکل شوی (`P018`)، هغه `برسېر` چې د سر کچه کې نه وي (`P019`)، د دندې ارزښت بې تنې (`P020`) |
| معنايي تحلیل | `S001`–`S081` | نااعلان نوم، د ډول ناسمون، ورک فایل (`S045`)، د ټولګي دننه امر (`S047`)، د `سیسټم`، `فایل` یا `ګرافیک` غړی بې راوړلو (`S049`)، «تکرار ... په» پر داسې ارزښت چې ټولګه نه وي (`S052`)، دوه ځله اعلان شوی ټولګی (`S064`)، هغه نوم چې د ټولګي دی (`S065`)، له خپل ټولګي بهر پټ غړی (`S066`)، بې ټولګي دننۍ دنده (`S067`: «'جذر' د 'ریاضي' ټولګي برخه ده: ریاضي.جذر ولیکئ»)، `سره` پر داسې ارزښت چې نه جوړښت وي او نه د ټولګي د دندې پایله (`S068`) یا ټولګی یې `وتړه` ونلري (`S069`)، هغه غړی چې ټولګی یې نه لري (`S070`)، د جوړښت له `:` وروسته داسې نوم چې نه برسېر دی نه ګډون (`S071`)، ګډون چې خپل ګډون لري (`S072`) یا عمومي دی (`S073`)، د برسېر ژمنه شوی غړی چې نشته (`S074`) یا ناسمه بڼه لري (`S075`)، شخصي غړی (`نوم_`) د جوړښت له دندو بهر (`S076`)، هغه دنده یا برخه چې ډول یې نه لري (`S077`)، دنده چې د بللو پر ځای لوستل شوې (`S078`)، جوړوونکې دنده چې د راګرځېدو ډول لري (`S079`)، د غړي نوم دوه ځله (`S080`)، د جوړښت سرچینه بې `وتړه()` دندې (`S081`) |
| خبرداري | `W001`–`W003` | نه کارېدلی متغیر، نه رسېدونکی کوډ |
| د اجرا | `R001`–`R036` | په صفر وېش، له حد اوښتل، له حده بهر لړ شمېره، له حده بهر واټن (`R012`)، ډېره لویه اعشاري پایله (`R025`)، د منفي عدد `ریاضي.جذر` (`R027`)، د `هېڅ` برخه (`R033`)، پر `هېڅ` د دندې بلنه (`R036`) |

جوړول په لومړي ناکام پړاو درېږي. نحوي تحلیل له تېروتنې رغېږي، نو په یو ځل کې څو
تېروتنې راپورولای شي.

## ۱۴. پروګرامونه په پښتو

د ژبې هره کلمه پښتو بڼه لري او پښتو پروګرام پایلې هم په پښتو چاپوي. ژبه د لومړۍ کرښې
لارښوونه ټاکي: `# ژبه: ps` (یا `thunderc --lang ps`).

| انګلیسي | پښتو | انګلیسي | پښتو |
| --- | --- | --- | --- |
| `var` | `متغیر` | `int` | `عدد` |
| `in` (په «تکرار ... په» کې) | `په` | `float` | `اعشاري` |
| `native` (++C) | `بهرنی` | `name_of` | `د دندې نوم` |
| `module` | `ټولګی` | `math` / `string` | `ریاضي` / `متن` |
| `with` (له نوم وروسته لیکل کېږي، یا کله چې نوم نه وي له ارزښت وروسته) | `سره` | `random` / `bytes` | `تصادفي` / `بایټونه` |
| `os` / `file` | `سیسټم` / `فایل` | `graphics` | `ګرافیک` |
| `const` | `ثابت` | `bool` | `منطقي` |
| `func` | `دنده` | `string` | `متن` |
| `struct` | `جوړښت` | `true` / `false` | `رښتیا` / `درواغ` |
| `interface` | `برسېر` | | |
| `enum` | `ګڼنه` | `byte` | `بایټ` |
| `graphics.Color` / `os.Platform` (ګڼنې) | `ګرافیک.رنګونه` / `سیسټم.پلیټفارم` | `to_byte` | `بایټ کړه` |
| `if` / `else` | `که` / `کنه` | `print` / `println` | `چاپ` / `کرښه چاپ` |
| `while` | `ترڅو` | `len` | `اوږدوالی` |
| `for` | `تکرار` | `str` / `to_int` | `متن کړه` / `عدد کړه` |
| `break` | `ودرېږه` | `array` | `لړۍ` |
| `math.sqrt` / `math.pow` | `ریاضي.جذر` / `ریاضي.توان` | `to_float` | `اعشاري کړه` |
| `math.min` / `math.max` | `ریاضي.کمینه` / `ریاضي.اعظمه` | `math.abs` / `math.round` | `ریاضي.مطلق` / `ریاضي.نیژدې کړه` |
| `continue` | `دوام` | `inspect` / `dump` | `کتنه` / `وښایه` |
| `return` | `راګرځه` | `copy` | `کاپي` |
| `pass` | `تېر` | `has` / `remove` | `لري` / `لیرې کړه` |
| `import` | `راوړه` | `keys` / `values` | `کیلۍ` / `ارزښتونه` |
| `and` / `or` / `not` | `او` / `یا` / `نه` | `main` (دنده) | `اصلي` |

* **څو-کلمه‌يي نومونه** (`کرښه چاپ`، `متن کړه`، ...) د عادي پښتو په څېر په تشه لیکل کېږي؛
  لغوي تحلیل یې یو توکی کوي، نو `متن.پاک کړه(س)` همغه `string.trim` بلي.
* **رقمونه:** `۰۱۲۳۴۵۶۷۸۹` (ASCII او عربي `٠١٢` هم منل کېږي). اعشاري شمېرې د عربي
  اعشاریې `٫` سره لیکل کېږي (`۳٫۱۴`)؛ `.` هم منل کېږي او پایلې په `٫` چاپېږي.
* **نښې او قوسونه:** پښتو پروګرامونه په کامه `،` بېلوي (په `تکرار` کې هم) او `"..."` قوسونه
  کاروي. ASCII کامه، `٪`، `×`/`÷` او `«...»` هم منل کېږي؛ ژباړن غوره بڼې (`،`، `%`، `"`) لیکي.
* **نومونه:** د سر دنده `اصلي` (یا `main`) نومېدای شي؛ `ګرافیک.کښېکښل شوې تڼۍ()` تڼۍ په پښتو نوموي
  («کیڼ»، «ښي»، ...). یو-توریز نومونه د ریاضي د عربي-لیکدود دود تعقیبوي: `ن` د n لپاره،
  `س`/`ص` د x/y، `الف`/`ب` د a/b.
* **پایله:** پښتو پروګرام عددونه په پښتو رقمونو، منطقي ارزښتونه `رښتیا`/`درواغ`، او د لړیو
  دننه `«»` قوسونه او `، ` بېلوونکي چاپوي. **منفي عددونه** په هر لیکدود کې علامت-مخکې لیکل
  کېږي: `-۳` (IDE یې همداسې ښيي — د ښي-نه-کیڼ لوستلو استثنا).
* **پیغامونه:** د جوړونکي او اجرا ټولې تېروتنې په پښتو دي.
* **د لوستلو لوری:** پښتو پروګرام توکی په توکی له ښي نه کیڼ ته لوستل کېږي؛ په لاتیني
  تورو نومونه خپل لوری ساتي. (README، «Right-to-left programs».)
* **د کلمو ترتیب:** کلیدي کلمه `سره` (`with`) له هغه څه وروسته راځي چې ورسره ده، لکه پښتو چې
  وايي «ساکټ سره» (۱۱ برخه): له نوم وروسته، `نوم سره = سرچینه`، یا کله چې نوم نه وي له ارزښت
  وروسته، `سرچینه سره`.
* **ټولګي:** دننۍ ټولګي پښتو نومونه لري (`ریاضي.جذر`، `متن.پاک کړه`، ۱۰ برخه)؛ انګلیسي ټولګي
  نومونه هم منل کېږي، له پښتو غړو نومونو سره (`math.جذر`).

```thunder
# ژبه: ps
جوړښت ټکی
    س: عدد
    ص: عدد

دنده جمع(الف: عدد، ب: عدد): عدد
    راګرځه الف + ب

متغیر ټ = ټکی(ص: ۵، س: ۱۰)
که ټ.س > ۰ او نه ټ.ص == ۰
    کرښه چاپ(جمع(۲۰، ۲۲)، " "، ټ)      # ۴۲ ټکی(س: ۱۰، ص: ۵)
```

**د پروګرامونو ژباړل.** `thunderc --translate ps program.th` پروګرام له ټولو کلیدي کلمو،
دننیو دندو، دننیو ټولګو، رقمونو او کامو سره په پښتو چاپوي، او `with` / `سره` په هغه ژبه کې
خپل ځای ته وړي؛ `--translate en` یې بېرته اړوي، او د IDE
«ژباړه» تڼۍ همدا کار کوي. تبصرې او ستاسو خپل نومونه نه بدلېږي؛ هغه نوم چې په موخنه ژبه
کې خوندي وي `_` ورپسې اخلي.

## ۱۵. د پراختیا لپاره ډیزاین

* **نورې طبیعي ژبې.** لغوي تحلیل هېڅکله د کلیدي کلمې له متن سره نه پرتله کوي: کلمې، نښې،
  رقمونه او قوسونه له **ژبنۍ بستې** (`src/core/language_pack.cpp`؛ پښتو په
  `src/core/language_pashto.cpp`) لټول کېږي. بسته دا هم ټاکي چې ارزښتونه څنګه چاپ شي او
  د هر پیغام متن څه وي. په پیغامونو کې ستنې توري شمېري، نه بایټونه، نو د عربي-لیکدود
  متن ځایونه سم پاتې کېږي.
* **نوي ډولونه او عملګرونه.** ډولونه `Type` بیانوي (`include/thunder/types.hpp`)، عملګرونه
  د تړلو-ځواک جدول، او لارښوونې په `include/thunder/bytecode.hpp` کې یو جدول.
