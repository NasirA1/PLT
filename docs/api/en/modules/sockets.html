    sockets

    import "sockets"

    talking over the network: TCP and UDP sockets (docs/sockets.md)

    import "sockets" and every function below is yours (thunderc finds this file in lib/thunder next to itself, or name a directory with --module-path). They are written in C++ (lib/native/sockets/thunder_sockets.cpp) and built with the toolchain as the native library thunder_sockets, which sits next to thunderc and thundervm and is copied beside a packaged program automatically.

    A socket is an int handle, like a ticket number. A result of -1 means "it did not work" and socket_error() says why; passing a handle that is not open is a mistake in the program and stops it, as a wrong built-in call would.
