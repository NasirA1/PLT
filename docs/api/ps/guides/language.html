    د تندر SDK لارښود یوه برخه.

    دا سند د docs/language.md پښتو ژباړه ده. انګلیسي اصل پره‌مختللی (معتبر) متن دی؛ دا ژباړه د مسلکي اصطلاحاتو له پلوه د یوه ژبپوه کتنې ته اړتیا لري.

    تندر یوه کوچنۍ، په جامد ډول ډول‌ شوې (statically typed) ژبه ده چې د دې لپاره جوړه شوې چې زده کوونکي وګوري پروګرام‌ژبې له دننه څنګه کار کوي. هر پروګرام له همغه لارې تېرېږي چې په IDE کې یې لیدلای شئ:

    سرچینه متن --لغوي تحلیل--> توکي --نحوي تحلیل--> نحوي ونه --معنايي تحلیل--> ډول لرونکې ونه + نښې
        --کوډ جوړونه--> بایټ کوډ (.thc) --مجازي ماشین--> پایله

    د سرچینې فایلونه .th شاوند لري او UTF-8 متن دی. جوړ شوي بایټ کوډ فایلونه .thc لري. پروګرامونه په انګلیسي یا پښتو لیکل کېدای شي (۱۱ برخه).

    ۲. لغوي جوړښت#

    توکی بېلګې یادښت

    تشې، ټبونه او د یونیکوډ د لوري نښې توکي بېلوي خو بل اثر نه لري. د کرښې ماتېدل مهم دي: امر پای ته رسوي (۶ برخه).

    ۶. امرونه، د کرښې ماتېدل او ننوتنه#

    بلاکونه ننوتل کېږي. هغه کرښه چې له مخکینۍ ډېره ننوتې وي بلاک پرانیزي؛ بلاک هلته پای ته رسېږي چې ننوتنه بېرته راکمه شي (لغوي تحلیل دا بدلونونه د INDENT/DEDENT توکو په بڼه ورکوي، چې د «توکي» پاڼه کې یې لیدلای شئ). «تېر» هغه امر دی چې هېڅ نه کوي، د قصداً تش بلاک لپاره. له یوې کچې کمه ننوتنه چې هېڅ بلاک ورسره سمون نه خوري تېروتنه L008 ده؛ بې‌ځایه ننوتنه P013 ده. شرطونه قوسونو ته اړتیا نلري.

    ۱۲. ګرامر (EBNF)#

    ګرامر د انګلیسي سند ۱۲ برخه کې دی (docs/language.md)؛ د کلیدي کلمو پښتو بڼې پورته جدول ورکوي. لنډیز: امرونه د کرښې په پای، بلاکونه د INDENT/DEDENT ترمنځ، افادې د Pratt الګوریتم په لومړیتوبونو (۵ برخه)، او د تکرار سرلیک درې برخې په کامو بېلې دي.

    نحوي تحلیل څنګه کار کوي. امرونه په تکراري-کښته (recursive descent) تحلیل کېږي: د ګرامر هره قاعده په src/core/parser.cpp کې یوه دنده ده. افادې د Pratt د لومړیتوب-ځواک الګوریتم سره تحلیلېږي: هر عملګر «تړلو ځواک» لري او تحلیل تر هغه کیڼ عملوند غځوي چې راتلونکی عملګر ټینګ تړي. له قوسونو بهر د کرښې ماتېدل دا غځېدل دروي — له همدې امله امرونه بې جلا کوونکو پای ته رسېږي.
