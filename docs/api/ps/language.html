    ډولونه

    ډولونهتشریحبله لیکبڼهپه انګلیسي
    عدد۶۴-بیټه علامه لرونکي بشپړ عددونه؛ تلواله ۰—int
    اعشاري۶۴-بیټه IEEE 754 اعشاري؛ تلواله 0.0—float
    منطقيرښتیا یا ناسم؛ تلواله ناسم—bool
    متننه بدلېدونکی یونیکوډ متن؛ تلواله ""—string
    ډولونهتشریح
    ت[]د ت لړۍ، لکه عدد[]؛ حوالوي ډول، په لفظي بڼه یا د لړۍ(ن، ارزښت) سره جوړېږي.
    (ت۱، ت۲، …)ټاپلونه: د ورکړل شویو ډولونو ثابت شمېر ارزښتونه؛ نه بدلېدونکي.
    {ک: ا}نقشې: د ک ډول کیلۍ (عدد، بولین یا متن) د ا ډول ارزښتونو ته.
    د جوړښت نومد هغه جوړښت ارزښتونه؛ عمومي جوړښتونه د ډول دلیلونه اخلي (ډېرۍ<عدد>).
    دنده(ت۱، …): رد دندې ارزښتونه: هغې دندې ته حواله چې دا پارامترونه او دا د راګرځېدو ډول لري.
