    دننۍ دندې

    په دې پاڼه کې

    • بنسټیزې (تل شته)
    • د سیسټم ماډیول (راوړه "سیسټم")
    • د ګرافیک ماډیول (راوړه "ګرافیک")
    • دننۍ ګڼنې

    هره هغه دنده چې کمپایلر پرته له راوړه پېژني، او د دننیو ماډیولونو دندې. بڼه او تشریح د کمپایلر خپلې دي (thunderc --language-info)، نو له اوزارو سره توپیر نه شي موندلی؛ د کتابتون لارښود هره ډله په بېلګو تشریح کوي.
