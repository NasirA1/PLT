# د تندر د ګرافیک لارښود

*[د تندر SDK لارښود](README.md) یوه برخه.*

> دا سند د `docs/graphics.md` پښتو ژباړه ده. انګلیسي اصل معتبر دی؛ ژباړه د یوه ژبپوه
> کتنې ته اړتیا لري.

دننی ماډیول **`ګرافیک`** پروګرام ته انځور کښل، حرکت (انیمېشن) او د کیبورډ او موږک غبرګون
ورکوي — د سمولېشنونو او ساده لوبو لپاره بس دی. انځور په IDE کې د **ټاټ** پاڼه کې ښکاري؛
په قومانده کې SVG انځور ته ساتل کېدای شي.

```thunder
# ژبه: ps
راوړه ګرافیک

ګرافیک.ټاټ(۴۰۰، ۳۰۰)
ګرافیک.ټاټ پاک کړه(ګرافیک.رنګ(۰، ۰، ۱۲۸))
ګرافیک.دایره(۲۰۰، ۱۵۰، ۴۰، ګرافیک.رنګونه.نارنجي)
ګرافیک.لیکنه(۱۰، ۱۰، "سلام، ګرافیک!"، ګرافیک.رنګونه.سپین)
```

`راوړه ګرافیک` (په سر کې، بې قوسونو) ټولګی د کارونې وړ کوي. بیا هره دنده د ټولګي له نوم
سره لیکل کېږي، `ګرافیک.دایره(...)`، او رنګونه د `ګرافیک.رنګونه` غړي دي. بې مختاړي د ګرافیک
دنده تېروتنه `S067` ده («'دایره' د 'ګرافیک' ټولګي برخه ده: ګرافیک.دایره ولیکئ»)؛ بې راوړلو
یې کارول `S049` دی. دنني ټولګي په عمومي توګه (او د `ریاضي` او `تصادفي` ټولګي چې ګرافیکي
پروګرامونه یې ډېر کاروي) په [د کتابتون لارښود](library.md) کې بیان شوي دي.

نمونې `29_drawing` تر `36_snake` (انګلیسي او پښتو دواړه) له ولاړ انځوره تر لوبې پورې ځي:

| نمونه | ښيي |
| --- | --- |
| `29_drawing` | ټاټ، ځایونه، رنګونه، `ګرافیک.رنګ`، هر ډول شکل، لیکنه |
| `30_bouncing_ball` | د حرکت تکرار: پاکول، کښل، `ګرافیک.چوکاټ()`، خوځول |
| `31_waves` | `ریاضي.جیب`، `ریاضي.تتمیم جیب` او `ریاضي.ظل`، کښل شوي او حرکت ورکړل شوي؛ رادیان او `ریاضي.پای()` |
| `32_orbits` | دایروي حرکت: سیارې په `ریاضي.جیب`/`ریاضي.تتمیم جیب` مدارونو، او له دوو دایرو سپیروګراف |
| `33_pendulum` | `ریاضي.جذر`، `ریاضي.نمايي` او `ریاضي.جیب`: د ځنګنده فورمول د حرکت له دقیق قانون سره پرتله |
| `34_fireworks` | د ذرو سمولېشن: جوړښتونه، جاذبه، ثابت-ټکی عددونه، `تصادفي.عدد`، `چاڼ کړه`، د موږک کلیک |
| `35_life` | د کانوې د ژوند لوبه: ۲-بعدي جال، تڼۍ، موږک |
| `36_snake` | لوبه: د غشو تڼۍ، ټکر، نمره، بیا پیل |

له IDE بهر، ګرافیکي پروګرام کولای شي **خپله کړکۍ** ولري: `thundervm --display sdl program.thc`
یې د یوه ښودونکي پلگ-ان له لارې کاږي. پلگ-انونه شریک کتابتونونه دي چې یو کوچنی C اړیکی لري،
نو د هرې بلې ګرافیکي کتابتون لپاره بل لیکل کېدای شي — [د ښودونکي لارښود](display.md) او
`lib/display/` وګورئ.

## ۱. ټاټ

* **ځایونه** د پکسلونو بشپړ عددونه دي. `(۰، ۰)` **پورته کیڼ** کونج دی؛ س ښي خوا ته
  لویېږي او **ص کښته لویېږي** (لکه پر هره پرده؛ د ریاضي برعکس).
* `ګرافیک.ټاټ(پلنوالی: عدد، لوړوالی: عدد)` اندازه ټاکي (۱ تر ۲۰۰۰ پکسله) او ټاټ سپینوي. بې
  هغه ۴۰۰ × ۳۰۰ ده.
* **شکلونه په ترتیب کښل کېږي**: وروستي مخکیني پټوي. له ټاټه بهر برخې نه ښکاري.
* **ټاټ هر څه ساتي** چې له وروستي `ګرافیک.ټاټ پاک کړه(...)` راهیسې کښل شوي، لکه رنګ پر کاغذ.
  حرکت نو هر چوکاټ په `ګرافیک.ټاټ پاک کړه(...)` پیلوي. د دوو پاکولو ترمنځ تر ۱۰۰٬۰۰۰ شکلونه
  منل کېږي (`R024`) — هغه پروګرامونه نیسي چې پاکول هېر کړي.

### رنګونه

رنګ د **`ګرافیک.رنګونه` ګڼنې** غړی یا یو متن دی:

* د **`ګرافیک.رنګونه` ګڼنې غړی** (ګڼنه د ټولګي ده، نو `راوړه ګرافیک` یې راوړي):
  `ګرافیک.رنګونه.سور`، `.زرغون`، `.شین`، `.سپین`، `.تور`، `.ژېړ`، `.نارنجي`، `.ګلابي`، `.خړ`،
  `.نسواري`، `.بنفش`، `.اسماني`، `.طلايي`. کمپایلر نوم ګوري، نو ناسم نوم د کمپایل تېروتنه ده
  (`S062`) نه د اجرا؛ `ګرافیک.رنګونه.ارزښتونه` ټول لیکي (د ژبې لارښود، ۸ برخه، «ګڼنې»). بې
  مختاړي `رنګونه` اعلان شوی نه دی (`S001`)؛
* یو **نوم**: انګلیسي (`black`، `red`، `sky`، ...) یا پښتو: `تور`، `سپین`، `سور`، `زرغون`،
  `شین`، `ژېړ`، `نارنجي`، `ګلابي`، `خړ`، `نسواري`، `بنفش`، `اسماني`، `طلايي`؛
* یو **کوډ** `"#rrggbb"` یا `"#rgb"`: `"#ff8800"`؛
* د **`ګرافیک.رنګ(سور: عدد، زرغون: عدد، شین: عدد): متن`** پایله، هر یو ۰ تر ۲۵۵:
  `ګرافیک.رنګ(۲۵۵، ۱۳۶، ۰)` = `"#ff8800"` — د محاسبه شویو رنګونو لپاره، لکه
  `ګرافیک.رنګ(۴۰ + پټه * ۶، ۱۱۰، ۲۳۰)`.

بل هر څه د اجرا تېروتنه `R021` ده.

## ۲. کښل

هر ارزښت او اندازه **اعشاري** (`اعشاري`) دي، نو شکل هلته کېني چې حساب یې ټاکي —
`ګرافیک.دایره(مس + ریاضي.تتمیم جیب(ز) * و، مص + ریاضي.جیب(ز) * و، ۲٫۵، "سپین")` بشپړولو ته
اړتیا نه لري. بشپړ عددونه پخپله پراخېږي، نو `ګرافیک.دایره(۵۰، ۵۰، ۱۰، "سور")` لا هم سم دی، او
بشپړ ارزښت بېرته د بشپړ عدد په بڼه لیکل کېږي. هر `رنګ_یې` پارامټر د `ګرافیک.رنګونه` غړی هم
مني، او متن هم.

| دنده | کاږي |
| --- | --- |
| `ګرافیک.ټاټ پاک کړه(رنګ_یې)` | ټول ټاټ ډکوي، پخواني شکلونه لیرې کوي |
| `ګرافیک.ټکی(س، ص، رنګ_یې)` | یو پکسل |
| `ګرافیک.لیکه(س۱، ص۱، س۲، ص۲، رنګ_یې)` | لیکه له (س۱، ص۱) تر (س۲، ص۲) |
| `ګرافیک.مستطیل(س، ص، پلنوالی، لوړوالی، رنګ_یې)` | ډک مستطیل؛ (س، ص) پورته کیڼ کونج |
| `ګرافیک.د مستطیل څنډه(س، ص، پلنوالی، لوړوالی، رنګ_یې)` | د مستطیل څنډه |
| `ګرافیک.دایره(س، ص، وړانګه، رنګ_یې)` | ډکه دایره؛ (س، ص) مرکز |
| `ګرافیک.د دایرې څنډه(س، ص، وړانګه، رنګ_یې)` | د دایرې څنډه |
| `ګرافیک.لیکنه(س، ص، پیغام، رنګ_یې)` | متن؛ (س، ص) پورته کیڼ کونج، د هرې لیکدود لپاره |

| ترتیب | اثر پر راتلونکو شکلونو |
| --- | --- |
| `ګرافیک.د لیکې پلنوالی(پلنوالی: اعشاري)` | د لیکو/څنډو پلنوالی (۰٫۱ تر ۱۰۰، اصلي ۱) |
| `ګرافیک.د لیکنې اندازه(اندازه: اعشاري)` | د متن لوړوالی (۱ تر ۴۰۰، اصلي ۱۶) |

منفي پلنوالی/لوړوالی مستطیل کیڼ/پورته خوا ته کاږي. له حده بهر ترتیبونه `R022` دي.

## ۳. حرکت (انیمېشن)

حرکت یو تکرار دی چې په یو وخت کې یو انځور — یو **چوکاټ** — کاږي:

```thunder
راوړه ګرافیک

متغیر س = ۰
ترڅو رښتیا
    ګرافیک.ټاټ پاک کړه(ګرافیک.رنګونه.تور)        # ۱. له تش ټاټه پیل
    ګرافیک.دایره(س، ۱۵۰، ۲۰، "نارنجي")           # ۲. هر څه چېرته چې اوس دي وکاږه
    ګرافیک.چوکاټ()                                # ۳. چوکاټ وښيه او انتظار وکړه
    س = (س + ۴) % ۴۰۰                             # ۴. لږ وخوځوه
```

| دنده | اثر |
| --- | --- |
| `ګرافیک.چوکاټ()` | انځور ښيي، بیا **انتظار کوي** تر راتلونکي چوکاټه — حرکت پر هر کمپیوټر یو شان چټک دی |
| `ګرافیک.د چوکاټ چټکتیا(شمېر: عدد)` | په ثانیه کې څو چوکاټه `ګرافیک.چوکاټ()` ښيي (۱ تر ۱۲۰، اصلي ۳۰) |
| `ګرافیک.ښکاره کړه()` | انځور **همدا اوس** ښيي، بې انتظاره |

* نه ښودل شوی انځور د پروګرام په پای (تر تېروتنې وروسته هم) ښودل کېږي.
* ورو چوکاټ حرکت ورو کوي؛ نه هڅه کوي چې ورسېږي.
* نه ختمېدونکی تکرار په IDE کې «درول» دروي. د لارښوونو حد د **دوو چوکاټونو ترمنځ**
  لګېږي، نو حرکت تر هر وخته چلېدای شي.
* د نرم حرکت لپاره ځایونه اعشاري وساتئ: `س = س + ۰٫۳۵` په هر چوکاټ کې د پکسل دریمه
  برخه ځي. (`34_fireworks` له اعشاري شمېرو مخکې لیکل شوی و او ځایونه د پکسل په لسمو
  برخو ساتي — هغه لار لا هم ګټوره ده کله چې پروګرام باید سم پاتې شي.)

## ۴. کیبورډ او موږک

| دنده | پایله |
| --- | --- |
| `ګرافیک.کښېکښل شوې تڼۍ(): متن` | **راتلونکې نه-اخیستل شوې کښېکښنه**، یا `""` |
| `ګرافیک.تڼۍ کښېکښل شوې ده(تڼۍ: متن): منطقي` | رښتیا ترڅو تڼۍ نیول شوې وي |
| `ګرافیک.موږک افقي(): عدد` / `ګرافیک.موږک عمودي(): عدد` | د موږک ځای، د ټاټ په پکسلونو |
| `ګرافیک.موږک کښېکښل شوی(): منطقي` | رښتیا ترڅو تڼۍ پر ټاټ نیول شوې وي |

**د تڼیو نومونه** په پښتو پروګرامونو کې: «کیڼ»، «ښي»، «پورته»، «کښته»، «تشه»، «ننوتل»،
«وتل»، «شاته»، «ټب» — او لیکل شوی توری یا رقم (`"a"`، `"۷"`؛ پښتو کیبورډ پښتو توري ورکوي).
`ګرافیک.تڼۍ کښېکښل شوې ده` دواړه (پښتو او انګلیسي) نومونه مني.

* `ګرافیک.کښېکښل شوې تڼۍ()` **کتار** دی: هره کښېکښنه ساتل کېږي (تر ۶۴) ترڅو پروګرام یې واخلي،
  نو دوه چټکې کښېکښنې نه ورکېږي. لوبه معمولاً په هر چوکاټ کې یوه اخلي (`36_snake`).
* `ګرافیک.تڼۍ کښېکښل شوې ده` دوامداره خوځېدو ته ښه ده: `که ګرافیک.تڼۍ کښېکښل شوې ده("کیڼ")`
  بیا `س = س - ۳` په هر چوکاټ کې.
* یو-ځلي کلیک له مخکیني چوکاټ سره پرتله کړئ (`34_fireworks`).
* په IDE کې **پر ټاټ کلیک وکړئ** چې کیبورډ واخلي؛ لومړی چوکاټ یې پخپله ورکوي.
* په قومانده کې (بې IDE) تڼۍ او موږک نشته: `""` او `درواغ` راځي.

## ۵. تصادفي عددونه

سمولېشنونه او لوبې تصادفي عددونو ته اړتیا لري. هغوی د **`تصادفي` ټولګي** کې دي، چې هر
پروګرام یې لري، له `راوړه ګرافیک` سره یا بې هغه ([د کتابتون لارښود](library.md)، ۶ برخه):

| دنده | پایله |
| --- | --- |
| `تصادفي.عدد(کم: عدد، ډېر: عدد): عدد` | تصادفي بشپړ عدد له کم تر ډېر، **دواړه پکې** (`کم > ډېر`: `R023`) |
| `تصادفي.اعشاري(): اعشاري` | له ۰ (شامل) تر ۱ (نه شامل) تصادفي اعشاري شمېره |
| `تصادفي.بنسټ(بنسټ: عدد)` | لړۍ بیا پیلوي: له یو بنسټ وروسته همغه عددونه راځي |

بې بنسټه هر چل بل دی. `thundervm --seed ن` (او طلايي ازموینې) له ټاکلي بنسټه پیلوي؛ تندر
خپل جوړوونکی (SplitMix64) کاروي، نو یو بنسټ پر هر سیسټم همغه عددونه ورکوي.

## ۶. په IDE کې

* د **ټاټ** پاڼه د «د پردې شاته» تر څنګ یوه ټوټه (tab) ده او د لومړي چوکاټ سره مخې ته
  راځي. لکه نورې پاڼې خوځول، بېلول (د لوبو لپاره ګټور) او تړل کېدای شي.
* انځور د پاڼې له اندازې سره برابرېږي (تناسب ساتل کېږي)؛ د موږک ځایونه بېرته د ټاټ
  پکسلونو ته اړول کېږي.
* د انځور پورته کرښه د چوکاټ شمېره او اندازه ښيي.
* `کرښه چاپ` لا هم د پایلې پاڼې ته ځي. د جوړولو یادښت وايي څو چوکاټونه ښودل شوي.
* وروستی انځور تر بل جوړولو/چلولو پاتې کېږي.

## ۷. په قومانده کې

```
thundervm picture.thc                        # چلوي؛ بې پردې هېڅ نه ښيي
thundervm --svg picture.svg picture.thc      # وروستی انځور SVG ته ساتي
thundervm --max-frames 100 --svg f.svg anim.thc   # نه ختمېدونکی حرکت تر ۱۰۰ چوکاټه
thundervm --seed 7 game.thc                  # په هر چل همغه تصادفي عددونه
thundervm --canvas game.thc                  # د ښودلو پروتوکول، لکه IDE چې کاروي
```

بې `--canvas` `ګرافیک.چوکاټ()` انتظار نه کوي (څوک یې نه ګوري)، نو بې-پردې چل ژر پای ته رسېږي.
SVG فایلونه هر براوزر پرانیزي.

## ۸. د پردې شاته

ټاټ د شکلونو لړۍ ده (`include/thunder/graphics.hpp`)؛ `ګرافیک.چوکاټ()`/`ګرافیک.ښکاره کړه()` یې یوه
**ګرافیک کوربه** ته وړاندې کوي. `thundervm --canvas` هر چوکاټ د معیاري پایلې پر یوه کرښه
د ریکارډ-بېلوونکي (ASCII 30) + JSON په بڼه لیکي، او تڼۍ/موږک د معیاري ننوت پر کرښو بېرته
راځي — د پروتوکول تفصیل د انګلیسي سند ۸ برخه کې دی. انځور د پکسلونو پر ځای د شکلونو په

## ۱۰. نومونه

ټولګی `ګرافیک` دی او `import graphics` = `راوړه ګرافیک` (انګلیسي `graphics` هم منل کېږي، د
مختاړي په توګه هم: `graphics.دایره`). ټول نومونه د پښتو ژبنۍ بستې کې دي
(`src/core/language_pashto.cpp`) او د ژبپوه کتنې ته اړتیا لري.

`تصادفي عدد(۱، ۶)`)؛ اوس `ګرافیک.دایره(...)`، `ګرافیک.رنګونه.سور` او `تصادفي.عدد(۱، ۶)` دي.
ژباړونکی زاړه پروګرامونه نه اړوي. د `دایره` په څېر دندې لپاره د کمپایلر `S067` پیغام وايي چې

(`P001`) ورکوي. بشپړ لېست د [د کتابتون لارښود](library.md) ۱۰ برخه کې دی.
