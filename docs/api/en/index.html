    Overview

    Overview

    Thunder is a small, statically typed language for learning how programming languages work, with a compiler, a bytecode virtual machine, an IDE and a VS Code extension. Programs can be written in English or Pashto; this documentation exists in both, and every page links to its counterpart.

    Language

    Keywords, types, literals and word operators, with every accepted spelling and the name in the other language.

    Built-in functions

    Input and output, text, arrays, maps, maths, higher-order functions, and the os and graphics modules.
